## 5.5 着手前チェック（摂動を 1 回も回さずに「測れる設計か」を判定する。**事前登録の一部**）

摂動を伴う実験では、**摂動の本番に着手する前に**次を実行し、出力 JSON を事前登録のハッシュに含める。

```
.venv/bin/python scripts/analysis/axis_feasibility.py --config experiments/EXP-YYYYMMDD-NNN/config.yaml
```

設定は `config.yaml` の `axis_feasibility:` 節に書く。判定は 3 値。

| 判定 | 意味 | すること |
|---|---|---|
| **合格** | 弱点は検出されなかった | 着手してよい |
| **判定保留** | 測れる可能性はあるが弱点が特定されている | **弱点と、それが結論に与える影響を下表に書き、PI の判断を仰いでから**着手する |
| **不合格** | この設計では目標の軸が測れない | **着手しない。** 計画を作り直して再度このチェックを通す |

| 指標 | 値 | 目安 | 判定 |
|---|---|---|---|
| **陽性対照の遺伝子数 K（最も強い条件）** | | **不合格 < 20** | |
| 陽性対照の検出率の中央値 | | 不合格 < 0.06 / 判定保留 < 0.12 | |
| 陽性対照のまとまり（遺伝子どうしの相関の中央値） | | 判定保留 < 0.030 | |
| 1 個のマーカーの得点寄与の最大 | | 判定保留 ≥ 25% | |
| 陽性対照の検出率のばらつき（最大 / 最小） | | 判定保留 ≥ 5 倍 | |
| （記録）目標を定義するマーカーのまとまり・検出率 | | 判定保留 < 0.030 / < 0.12 | |
| 軸の長さの比（出発点→目標 ÷ 出発点→参照状態、3 回の最小） | | 不合格 < 0.35 / 判定保留 < 0.60 | |

**並びには意味がある。** 過去 4 実験を分けたのは K であり、軸の長さの比は
うまくいった実験（0.452）と失敗した実験（0.442）をまったく分けなかった。
**K が 20 に届かないなら、他の指標がどれだけ良くても着手しない。**
K < 20 で止まったときは、**条件を満たす候補が何個あるか**を併せて数え、
陽性対照を組み直せるかどうかを判断材料にする。

## 6. 評価指標と判定基準（事前登録）

### 6.1 主指標の形（**2026-10-01 に PI が決定。結果を見る前に固定する**）

**主指標 = 変位ベクトルを「出発点の重心 → 目標の重心」の向きへ射影し、移動量で割ったもの**
（＝変位が目標の向きとどれだけ同じ向きか。角度の余弦）。

**2 つの重心への寄りの差を使わない。** 差の形にすると次の 2 つが避けられない。

| 問題 | 中身 |
|---|---|
| **差し引く相手で符号が変わる** | 摂動の一様な引き寄せの強さは状態ごとに違う（実測: 目標 +0.09〜0.12 / 出発点 +0.18〜0.22 / 退化した髄質線維芽細胞 +0.52）。差し引きを 3 状態の平均から出発点 1 本に変えただけで、残差と移動量の相関が +0.009〜+0.049 → **−0.122〜−0.148** と符号反転した |
| **中立性の指標と算術的に相関する** | 主指標（差）と一様成分（和）は同じ 2 量から作られる。2 量の相関 0.937〜0.944・分散比 1.23〜1.25 から理論値 **0.28〜0.30** が出て、実測と小数第 4 位まで一致した。**交絡ではないので補正では消えない** |

EXP-20260930-001 のデータでの実測（主指標を射影に替え、移動量の補正を外した場合）:

| 診断 | 差の形＋移動量の補正 | **射影（`lp`・`ll` の補正は残す）** | 参考: 射影・補正を一切しない | 閾値 |
|---|---|---|---|---|
| M4（一様成分との相関） | 0.401 / 0.368 / 0.366 **不合格** | **+0.048 / −0.001 / +0.012 合格** | +0.057 / +0.015 / +0.024 | 0.40 |
| M5（移動量との相関） | −0.122 / −0.148 / −0.128 **不合格** | **−0.055 / −0.096 / −0.078 合格** | +0.010 / −0.048 / −0.013 | 0.10 |
| 目標の軸の陽性対照 | 1.002 / 1.093 / 1.067 合格 | **0.912 / 1.018 / 1.003 合格** | 0.930 / 1.030 / 1.017 | 維持 |

※ M4 の値は**一様成分を主指標に使っていない状態から作った場合**（§6.1 の最後の箇条書き）。
同じ 2 量の差と和で作ると 0.32 前後になる。

**「補正を一切しない」版を採ってはいけない。** M5 の余裕は大きくなるが（0.052 対 0.004）、
**元の順位・入力の長さとの交絡がそのまま残り、指標の健全性 M2（残差とこれらの順位相関、
閾値 0.25）が落ちる**。交絡の除去はこの設計の土台であり、外す理由にならない。
**`lp`・`ll` の補正は残し、`ld`（移動量）だけを入れない**（§6.1.1）。

**M5 の余裕が薄いことは、計画の §9 に危険として明記する。**
実測の余裕は閾値 0.10 に対して最小 0.004（seed82、−0.096）しかない。

- **一様成分は、主指標の差し引きに使っていない状態から作る**（同じ 2 量の差と和にしない）
- **差し引く／射影に使う状態の組は、結果を見る前に固定する。** 感度分析は入れ子で並べる

### 6.1.1 移動量の補正（**既定では入れない**）

交絡を除く回帰の説明変数は **元の順位 `lp` と入力の長さ `ll` の完全二次式**。
**移動量の対数 `ld` は既定では入れない**（2026-10-01、PI 決定）。

`ld` は EXP-20260929-001 の設計（差の形・3 状態の平均を差し引く）では恒常発現遺伝子を
中立域へ戻す効果があった（1.071 → 0.335）。しかし **EXP-20260930-001 の設計では、
補正なしでも恒常発現遺伝子は範囲内**であり（ACTB 0.834/0.840/0.863、GAPDH 0.753/0.740/0.792）、
`ld` を入れると **M4 が 0.31 → 0.40、M5 が −0.07 → −0.12 と悪化した**。

→ **設計が変われば、改良が今も必要かを毎回測り直す。** 入れるなら理由と実測を §6.1 に書く。
実装は `scripts/analysis/movement_correction.py`（`use_dnorm` で切り替える）。

### 6.1.2 恒常発現の対照の採用規則（**結果を見る前に数値で決める。2026-10-01 PI 決定**）

恒常発現遺伝子は「どの細胞でも一定だから目標へ寄る理由がない」という前提で中立の対照に使う。
**単一核 RNA-seq ではこの前提が成り立たないことがある**（実測: B2M の検出率は出発点 0.469・目標 0.425、
GAPDH は 0.197 / 0.133）。実際 B2M は対照 500 個の下位 0.7〜1.7% に外れ、
どの補正でも動かなかった（指標の欠陥では説明できない）。

**結果を見てから外すのは事後の選び直しである。** 次の規則をここに数値で書き、
**現行の遺伝子にも新しい候補にも機械的に当てはめる。**

| # | 条件 | 閾値 |
|---|---|---|
| H-1 | 出発点・目標の**両方**での検出率 | ≥ |
| H-2 | 2 群間の発現の偏り（検出率の対数比）の絶対値 | ≤ |
| H-3 | 提供者間の変動係数 | ≤ |

- 通った遺伝子だけを判定に使う。**落ちた遺伝子は記述にとどめる**
- 単一核では恒常発現遺伝子がもともと弱いので、**データで発現差が無いことを確かめて選んだ中立対照パネルを主にし、
  恒常発現遺伝子は記述にとどめる**設計も選べる。どちらにするかをここに書く

### 6.1.3 交絡除去の実装

対照遺伝子で当てた回帰からの残差を主指標にする。説明変数は完全二次式で、次の 3 つ。

| 記号 | 中身 | 何を打ち消すか |
|---|---|---|
| `lp` | log2(1 + 摂動した遺伝子の元の順位) | 上げしろの大きさ |
| `ll` | log2(入力の長さ) | 細胞あたりの遺伝子の数 |
| **`ld`** | **log2(移動量 ‖Δ‖)** | **摂動でどれだけ動いたかの大小** |

**`ld` を入れる理由**: 恒常発現遺伝子（細胞の種類によらず常に働いていて、目標の状態へ寄る理由がない遺伝子）
が中立にならない問題が 4 実験続いた。原因はこれらの**移動量が飛び抜けて大きい**ことだった
（ACTB・GAPDH・PPIA は対照の 97.8〜99.8 パーセンタイル）。EXP-20260929-001 の実測:

| 見るもの | 従来（`lp`・`ll`） | **`ld` を入れる** |
|---|---|---|
| 恒常発現遺伝子 3 個のセット平均（中立であるべき） | +1.071 | **+0.335** |
| 中立の範囲に入る seed 数（必要 2） | **0 / 3 = 不合格** | **2 / 3 = 合格** |
| 残差と移動量の順位相関（小さいほど良い） | 0.127〜0.171 | **0.009〜0.049** |

実装は `scripts/analysis/movement_correction.py`。設定は `config.yaml` の `metric.confound_correction`。

- **摂動が起きなかった細胞（‖Δ‖ = 0）は外す。** 元の順位がすでに最上位の遺伝子を
  過剰発現させても入力が変わらないため起きる。**比べる版すべてで同じ細胞を外す。**
- **どの版を主判定に使うかは、結果を見る前にここで固定する。** 後から選び直さない。
- **この補正は「中立であるべきものが中立に戻る」ためのもので、目標の軸の陽性対照が
  立たない問題は解決しない**（EXP-20260929-001 では 0.684 → 0.826 と近づいたが、必要な 0.861〜0.896 には届かない）。
  そちらは §5.5 の陽性対照 K ≥ 20 で対処する。

### 6.3 偽のセットによる確認（合格条件は偶然合格率と整合させる）

「経路だから動いた」のか「そろえた性質のせいで動いた」のかを分けるため、
対照遺伝子から性質をそろえた**偽のセット**を作って同じ規則に当てる。

**「N 組すべて不合格」を条件にしてはいけない。** 単一遺伝子の偶然合格率 p が分かっているなら、
偽のセットも p の割合で偶然合格する。EXP-20260929-001 では期待合格数 1.12 組に対して
「200 組中 0 組」を要求しており、**問題のない設計でも 67% の確率で落ちる**条件になっていた。

- 対照で**実測した偶然合格率 p** を先に出す
- 偽のセット N 組のうち合格した数 k について、**二項検定（k ~ Binomial(N, p)）で「p より多く合格していないか」**を見る
- 合格条件: 片側 p 値 ≥ 0.05（＝偶然の範囲）。**N・p・期待合格数・実際の k をすべて報告する**

| 項目 | 値 |
|---|---|
| 偽のセットの組数 N | |
| 単一遺伝子の偶然合格率 p（対照で実測） | |
| 期待合格数 N·p | |
| 実際の合格数 k | |
| 片側 p 値 | |

### 6.4 途中で主判定を計算しない

**チェックポイントでは、主判定のセットの値を計算も保存もしない。**
途中経過を見てから基準を変える余地を作らないため（`plan.md` を固定した意味がなくなる）。
チェックポイントで見てよいのは、**装置が働いているかの確認（陽性対照・中立性・指標の健全性）だけ**。

## 7.5 中断条件（**止める**ものと**記録して続ける**ものを分けて書く）

実行担当が自分で判断しなくて済むように、**着手前に両方を列挙する**。
過去に、実行担当が中断条件に当たったのに自分で判断して続行した事例がある。

| # | 条件 | 種別 | すること |
|---|---|---|---|
| A-1 | | **止める** | 直ちに停止し、Labretary へ報告して指示を待つ |
| A-2 | | 記録して続ける | `logs/progress.md` に書いて続行 |

- **「止める」条件に当たったら、必ず止めて報告する。** 実行担当が続行を自分で決めてはいけない
- **「記録して続ける」条件は、続けてよい理由をここに書いておく**（小さい K や 1 seed のばらつきの範囲内、など）
