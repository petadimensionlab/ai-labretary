# HYP-20260925-04: ccRCC の腫瘍内 CD8 T 細胞では、老化関連 T 細胞（SA-T）軸である CD153/CD30（TNFSF8/TNFRSF8）と p16 が、TLS を誘導する CXCL13⁺ 組織常在型の状態への移行を駆動する

- Status: proposed
- 起点: `outputs/literature/2026-09-25-tls-feasibility/feasibility.md` §0-6・§3.3（A3 では CXCL13 カウントの 72.5% が CD8⁺T_RM-CXCL13 由来。この状態は CDKN2A⁺ 20.8%、TNFSF8⁺ 17.7% と、他の CD8 状態（TNFSF8⁺ 3〜13%）より高い）、カタログ §2「老化関連 T 細胞（SA-T）」（Sato 2022 PMID 34813503: CD153/CD30 の阻害で腎 TLT が縮小する）、TLS コア（Sautès-Fridman 2019 PMID 31092904）
- 新規性: 新規予測（腎 TLT で見つかった CD153/CD30 の SA-T 軸が、ccRCC の CXCL13⁺ CD8 状態にも当てはまるという種・文脈を越えた予測）。CXCL13 自体の摂動は goal ラベルの健全性チェック

## 仮説
ccRCC の腫瘍内 CD8 T 細胞（A3 Li 2022）において、**TNFSF8 (CD153), TNFRSF8 (CD30), CDKN2A (p16)** を activate すると、細胞状態が **CD8_Tex_CXCL13neg（start）** から **CD8_RM_CXCL13（goal）** へ近づく。

- データ: A3 `A3_RCC_LiR2022.h5ad`（CD8 T のみを抽出したコピーを experiments 側に作る）
- state_key: `cd8_state`（細胞状態は著者の `annotation`。**CXCL13 陰性の判定と「腫瘍内」は推定ラベル**）
  - goal = `CD8_RM_CXCL13`: annotation = CD8+T_RM-CXCL13、summaryDescription = Tumour → **2,059 細胞 / 11 donor**（CXCL13⁺ 99.3%）
  - start = `CD8_Tex_CXCL13neg`: annotation ∈ {CD8+T_EX-CCL4L2, CD8+T_preEX-CXCR4, CD8+T_EX-IL10}、Tumour、CXCL13 が 0 カウント → **約 17,000 細胞 / 11 donor**（ここから seed ごとに抽出。1 donor あたり上限 15 細胞）
  - alt = `CD8_EM`: CD8+T_EM（Tumour 15,968）→ 分化の一般的な方向と区別するための参照
  - 再現用データ: A4 Krishna 2021 の CD8A⁺ Exhausted 17,893 細胞（CXCL13⁺ 50.5%）。**A4 は donor が 6 名しかない**ので、あくまで再現の確認に使う
- 摂動: `perturb_type: activate`、emb_mode `cls`
  - 対象（新規予測）: TNFSF8 (ENSG00000106952), TNFRSF8 (ENSG00000120949), CDKN2A (ENSG00000147889)
  - 対象（比較）: PDCD1 (ENSG00000188389), CDKN1A (ENSG00000124762)
- 事前チェック: start と goal の CLS 埋め込みで 5-fold AUC を出す。CXCL13 は goal を定義する遺伝子なので、CXCL13 を除いた特徴で状態が分かれるか（AUC > 0.75）を確認してから ISP に進む
- 限界: **A3 に TLS の組織学的ラベルはない。**「CXCL13⁺ CD8 が TLS を誘導する」という部分はこのデータでは検証できず、文献に依存する。さらに本解析では、腫瘍サンプル単位の CXCL13⁺CD8 比率と B＋形質細胞比率の相関は有意でなかった（ρ = 0.31、n = 11、p = 0.36）ので、**この前提自体が弱い**。腫瘍内の PDCD1 は疲弊マーカーでもあり、老化 T 細胞（SA-T）と同一視できない。CDKN2A は start での検出率が 5〜20% と低く、activate による効果は発現量の低い細胞で不安定になりうる

## 予測（定量）
- TNFSF8, TNFRSF8 のいずれかで、CD8_RM_CXCL13 重心への goal_state_shift が発現量マッチのランダム 20 遺伝子の null の上位 5% に入る（対象 5 遺伝子で BH-FDR < 0.05）。3 seed のうち 2 つ以上で成立すること
- CDKN2A の activate は null の上位 10% に入る
- 特異性: 同じ遺伝子の alt（CD8_EM）重心へのシフトは goal 方向のシフトより小さい（比 ≥ 1.2）
- 再現: A4 で同じ摂動をしたときのシフトの向きが A3 と一致する（効果量は問わない）

## 反証条件
- TNFSF8, TNFRSF8 がどちらも 3 seed すべてで null の 80 パーセンタイル以下、または向きが逆 → 主要予測は棄却
- CXCL13 の activate（健全性チェック）で goal へ動かない → **inconclusive**（状態定義・パイプラインの問題）
- goal 方向と alt 方向のシフトが同程度 → 「CXCL13⁺ 常在型への特異的な移行」の部分は棄却（疲弊・分化一般の効果）

## コントロール
- ポジティブ: CXCL13（goal を定義する TLS コア遺伝子、Sautès-Fridman 2019 PMID 31092904 / 腎 TLT は Sato 2016 PMID 27699223）。健全性チェックとして扱い、新規性の主張には使わない。PDCD1（疲弊 CD8 の確立したマーカーであり、SA-T セットにも含まれる。Sato 2022 PMID 34813503）
- ネガティブ: 発現頻度マッチのランダム 20 遺伝子（start で 500 細胞以上に発現しているものから seed ごとに抽出）、ハウスキーピング ACTB, GAPDH, PPIA
- 状態のコントロール: alt（CD8_EM）重心へのシフト

## 実験コスト概算
- 100 細胞/遺伝子 × 30 遺伝子（対象 5 + 陽性 2 + ランダム 20 + HK 3）× 3 seed = 9,000 細胞・遺伝子。CD8 T の中央値遺伝子数 ≈ 1,320
- 下限: 2 × 1,320 ÷ 7,200 ≈ 0.37 s/回 → 0.92 h。上限（0.8 s/回）→ 2.0 h。状態重心（3 状態 × 500 細胞）0.1 h
- **合計 ≈ 1.0〜2.1 h（MPS）、細胞数 1 万未満。2 h を超える見込みなら G2 承認をとる**
- A4 での再現（同じ設計）はさらに +1.0〜2.0 h → 2 本を続けて回すなら **G2 必須**

## 支持された場合の次の一手（wet 実験）
- ccRCC 手術検体の TIL を分離し、CD153（CD30L）架橋または抗 CD30 アゴニストで刺激して、CXCL13 の産生（細胞内染色・ELISA）と組織常在マーカー（CD69, ITGAE）の誘導を測る
- ccRCC 切片の多重免疫染色で、CD153⁺/CD30⁺ CD8 T と p16⁺ 細胞が TLS（CD20⁺ 濾胞）の近傍に位置するかを定量する
- TIL 上清を使った B 細胞遊走アッセイを、抗 CXCL13 中和の有無で比較する
- 高齢マウスの腎癌／IRI 後 TLT モデルで抗 CD153 抗体を投与し（Sato 2022 PMID 34813503 の方法）、TLS の数・面積と CXCL13⁺ CD8 の割合を測る
