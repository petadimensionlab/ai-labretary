# HYP-20260926-04（方法仮説）: 文献で因果が確立した PT 障害ドライバー／保護因子を陽性対照に採ると、FT-Geneformer の ISP（a2）はそれらを null から分離し、その分離は「分類器マーカーの除去／付加」だけでは説明できない

- Status: inconclusive（G3: PI, 2026-09-27。削除型は有効な否定的結果、過剰発現型は摂動サイズの交絡により判定不能）
- 起点: PI 指示（2026-09-26）「(b) 陽性対照の見直し」。FT モデル前提・リモート PC を積極利用
- 背景: [EXP-20260926-003](../experiments/EXP-20260926-003/plan.md) phase 3 で、FT（aPT_CKD vs PT_healthy 2 クラス）CellClassifier の CLS 埋め込みは**削除ドリフトをほぼ解消**した（null 遺伝子の補正前 shift_goal が負の割合 1.00 → 0.10〜0.15）。HK（ACTB/GAPDH/PPIA）と陰性対照パネル 7 遺伝子はすべて null の内側、C2 は 16/18。しかし **C1 が不合格**: VCAM1 は null 分位 0.98 で一貫して上位だが、HAVCR1 は 0.45/0.75/0.75 で null に埋もれた。VCAM1 は start（aPT TLS-high）で 62.1%、goal（held-out 健常）で 7.6% の細胞に検出される極端なマーカー（|Δ検出率| は背景 9,615 遺伝子中 99 パーセンタイル）で、「分類器が直接使うマーカーを消した」だけの可能性がある
- 問題の切り分け: 旧陽性対照 VCAM1/HAVCR1 は「aPT のマーカー」であって「aPT 状態を**駆動**する因子」ではない。ISP が読むべきなのは駆動因子の効果である。そこで陽性対照を「PT 細胞で遺伝学的操作の因果効果が報告されている遺伝子」に置き換える
- 新規性: 方法の検証（生物学的な新規予測ではない）。実験計画: [EXP-20260926-005](../experiments/EXP-20260926-005/plan.md)

## 仮説
EXP-20260926-003 と同じ FT モデル・同じ start 細胞（held-out TLS-high aPT, 200 細胞/遺伝子, seed 3/4/5）・同じ goal 重心（held-out 健常 9 donor）で、

- **P1（delete 型）**: マウス／ヒトで「PT（尿細管）特異的な欠損が障害・線維化を軽減する」ことが示されている 5 遺伝子（HIF1A, NOTCH1, EGFR, YAP1, KEAP1）を delete すると、主指標 a2 で **5 遺伝子中 2 以上**が同 seed の発現頻度マッチ null の上位 10%（分位 ≥ 0.90）に 3 seed 中 2 以上入る
- **P2（overexpress 型）**: 「PT での発現低下が障害の原因で、回復・過剰発現が保護的」と示されている 6 遺伝子（HNF4A, PPARGC1A, PPARA, ESRRA, CPT1A, NFE2L2）を overexpress すると、同じく **6 遺伝子中 2 以上**が null 上位 10% に入る（overexpress 専用の発現頻度マッチ null を使う）
- **P3（駆動 vs マーカー）**: P1・P2 で合格した遺伝子の少なくとも 1 つは、start と goal の検出率差 |Δdet| が背景分布の 80 パーセンタイル以下（＝分類器の自明なマーカーではない）
- **P4（陰性対照の維持）**: HK 3 遺伝子は null 分位 0.10〜0.90（C3）、陰性対照パネル 7 遺伝子中 5 以上も同範囲（C3-panel）— EXP-003 と同じ

## 反証条件
- delete 型・overexpress 型のどちらでも C1'（合格遺伝子 ≥ 2）を満たさない → 「陽性対照を因果の確立した遺伝子に替えても、FT-Geneformer の ISP は既知のドライバーを null から分離しない」と結論（**棄却**）。この場合、EXP-003 の VCAM1 の合格は分類器マーカーの除去で説明され、この ISP 系は駆動因子の検出には使えない
- C3 または C3-panel が不合格 → 系が壊れている（この run は判定不能）
- P1/P2 は満たすが P3 が満たされない（合格がすべて |Δdet| 高分位の遺伝子）→ **部分的支持にとどめ、「マーカー除去では説明できない」とは主張しない**

### 採用しなかった候補と理由
- **TGFBR2 / SMAD3**: 方向が文献で対立する。PT 特異的 Tgfbr2 欠損は急性 PT 障害を軽減（PMID 23160515）一方、CKD では PT 内在性 TGF-β シグナルが**保護的**（PMID 37270534）、TGF-β／β-catenin の遮断は CKD を悪化（PMID 28701516）。方向が一意に決まらない対照は陽性対照にしない
- **KLF15**（PMID 34634362, 欠損が障害を悪化＝過剰発現型の候補）: start 細胞での検出が 213 細胞のみで、200 細胞 × 3 seed を donor 上限 25 で満たせない恐れ
- **SNAI1 / TWIST1 / FOXM1 / CDKN2A**: start 細胞での検出が 2〜75 細胞で実行不可能
- **SOX9**: 欠損は修復を**阻害**する（保護的でない）ため方向が逆
- **TP53, CDKN1A, LTBR, SPP1, LCN2**: 盲検の主要対象・参照のため除外（`controls_only: true` で回さない）

## 循環性・交絡への対策（HYP-20260926-02 から継承）
- 分類器は start/goal を分けるよう学習しているので、goal 方向の移動は循環的に見える。対策: (i) 埋め込みの移動（主, a2）と分類確率 ΔP(PT_healthy)（副）を両方出す、(ii) 特異性は HK・パネル・null との比較で判定、(iii) ISP の細胞は FT に一切使っていない donor、(iv) **マーカー度（|Δdet| の背景分位）を遺伝子ごとに事前登録して、合格が駆動因子かマーカー操作かを分ける（P3）**
- ISP の細胞選抜は「その遺伝子を発現している細胞」に限る（delete も overexpress も同じ規則）。overexpress は「発現細胞で rank を最上位に移す」操作であり、非発現細胞への導入ではない

## コントロール
- ネガティブ: 発現頻度マッチのランダム null 20 遺伝子（seed ごと・run ごとに、その run の陽性対照の発現頻度に合わせて抽出）
- ハウスキーピング: ACTB, GAPDH, PPIA（C3）
- 陰性対照パネル: CERS4, TATDN1, IFT25, VAPA, PHPT1, ANAPC16, EEF1D（C3-panel）
- 継続比較: 旧陽性対照 VCAM1, HAVCR1 を delete run に同梱（判定には使わない）
- 方向対照: VCAM1, HAVCR1 の **overexpress**（障害マーカーを足しても健常方向へは動かないはず。C7, 参考）

## 実験コスト概算
