## 1. 何が行き詰まっていたか（この仮説が解く問題）

過剰発現型の摂動は、`scripts/geneformer/run_isp.py` の `select_cells()` が示すとおり
**「出発点の細胞のうち、その遺伝子のトークンが入力に含まれる細胞」**だけを対象にする
（`min_cells_per_gene` に満たなければ遺伝子ごと飛ばされる）。

従来の出発点 `FIB_neg_TLShigh` は「CXCL13・CCL19・CCL21 がすべて 0 の線維芽細胞」だったので、
**この 3 遺伝子を摂動できる細胞は構造的に 0** だった。EXP-20260928-002 が
「経路の出口（分泌プログラム）を測れていない」と結論した原因の中核はここにある。

**目標の定義を、この 3 遺伝子を使わない形に組み直せば、3 遺伝子は出発点に残り、摂動できる。**

**はじめて満たせる**（EXP-20260927-003 以降ずっと満たせていなかった）。

### 3.3 落とした候補（**使えないと明記する**）

## 4. 仮説

**ヒト腎の線維芽細胞（A1、単一核、19,049 細胞 / 79 提供者）において、リンパ組織様の分泌プログラムの遺伝子セット S（K ≈ 25。§3.1）を 1 つずつ過剰発現すると、細胞埋め込みが、出発点 `FIB_orgLow` から目標 `FIB_orgHigh`（三次リンパ組織を形づくる細胞のマーカー 7 個の得点が、読み取りの深さをそろえたうえで上位 5%）の側へ、セット全体として寄る。**

- 摂動の種類: `overexpress`、埋め込みは `cls`
- 主指標: **目標に特異的な成分**（目標の重心への接近 − 別の状態の重心への接近。guardrails 2026-09-27）。
  二次回帰で「元の位置・入力の長さ」の交絡を補正し、対照遺伝子群の標準偏差で標準化する
  （EXP-20260927-003 以降で確立した指標をそのまま使う）
- **判定の単位はセットの平均**。個々の遺伝子は記述値にとどめる（§7）

### 4.1 この仮説が、否定された HYP-20260928-01 と違う点

| | HYP-20260928-01（否定） | 本仮説 |
|---|---|---|
| 摂動した遺伝子 | 経路の**構成因子**が中心（120 個中、ケモカイン・サイトカインは 7 個） | **分泌プログラムそのもの**（25 個すべて） |
| CXCL13/CCL19/CCL21 | 構造的に摂動不能（0 細胞） | **摂動できる**（129 / 135 / 278 細胞） |
| 目標の定義 | 3 遺伝子の検出 | 別の 7 マーカー（深さで層別） |
| 目標の軸の陽性対照 | **無かった** | **7 マーカーを置ける** |
| 深さだけの AUC | 0.676（従来の事前チェック時点） | **0.6025** |

**本仮説は HYP-20260928-01 の再検定ではない。** 前者が否定したのは「この単一核データで測れる
経路の標的遺伝子 120 個に 0.37 標準偏差以上の効果はない」であり、本仮説が問うのは
「測れていなかった出口（分泌プログラム）に効果があるか」である。

### 4.2 循環性への対処（**目標の定義に使う遺伝子と摂動の対象を完全に分ける**）

| 項目 | 実測 |
|---|---|
| 目標の定義に使う遺伝子（7）∩ 摂動の対象（25） | **0 個**（重なりなし） |
| 目標の定義に使う遺伝子 ∩ 従来の 3 ケモカイン | **0 個** |

遺伝子としては重ならないが、**細胞としては共起する**。これを事前に数値化しておく
（§3.1 の「目標との共起」の列）。

| 群 | 遺伝子 | 目標との共起のオッズ比 |
|---|---|---|
| 目標に濃縮される側 | CCL19 (6.29), TNFSF14 (5.34), CXCL1 (3.20), CCL21 (2.96), LTB (2.41), IL33 (2.11), CCL2 (1.92) | ≥ 1.9 |
| 濃縮されない側 | **CXCL13 (0.92)**, CXCL16 (1.10), VEGFA (1.05), CCL28 (0.93), IL11 (0.75), TNFSF15 (0.70), ANGPT1 (0.64) | ≤ 1.1 |

→ **事前登録する副次的な予測**: セットを「共起オッズ比 2.0 以上」と「2.0 未満」に**結果を見る前に**分け、
両方の部分セットで値を報告する。**濃縮される側だけが動く場合は、相関の回収であって
駆動因子の証拠ではない**と書く（EXP-20260928-002 の「非マーカー部分セット」と同じ扱い）。

- **CXCL13 は目標に濃縮されていない**（オッズ比 0.92）。A1 では CXCL13 が髄質の M-FIB に偏り
  （173 中 130）、マーカー 7 個は皮質の FIB / aFIB に偏るためと考えられる（未確認の解釈）。
  したがって CXCL13 についての予測は**純粋に新規**であり、循環していない。

### 4.3 深さの交絡への対処（guardrails 2026-09-27）

1. 目標を**検出遺伝子数の十分位の中で**定義する（中央値 1,590.5 対 1,591.0）
2. 状態の重心は**深さをそろえた細胞から作る**（guardrails 2026-09-27）
3. 事前チェックで**深さ 2 変数だけの AUC を必ず報告する**（実測 0.6025）
4. **感度分析を事前登録する**: 総カウントの十分位で層別した版（深さだけの AUC **0.5667**、
   従来 `FIB_org` との濃縮のオッズ比 2.80、CXCL13 129 / CCL19 138 / CCL21 281 / LTB 131）。
   主判定は検出遺伝子数の十分位の版（`procedure.md` 固定時の既定）で行い、総カウント版は感度分析に置く

## 5. 予測（定量）

すべて **3 seed すべてで**成立することを要求する。単位は対照遺伝子群の標準偏差。

| # | 内容 | 判定基準 |
|---|---|---|
| **P-1（主予測）** | セット S（K ≈ 25）の目標に特異的な成分のセット平均 | 対照遺伝子群から**復元ありで**引いた K 個セットの **99 パーセンタイル**を超え、**かつ**絶対値の条件（対照で偶然合格率 0.02 以下になるよう計画時に較正。K = 25 では **0.46 前後**の見込み）を満たす |
| **P-2（特異性）** | 3 本の軸をすべて出す | 目標の軸 − 筋線維芽細胞の軸 **> 0**、**かつ** 目標の軸 − 対照の状態の軸 **> 0**（validation.md §3.4(b) の指摘への対処） |
| **P-3（アッセイの妥当性）** | 目標の定義に使ったマーカー 7 個のセットが、**目標の軸**で K = 7 の 99 パーセンタイルを超える | **健全性チェック。仮説の支持には使わない** |
| **P-4（順序）** | リンパ組織のケモカイン部分（CXCL13, CCL19, CCL21, LTB, TNFSF14）の平均 > それ以外の部分の平均 | 記述値 + 3 seed での符号の一致 |
| **P-5（中立性）** | 恒常発現遺伝子 3 個と中立対照パネル 7 個が、無作為セットの 5〜95 パーセンタイルに入る | 3 seed とも |
| **P-6（部分セット）** | 共起オッズ比 2.0 未満の部分セット（§4.2）も 99 パーセンタイルを超える | 超えなければ「相関の回収」と書く |

**効果の大きさの見込み**: 0.9〜1.5 標準偏差。根拠は、EXP-20260928-002 で
筋線維芽細胞マーカー 24 個が自分の軸で **1.39〜1.45** を出したこと（同じ規模のセットで、
生物学的に筋の通った摂動が出した実測値）。これより小さい効果は §7 のとおり検出できない。

## 7. 判定の単位と、必要な遺伝子数

- **単一遺伝子では判定しない。** 事前登録の記述値の規則（3 seed すべてで 2.5 標準偏差以上）は
  記述にとどめる。単一遺伝子の最小検出可能効果量（minimum detectable effect）は EXP-20260928-002 の実測で **2.73 標準偏差**相当であり、
  リンパ組織のケモカインにそれだけの効果を期待する根拠がない
- **判定はセットの平均で行う。** 必要な遺伝子数と最小検出可能効果量の見積もり
  （対照遺伝子間の標準偏差 σ ≈ 0.98 を EXP-20260928-002 の実測から引く。
  99 パーセンタイル ≈ 2.326 σ / √K、最小検出可能効果量 ≈ 2.07 × 閾値（EXP-20260928-002 の比））:

| K | 99 パーセンタイルの見込み | 最小検出可能効果量の見込み | 備考 |
|---|---|---|---|
| 13 | 0.63 | 1.30 | EXP-20260928-002 の実測 0.645〜0.652 と整合 |
| **25（本仮説）** | **0.46** | **≈ 0.95〜1.05** | 本設計 |
| 40 | 0.36 | ≈ 0.75 | 分泌因子の枠を広げれば届く |
| 120 | 0.21 | 0.44 | EXP-20260928-002 の実測値 |

- **リンパ組織様の分泌プログラムとして意味のある遺伝子は、このデータでは 25 個前後が上限**である。
  名前で機械的に拾ったリガンド様の遺伝子（受容体を含む）は 129 個が 120 細胞の条件を満たすが、
  そこまで広げるとセットが「分泌プログラム」を指さなくなる。
  → **計画の段階で、文献に基づく分泌因子の一覧を先に固定してから、120 細胞の条件を当てる**。
  結果として K が 25 を大きく下回るなら、最小検出可能効果量が 1.3 標準偏差を超えるので**設計を諮り直す**
- **上の見積もりは計画の段階で実測し直すこと**（guardrails 2026-09-28「最小検出可能効果量は事前登録する規則そのもので計算する」）

## 9. 事前チェック（摂動の前に必ず通す。EXP-20260927-002 と同じ形）

1. 目標 `FIB_orgHigh` と出発点 `FIB_orgLow` の Geneformer の CLS 埋め込みで、
   **深さをそろえた**集合のロジスティック回帰、**提供者で分割した** 5 分割 AUC
   - **AUC ≥ 0.65 でなければ摂動を行わない**（F-6）
   - 並べ替え検定 p < 0.01、**深さ 2 変数だけの AUC を併記**（生カウントでの実測 0.6025）
2. **トークン化済み入力**での摂動対象の細胞数を数え直す（**生カウントでの検出は上限であって実測ではない**）。
   §3 の値は生カウントから数えたもので、Geneformer の入力長 4,096 での切り捨ては考慮していない。
   最も保守的に「検出遺伝子数が 4,096 を超える細胞を出発点から外す」と CXCL13 は **119** に下がる
   （希少な遺伝子は正規化後の順位が高く切り捨てられにくいので、実際は 129 に近いと予想するが**未確認**）
3. 対照遺伝子群・偽セット・最小検出可能効果量を**この出発点で実測**してから事前登録を固定する

## 10. この仮説で答えが出ること・出ないこと

### 答えが出ること

- リンパ組織様の分泌プログラム 25 個を 1 つずつ過剰発現したとき、
  三次リンパ組織を形づくる細胞のマーカーが高い状態へ、**セットとして 1.0 標準偏差程度以上**寄るか
- **CXCL13・CCL19・CCL21 を摂動したときに何が起きるか**（EXP-20260928-002 では構造的に測れなかった）
- 目標の軸で摂動が効くことを示せるか（**この系ではじめて**。P-3）
- 分泌プログラムの効果が、筋線維芽細胞の軸・対照の状態の軸と区別できるか（P-2）

### 答えが出ないこと

- **1.0 標準偏差未満の効果**。EXP-20260928-002 の経路セットが示した 0.17 標準偏差のような
  大きさは、K = 25 では**まったく検出できない**。K を増やしても、測れる分泌因子が 25 個前後しかない
- **個々の遺伝子が効くかどうか**。判定の単位はセットである
- **三次リンパ組織が実際にできるかどうか**。目標のラベルは
  **マーカー遺伝子の検出による推定**であって、組織学的な確認ではない
  （A1 に三次リンパ組織の注釈は無い。共通の限界）
- **細胞老化との関係**。盲検中の 5 遺伝子（TP53, CDKN1A, LTBR, SPP1, LCN2）を摂動しないため、
  本仮説は細胞老化に直接触れない。CDKN2A も線維芽細胞 19,049 中 **42 細胞**しか検出されず摂動できない。
  細胞老化との関連は、目標が急性腎障害で最も濃縮される（9.62% 対 健常 2.58%）という
  **記述値**にとどまる
- **因果**。過剰発現型の摂動は「入力の順位を最上位へ動かす」操作であって、
  遺伝子の実際の過剰発現でも経路の活性化でもない。1 遺伝子ずつであって同時摂動でもない
- **CXCL13 の余裕が小さいこと**（129 細胞、下限 120 に対して +9）。
  トークン化後の実測で下回れば、CXCL13 はセットから落ちる（F-9）。
  また、余裕の小さい遺伝子は **seed を変えてもほぼ同じ細胞が選ばれる**ので、
  seed 間の独立性が弱い（guardrails 2026-09-27）

## 11. 実験コスト概算

- 遺伝子数: セット 25 + 目標マーカーの陽性対照 7 + 筋線維芽細胞マーカー 24 + 恒常発現 3 +
  中立対照パネル 7 + 対照遺伝子群 300 = **約 366**
- 細胞数: 遺伝子あたり最大 200（実際は 129〜200、平均 185 程度の見込み）
- seed: 3

| 見積もり | 計算 | 時間 |
|---|---|---|
| 上限（全遺伝子 200 細胞） | 366 × 200 × 3 × 0.1154 秒 | **7.04 時間** |
| 見込み（平均 185 細胞） | 366 × 185 × 3 × 0.1154 秒 | **6.51 時間** |
| 状態の重心（3 状態 × 約 900 細胞 × 3 seed） | — | 約 0.3 時間 |
| **合計** | | **約 6.8〜7.4 時間** |

- 上限 24 時間に対して余裕がある
- **G2 の要否**: `run_isp.py` の判定条件は `hours > 24 or n_cells > 10000 or 全遺伝子`。
  `n_cells` は `max_cells_per_gene`（200）を指すので 10,000 を超えない。
  したがって **G2 の条件には当たらない**（guardrails 2026-09-28: Labretary が自分で確かめること）。
  **ただしこの判断は計画の段階で dry-run の出力と突き合わせて確認する**
- 対照遺伝子群を 500 に増やす場合: 566 × 200 × 3 × 0.1154 = **10.9 時間**。それでも 24 時間内

## 12. 支持された場合の次の一手（実験室での検証）

- ヒト腎の初代皮質線維芽細胞に、CCL19 / CXCL13 / LTB を単独および組み合わせで強制発現させ、
  PDPN・NGFR・ICAM1・VCAM1・TNFSF13B の発現（定量 PCR、フローサイトメトリー）が上がるかを見る。
  **in silico で予測された「分泌因子 → オーガナイザー様マーカー」の向きを直接試す**
- 上清でヒト B 細胞の遊走（トランスウェル）を測り、CXCL13 の中和で消えるかを確認する
- 照射（10 Gy）または反復継代で老化させた線維芽細胞で同じ実験を行い、応答が増強するかを比べる
  （細胞老化 → オーガナイザー化のしやすさ。**盲検の解除後に**、細胞老化の遺伝子を含む設計に拡張する）
- 生体内: 高齢マウスの虚血再灌流障害後の三次リンパ組織モデル（Yoshikawa 2023, PMID 37548710）で、
  線維芽細胞特異的な Ccl19 欠損が三次リンパ組織の形成を抑えるかを見る
