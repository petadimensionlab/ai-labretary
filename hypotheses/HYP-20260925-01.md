# HYP-20260925-01: TLS-high の CKD 腎では、修復不全型の近位尿細管（aPT）が p53–p21 老化軸と LTβR に強く依存しており、これらを削除すると健常 PT 状態へ近づき、その効果は TLS-low 腎の aPT より大きい

- Status: inconclusive
- 起点: `outputs/literature/2026-09-25-tls-feasibility/feasibility.md` §2・§3.1（A2 で TLS スコアと aPT 比率が相関 ρ = 0.43、n = 74 donor。TLS-high の aPT で SPP1/LCN2/HAVCR1/TP53 の検出率が高い）、カタログ §2（腎の障害・修復不全 PT、細胞老化コア）、Yoshikawa 2023（TLT 周囲の Vcam1⁺ 障害 PT、PMID 37548710）
- 新規性: 新規予測（TP53 / CDKN1A / LTBR の効果が TLS の状態によって変わること）。既知の再確認（VCAM1 / HAVCR1 の削除で aPT が健常側へ動くこと）を陽性対照として含む

## 仮説
ヒト CKD 腎の近位尿細管（A2 KPMP scRNA）において、**TP53, CDKN1A（p53–p21 老化軸）と LTBR（TLS のリンパ球が出す LTα1β2 の受容体）** を delete すると、細胞状態が **aPT_CKD_TLShigh（start）** から **PT_healthy（goal）** へ近づく。その goal 方向シフトは、TLS-low の CKD 腎の aPT（alt）で同じ摂動をしたときより大きい。

- データ: A2 `A2_KPMP_v1.5_scRNA_Lake2023.h5ad`（raw.X → X、n_counts を付けたコピーを `experiments/EXP-*/work/` に作る。data/raw は変更しない）
- state_key: `isp_state`（**推定ラベル**。`author_cell_type` は著者のアノテーション、TLS 群は本解析で推定したもの）
  - start = `aPT_CKD_TLShigh`: author_cell_type = aPT、disease = CKD、donor の TLS 群 = high → **7,533 細胞 / 14 donor**
  - goal = `PT_healthy`: author_cell_type ∈ {PT-S1/S2, PT-S3}、disease = normal → **6,149 細胞 / 22 donor**
  - alt = `aPT_CKD_TLSlow`: aPT、CKD、TLS 群 = low → **4,002 細胞 / 8 donor**
- 摂動: `perturb_type: delete`、emb_mode `cls`（V2 の必須設定、guardrails 参照）
  - 対象（新規予測）: TP53 (ENSG00000141510), CDKN1A (ENSG00000124762), LTBR (ENSG00000111321)
  - 対象（データ駆動。TLS-high の aPT で検出率が高い障害マーカー。削除すれば健常側へ動くのは半ば自明なので、効果量の参照に使う）: SPP1 (ENSG00000118785), LCN2 (ENSG00000148346)
  - start の CKD TLS-high aPT のうち各遺伝子を発現している細胞数: TP53 1,063、CDKN1A 572、LTBR 1,600、SPP1 5,730、LCN2 514、VCAM1 4,685、HAVCR1 660（delete は発現している細胞にしか効かないため、**遺伝子ごとに発現細胞から抽出**し、1 donor あたり 15 細胞以下にする）
- 事前チェック（ISP の前に行う）: start / goal / alt の CLS 埋め込みでロジスティック回帰の 5-fold AUC を出す。start vs goal の AUC が 0.8 未満なら ISP は行わない。start vs alt の AUC が 0.6 未満なら 2 回目（alt 条件）は行わない
- 限界: TLS-high / TLS-low は pseudo-bulk の組成から推定したもので、組織学的な TLS ではない。CKD 内に限定して疾患の交絡を減らしたが、CKD の重症度（eGFR）の差は残る。IL7R/LTB/CCL19 の aPT での陽性は ambient RNA の可能性がある

## 予測（定量）
- 主要: TP53, CDKN1A, LTBR のそれぞれで、goal_state_shift（PT_healthy 重心へのコサイン類似度の増加の細胞平均）が、発現量をマッチさせたランダム 20 遺伝子の null 分布の上位 5% に入る（経験的 p、対象 5 遺伝子で BH-FDR < 0.05）。3 seed（異なるサブサンプル）のうち 2 つ以上で成り立つこと
- 文脈依存性（新規予測の中心。2 回目の実行）: 同じ遺伝子を aPT_CKD_TLSlow で削除したときのシフトとの比 shift(TLS-high) / shift(TLS-low) が 1.2 以上で、donor 単位のブートストラップ 95% CI が 1 を含まない
- 参照: SPP1 / LCN2 のシフトは VCAM1 / HAVCR1 と同程度（null の上位 10% 以内）になると予想する

## 反証条件
- TP53, CDKN1A, LTBR のシフトが 3 seed すべてで null の 80 パーセンタイル以下、またはシフトの向きが逆（healthy から離れる）→ 主要予測は棄却
- shift 比の 95% CI が 1 を含む → 「TLS の状態で変わる」という部分は棄却（遺伝子の効果が一般的なだけ、という結論になる）
- 陽性対照（VCAM1, HAVCR1）が null の上位 10% に入らない → 棄却ではなく **inconclusive**。パイプライン・状態定義を見直す

## コントロール
- ポジティブ: VCAM1（修復不全 PT マーカー、Kirita 2020 PMID 32571916 / Yoshikawa 2023 PMID 37548710）、HAVCR1（KIM-1、障害 PT、Lake 2023 PMID 37468583）。どちらも delete で aPT → 健常へ動くことが期待される既知の再確認
- ネガティブ: 発現頻度をマッチさせたランダム 20 遺伝子（start 細胞のうち 300 細胞以上で発現しているものから、seed ごとに抽出）。ハウスキーピングの ACTB, GAPDH, PPIA（delete による非特異的なシフトの大きさの参照）
- 状態のコントロール: alt（TLS-low aPT）へのシフトも同時に記録する（goal ではなく「別の aPT 状態」へ動いただけではないことを確認）

## 実験コスト概算
- 1 回目（TLS-high のみ）: 100 細胞/遺伝子 × 30 遺伝子（対象 5 + 陽性 2 + ランダム 20 + HK 3）× 3 seed = 9,000 細胞・遺伝子
  - 下限: 2 forward × 1,660 tok ÷ 7,200 tok/s ≈ 0.46 s → 1.15 h。上限: smoke fp32 の実測 ≈ 0.8 s → 2.0 h
  - 状態重心（start / goal / alt 各 500 細胞）: 0.1〜0.15 h
  - **合計 ≈ 1.3〜2.2 h（MPS）。2 h の境界にある** → smoke で bf16 の実測値を取り、2 h を超える見込みなら着手前に **G2 承認**をとる
- 2 回目（alt: TLS-low aPT で同じ摂動）: さらに ≈ 1.2〜2.0 h。1 回目と合わせると 2 h を超えるので **G2 必須**
- 細胞数はいずれも 1 万未満（start 抽出の上限 7,533）

## 支持された場合の次の一手（wet 実験）
- ヒト近位尿細管細胞（RPTEC/TERT1 または初代 PT 細胞）で、反復低用量シスプラチンまたは放射線照射（10 Gy）により修復不全・老化様の状態を誘導する。そこへ TP53 / CDKN1A / LTBR の siRNA を入れ、HAVCR1・VCAM1・SPP1（qPCR）、SA-β-gal、p21 蛋白（WB）を測る
- LTα1β2 またはアゴニスト抗 LTβR 抗体で PT 細胞を刺激し、LTBR ノックダウンの有無で比較する。障害マーカーと CCL2/CXCL10/CCL19 の分泌（ELISA）、リンパ球の transwell 遊走を読む（TLS → 尿細管の方向のクロストーク）
- in vivo: 高齢マウスの IRI 後 TLT モデル（Sato 2016 PMID 27699223、Yoshikawa 2023 PMID 37548710）で、LTβR-Ig（LT 経路の阻害）または senolytic（ABT-263）を投与し、TLT の面積と Vcam1⁺ PT の比率を定量する
