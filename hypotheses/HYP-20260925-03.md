# HYP-20260925-03: ccRCC の腫瘍内 B 細胞では、加齢関連 B 細胞（ABC）プログラム（TBX21/ITGAX/ZEB2）と p21 が形質細胞への分化を押し進めており、これらを活性化すると TLS 由来の腫瘍内形質細胞状態へ近づく

- Status: proposed
- 起点: `outputs/literature/2026-09-25-tls-feasibility/feasibility.md` §3.3（A3 の腫瘍・腫瘍境界に活性化 B 1,498 細胞、IgG 形質細胞 283、IgA 形質細胞 253。活性化 B の CDKN1A⁺ が 27〜31% と naive B の 2.5% より高い）、カタログ §2「TLS 形質細胞（RCC）」（Meylan 2022 PMID 35231421）、「加齢関連 B 細胞（ABC）」（Arazi 2019 PMID 31209404）
- 新規性: 新規予測（ABC プログラムと CDKN1A が腫瘍内 B → 形質細胞の状態遷移を駆動するという予測）。既知の再確認（PRDM1/XBP1 による形質細胞分化）を陽性対照に置く

## 仮説
ccRCC の腫瘍内 B 細胞（A3 Li 2022）において、**TBX21, ITGAX, ZEB2（ABC プログラム）と CDKN1A** を activate すると、細胞状態が **B_tumour（start）** から **PlasmaCell_tumour（goal）** へ近づく。

- データ: A3 `A3_RCC_LiR2022.h5ad`（B 系列のみを抽出したコピーを experiments 側に作る）
- state_key: `b_state`（細胞種は著者の `annotation`（アノテーション済み）。**「腫瘍内」「TLS-high」は推定ラベル**）
  - start = `B_tumour`: annotation ∈ {Naïve_B.1/2, Non-switched-memory_B, Switched-memory_B, Activated_B-AREG, Activated_B-RHOB}、summaryDescription ∈ {Tumour, Tumour-normal} → **約 1,833 細胞 / 11 donor**（うち活性化 B 1,498、メモリー B 255、naive B 80）
  - goal = `PlasmaCell_tumour`: Plasma-IgG ＋ Plasma-IgA、Tumour ＋ Tumour-normal → **536 細胞 / 11 donor**（IgG 283、IgA 253）
  - alt = `B_blood`: 同じ donor の末梢血 B（Naïve_B.1 2,765、Non-switched-memory 1,130）→ **約 4,000 細胞**
  - 感度分析: start を TLS-high サンプルの腫瘍内 B（780 細胞）に絞った場合も見る
- 摂動: `perturb_type: activate`（`perturb_rank_shift` は Geneformer の既定に従う）、emb_mode `cls`
  - 対象（新規予測）: TBX21 (ENSG00000073861), ITGAX (ENSG00000140678), ZEB2 (ENSG00000169554), CDKN1A (ENSG00000124762)
  - 対象（TLS 側の入力）: CXCR5 (ENSG00000160683), CD40 (ENSG00000101017), TNFSF13B/BAFF (ENSG00000102524)
- 事前チェック: start と goal の CLS 埋め込みで 5-fold AUC を出す（形質細胞は転写プロファイルが大きく違うので AUC > 0.95 を期待する）。goal の中央値遺伝子数は IgG 形質細胞で 417 と低く、重心が浅い深度に引っ張られる可能性があるため、**深度をマッチさせたサブサンプル**でも重心を作って感度分析する
- 限界: **A3 には TLS の組織学的ラベルがない。**「腫瘍内形質細胞 = TLS 由来」は Meylan 2022 の知見に基づく仮定であって、このデータでは確かめられない。IGHG1/IGHA1 は Geneformer のトークン辞書にないため、クラススイッチそのものは摂動できない。10x 5' のデータであり、Geneformer の事前学習の分布とずれている

## 予測（定量）
- TBX21, ITGAX, ZEB2 のいずれか 2 つ以上で、PlasmaCell_tumour 重心への goal_state_shift が発現量マッチのランダム 20 遺伝子の null の上位 5% に入る（対象 7 遺伝子で BH-FDR < 0.05）。3 seed のうち 2 つ以上で成立すること
- CDKN1A は null の上位 10% に入る（老化プログラムが分化を押す、という弱めの予測）
- 効果量の順序: shift(PRDM1) > shift(TBX21) > null の中央値。ABC プログラムの効果は既知のマスター転写因子（PRDM1）より小さいと予想する
- alt（血中 B）を start にすると、TBX21/ITGAX/ZEB2 のシフトは腫瘍内 B より小さい（腫瘍微小環境で準備が整っている、という予測）

## 反証条件
- TBX21, ITGAX, ZEB2 のいずれも 3 seed すべてで null の 80 パーセンタイル以下、または向きが逆 → 主要予測は棄却
- 陽性対照（PRDM1, XBP1）が null の上位 10% に入らない → **inconclusive**（パイプライン・状態定義の問題）
- start を血中 B にしたときのシフトの方が大きい → 「腫瘍微小環境での準備」の部分は棄却

## コントロール
- ポジティブ: PRDM1/BLIMP1 (ENSG00000057657), XBP1 (ENSG00000100219) — 形質細胞分化のマスター制御因子。RCC の TLS で形質細胞への分化が起きるという文脈は Meylan 2022 PMID 35231421。既知の再確認として扱う
- ネガティブ: 発現頻度マッチのランダム 20 遺伝子（start で 200 細胞以上に発現しているものから seed ごとに抽出）、ハウスキーピング ACTB, GAPDH, PPIA
- 状態のコントロール: メモリー B 重心へのシフトも記録し、「B 細胞の活性化一般」ではなく形質細胞方向であることを確認する

## 実験コスト概算
- 100 細胞/遺伝子 × 32 遺伝子（対象 7 + 陽性 2 + ランダム 20 + HK 3）× 3 seed = 9,600 細胞・遺伝子。B 細胞の中央値遺伝子数 ≈ 1,100
- 下限: 2 × 1,100 ÷ 7,200 ≈ 0.31 s/回 → 0.82 h。上限（0.8 s/回）→ 2.1 h。状態重心（3 状態 × 500 細胞）0.1 h
- **合計 ≈ 0.9〜2.2 h（MPS）、細胞数 1 万未満。bf16 の実測が下限に近ければ G2 不要。2 h を超える見込みなら G2 承認をとる**
- 感度分析（TLS-high に絞った start、深度マッチ重心）を足す場合は +0.5〜1.0 h

## 支持された場合の次の一手（wet 実験）
- ccRCC 手術検体から CD19⁺ B 細胞を分離し、CD40L＋IL-21＋BAFF で刺激する系で、T-bet（TBX21）誘導条件（IFN-γ＋TLR9 リガンド）を加えたときの形質芽細胞（CD38⁺CD27⁺）への分化と IgG 分泌（ELISpot）を測る。TBX21 / ZEB2 のノックダウンで減るかを確認する
- ccRCC 切片で ABC（CD11c⁺T-bet⁺ B）と TLS の位置関係を多重免疫染色で確認し、TLS 成熟度（CD21⁺ FDC ネットワークの有無）と p21 陽性 B の割合を比べる
- Meylan 2022 の Visium データ（GSE175540、カタログ B4）で、TLS スポットの ABC シグネチャースコアと IgG 形質細胞シグネチャーの共局在を検証する（ドライラボでの追試）
- 予後との対応: TCGA-KIRC のバルクで ABC スコアと TLS スコアの交互作用が全生存と関連するかを見る
