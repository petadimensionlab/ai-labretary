# HYP-20260927-01（方法仮説）: 過剰発現型の摂動で「移動距離（元の位置）」と入力の長さをそろえた null と比べると、交絡が除かれ、文献で保護的とされる陽性対照が null・恒常発現遺伝子・発現をそろえた比較遺伝子群のすべてを上回る

- Status: proposed（G1 は PI。判定はしない）
- 起点: PI 承認済みの方針（2026-09-27）。[EXP-20260926-005](../experiments/EXP-20260926-005/plan.md) run O（過剰発現型）が、摂動遺伝子の元の順位と効果の相関（遺伝子単位 ρ 0.65 / 0.47 / 0.32）のため判定不能になったことへの対処。研究報告（`outputs/reports/2026-09-26-腎臓リンパ組織と細胞老化-研究報告.md` §7）の推奨 1〜3 を組み込む
- 新規性: 方法の検証（生物学的な新規予測ではない）。実験計画: [EXP-20260927-001](../experiments/EXP-20260927-001/plan.md)

## 背景
- 過剰発現型の摂動は「その細胞の入力の順位列で遺伝子を最上位へ移す」操作で、元の位置が下にある遺伝子ほど大きく動かすことになる。EXP-005 run O では、長さ補正した接近度の null 分位がこの移動距離でかなり説明できた（validation.md §4）
- 事後検証（validation.md §9, 探索的）では、元の位置を区間に分けて補正しても遺伝子単位の相関はほとんど縮まなかった（seed4 +0.47 → +0.45〜+0.50）。区間の中に相関が残るため
- 本仮説は「細胞ごとに移動距離と長さで偏りを補正し、分布の重なる null 遺伝子とだけ比べれば交絡は除ける」という方法の主張と、「そのうえで陽性対照が分離する」という主張を分けて検証する

## 仮説
EXP-005 run O と同じ追加学習済みモデル・同じ出発点（三次リンパ組織が多い群の修復不全の近位尿細管）・同じ目標の重心（追加学習に使っていない健常 9 提供者）で、新しい seed 11/12/13・1 遺伝子 100 細胞として、

- **P1（交絡の除去）**: 主検定（移動距離をそろえた並べ替え検定）で、null 遺伝子自身を対象にしたときの分位が較正されており（上位・下位 10% に入る割合がともに 0.20 以下）、null 遺伝子の補正後の値と元の位置・相対位置の |Spearman ρ| が 0.25 以下（3 seed 中 2 以上）
- **P2（陽性対照の分離）**: 過剰発現型の陽性対照 6 遺伝子（HNF4A, PPARGC1A, PPARA, ESRRA, CPT1A, NFE2L2）のうち 2 以上が、次の 3 つをすべて満たす
  - 並べ替え検定の分位 ≥ 0.90 が 3 seed 中 2 以上
  - 恒常発現遺伝子（ACTB, GAPDH, PPIA）を 9 組中 7 以上で上回る
  - 自分に発現差・頻度・相対順位・元の位置をそろえた比較遺伝子 5 つのうち 4 以上を、3 seed 中 2 以上で上回る（null を上回るだけでは合格にしない）
- **P3（陰性対照の中立）**: 恒常発現遺伝子 3 つが分位 0.10〜0.90（3 seed 中 2 以上）、中立対照パネル 7 遺伝子のうち 5 以上も同じ
- **P4（参考・示唆のみ）**: P2 で合格した遺伝子に、出発点と目標で検出率の差が小さい（EXP-005 の ddet_pct ≤ 0.80）ものが含まれる

## 反証条件
- P1 と P3 が満たされ、P2 が満たされない → **否定**。内訳を分けて報告する: (i) 並べ替え検定の分位で 2 遺伝子以上が上位に入らない＝「移動距離をそろえると陽性対照は null から分離しない」（EXP-005 run O の合格は移動距離で説明できた）、(ii) 分位では入るが恒常発現遺伝子・比較遺伝子群を上回らない＝「分離は特異的でない」
- P1 が満たされない → **判定不能**（この補正でも交絡が除けない／検定が較正されていない。方法の改良が必要）
- P3 が満たされない → **判定不能**（系が中立でない）

## コントロール（EXP-005 run O から継承）
- 陽性対照: 上の 6 遺伝子（根拠と PMID は [HYP-20260926-04](HYP-20260926-04.md)）
- 恒常発現遺伝子: ACTB, GAPDH, PPIA
- 中立対照パネル: CERS4, TATDN1, IFT25, VAPA, PHPT1, ANAPC16, EEF1D
- 方向対照（参考）: VCAM1, HAVCR1 の過剰発現（障害マーカーを足しても健常方向へは動かないはず）
- 新規: null 遺伝子 54（固定 18 遺伝子それぞれに発現頻度・元の位置・入力の長さをそろえた 3 遺伝子）、発現をそろえた比較遺伝子群 30（陽性対照 1 つにつき 5）。選定は ISP の結果を使わない（`experiments/EXP-20260927-001/analysis/select_genes.py`）

## 限界（事前に明記）
- **EXP-005 の結果を見た後に立てた仮説である。** 移動距離をそろえるという方法の選択自体が EXP-005 の探索的な結果に動機づけられており、事後検証では HNF4A・PPARA・NFE2L2 が上位に残ることを既に知っている。判定基準は 6 遺伝子すべてに対する件数で定め、特定の 3 遺伝子に絞らない。seed・細胞（陽性対照の細胞の 18〜53% が EXP-005 と重なる）・null・比較遺伝子は新しいが、出発点の細胞の母集団（7,533 細胞, 14 提供者）とモデルは同じなので、独立な再現ではなく「同じデータでの再検定」である
- 比較遺伝子を「駆動因子ではない」とした判断は知識に基づくもので、系統的な文献調査ではない（遺伝子ごとに不確実性を記録）
- in silico の結果であり、支持されても「このモデルが文献の保護因子の過剰発現を健常方向への移動として表す」ことが示唆されるにとどまる
