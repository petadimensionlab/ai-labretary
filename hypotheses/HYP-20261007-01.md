## 4. 予測（**定量。結果を見る前に固定する**）

判定の単位は「標準得点」。対照遺伝子群で標準化した主指標の値である。
主指標は EXP-20261004-001 と同じ（出発点の重心から目標の重心へ向かう軸の向きベクトルへの射影 ÷ 移動量）。

### 4.1 再現の単位 —— **提供者で分けた、互いに重ならない 3 群**

A1 の「3 seed」は細胞を引き直すだけで、同じ細胞が複数の seed に入りうる。
**A2 では出発点が 173 細胞しかないので、引き直すと 3 群がほぼ同じ細胞になる。**

→ **提供者 50 人を 3 群に分け、互いに 1 細胞も重ならない 3 つの部分集合（各 55〜60 細胞）で測る。**
これは A1 の 3 seed より強い再現の条件である。群の作り方（層別の規則と乱数の鍵）は
実験計画で固定し、**結果を見る前に動かさない**。

### 4.2 主判定 P-1（**セット単位**）

> 候補 8 個の**セット平均の標準得点**が、**3 群すべて**で
> (i) A2 の対照遺伝子群から復元ありで引いた 8 個の偽セット 1,000 組の **99 パーセンタイル**を超え、
> かつ (ii) **絶対値 1.59 以上**になる。

- 絶対値の条件 1.59 = 4.5/√8。本プロジェクトが K=119 で 0.41 を事前登録したときと同じ式である
- **K=8 のときの最小検出可能効果量は 2.34 標準偏差**。
  本プロジェクトが過去に事前登録した値（K=13 で 1.841、K=45 で 0.984、K=61 で 0.852、
  K=114 で 0.619、K=119 で 0.606、K=135 で 0.574）は、いずれも 6.63/√K に 0.5% 以内で一致する。
  その式を K=8 に当てはめた
- **A2 の対照遺伝子群で最小検出可能効果量を実測し直す。**
  実測値が 2.34 を上回ったら、**実測値のほうを合格の条件に使う**（この置き換えの規則を、結果を見る前にここで固定する）

### 4.3 副次の予測 P-2（**遺伝子ごと。何個通るかを先に書く**）

> 候補 8 個のうち **3 個以上**が、3 群すべてで標準得点 2.73 を超える。

- **根拠（外れうる形で書く）**: A1 の共通細胞集合で 3 seed 平均が最も高い 3 個は
  CA12 9.99・GSN 7.71・MADCAM1 7.03 で、閾値 2.73 の **2.6〜3.7 倍**の余裕がある。
  単一核から単一細胞へ移すときの減衰を **2 分の 1 まで**と見込めば、この 3 個は閾値を上回る。
  **減衰が 2 分の 1 より大きければ 3 個に届かず、この予測は外れる。**
  「減衰は 2 分の 1 まで」は実測の裏づけが無い想定であり、**そこがこの予測の賭けている点**である
- 偶然の期待件数は 8 × 偽陽性率。A1 の 0.546% なら 0.044 件。
  **A2 の偽陽性率は A2 の対照で実測し直す**（A1 の値は使わない）
- 2.73 は A1 の 200 細胞で較正された値である。A2 で実測した最小検出可能効果量が
  2.73 を上回ったら、**そちらを閾値に使う**（§4.2 と同じ置き換えの規則）

### 4.4 副次の予測 P-3（**三次リンパ組織の 3 個**）

> MADCAM1・CXCL13・CCL21 のうち **1 個以上**が P-2 の条件を満たす。

- 根拠: A1 の共通細胞集合で 3 個とも合格し、3 seed 平均は 7.03 / 4.42 / 6.76 だった。
  うち CCL21 は A2 で検出率が約 6 倍になる（§3.2）
- **この 3 個が 1 個も通らなければ、本研究の主題に最も近い部分は再現しなかったことになる**

### 4.5 判定を保留する範囲（**bfloat16 の分解能**）

計算は **bfloat16** で行い、状態の比較は **float32** で行う（既存の設定のまま）。
A1 で実測した bfloat16 と float32 の食い違いは標準得点で平均 0.194・標準偏差 0.243・最大 0.436 だった。

- **3 群平均の標準得点が 2.73 以上 3.6 未満の遺伝子は「判定保留」とし、合否を論じない**
  （EXP-20261004-001 と同じ規則。範囲の幅 0.87 は観測最大の食い違いの 2.00 倍）
- すべてを float32 で測り直すと約 5.0 倍の時間になる。必要になったら PI に諮る

|---|---|
| P-1 と P-3 が通る | 三次リンパ組織に関わる遺伝子が、2 つの測定手法で活性化した間質の状態へ寄せることが示唆される。[HYP-20261007-02](HYP-20261007-02.md) の細胞老化との接続へ進む |
| P-1 が通り P-3 が通らない | 再現したのは三次リンパ組織以外の遺伝子である。CA12 などデータが指した候補を主題にし直すかを PI に諮る |
| R-1 / R-2 | A1 の上位は、その測定手法に固有の可能性が高い。**A1 の順位表をそれ以上追わない**ことを PI に提案する |
| R-6 | A2 では活性化した間質の状態の軸が立たない。別のデータ（A6 尿管閉塞腎、PMID 40399382）を検討する |

**wet 実験の提案**（本実験は in silico であり、提案にとどまる）: ヒト腎線維芽細胞の初代培養で
MADCAM1 または CCL21 を強制発現させ、活性化の指標（COL1A1・FN1・ACTA2、細胞外基質の産生）を測る。

## 10. 限界（**必ず報告に書く**）

1. **A2 は独立したコホートではない。** A1 と同じ研究である。提供者の重なりを実測した
   —— 全提供者では A1 の 80 人と A2 の 77 人のうち **34 人が共通**。
   出発点の線維芽細胞に限ると、A2 の 50 人のうち **21 人が A1 の出発点にも出る**。

3. **細胞数が 2 桁少ない。** A1 の分散分解では標準得点の分散の 92.0% が遺伝子ごとに再現する成分で、
   細胞の引き直しは 8.0% だった。細胞数の影響は小さい見込みだが、**A2 で測り直すまでは見込みである**

   「A1 の上位が別の測定手法でも再現した」までで、腎臓で起きる事実ではない
5. **目標の状態は活性化した間質であって、三次リンパ組織ではない**（§0.3）
