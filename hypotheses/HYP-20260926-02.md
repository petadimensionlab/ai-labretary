# HYP-20260926-02（方法仮説）: 腎 PT の障害軸（aPT_CKD vs PT_healthy）で fine-tuning した Geneformer CellClassifier の埋め込みでは、削除ドリフトが小さくなり、陽性対照が HK・陰性対照パネル・ランダム null から事前登録基準（C1〜C3, C3-panel）で分離する

- Status: refuted（G3: PI, 2026-09-26。P1 棄却: a2 で C1 の HAVCR1 不合格。P2（削除ドリフト減少）・P3（C2 勝ち数 16 vs 10）は支持）
- 起点: PI 指示（2026-09-26）「A の後に、そもそもファインチューニングをしていないと思うので、ファインチューニングをしたトレインドのモデルを使ったインシリコパーターベーションの実験を試みてください」。これまでの ISP（EXP-20260925-001, EXP-20260926-001, -002）はすべて Geneformer V2-316M **Pretrained**（BertForMaskedLM）の CLS 埋め込み
- 背景: Pretrained の CLS 埋め込みでは、1 遺伝子 delete がどの遺伝子でも goal/start/alt の全重心から離れる「削除ドリフト」があり（EXP-001 run 1 で 90/90）、陽性対照 VCAM1/HAVCR1 が HK（GAPDH/PPIA）と区別できなかった。ドリフトの 56% は変位の半径成分（どの向きに動いても元の近くの重心から離れる 2 次の項）で、start→goal 軸の変化は小さい（|shift| ~10⁻⁴, EXP-002 §6.3）。Geneformer 原著の ISP（Theodoris 2023, *Nature* 618:616, PMID 37258680）は疾患状態で fine-tuning した分類モデルで行っており、fine-tuning で埋め込み空間の start→goal 軸が引き伸ばされれば、遺伝子特異的な移動がドリフトに対して相対的に大きくなると期待される
- 新規性: 方法の検証（生物学的な新規予測ではない）。実験計画: [EXP-20260926-003](../experiments/EXP-20260926-003/plan.md)

## 仮説
KPMP A2 scRNA の近位尿細管で、aPT_CKD（TLS-low の CKD donor の aPT）と PT_healthy を donor 単位で分けて 2 クラス分類に fine-tuning した Geneformer V2-316M（CellClassifier）の CLS 埋め込み（emb_layer −1）では、fine-tuning に使っていない donor の aPT_CKD_TLShigh 細胞（start）で 1 遺伝子 delete をしたとき、主指標 a2（EXP-20260926-002 §6.4 と同一定義）で陽性対照（VCAM1, HAVCR1）がランダム null・HK（ACTB, GAPDH, PPIA）・陰性対照パネル 7 遺伝子の全てから分離し、HK とパネルは null の内側に収まる。

## 予測（定量。EXP-20260926-002 plan.md §6.2 / §6.4 と同じ基準・同じ細胞・同じ遺伝子）
- 前提（ゲート, phase 2）: FT 分類器が held-out donor（TLS-high aPT 14 donor + 健常 9 donor）で、凍結 Pretrained 埋め込み＋ロジスティック回帰に対し AUROC・macro-F1 ともに劣らず（ベースライン ≥ 0.99 の指標は 0.01 の非劣性）、donor 別の最小正解率 ≥ 0.80
- P1（主）: a2 で C1（VCAM1・HAVCR1 がそれぞれ null 上位 10% に 3 seed 中 2 以上）、C2（陽性 > HK が 18 組中 15 以上）、C3（ACTB・GAPDH・PPIA が null 分位 0.10〜0.90 に 3 seed 中 2 以上）、C3-panel（7 遺伝子中 5 以上が 3 seed 中 2 以上で 0.10〜0.90）をすべて満たす
- P2（副）: 同じ細胞・同じ goal 重心定義の Pretrained（EXP-002 案 A の埋め込みから再計算）と比べ、補正前の shift_goal での削除ドリフトが小さい（null 遺伝子×seed の負の割合が小さく、null の平均 shift_goal を start–goal 重心間距離 1 − cos(c_start, c_goal) で割った値の絶対値が小さい）
- P3（副）: C2 の勝ち数（陽性 > HK, 18 組中）が Pretrained 以上
- 参考（合否に使わない）: C4（split-half・seed 間の順位 ≥ 0.7）・C5（細胞長・発現細胞数との |ρ| ≤ 0.3 / 0.2）、分類ヘッドの ΔP(PT_healthy)（a2 と同じ長さビン補正）での C1〜C3

## 反証条件
- ゲート通過後、FT モデルで a2 が C1・C2・C3・C3-panel のいずれかを満たさない → 「この系では fine-tuning しても、delete の対照が事前登録基準で分離しない」と結論（棄却）。主要対象（TP53/CDKN1A/LTBR, SPP1/LCN2）は評価しない
- ゲート不通過 → 仮説は検証できない（inconclusive）。FT モデルでの ISP は行わない

## 循環性（start と goal で学習した分類器で goal 方向の移動を読む）への対策
- 読み出しを 2 つ出す: 埋め込みの移動（主, a2）と分類確率の変化（副, ΔP）。両者の一致・不一致を報告する
- 特異性は「陽性対照がドリフトの大きさではなく HK・パネル・null より大きく動くか」で判定する（C2/C3/C3-panel）。分類器が単に「発現の多い遺伝子を消すと障害らしさが減る」ように学習していれば HK とパネルも動き、C3/C3-panel で不合格になる
- 陽性対照 VCAM1/HAVCR1 は aPT のマーカーでもあり、分類器が直接使っている可能性がある（マーカー除去効果）。この場合の C1 合格は「駆動因子」の証拠ではない。探索枠として、陽性対照と同程度に aPT で上昇する非ドライバー遺伝子（DE マッチ null）を加える案を plan §4.5 に記載（PI 判断）
- ISP の細胞は fine-tuning に一切使っていない donor（start の 14 donor は全員 held-out、goal 重心も held-out の健常 9 donor）

## コントロール
- ポジティブ: VCAM1（Kirita 2020 PMID 32571916）、HAVCR1（Lake 2023 PMID 37468583）
- ネガティブ: 発現頻度マッチのランダム null 20 遺伝子（seed ごと, EXP-002 案 A と同じ遺伝子）、HK の ACTB/GAPDH/PPIA（C2/C3 に含める, PI 方針）、陰性対照パネル CERS4/TATDN1/IFT25/VAPA/PHPT1/ANAPC16/EEF1D（C3-panel）、探索枠 RPS13/RPL32（報告のみ）
- モデルの対照: 同じ細胞・同じ遺伝子・同じ goal 重心定義の Pretrained

## 実験コスト概算（EXP-20260926-003 plan.md §8）
- fine-tuning: リモート NVIDIA GPU で約 0.1〜0.9 h（RTX 4090〜A100 級。GPU 未確定のため probe で実測。未知の GPU なら最大 ~3 h）。MPS フォールバックは縮小構成で 0.8〜1.6 h
- ゲート評価（Mac MPS）約 0.5 h、FT モデルの対照 ISP（34 遺伝子 × 200 細胞 × 3 seed）約 4.3 h、Pretrained の goal 重心の再抽出 約 0.1 h
- 合計 約 5.0〜5.8 h（G2 必要。リモート GPU の時間も含む）
