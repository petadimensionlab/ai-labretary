## 仮説
KPMP A2 の CKD aPT（aPT_CKD_TLShigh, start）→ PT_healthy（goal）において、Geneformer V2-316M の CLS 埋め込みで 1 遺伝子 delete をしたとき、摂動変位ベクトルから null 遺伝子の平均的な変位（削除ドリフト）を除いた成分を start→goal 軸へ射影した指標は、陽性対照（VCAM1, HAVCR1）をランダム null と HK（ACTB, GAPDH, PPIA）の両方から分離し、HK を null の内側に置く。

## 予測（定量。EXP-20260926-002 plan.md §6.2 の C1〜C5 と同じ）
- C1: VCAM1・HAVCR1 がそれぞれ null の上位 10% に 3 seed 中 2 以上
- C2: 陽性 > HK が 18 組中 15 組以上
- C3: ACTB・GAPDH・PPIA の null 分位が 0.10〜0.90 に 3 seed 中 2 以上
- C4: split-half の遺伝子順位 Spearman ≥ 0.7、seed 間（固定対照）≥ 0.7
- C5: 細胞長・発現細胞数との |ρ| ≤ 0.3（遺伝子単位）、細胞長との |ρ| ≤ 0.2（細胞単位, 中央値）

## 反証条件
- 採用候補の指標が 3 seed の本番（対照のみ）で C1〜C3 のいずれかを満たさない → 「この系・この埋め込みでは、ドリフト補正後も陽性対照の特異的な信号を検出できない」と結論し、HYP-20260925-01 の再解析は行わない（陽性対照か goal 状態の定義を見直す）
