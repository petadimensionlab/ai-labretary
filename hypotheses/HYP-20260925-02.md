# HYP-20260925-02: 腎線維芽細胞で LTβR–非古典的 NF-κB 経路（LTBR/RELB/NFKB2）と p21 老化プログラムを活性化すると、TLS オーガナイザー様（CCL19/CCL21/CXCL13⁺）の状態へ近づく

- Status: proposed
- 起点: `outputs/literature/2026-09-25-tls-feasibility/feasibility.md` §3.2（A1 で CCL19/CCL21/CXCL13⁺ 線維芽細胞 777 細胞 / 65 donor、donor ごとの比率が TLS スコアと ρ = 0.59、n = 71、p < 10⁻⁶）、カタログ §2「腎 TLT 線維芽細胞」（Sato 2016 PMID 27699223、Arai 2021 PMID 33951198）
- 新規性: 新規予測（ヒト腎線維芽細胞での LTBR/RELB/NFKB2・CDKN1A の効果）。ラベル定義遺伝子（CCL19/CXCL13）の過剰発現は健全性チェックとしての既知の再確認

## 仮説
ヒト腎の線維芽細胞系（A1 KPMP snRNA: FIB, aFIB, dFIB, M-FIB, dM-FIB, MYOF, cycMYOF）において、**LTBR, RELB, NFKB2, CDKN1A** を overexpress すると、細胞状態が **FIB_neg_TLShigh（start）** から **FIB_org（goal）** へ近づく。

- データ: A1 `A1_KPMP_v1.5_snRNA_Lake2023.h5ad`（線維芽細胞系 21,769 細胞のみを抽出したコピーを `experiments/EXP-*/work/` に作る。data/raw は変更しない）
- state_key: `fib_tls_state`（**推定ラベル**。細胞種は著者の subclass.l2、TLS 状態は本解析の遺伝子検出による推定）
  - goal = `FIB_org`: CCL19 / CCL21 / CXCL13 のいずれかが 1 カウント以上 → **777 細胞 / 65 donor**（AKI 349、CKD 218、normal 200）
  - start = `FIB_neg_TLShigh`: 上記 3 遺伝子がすべて 0、TLS-high donor、disease ∈ {AKI, CKD} → **5,748 細胞 / 22 donor**
  - alt = `FIB_neg_TLSlow`: 3 遺伝子がすべて 0、TLS-low donor → **3,768 細胞 / 25 donor**
- 摂動: `perturb_type: overexpress`（発現していない細胞にも適用できる）、emb_mode `cls`
  - 対象（新規予測）: LTBR (ENSG00000111321), RELB (ENSG00000104856), NFKB2 (ENSG00000077150), CDKN1A (ENSG00000124762)
  - 対象（既知の再確認・健全性チェック）: CCL19 (ENSG00000172724), CXCL13 (ENSG00000156234) — goal ラベルを定義する遺伝子なので、これで動かなければ状態定義かパイプラインが壊れている
- 事前チェック（ISP の前）: FIB_org と FIB_neg の CLS 埋め込みでロジスティック回帰の 5-fold AUC を計算する。**AUC < 0.65 なら ISP は行わない**（snRNA で 1 カウント検出しただけの推定ラベルであり、ノイズが大きすぎると判断する）。その場合は goal を Meylan 2022 Visium（カタログ B4）の TLS スポット由来シグネチャーで定義し直してから再検討する
- 限界: goal は 1〜数カウントの検出に基づく推定ラベル。皮質 FIB と髄質 M-FIB が混ざる（感度分析として皮質のみでも実行）。TLS スコアに CCL19/CCL21/CXCL13 が含まれるため、TLS 群との相関は一部循環的。snRNA のため CDKN1A 検出率は FIB 1.0%・aFIB 2.9% と低い

## 予測（定量）
- LTBR, RELB, NFKB2 の overexpress で、FIB_org 重心への goal_state_shift が、発現量をマッチさせたランダム 20 遺伝子（同じく overexpress）の null の上位 5% に入る（対象 6 遺伝子で BH-FDR < 0.05）。3 seed のうち 2 つ以上で成立すること
- CDKN1A は null の上位 10% に入る（LT 軸より弱いと予想する）
- 順序の予測: shift(LTBR) ≥ shift(RELB) ≈ shift(NFKB2) > shift(CDKN1A) > null の中央値
- 文脈: start を FIB_neg_TLSlow に替えても LTBR のシフトは有意に残る（TLS 環境がなくても LT 軸は効く、という予測。差が出れば環境依存性の証拠になる）

## 反証条件
- LTBR, RELB, NFKB2 のいずれも 3 seed すべてで null の 80 パーセンタイル以下、またはシフトの向きが逆 → 主要予測は棄却
- CCL19 / CXCL13 の overexpress でも goal へ動かない → 棄却ではなく **inconclusive**（状態定義・パイプラインの問題）。事前チェックの AUC と合わせて判断する
- ハウスキーピング 3 遺伝子の overexpress が対象遺伝子と同程度のシフトを出す → 非特異的なシフトとして **inconclusive**

## コントロール
- ポジティブ: CCL19（腎 TLT のオーガナイザー様線維芽細胞のマーカー、Sato 2016 PMID 27699223）、CXCL13（TLS コア、Sautès-Fridman 2019 PMID 31092904）。どちらも goal ラベルを定義する遺伝子なので、健全性チェックとして扱い、新規性の主張には使わない
- ネガティブ: 発現頻度をマッチさせたランダム 20 遺伝子（start 細胞で 300 細胞以上に発現しているものから seed ごとに抽出）、ハウスキーピング ACTB, GAPDH, PPIA
- 状態のコントロール: MYOF（筋線維芽細胞）重心へのシフトも記録し、「線維化の方向へ動いただけ」でないことを確認する

## 実験コスト概算
- 100 細胞/遺伝子 × 29 遺伝子（対象 6 + ランダム 20 + HK 3）× 3 seed = 8,700 細胞・遺伝子。線維芽細胞の中央値遺伝子数 ≈ 1,590
- 下限: 2 × 1,590 ÷ 7,200 ≈ 0.44 s/回 → 1.1 h。上限（smoke fp32 実測 0.8 s/回）→ 1.9 h。状態重心（3 状態 × 500 細胞）0.1 h
- **合計 ≈ 1.2〜2.0 h（MPS）、細胞数 1 万未満。境界なので smoke で bf16 の実測を取り、2 h を超える見込みなら G2 承認をとる**
- alt を start にした 2 本目を回す場合はさらに +1.2〜2.0 h → その時点で **G2 必須**

## 支持された場合の次の一手（wet 実験）
- ヒト腎線維芽細胞（初代皮質線維芽細胞または HRPF）をアゴニスト抗 LTβR 抗体、または LTα1β2＋TNF で刺激し、CCL19・CCL21・CXCL13・PDPN・NGFR の発現（qPCR、ELISA）を測る。RELB / NFKB2 の siRNA で阻害されるかを確認する
- 照射（10 Gy）または反復継代で老化させた線維芽細胞で、同じ LTβR 刺激への応答が増強するかを比べる（老化 → オーガナイザー化のしやすさ）
- 刺激した線維芽細胞の上清でヒト B 細胞の遊走（transwell）を測り、CXCL13 中和で消えるかを確認する
- in vivo: 高齢マウス IRI 後 TLT モデル（Yoshikawa 2023 PMID 37548710）で、線維芽細胞特異的な Ltbr 欠損（Pdgfrb-CreERT2）が TLT 形成を抑えるかを見る
