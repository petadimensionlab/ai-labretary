# HYP-20260926-03（方法仮説）: FT CellClassifier の ISP における VCAM1 の特異性と donor 単位の再現性

- Status: partially_supported（G3: PI, 2026-09-27。比較遺伝子の予測 P-a は支持、提供者単位の一致 P-c1 は支持、提供者を増やした再現性の改善 P-c2 は不成立）
- 起点: EXP-20260926-003 の結果（FT で削除ドリフトは消えたが C1 は HAVCR1 で不合格、VCAM1 のみ null 上位、split-half 0.46）
- 実験計画: [EXP-20260926-004](../experiments/EXP-20260926-004/plan.md)（(a) DE マッチ比較、(c) donor 単位解析。(b) 陽性対照の見直しは別担当）
- 新規性: 方法の検証であり、生物学的な予測ではない

## 予測（事前登録は EXP-20260926-004 plan.md §A.3 / §C.1）
- P-a: 主指標 a2 で、VCAM1 の値は DE マッチ比較 10 遺伝子（発現差・発現頻度・入力内順位がマッチした非ドライバー）の 90% 以上を上回る（3 seed 中 2 以上）
- P-c1: donor 単位に集約した指標（DL-med）でも、C1・C2・C3・C3-panel の判定が細胞単位と一致する
- P-c2: donor を 14 → 29（TLS-mid の CKD donor を追加、FT 未使用）に増やしても判定が再現し、donor split-half が改善する

## 反証条件
- P-a を満たさない → 「VCAM1 の C1 合格はマーカー除去効果と区別できない」（EXP-003 の C1 を駆動因子の証拠に使わない）
- P-c1 が食い違う → 指標が donor の重みづけに依存する（細胞数の多い donor に引きずられる）
- P-c2 で split-half が 0.7 未満のまま → donor 間の異質性が主因であり、donor 数を増やしても順位の再現性は確保できない

## コントロール
- 陽性 VCAM1 / HAVCR1、HK（ACTB/GAPDH/PPIA）、陰性対照パネル 7、発現頻度マッチ null 20/seed、探索枠 RP 2
- (a) の比較群 DE マッチ 10（陰性対照ではなく「マーカー除去」の対照）

## コスト
- リモート GPU（spark-cf5b）: (a) 約 0.3 h、(c-2) 約 1.4 h。CPU 解析は数分
