# 退役した見張りスクリプト（2026-09-30）

**使わないこと。** `scripts/remote/watch_run.py` に置き換えた。

退役の理由は 2 つある。

1. **macOS の /bin/bash（3.2）で書いたのが誤りだった。** この Mac のシェルは zsh であり、
   プロジェクトの計算はすべて Python で動いている。**bash 3.2 を選ぶ理由が無かった。**
   連想配列が使えない・`$VAR` の直後に日本語が来ると変数名を取り違える、という
   古い bash 固有の不具合で 2 度落とした。**環境の古さではなく、道具選びの誤りである。**
2. **`wait_exp004.sh` は「3 seed がすべて終わったら知らせる」作りで、異常を検知できなかった。**
   `handoff_seed83.sh` が死ぬと条件が永久に満たされず、鳴らない。
   気づけたのは PI が状況を尋ねたからで、放置すれば見落としに上限が無かった。

置き換え先は **「進んでいないこと」を検知する**（`watch_run.py`）。
