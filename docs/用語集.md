| 単一細胞 RNA-seq | 細胞 1 個ずつの遺伝子発現を測る手法 | scRNA-seq |
| 提供者 | 検体を提供した患者・ドナー 1 人 | donor |

| 三次リンパ組織が多い群／少ない群／中程度の群 | 上のスコアを 3 等分した提供者グループ | TLS-high / low / mid |
| 出発点の状態・目標の状態・対照の状態 | 摂動で「どこから」「どこへ」動くかを測る基準。対照の状態は比較用の第 3 の状態 | start / goal / alt |

## 2. モデルと計算

| 使う言葉 | 意味 | 旧表記・内部名 |
|---|---|---|
| Geneformer | 大量の単一細胞データで学習した、遺伝子発現の基盤モデル。本研究では 3.16 億パラメータの第 2 版を使用 | V2-316M |
| 事前学習モデル | 追加学習をしていない、配布されたままの Geneformer | Pretrained |
| 追加学習済みモデル | 本研究のデータで「修復不全か健常か」を見分けるよう追加学習させた Geneformer | FT, fine-tuned, CellClassifier |
| コンピュータ上の遺伝子摂動 | モデルの中で遺伝子を消す・増やすなどして、細胞の状態がどう動くかを計算する模擬実験 | in silico perturbation, ISP |
| 削除型の摂動 | その遺伝子を入力から取り除く操作 | delete |
| 過剰発現型の摂動 | その遺伝子の発現順位を引き上げる操作 | overexpress |
| 細胞埋め込み | 細胞 1 個をモデルが数値ベクトルで表したもの。状態の近さはこのベクトルの角度で測る | CLS embedding |
| 状態のセントロイド | ある状態の細胞群の埋め込みの平均。状態の代表点 | state centroid |
| 目標状態への接近度 | 摂動によって、細胞が目標の状態のセントロイドにどれだけ近づいたか | shift_goal |
| bfloat16 | 計算を bfloat16 という 16 ビットの形式で行い高速化する方式。本研究では順伝播のみ bfloat16 で、状態の比較は float32（単精度）で行う。**「bfloat16」と呼んではいけない。bfloat16（FP16）は別の形式である** | bf16, bfloat16 での計算 |

## 3. 指標と対照

| 使う言葉 | 意味 | 旧表記・内部名 |
|---|---|---|
| 一様な削除効果 | どの遺伝子を消しても細胞がすべての状態から同じように離れてしまう、遺伝子によらない見かけの動き | deletion drift, 削除ドリフト |
| 長さ補正した接近度 | 細胞の入力の長さ別に対照遺伝子の平均を差し引き、一様な削除効果を取り除いた主指標 | a2 |
| 入力の長さ | 細胞 1 個をモデルに入れるときのトークン数。検出された遺伝子数にほぼ等しい | length, token 数 |
| 総 UMI 数 | 細胞・核 1 個で検出された転写産物分子の一意なタグ（UMI）の総数。ライブラリサイズとも呼ばれる。**生リード数（シーケンシング深度）とは別の量**。**「深さ」のような総称で書かない** | n_umi, total UMI count, library size |
| 検出された遺伝子数 | 細胞・核 1 個で発現が検出された（UMI ≥ 1）遺伝子の数。**総 UMI 数とは別の量** | n_genes, genes detected per cell |
| 検出された遺伝子数の分布をそろえる | 比べる群の間で、検出された遺伝子数の分布（または総 UMI 数の分布）を 1 対 1 で重ねる操作。検出された遺伝子数（または総 UMI 数）の違いによる見かけの差を取り除く。英語の標準的な操作名は **downsampling / subsampling / rarefaction**。本プロジェクトの `depth match` はこれに相当する**造語**なので、使うときはそろえた量（検出された遺伝子数か総 UMI 数か）を必ず併記する | downsampling, subsampling, rarefaction |
| 陽性対照 | 効果が出ると期待される既知の遺伝子。手法が働いているかの確認に使う | positive control |
| 対照遺伝子群 | 効果がないはずの遺伝子を、発現頻度をそろえて多数選んだもの。比較の土台 | null, negative random |
| 恒常発現遺伝子 | どの細胞でも安定して働くとされる遺伝子（ACTB, GAPDH, PPIA） | HK, housekeeping |
| 中立対照パネル | 出発点と目標で発現差がないことを発現データだけで確認して選んだ 7 遺伝子 | negctrl_panel |
| 発現をそろえた比較遺伝子 | 陽性対照と同程度に修復不全側で発現が上がるが、原因とは考えられていない遺伝子 | DE マッチ, de_matched |
| 元の位置・移動距離 | 摂動する遺伝子が、その細胞の入力の順位列で何番目にあったか。過剰発現型の摂動では最上位へ動かすので、これがそのまま動かす距離になる | pos, relpos（= 元の位置 / 入力の長さ, 相対位置） |
| 移動距離をそろえた並べ替え検定 | 細胞ごとに元の位置と入力の長さによる偏りを null 細胞で推定して差し引き、元の位置と長さの分布が重なる null 遺伝子の中で順位をつける検定（EXP-20260927-001 の主検定） | pos_matched_permutation, D_raw |
| 区間内パーセンタイル検定 | 元の位置と長さで区間を作り、同じ区間の null 細胞の中での分位を細胞ごとに求めて遺伝子で平均する検定（EXP-20260927-001 の副検定） | within_bin_percentile |
| 比較遺伝子群 | 陽性対照ごとに、発現差・発現頻度・順位・元の位置をそろえて選んだ駆動因子でない遺伝子 5 つ。「発現をそろえた比較遺伝子」を過剰発現型に広げたもの | comparator |
| 対照遺伝子群の中での順位 | ある遺伝子の値が、対照遺伝子群の分布のどの位置にあるか（0〜1） | null 分位, null_pct |
| 提供者単位の集計 | 細胞ごとではなく提供者ごとにまとめてから比較する方式 | donor-level, DL-med, DL-mean |
| 折半信頼性（split-half reliability） | 提供者を 2 群に分けて別々に順位を出し、両者がどれだけ一致するか（1 に近いほど安定） | split-half, 折半信頼性 |
| 提供者を 1 人ずつ除く検証 | 結論が特定の提供者に依存していないかの確認 | LODO, leave-one-donor-out |
| 検出された遺伝子数の分布をそろえたセントロイド | 目標の状態の細胞を、出発点の細胞と検出された遺伝子数（トークン数にほぼ等しい）が 1 対 1 で対応するものだけに絞って作った、細胞群の埋め込みの平均。検出された遺伝子数の違いがセントロイドの位置に入るのを防ぐ（EXP-20260927-002 の分布をそろえる操作をセントロイドに適用したもの）。**本文では「検出された遺伝子数の分布をそろえたセントロイド」と書く** | depth-matched centroid |
| 状態の対照 | 目標とは別の状態（本研究では筋線維芽細胞）のセントロイド。目標への接近が「別の方向へ動いただけ」でないかを見る | state control, MYOF centroid |
| 差の向き | 2 つ以上の目標の状態へ向かう向きのうち、一方から他方を引いた向き（`u_diff = (u_ada − u_deg) / ‖u_ada − u_deg‖`）。2 本に共通な成分を除き、どちらの目標に固有な移動かを測る。**共通の向きと直交する**（HYP-20261011-01 で定義） | difference direction |
| 共通の向き | 2 つ以上の目標の状態へ向かう向きの和（`u_common = (u_ada + u_deg) / ‖u_ada + u_deg‖`）。どの目標へも一様に近づく成分を測る。**差の向きと直交する**（HYP-20261011-01 で定義） | common direction |
| 参考対象 | 細胞数などの制約で力のある検定にならないため、事前に主判定から外すと決めた摂動対象 | target_ref |

## 3.5 着手前チェック（摂動を回す前に測るもの）

摂動を 1 回も使わずに、状態のセントロイドと発現データだけから「目標の軸が測れる設計か」を判定する
（`scripts/analysis/axis_feasibility.py`、2026-09-30 新設）。

| 使う言葉 | 意味 | 内部名 |
|---|---|---|
| 着手前チェック | 摂動の本番を始める前に、目標の軸が測れる状態にあるかを判定する手続き。**合格・判定保留・不合格**の 3 値で、不合格なら実験に着手しない | axis feasibility, 事前チェック |
| 軸の長さ | 出発点のセントロイドから、ある状態のセントロイドまでの距離（セントロイドはすべて長さ 1 に直してから測る） | axis length |
| 軸の長さの比 | 出発点から目標までの距離 ÷ 出発点から参照状態までの距離。1 より小さいほど目標が近く、同じ摂動でも読み取れる信号が小さくなる | axis_length_ratio |
| 参照状態 | うまく測れていることが分かっている別の状態（本研究では筋線維芽細胞）。軸の長さの比の分母に使う | reference state |
| 軸の向きベクトル | その状態のセントロイドから、他の状態のセントロイドの平均を引いたもの。摂動の主指標が実際に使う向き。**軸の長さとは別の量なので混ぜて比較しない** | direction vector |
| マーカー群のまとまり | 目標を定義するマーカーどうしの相関の中央値。低いほど、目標は 1 つの細胞状態ではなく「どれか 1 個がたまたま検出された細胞の寄せ集め」に近い | marker coherence, corr_median |
| マーカーの検出率 | そのマーカーが検出された細胞の割合。単一核 RNA-seq では低くなる遺伝子がある | detection rate |
| 陽性対照の遺伝子数（K） | 目標の軸の健全性チェックに使える遺伝子が何個あるか。K が小さいほど最小検出可能効果量（minimum detectable effect）が上がり、正しい設計でも合格できなくなる | K, K_positive_control |
| 最小検出可能効果量 | その規則で合格できる最小の効果量（対照遺伝子群の標準偏差を単位とする）。陽性対照 7 個で 1.71、24 個で 0.91、単一遺伝子で 2.73 | detectable effect floor, 最小検出可能効果量 |
| サイズを揃えたランダム遺伝子セット | 対照遺伝子群を母集団として、調べたい遺伝子セットと同じ個数を復元ありで引いて作る、偶然の遺伝子セット。これを多数回繰り返して、その大きさのセットで平均スコアが偶然大きくなる分布（帰無分布）を作る。**本文では「偽セット」と書かない。「sham set」という学術語は存在しない**（医学の sham control と誤読される）。英語では gene-set permutation / competitive null hypothesis。復元ありで引くことを明記する | sham set, 偽セット |
| 較正 | 対照遺伝子群自身を検定したときに、偶然検定結果が有意側に動く割合が想定どおり（片側 1%）に収まることの確認。統計・機械学習の文献では「較正（calibration）」が定着している。**計量・測定分野の「校正」（JIS Z 8103、機器の目盛り直し）とは別語**なので混同してはならない | calibration, 較正 |
| その遺伝子が検出された核の数 | 単一核 RNA-seq で、対象の遺伝子が検出された（読み取り ≥1 になった）核の個数。単独の定着訳語はないため、このように説明的に書く。**割合（遺伝子検出率）と混ぜない** | 検出核, n_cells per gene |
| 遺伝子セットの平均スコア | 遺伝子セットに属する遺伝子の標準化スコアの平均。「セット平均」という単独語は学術語として定着していないため、何の平均か（標準化スコア）を必ず添える | セット平均, mean gene set score |
| 得点寄与の偏り | 目標を定義する得点のうち、1 個のマーカーが占める割合。大きいほどセットの値が 1 遺伝子に依存する | score_share_max |
| 循環した陽性対照 | 目標の定義に使った遺伝子をそのまま陽性対照にすること。健全性チェックには必要だが、これだけでは「目標のラベルが正しい」証拠にならない | circular positive control |

## 4. 判定基準（結果を見る前に決めたもの）

本文では番号ではなく名前で呼ぶ。

| 使う言葉 | 内容 | 内部名 |
|---|---|---|
| 判定基準: 陽性対照の分離 | 陽性対照が対照遺伝子群の上位 10% に入ること | C1 |
| 判定基準: 恒常発現遺伝子との差 | 陽性対照が恒常発現遺伝子を上回ること | C2（組数は実験ごとに異なる。EXP-20260926-002/003/004 は 18 組中 15 以上、EXP-20260927-001 は 9 組中 7 以上。各 plan.md を参照）|
| 判定基準: 恒常発現遺伝子の中立性 | 恒常発現遺伝子が対照遺伝子群の中（上下 10% の内側）に収まること | C3 |
| 判定基準: 中立対照パネルの中立性 | 中立対照パネル 7 遺伝子のうち 5 つ以上が中立の範囲に収まること | C3-panel |
| 判定基準: 比較遺伝子群との差 | 陽性対照が自分の比較遺伝子 5 つのうち 4 つ以上を 3 seed 中 2 以上で上回ること（EXP-20260927-001） | C9 |
| 判定基準: 較正 | null 遺伝子自身を検定したとき上位・下位 10% に入る割合がともに 0.20 以下であること（EXP-20260927-001） | C8a |
| 判定基準: 交絡の除去 | 補正後の null 遺伝子の値が元の位置・相対位置と相関しないこと（\|ρ\| ≤ 0.25, EXP-20260927-001） | C8b |
| 判定基準: 対照遺伝子群からの分離 | 対象が対照遺伝子群の上位 10% に入り、かつ符号が正（目標へ近づく）であること（EXP-20260927-003） | C1(a) |
| 判定基準: 状態の特異性 | 対象の目標への接近が、状態の対照（筋線維芽細胞）への接近より大きいこと（EXP-20260927-003） | C10 |
| 判定基準: パイプラインの陽性対照 | セントロイドへ近づく効果を検出できることの確認。ACTA2 / TAGLN が筋線維芽細胞のセントロイドへ近づくかで見る（EXP-20260927-003） | C11 |
| 参考: 再現性 | 折半信頼性が 0.7 以上 | C4 |
| 参考: 交絡のなさ | 入力の長さや発現頻度と相関しないこと | C5 |

## 4.5 予測と反証条件の呼び方（2026-10-11 追加）

実験計画・仮説では予測を **P-1・P-2・…**、反証条件を **R-1・…** と書く。
**報告・検証・レポートの本文には、この番号をそのまま書かない。必ず内容を添えて呼ぶ。**
PI 指摘（2026-10-11）: 「P4 が何とか説明も書かずに書くな」。2026-09-26・2026-10-04 と同じ指摘の再発。

| 使う言葉 | 内容 | 内部名 |
|---|---|---|
| 主判定 | その実験で結論を決める 1 つの予測。**内容を必ず添えて書く**（EXP-20261007-001 の例: 候補の 8 遺伝子の標準化スコアの平均が 3 群すべてで、サイズを揃えたランダムな遺伝子セット（対照遺伝子群から復元ありで引く）の 99 パーセンタイルを超え、絶対値 1.59 以上） | P-1 |
| 副次（遺伝子ごと） | 主判定とは別に、遺伝子ごとに読む予測（同例: 候補 8 個のうち 3 個以上が 3 群すべてで 2.73 を超える） | P-2 |
| 副次（三次リンパ組織の 3 個） | 主題に最も近い 3 遺伝子についての予測（同例: MADCAM1・CXCL13・CCL21 のうち 1 個以上が合格） | P-3 |
| 反証条件 | 結果を見る前に決めた、支持されない・判定不能と読む条件。**番号ではなく条件の内容で書く**（例: 「遺伝子ごとの再現が 3 個に届かない」） | R-1〜R-8 |

- 番号を使うのは計画・仮説の内部のみ。報告では「主判定」「副次（遺伝子ごと）」のように呼び、必要なら括弧で内容を書く
- 反証条件に当たったと報告するときは、**番号を書かずに、当たった条件の内容を書く**

## 5. 進め方

| 使う言葉 | 意味 |
|---|---|
| ゲート G1（仮説採択） | その仮説を実験対象にしてよいかの PI 判断 |
| ゲート G2（計画承認） | 計算量の大きい実行を始めてよいかの PI 判断 |
| ゲート G3（結論確定） | 結果の判定（支持・否定・判定不能）を確定する PI 判断 |
| 支持された | 事前に決めた基準を満たした |
| 否定された | 事前に決めた否定の条件に当てはまった |
| 判定不能 | 対照が働かないなど、判定できる状態になかった |
| 事前登録 | 結果を見る前に判定基準を文書に固定すること |
| 盲検 | 手法の妥当性が確認できるまで、本命の遺伝子の結果を見ないこと |
