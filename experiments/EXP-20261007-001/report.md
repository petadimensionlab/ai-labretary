# 実験レポート: EXP-20261007-001 — 活性化した間質へ寄せた候補 8 個の効果は、同じ研究の単一細胞 RNA-seq でも再現するか

- 状態: 確定
- 対象の仮説: [HYP-20261007-01](../../hypotheses/HYP-20261007-01.md) — 活性化した間質の状態へ寄せると測られた候補 8 個の効果は、同じ研究の単一細胞 RNA-seq でも再現する
- 作成: Labretary / 2026-10-11（本文は report-writer が作成）
- 承認: PI 2026-10-11「このまま進めてください」（ゲート G3）。ただし §7 の 2 点（評価コードの事後修正の扱い、次に進む順序）は残る PI の判断

## 要旨（5 行以内。結論を先に）

1. 候補 8 個をまとめた値（遺伝子セットの平均スコアの標準得点）は 3 群すべてで 2.664 / 2.776 / 2.302 で、事前に決めた主判定（3 群すべてでサイズを揃えたランダム遺伝子セットの 99 パーセンタイル超、かつ絶対値 1.59 以上）を満たした。
2. 1 つずつでは 8 個のうち 3 個以上に届かず、合格は CCL21（3.938 / 4.148 / 4.076）と ELN（4.446 / 4.527 / 3.579）の 2 個だった（遺伝子ごとの閾値 2.73）。事前に決めた反証条件「遺伝子ごとの再現が 3 個に届かない」に当たった。
3. 三次リンパ組織に関わる 3 個（MADCAM1・CXCL13・CCL21）は CCL21 の 1 個だけが合格した。この 1 個は偶然の水準（約 4.6%）に近い。
4. 候補 8 個で 2 個が合格する確率は、対照での偽陽性率（1.57%）から期待される件数（0.1255 件）を上回った（二項検定 片側 p = 0.0065）。
5. 意味: 候補 8 個をまとめて活性化した間質の状態へ寄せる効果は、単一核とは別の測定手法でも**示唆される**。ただし遺伝子ごとの再現は弱く、陽性対照にも入る ELN に支えられている。次は事前登録の提案どおり HYP-20261007-02（細胞老化との接続）へ進む。

## 1. 目的と狙い

- **何を知りたいのか**: EXP-20261004-001 で「活性化した間質の状態へ細胞を寄せる」と測られた候補 8 個（CA12・GSN・MADCAM1・CCL21・ELN・ZFHX3・SLC4A9・CXCL13）の効果が、同じ研究の**別の測定手法（単一細胞 RNA-seq）・別の細胞**でも再現するか。
- **なぜ今この実験が必要なのか**: 候補 8 個は EXP-20261003-001 の**同じ単一核 RNA-seq データの探索で上位だった**から選ばれている。同じデータで測り直しても選択の偏りは残る（プロジェクト規則「確認は別のデータか別の seed で行う」）。摂動そのものは候補 8 個で共通で、変えたのは**測定手法とデータ**である。
- **この実験で答えが出ること**: 候補 8 個の遺伝子セットの平均スコアが 3 群すべてで偶然の水準と最小検出可能効果量を超えるか（主判定）／候補のうち何個が遺伝子ごとに 3 群すべてで閾値を超えるか（副次）／三次リンパ組織に関わる 3 個のうち 1 個以上が通るか（副次）。
- **この実験で答えが出ないこと**: 三次リンパ組織が作られるか（目標は著者が定義した「活性化した間質の状態」で、三次リンパ組織の組織学的ラベルはどのデータにも無い）／提供者が独立なコホートでの再現（同じ研究の単一細胞データで、出発点提供者の一部が共通）／細胞老化との関係（HYP-20261007-02 で扱う）。

## 2. 背景

- 腎臓の三次リンパ組織は、加齢や障害が続く腎臓に後天的にできるリンパ組織様の構造で、修復不全の尿細管と相互作用すると報告されている（Sato 2016, PMID 27699223; Yoshikawa 2023, PMID 37548710）。本研究の目的は、腎臓の三次リンパ組織と細胞老化に関わる**正しい遺伝子を見つけること**である。
- 使う主データは腎臓アトラス（KPMP）の単一細胞 RNA-seq（Lake ら 2023, Nature 619:585-594, PMID 37468583）である。同じ研究は単一核 RNA-seq 版も公開しており、過去の実験（EXP-20261003-001・EXP-20261004-001）は単一核版を使った。**両者は提供者の一部が共通で、独立なコホートではない**（限界参照）。
- これまでの経緯: EXP-20261003-001 の探索で候補 8 個が上位に出た。EXP-20261004-001 は、摂動に使う細胞を遺伝子によらず同一にしても上位が残ることを示した。**ただしそれは同じデータでの測り直しである。** この実験は、測定手法を単一核から単一細胞へ替えて、事前登録どおりに確認する。

## 3. アプローチ

### 3.1 使ったデータ

- 腎臓アトラス（KPMP）の単一細胞 RNA-seq（Lake ら 2023, PMID 37468583、KPMP v1.5）。生カウントのみ使用。原データは読み取り専用。
- 状態は著者のラベル `author_cell_type` をそのまま使う。出発点＝腎線維芽細胞（FIB）、目標＝活性化した間質の状態（aFIB + MyoF）。出発点は提供者あたり 20 細胞の上限を当てて 173 細胞・50 提供者。
- 摂動する細胞は遺伝子によらず同一（同じ群の中で全遺伝子が同じ細胞集合）。

### 3.2 使ったモデルと計算環境

- モデル: 追加学習をしていない Geneformer 第 2 版（3.16 億パラメータ、`emb_mode: cls`、最終層）。EXP-20261004-001 と同じ。
- 摂動の型: 過剰発現型の摂動（1 遺伝子ずつ独立に）。入力に無い遺伝子は順位列の先頭に挿入される。
- 数値型: **float32（単精度）**。本実験は採択した仮説の確認的な検定であり、「判定の基準を作る用途は float32」という方針（2026-10-04）に当たるため。tf32 は閉じた（`float32_matmul_precision: highest`）。
- 計算機: リモート計算機 1 号（spark-cf5b、NVIDIA GB10）が群 81、リモート計算機 2 号（spark-c083、同型）が群 82・83 を担当。**2 台の間で一致を確認してから本番を回した**（下記）。

### 3.3 やったこと（手順を順番に）

1. 結果を見る前に、遺伝子 587 個（候補 8・陽性対照 71・恒常発現 3・中立対照パネル 7・対照 500、重なりを除く）、3 群の分け方、状態のセントロイド（3 群で同一）、判定基準を `plan.md` と `config.yaml` に固定した（事前登録）。
2. 摂動を回す前に、目標の軸が測れる状態かを判定する着手前チェックを行った（判定保留。PI が着手を判断、2026-10-07）。
3. 対照 12 個を bfloat16 と float32 の両方で回し、数値型の違いでどこまで値がずれるかを測った（判定には使わない）。
4. 2 台の機体で同じ設定を回し、主指標の差が標準得点で 0.05 以下であることを確認した（合格・差 0.0）。
5. float32 で試し実行（Mac、3 群 × 10 細胞 × 41 遺伝子）を行い、評価コードを最後まで通した。
6. 本番: 2 台で 587 遺伝子 × 173 細胞を回した（各機体で 587 遺伝子、終了コード 0）。回収・統合のあと評価した。

### 3.4 比べたもの（対照）と、成功・失敗をどう判定するか

判定の単位は「標準得点」（対照遺伝子群 510 個の平均と標準偏差で標準化した主指標。主指標は出発点→目標の向きへの射影を移動量で割ったもの）。結果を見る前に決めた内容は次のとおり。

- **主判定（候補 8 個の遺伝子セットの平均スコア）**: 候補 8 個の遺伝子セットの平均スコアの標準得点が、**3 群すべてで**、対照遺伝子群から復元ありで引いた 8 個のサイズを揃えたランダム遺伝子セット 1,000 組の **99 パーセンタイルを超え**、かつ **絶対値 1.59 以上**になること。両方を満たせば合格。
- **副次（遺伝子ごと）**: 候補 8 個のうち **3 個以上**が、3 群すべてで標準得点 **2.73 を超える**こと。
- **副次（三次リンパ組織の 3 個）**: MADCAM1・CXCL13・CCL21 のうち **1 個以上**が上の条件を満たすこと。
- **測定が働いているか**: 陽性対照 71 個の遺伝子セットの平均スコアが 3 群すべてでサイズを揃えたランダム遺伝子セットの 99 パーセンタイルを超えること／新しく引いたサイズを揃えたランダム遺伝子セット 1,000 組で主判定に合格する数が偶然の水準に収まること。どちらかに当たれば判定不能として以降を読まない。
- **偶然の水準**: 対照遺伝子群に同じ規則を当てた合格の割合と、候補 8 個での期待件数、二項検定の片側 p を必ず並べる。
- **最小検出可能効果量の置き換え**（上向きだけ。厳しくなる側だけ）: 遺伝子ごとは実測 2.3985 で閾値 2.73 を上回らなかったので **2.73 のまま**、セットは実測 1.2136 で 2.34 を上回らなかったので **1.59 のまま**だった。

## 4. 結果

すべてコンピュータ上の遺伝子摂動の結果である（実験的に確認された事実ではない）。群の細胞数は 55 / 59 / 59（提供者 17 / 16 / 17）で、3 群は提供者も細胞も重ならない。

### 4.1 主判定（候補 8 個の遺伝子セットの平均スコア）— 合格

| 群 | 遺伝子セットの平均スコアの標準得点 | サイズを揃えたランダム遺伝子セットの 99 パーセンタイル | 絶対値条件 1.59 |
|---|---|---|---|
| 第 1 群 | 2.664 | 0.855 | 満たす |
| 第 2 群 | 2.776 | 0.884 | 満たす |
| 第 3 群 | 2.302 | 0.894 | 満たす |

- 3 群すべてでサイズを揃えたランダム遺伝子セットの 99 パーセンタイルを超え、絶対値 1.59 以上だった。**事前に決めた主判定の条件を満たした。**

### 4.2 副次（遺伝子ごと）— 反証条件「遺伝子ごとの再現が 3 個に届かない」に当たった

各値は標準得点（3 群の値と 3 群平均）。閾値は 2.73。

| 遺伝子 | 第 1 群 | 第 2 群 | 第 3 群 | 3 群平均 | 判定 |
|---|---|---|---|---|---|
| ELN | 4.446 | 4.527 | 3.579 | 4.184 | 合格 |
| CCL21 | 3.938 | 4.148 | 4.076 | 4.054 | 合格 |
| CXCL13 | 3.132 | 3.092 | 2.537 | 2.921 | 不合格 |
| CA12 | 2.668 | 2.964 | 2.777 | 2.803 | 不合格 |
| ZFHX3 | 2.865 | 2.698 | 2.040 | 2.534 | 不合格 |
| GSN | 1.928 | 2.151 | 1.475 | 1.851 | 不合格 |
| SLC4A9 | 1.115 | 1.390 | 1.370 | 1.292 | 不合格 |
| MADCAM1 | 1.221 | 1.241 | 0.559 | 1.007 | 不合格 |

- 合格は **2 個**（ELN・CCL21）で、予測（3 個以上）に届かなかった。**「遺伝子ごとの再現は 3 個に届かなかった」。**
- 不合格の中でも、CXCL13 は第 3 群の 2.537（閾値との差 0.193）、CA12 は第 1 群の 2.668（差 0.062）と、閾値のすぐ下で不合格になっている。

### 4.3 副次（三次リンパ組織の 3 個）— 1 個合格

- MADCAM1・CXCL13・CCL21 のうち合格したのは **CCL21 の 1 個だけ**。MADCAM1（1.221 / 1.241 / 0.559）と CXCL13（3.132 / 3.092 / 2.537）は不合格だった。
- 規則どおりの読みは「1 個以上で予測どおり」だが、**この 1 個は偶然の水準に近い**（4.4 参照）。

### 4.4 偶然の水準

- 対照遺伝子群 510 個に同じ規則を当てると、合格は **8 個**で**偽陽性率 1.57%** だった。
- 候補 8 個の合格数は 2 個で、期待件数は 8 × 1.57% = **0.1255 件**。二項検定 片側 **p = 0.0065**。
- 三次リンパ組織の 3 個では、偽陽性率 1.57% のもとで 3 個中 1 個以上が偶然合格する確率は 1 − (1 − 0.0157)³ ≈ **0.046（片側約 4.6%）**。CCL21 の 1 個だけの合格は偶然と区別しにくい。

### 4.5 測定が働いているか — 当たらず（判定不能にはならない）

- 陽性対照 71 個の遺伝子セットの平均スコアは 1.449 / 1.398 / 1.262 で、サイズを揃えたランダム遺伝子セットの 99 パーセンタイル（0.279 / 0.269 / 0.279）を 3 群すべてで超えた。GSN・ELN を除いた 69 個でも同様に通過し、**陽性対照の合格は GSN・ELN に依存していない**。
- 新しく引いたサイズを揃えたランダム遺伝子セット 1,000 組で主判定に合格したのは **0 組**（片側 p = 1.0）。較正（calibration。計量・測定分野の「校正」（JIS Z 8103）とは別語）は崩れていない。
- **恒常発現遺伝子 ACTB が 3 群すべてで閾値 2.73 を超えた**（2.573 / 2.996 / 3.704）。事前登録の規則により「**中立でない成分が残る**」ことを記録する（GAPDH は 1.286 / 1.202 / 1.837、B2M は −1.483 / −1.184 / −1.197）。

### 4.6 全遺伝子の順位表（探索。CLAUDE.md §3.5）

- 587 遺伝子すべての順位表を `results/gene_rank_011.csv` に保存した。セットの平均だけで終えないための記録で、**これは探索であり、事前登録どおりの確認的な検定ではない**。上位の評価は別データか別 seed で改めて行う。

## 5. 考察

- 主判定が通ったのは、候補 8 個を**まとめて**測ったときである。「活性化した間質の状態へ寄せる」という効果は、単一核とは別の測定手法でも**示唆される**。ただし、遺伝子ごとに見ると再現は弱く、合格 2 個のうち ELN は陽性対照 71 個にも入る遺伝子で、「候補としての値」と「活性化した間質のマーカーである性質」を切り分けられない。
- 別の説明の可能性: (1) 候補 8 個は元の探索で選ばれたもので、A1 の上位が測定手法に固有でないとしても、候補選択の偏りは残る。(2) 恒常発現遺伝子 ACTB が閾値を超えており、標準化の対照に入れた一部の遺伝子が中立でない可能性がある。標準化の尺度がわずかに動けば、閾値近傍の合否（CXCL13・CA12）は入れ替わりうる。
- 予想と違った点: 予測は「遺伝子ごとに 3 個以上」だったが 2 個だった。予測の根拠は「単一核から単一細胞への減衰は 2 分の 1 まで」という実測の裏づけの無い想定で、そこが外れた。一方、検出率が単一核の約 6 倍になった CCL21 は通った。

## 6. 限界

1. **独立コホートではない。** 単一核 RNA-seq と単一細胞 RNA-seq は同じ Lake ら 2023 の研究で、出発点の提供者 50 人のうち 21 人が単一核側の出発点にも出る。言えるのは「別の測定手法・別の細胞で再現した」までで、「独立なコホートで再現した」とは書けない。
2. **三次リンパ組織の 3 個の合格は CCL21 1 個だけで、偶然の水準（約 4.6%）に近い。** 偶然と区別しにくい。
3. **遺伝子ごとは予測外れ**（合格 2 個）。合格 2 個のうち ELN は陽性対照にも含まれる。
4. **閾値のすぐ下の不合格。** CXCL13（第 3 群、差 0.193）と CA12（第 1 群、差 0.062）は余裕のない不合格で、細胞数を増やしたら入れ替わる可能性を排除できない。
5. **3 群はそれぞれ 55〜59 細胞と小さい。** 細胞の引き直しが標準得点の分散に与える影響は、この単一細胞データでは測っていない（最小検出可能効果量はこのデータの対照で実測した）。
6. **評価コードを結果の後に修正した。** 回収後の評価で、記述の節（A1 との突き合わせ）の重複除去のため `evaluate_011.py` を 1 か所直した。判定値への影響は、修正箇所が記述の節に閉じていることと、保存済みの値からの独立再計算の一致（最大差 7.5×10⁻¹⁵）で否定された。ただし「結果を見る前の固定」が評価コードについて厳密には満たされておらず、修正前ファイルのバックアップも無い（diff を直接検証できない）。**この扱いを記録として認めるかは PI の判断を仰ぐ。**
7. 目標は著者定義の「活性化した間質の状態」であり、三次リンパ組織ではない。三次リンパ組織の組織学的ラベルはどのデータにも無い。提供者を 1 人ずつ除く頑健性は事前登録外で未実施。文献との一致・不一致は判定の根拠にしない。

## 7. 次のアクション

- **コンピュータ上で行うこと**: 事前登録の提案どおり [HYP-20261007-02](../../hypotheses/HYP-20261007-02.md)（細胞老化との接続）へ進む（PI 指示 2026-10-11「このまま進めてください」）。なお検証担当からは、三次リンパ組織の 3 個の合格が偶然の水準に近いことを踏まえ、先に別データ（尿管閉塞腎の公開データなど）で確認する選択肢も示されている。**どちらを先にするかは PI が決める。**
- **実験室で行うこと（提案。本実験はコンピュータ上であり提案にとどまる）**: ヒト腎線維芽細胞の初代培養で CCL21 などを強制発現させ、活性化の指標（COL1A1・FN1・ACTA2、細胞外基質の産生）を測る。
- **PI に諮る点**: (1) 結論の確定（ゲート G3）。(2) 評価コードの事後修正を記録として認めるか。(3) 次に進む順序（HYP-20261007-02 を先にするか、別データでの確認を先にするか）。

| コンピュータ上の遺伝子摂動 | モデルの中で遺伝子を消す・増やすなどして、細胞の状態がどう動くかを計算する模擬実験 |
| 過剰発現型の摂動 | その遺伝子の発現順位を引き上げる操作。入力に無い遺伝子は先頭に挿入される |
| 主指標 | 出発点から目標へ向かう向きへの移動の射影を、移動量で割った値 |
| 標準得点 | 主指標を、その群の対照遺伝子群 510 個の平均と標準偏差で標準化した値 |
| 遺伝子セットの平均スコア | 候補 8 個の標準得点の平均 |
| サイズを揃えたランダム遺伝子セット | 対照遺伝子群から復元ありで引いた 8 個の組。1,000 組で偶然の水準を作る |
| 陽性対照 | 効果が出ると期待される既知の遺伝子。手法が働いているかの確認に使う |
| 対照遺伝子群 | 効果がないはずの遺伝子を、発現頻度をそろえて多数選んだもの。比較の土台（今回は 510 個） |
| 恒常発現遺伝子 | どの細胞でも安定して働くとされる遺伝子（ACTB・GAPDH・B2M） |
| 中立対照パネル | 出発点と目標で発現差がないことを確認して選んだ 7 遺伝子 |
| 最小検出可能効果量 | その規則で合格できる最小の効果量（対照遺伝子群の標準偏差を単位とする） |
| 偽陽性率 | 効果がない対照遺伝子群で、同じ規則に合格してしまう割合 |
| 主判定 | その実験で結論を決める 1 つの予測。今回は候補 8 個の遺伝子セットの平均スコアが 3 群すべてでサイズを揃えたランダム遺伝子セットの 99 パーセンタイルを超え、絶対値 1.59 以上になること |
| 副次（遺伝子ごと） | 候補 8 個のうち 3 個以上が 3 群すべてで閾値 2.73 を超えるという予測 |
| 副次（三次リンパ組織の 3 個） | MADCAM1・CXCL13・CCL21 のうち 1 個以上が合格するという予測 |
| 反証条件 | 結果を見る前に決めた、支持されない・判定不能と読む条件。今回は「遺伝子ごとの再現が 3 個に届かない」に当たった |
| 単精度（float32） | 計算の数値形式。判定の基準を作る用途に使う。今回の本番はこの形式で計算した |
| ゲート G3（結論確定） | 結果の判定（支持・否定・判定不能）を確定する PI の判断 |
