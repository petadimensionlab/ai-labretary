## 0. 目的と、この実験で何が決まるか

### 0.1 大きな目的とのつながり

本研究の目的は、腎臓の三次リンパ組織が腎臓病・腎臓癌に果たす役割を、単一細胞データと
Geneformer のコンピュータ上の遺伝子摂動で調べ、細胞老化と関連づけてまとめることである。

単一核 RNA-seq（A1）の探索で、候補 8 個（MADCAM1・CXCL13・CCL21・CA12・ZFHX3・SLC4A9・GSN・ELN）が
「活性化した間質の状態」へ細胞を寄せる上位に出た。うち 3 個は三次リンパ組織の中核の遺伝子である。
EXP-20261004-001 は、摂動に使う細胞を遺伝子によらず同一にしても上位が残ることを示した。

**ただし、それは同じデータでの測り直しである。** 候補は A1 の探索で選ばれたので、選択の偏りが残る。
この実験は、**同じ研究の別の測定手法（単一細胞 RNA-seq、A2）・別の細胞**で、事前登録どおりに確認する
（CLAUDE.md §3.5「確認は別のデータか別の seed で行う」）。

### 0.2 この実験で決まること・決まらないこと

| 決まること | どこで |
|---|---|
| 候補 8 個の遺伝子セットの平均スコアが、A2 の 3 群すべてで偶然の水準と最小検出可能効果量を超えるか（主判定 P-1） | §6.3 |
| 候補のうち何個が、遺伝子ごとに 3 群すべてで閾値を超えるか（P-2） | §6.4 |
| 三次リンパ組織に関わる 3 個のうち 1 個以上が P-2 を満たすか（P-3） | §6.4 |
| A2 で陽性対照が働くか（測定そのものが機能しているか） | §6.5 |

| 決まらないこと | 理由 |
|---|---|
| 三次リンパ組織が作られるか | 目標は「活性化した間質の状態」（著者のラベル）であり、三次リンパ組織ではない（§10-1） |
| 提供者が独立なコホートでの再現 | A2 は A1 と同じ研究。出発点の提供者 50 人のうち 21 人が A1 の出発点にも出る（§10-2） |
| 細胞老化との関係 | この実験は細胞老化を測っていない（HYP-20261007-02 で扱う） |
| ヒトの腎臓で起きること | コンピュータ上の摂動であり、実験的事実ではない |

## 4. 細胞の選び方 —— 提供者で分けた互いに重ならない 3 群

### 4.1 群の作り方（**結果を見る前に固定**）

| 項目 | 値 |
|---|---|
| 母集団 | 出発点 FIB の 252 細胞・50 提供者 |
| 提供者あたりの上限 | 20（上限の後 173 細胞） |
| 層 | **疾患**（`disease` 列。出発点の提供者 50 人は 急性腎障害 10・正常 12・慢性腎臓病 28。1 人の提供者は 1 つの区分にだけ属する） |
| 群分けの規則（**PI 判断 2026-10-08 で改訂**） | 層を提供者数の少ない順（急性腎障害 → 正常 → 慢性腎臓病）に処理する。層の中では提供者を「上限 20 を当てた細胞数」の多い順に並べ、**(1) その層の提供者が最も少ない群、(2) 同点なら細胞数の合計（全層）が最も少ない群、(3) さらに同点なら群の番号の小さい群**へ順に入れる |
| 同じ細胞数の提供者の順 | 層ごとに `random.Random(20261008).shuffle` の後に安定ソート（乱数は 1 本を層の順に使う） |

### 4.2 なぜ seed の引き直しではなく群に分けるのか（仮説 §4.1）

出発点が 173 細胞しかないので、seed で引き直すと 3 回がほぼ同じ細胞になる。
**互いに重ならない群なら、細胞も提供者も重ならない 3 回の測定になる。** A1 の 3 seed より強い再現の条件である。
代わりに 1 群あたり 57〜58 細胞と少なくなる（§10-5）。

### 5.3 数値型 —— **float32 を使う。判定を保留する範囲は置かない**（PI 判断 2026-10-08）

**決定**: 摂動も状態の比較も **float32**。tf32 は閉じる（`run_isp.py` の `apply_dtype` が `allow_tf32 = False` と
`set_float32_matmul_precision("highest")` を設定し、`device.json` に実測値を残す）。

**理由**（PI 判断 2026-10-08。本番の結果を見る前の変更）:

1. PI の方針（2026-10-04）「判定の基準を決めるときは float32、候補を探すときは bfloat16」に当たる。
   本実験は採択した仮説の確認的な検定である
2. A2 で実測した bfloat16 と float32 の食い違いの最大は 1.0116（A1 の 0.436 の 2.3 倍。§5.3.1）。
   規則どおりだと判定を保留する範囲は 2.73〜4.75 になり、候補の多くがこの範囲に入る見込みが高い。
   その場合は float32 での測り直しが要るので、最初から float32 で回す

**判定を保留する範囲は置かない。** P-2 は「3 群すべてで標準得点 > 閾値」だけで合否を決める（§6.4）。

## 10. 限界（**結果を見る前に書く**）

1. **目標は三次リンパ組織ではない。** 著者が定義した「活性化した間質の状態」である。三次リンパ組織の組織学的ラベルはどのデータにも無い
2. **A2 は独立したコホートではない。** A1 と同じ研究で、全提供者では 80 人と 77 人のうち 34 人が共通、
   出発点に限ると A2 の 50 人のうち 21 人が A1 の出発点にも出る（仮説 §10-1）。独立なのは測定手法と細胞である
3. **出発点の構成が違う。** A1 は FIB + M-FIB 15,477 細胞、A2 は FIB 252 細胞
4. **陽性対照の検出率のばらつき 44.4 倍（PI 判断: 切らない）。** 陽性対照の遺伝子セットの平均スコアは検出率の低い遺伝子に引きずられる。
   低い遺伝子が動かなければ平均が薄まり、R-6（判定不能）に寄る。逆に R-6 を通っても、その合格は検出率の高い一部の遺伝子に支えられている可能性がある
5. **1 群 57〜58 細胞と少ない。** A1 では細胞の引き直しは標準得点の分散の 8.0% だったが、A2 で同じかは測っていない。
   最小検出可能効果量は §6.2 で A2 の対照から実測する
6. **群は疾患で層別したが、検出された遺伝子数の分布は完全にはそろっていない**（入力の長さの中央値 917・999・899）。
   疾患の各区分の提供者数は群の間で最大 1 人の差である。群の間で値が違っても、群の違いと検出された遺伝子数の違いは分けられない
7. **出発点のセントロイドには、摂動する 173 細胞がすべて含まれる**（セントロイド 173 細胞は上限 20 を当てた全出発点）。
   A1 でもセントロイドと摂動の細胞は一部重なっていた
8. **軸の長さの比 0.4637、出発点と目標の角度 2.13 度。** 動かなかった場合、「効果がない」と「軸が狭すぎて読めない」を区別できない
9. **中立対照パネルのうち CERS4 は目標側の検出率が出発点の 4.2 倍、TATDN1 は 2.1 倍である**（§3.3）。
   A2 では中立とは言いにくい。PI 判断（2026-10-08）で入れ替えていない。7 個は標準化の対照 510 個に入るだけで、単独では判定に使わない
10. **本番は float32 で、判定を保留する範囲を置かない**（§5.3）。数値型の誤差は無視できる大きさになるが、
    **2 台の機体の違い**が残る。§5.4.1 の機体の一致確認（対照 12 個 × 3 群、主指標の差が標準得点で 0.05 以下）で確かめる。
    12 個は 587 個のうちの一部であり、候補で同じ大きさになる保証はない
11. **dFIB は原著の定義（検出遺伝子数の減少）と逆を向いている**（§2.1）。主指標には入らない
12. **候補 8 個は A1 の探索で選ばれている。** A2 で通っても言えるのは「A1 の上位が別の測定手法でも再現した」までである
13. **コンピュータ上の摂動である。**「示唆される」までで、実験的事実としては書かない
14. **文献との一致・不一致は根拠に使わない**（無作為な対照でも一致率 71%。仮説 §10-8）
