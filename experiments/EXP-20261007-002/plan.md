## 0. 目的と、この実験で何が決まるか

### 0.1 大きな目的とのつながり

本研究の主題は細胞老化である。しかし現在の目標の状態（活性化した間質）は細胞老化を測っていない。
原著（Lake ら 2023, PMID 37468583）は `dFIB` などの「退化した状態」の命名の根拠に細胞老化の総説を引いているが、
**これは命名上の参照であって、退化した状態の細胞が老化細胞だと示されたわけではない**（仮説 §0）。

段階 1 は、**摂動を使わずに**、著者ラベルの退化した線維芽細胞が細胞老化の遺伝子リストの得点を高く持つかを検定する。
段階 1 が不合格なら段階 2 に着手しない（仮説 §0）。その場合に書けるのは
「この 2 つのデータでは、退化した状態を細胞老化の指標として使えない」であって、「退化した状態は老化していない」ではない。

### 0.2 この実験で決まること・決まらないこと

| 決まること | どこで |
|---|---|
| 退化 93 細胞の SenMayo 得点が参照 81 細胞より高いか（効果量・片側 p） | §4.1（主判定） |
| その差が、発現頻度をそろえた無作為な遺伝子集合より大きいか（特異性） | §4.2 |
| そろえる前後で効果量がどれだけ変わるか（検出された遺伝子数への依存） | §4.3 |

| 決まらないこと | 理由 |
|---|---|
| 細胞が実際に老化しているか | 発現の特徴を測るだけ。SA-β-ガラクトシダーゼ活性や分裂停止そのものではない（仮説 §0.1・§8-7） |

| 新規の候補遺伝子 | この実験は既知の SenMayo リストの確認的な検定であり、探索ではない |

## 3. 指標 —— SenMayo 得点

### 3.1 遺伝子リストの固定（**122 個。結果を見る前に固定**）

- 出典: SenMayo（Saul ら 2022, Nat Commun 13:4827, **PMID 35974106**）補足データ 1 の human シート。
  取得物 `outputs/literature/2026-10-11-senescence-and-degenerated-lists/senmayo_125.csv`（126 行、125 遺伝子）。
- 使う 122 個の作り方（**機械的。順序も固定**）:
  1. senmayo_125.csv の `in_A2_var = True` の 123 個を取る（A2 に無い **CCL1・CCL3L1** を除く。PI 判断 2026-10-11）
  2. 盲検中の **SPP1** を機械的に除く（PI 判断 2026-10-11。**理由のメモ: 盲検中だから。解除の指示があるまで戻さない**）
  3. 残り **122 個**を辞書順に固定する。個数の期待値は 122（`config.yaml` の `genes.expected_gene_count`）
- 122 個のうち 5 個（**IL6・IL1B・CXCL8・SERPINE1・MMP3**）は、仮説 §3.2 であとから副の指標として数えた 8 個のメンバーと重なる。
  **PI 判断 2026-10-11: そのまま使う。** 理由は、§3.2 の 8 個を単独の副の指標として使う場合の話であり、SenMayo は主の指標として固定した既知リストだからである。**この重なりは限界 §10-3 に明記する。**
- A1 でも**同じ 122 個**を使う。122 個はすべて A1 の `var` にもある（本計画の作成時に名前の一致だけで確認）。分母は両データで 122 に固定する。
- **T-5**: A2 で使える個数が 25 個未満なら判定不能（§4.5）。122 個なので当たらない見込み。実行時に数えて記録する。

### 3.2 得点の計算式（**固定**）

細胞 `i` の得点を、リスト `G`（122 遺伝子）のうち検出された遺伝子の**割合**とする。

```
score_i = (1 / 122) * Σ_{g ∈ G} 1[ raw_count(i, g) > 0 ]
```

- **検出 = 生カウント > 0。** 発現量の大きさは使わない（1 カウントでも高発現でも同じ 1 として数える）。
  これは得点の性質であり、限界 §10-8 に書く。
- 分母は 122 に固定する。細胞ごとに分母を変えない（検出できない遺伝子は 0 として数える）。

### 3.3 標準化（**固定**）

- 同じ区間の中の**参照（FIB）だけの細胞**（A2 では 81 細胞）から、平均 `m` と不偏標準偏差 `sd`（分母 n−1）を出す。**PI 判断 2026-10-11（案 B）**。
- `z_i = (score_i − m) / sd` を A2 の主の報告値とする。**「参照の平均を 0 としたとき、退化の細胞が何標準偏差ぶん高いか」という読み方になる。**
- **この標準化の選び方は合否に影響しない。** Cohen's d も t 検定の p 値も、正の定数倍と平行移動で値が変わらない（参照＋退化の全体の平均・標準偏差でそろえても同じ値になる）。このことを明記しておく（基準を後から動かす余地を残さないため）。
- A1（S-4）は A1 の区間の参照状態の細胞から出した `m`・`sd` で標準化する。A2 とは尺度を混ぜない。

### 3.4 使わない指標

仮説 §3.2 の副の指標 8 個（CDKN2A・IL6・IL1B・CXCL8・SERPINE1・GLB1・LMNB1・MMP3）は、
**本仮説を書く前に検出率を数えてしまったため、判定に使わない。** 記述としてだけ報告する（仮説 §3.2・§8-4）。

### 3.5 盲検

盲検中: **TP53・CDKN1A・LTBR・SPP1・LCN2**。

- 摂動の対象・対照・指標のいずれにも入れない。
- SenMayo の SPP1 は §3.1 で機械的に除外した（122 個に含まれない）。
- 結果ファイルのどこにも 5 遺伝子の値が現れないことを検査する（§7 A-1）。**現れたら止める。**
- 検出率などの値は、本計画でも実行でも一切数えない・書かない。

## 4. 判定規則（**事前登録。結果を見る前に固定する。結果を見てから変えない**）

実装は `analysis/score_senescence_012.py`（本計画の固定後に作成する。**本計画の作成時点では書いていない**）。
判定に使う数値は `config.yaml` の `decision:` 節にも書く。**評価コードは、その値が本計画と同じかを検査し、違えば止める。**

### 4.1 主判定 S-1

| 条件 | 中身 |
|---|---|
| (i) 向き | 退化 93 細胞の得点の平均 > 参照 81 細胞の得点の平均（`d = 平均(退化) − 平均(参照) > 0`） |
| (ii) 効果量 | **Cohen's d ≥ 0.5**（プールした標準偏差。分母 n−1） |
| (iii) 有意性 | **片側 p < 0.05**。検定は **Welch の 2 標本 t 検定（片側。対立仮説は「退化 > 参照」）** に固定する |

- **(i)・(ii)・(iii) のすべてを満たせば S-1 合格。**
- **最小検出可能効果量 d = 0.38**（n = 81 対 93、片側 α = 0.05、検出力 80%。仮説 §4.1 の値をそのまま使う）。
  d = 0.5 のときの検出力は 0.95（仮説 §4.1）。この 2 つの数値は仮説からの引用であり、ここで計算し直さない。
- 検定を Welch に固定する理由: 2 群の細胞数が違い（81 対 93）、得点が割合（0〜1 の有界）であり、等分散を仮定する根拠が無い。Welch は等分散を仮定しない。
- **参考文献値（判定には使わない）**: Student の t 検定（片側）と Mann-Whitney U 検定（片側）の p 値も併記する（§6.1）。

### 4.2 特異性の条件 S-2（**S-1 と同時に満たす必要がある**）

> 発現頻度の分布をそろえて無作為に引いた 122 遺伝子の 1,000 組で同じ比較を行ったとき、
> **SenMayo の効果量が、その 1,000 組の効果量の 99 パーセンタイルを超える。**

- 効果量は §4.1 と同じ Cohen's d（同じ細胞、同じ式）。
- **99 パーセンタイル** = 1,000 個の d を昇順に並べたときの 990 番目と 991 番目（1 始まり）の平均（線形補間。`numpy.percentile` の既定と同じ）。SenMayo の d がこれを**厳密に超える**とき合格。
- 参考として、経験的な片側割合 `p = (SenMayo の d 以上の無作為集合の数 + 1) / 1001` も報告する。

**無作為抽出の層の切り方（固定）**:

1. 頻度 `freq(g)` = 区間の 174 細胞（参照＋退化）のうち生カウント > 0 の細胞の割合。
2. **SenMayo の 122 個の `freq` の 10 分位点**を層の境界にする（`q_0 = 最小` 〜 `q_10 = 最大`。境界は線形補間で求める）。
   層 `j` は `q_{j-1} ≤ freq < q_j`（最上位の層は `freq ≤ q_10` を含む）。
3. 層 `j` から引く個数 `k_j` = SenMayo の 122 個のうち層 `j` に入る数。合計は 122。
4. 引く元（プール）: A2 の `var` にあり、Geneformer の辞書にあり、**盲検 5 個を除き、SenMayo の 122 個を除き、区間での `freq = 0` の遺伝子を除く**。プールの個数を記録する。
5. 各層で復元なしに `k_j` 個を引く。`random.Random(20261012)` を 1 本使い、層の番号の昇順に `sample` を呼ぶ。
6. **不足の扱い（固定）**: ある層のプールが `k_j` に足りないときは、頻度の中央値が最も近い層で余っている層から補い、補った回数と層の組を記録する。プール全体が 122 個未満なら中止して報告する（起こらない見込み。実測を記録）。
7. 1,000 組それぞれについて、その 122 個で §4.1 と同じ Cohen's d を計算する。**同じ細胞（区間の 174 細胞）を使う。**
8. 組の遺伝子の重複は許さない（1 組の中で同じ遺伝子を 2 回引かない）。

**S-2 を置く理由**: 検出遺伝子数をそろえても、退化側のほうがどの遺伝子集合でも得点が高くなる成分が残りうる。頻度をそろえた無作為集合を対照に置いて、それを除く。

### 4.3 検出された遺伝子数への依存の条件 S-3

- **そろえる前**の効果量 `d_unmatched` = 区間を付けない全 `FIB`・全 `dFIB` での Cohen's d。
- **そろえた後**の効果量 `d_matched` = §4.1 の効果量。
- 両方を必ず報告する。比 `d_matched / d_unmatched` も報告する。
- **`d_matched < (1/3) * d_unmatched` なら、T-4（§4.5）: 「この差の大部分は検出遺伝子数で説明できる」。判定不能。**
- `d_unmatched ≤ 0` のときは T-2（向きが逆）を先に読む。T-4 は評価しない。

### 4.4 副次 S-4（A1。**判定に使わない**）

- A1（単一核 RNA-seq）の区間 500〜1,100 で、参照 `FIB`＋`M-FIB` と比較対象 `dFIB` の SenMayo 得点を同じ式で計算し、Cohen's d と片側 p を報告する。
- 参考として、A1 でも §4.2 と同じ 1,000 組の無作為集合の 99 パーセンタイルを出す（乱数の鍵は **20261013**）。
- **A1 では細胞老化の遺伝子の検出率が 1% 前後以下である**（仮説 §3.2 の実測）。
  **S-4 が不合格でも段階 1 の判定には影響しない。** この 1 文を必ず報告に付ける。

| **T-4** | S-3 で、そろえた後の効果量がそろえる前の 3 分の 1 未満 | **判定不能。** 差の大部分は検出遺伝子数で説明できる | `T4_depth_explains` |
| **T-5** | SenMayo の 125 個のうち A2 で使えるのが 25 個未満 | **判定不能。** 指標が成り立たない | `T5_indicator_not_viable` |
| **T-6** | 区間の中に残る細胞が、どちらかの状態で 30 細胞未満 | **着手しない。** 区間の取り方を先に決め直して PI に諮る | `T6_too_few_cells` |

**評価の順序（固定。複数が当たるときは先のものを採る）:**

1. **T-5**（データ読み込み時の個数の検査）
2. **T-6**（データ読み込み時の細胞数の検査。当たれば実行を始めない）
3. 値をすべて計算する（T-1〜T-6 のどれが当たるかは、値を出してから判定する）
4. `d_matched < 0` → **T-2**（T-1 が同時に当たっても T-2 を採る）
5. そうでなく `d_matched < 0.5` または片側 p ≥ 0.05 → **T-1**
6. そうでなく S-2 不合格 → **T-3**
7. そうでなく `d_unmatched > 0` かつ `d_matched < (1/3) * d_unmatched` → **T-4**
8. どれにも当たらない → **S-1・S-2・S-3 すべて合格 = 段階 1 合格**（PI に提案する。支持・否定の確定は PI のゲート G3）

**T-1 / T-3 で不合格のときに書けること**（仮説 §5 をそのまま使う）:
「この単一細胞 RNA-seq で測れる範囲では、著者ラベルの退化した線維芽細胞に、細胞老化の発現特徴は
**Cohen's d = 0.38 以上**の大きさでは認められなかった」。**「退化した状態は老化していない」とは書かない。**

### 4.6 結果が出ない・値が欠けた場合（**手続き。規則を後から作らない**）

- どれかの値が欠けて T-1〜T-6 に当てはめられないときは、**保留**として事実だけを報告し、規則を後から作らない。
- 片方の状態の細胞が 0 で得点が計算できないときも同じ（保留。T-6 が既に当たる可能性が高い）。

## 10. 限界（**結果を見る前に書く**。仮説 §8 の 9 個を写し、本計画で増えたものを足す）

1. **退化した状態と検出遺伝子数の関係が、2 つの測定手法で逆である**（仮説 §2.1）。このラベルは測定手法に強く依存する。

6. **副の指標 8 個は盲検ではない**（仮説 §3.2）。判定に使わない。
7. **SenMayo はリストの取得のみ済んでいる**（`senmayo_125.csv`、一次情報）。得点はまだ 1 つも計算していない。
8. **得点は「検出の有無」だけを見る。** 1 カウントでも高発現でも同じ 1 として数える。発現量の大きさは使わない。
9. **S-2 の無作為集合は、SenMayo と同じ発現頻度の分布にそろえているが、遺伝子の機能や長さはそろえていない。** 差が残っても、それが「細胞老化に特異的」であることの証明にはならない。
10. **発現の特徴を測るだけであり、細胞が老化していることの確認ではない**（仮説 §8-7）。
11. **文献との一致・不一致を根拠の中心に置かない**（仮説 §8-8。2026-10-03 の較正で、上位の遺伝子の文献一致率 72% に対し無作為な対照も 71% で差が無い）。
