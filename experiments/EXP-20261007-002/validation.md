### 2.2 項目 1 — 規則の機械的な適用

- **区間**: A2 は `1,000 ≤ nFeature_RNA ≤ 2,000`（両端を含む）。実測 参照 81 細胞 / 31 提供者、退化 93 細胞 / 11 提供者で、
  仮説 §2.2・config の期待値と一致（`matches_expected: true`）。A1 は `500 ≤ nFeature_RNA ≤ 1,100` で 3,619 / 337、
  同じく期待値と一致
- **ラベル**: A2 は 参照 `FIB`・比較対象 `dFIB`（`obs/author_cell_type`）、A1 は 参照 `FIB`+`M-FIB`・比較対象 `dFIB`（`obs/subclass.l2`）。
  config の指定どおりで、実データに実在することをコードが検査している（A-2）
- **122 個**: `senmayo_125.csv` の `in_A2_var = True` の 123 個から、A2 に無い CCL1・CCL3L1 と盲検の SPP1 を機械的に除いた 122 個。
  独立に作り直して config の `senmayo_122` と**完全一致**（辞書順・個数 122）。122 個すべてが A2 の `var` と Geneformer の辞書にあり、
  A1 の `var` にも 122 個すべてがある（独立に確認。JSON の `gene_list.n_in_A1_var` は `null` で未記入。§4 に記載）
- **得点**: `score = (検出された遺伝子数) / 122`。検出は「生カウント > 0」。分母は細胞ごとに 122 に固定。
  `raw.X` は整数様（A2: `median_rowsum_over_nCount` = 0.9991、A1: 0.9960）で、行和が検出数と整合する（A-3 合格）
- **Cohen's d**: プールした標準偏差（分母 n−1）で割る式をコードが実装。独立再計算と一致（§2.1）
- **有意性**: Welch の 2 標本片側 t 検定（対立仮説は「退化 > 参照」）。`scipy` の `equal_var=False, alternative="greater"` で、値は 1.509e-11
- **S-2 の 99 パーセンタイル**: コードは `numpy.percentile(ds, 99)`（既定の線形補間）。config の `percentile_method: linear_numpy_default` と一致。
  合格判定は「SenMayo の d > パーセンタイル」の厳密超え。実測 1.0929 > 1.0254 で成立。
  **ただし plan §4.2 の括弧書き「昇順 990 番目と 991 番目（1 始まり）の平均」は、numpy 既定の値とわずかに違う**
  （この例では 990 番目 1.0254260・991 番目 1.0263923、その平均 1.0259091 に対し、使われた numpy 既定は 1.0254356、差 0.00047）。
  差は SenMayo の余裕 0.067 より 2 桁小さく、合否は動かない
- **S-3 の 3 分の 1**: `d_matched < (1/3) × d_unmatched` が T-4。実測は 1.0929 対 2.1105（比 0.5178）で当たらない
- **評価順**: config の `evaluation_order` は `[T5, T6, T2, T1, T3, T4]`、コードもこの順で最初に当たったものを採る。plan §4.5 と一致。
  当てはめた結果は T-1〜T-6 のすべてが `false` で、`first_triggered` は `all_pass`。**規則の適用は機械的に正しい**
- **各閾値との距離**（余裕の確認）: S-1 の d は 0.5 に対し +0.593、p は 0.05 に対し 1.5×10⁻¹¹。T-6 は 81/93 に対し下限 30。
  T-5 は 122 個に対し下限 25。S-3 は比 0.518 に対し下限 0.333（T-4 を当てるには d_matched が 0.703 を下回る必要がある）。
  **いちばん余裕が小さいのは S-2**（§1.1 限定 2）

### 2.3 項目 2 — 標準化は「参照だけ（案 B）」

- `metric.standardization = reference_only_within_interval`、`sd_denominator = unbiased_n_minus_1`。コードは区間の**参照だけ**（A2 の 81 細胞）から
  m・sd を出し、`z = (score − m) / sd` を作る。参照＋退化の全体ではない
- 得点一覧で確認: 参照の `z` は平均 0・不偏 sd 1（A2・A1 とも）。A2 の退化の `z` の平均は 1.034（参照の sd だけを単位にしている）
- PI 判断 2026-10-11（案 B）のとおり。§3.3 の注のとおり、Cohen's d と p はこの選び方に依らない（実際、独立再計算も同じ d・p を出した）

### 2.4 項目 3 — S-2 の層別抽出と、不足の補い

- 頻度 `freq` = 区間の 174 細胞（参照＋退化）のうち生カウント > 0 の割合。SenMayo の 122 個の 10 分位点で層を切る。
  境界・層ごとの SenMayo の数・プールの数を独立に再計算し、JSON と一致した（境界は 0, 0, 1/174, 2/174, …）
- **不足は構造的である。** 層 2 は `[0, 1/174)`、つまり頻度 0 の遺伝子だけが入る層で、**SenMayo の 24 個がここに入る**
  （区間の 174 細胞で一度も検出されない。§1.1 限定 4）。いっぽうプールは plan §4.2 手順 4 で **`freq = 0` の遺伝子を除く**ので、
  層 2 のプールは 0 個になる。**したがって層 2 は補わないと埋まらない**
- 記録された補いは「層 2 へ層 3 から 24 個」（`shortage_records`）。層 3 は `[1/174, 2/174)`、つまり 1 細胞だけで検出される遺伝子の層である。
  補った先が層 3（隣の低頻度側の層）であることは、独立再計算でも一致した
- **規則の適用について**: plan §4.2 手順 6 は「頻度の中央値が最も近い層で余っている層から補う」と定めるが、
  **欠損している層 2 はプールが空なので、その中央値は定義できない**（NaN）。実装は NaN をキーにした並べ替えになり、
  実質は「余っている層のうち番号が小さいもの（層 3）」を選ぶ。**結果として選ばれた層 3 は低頻度側の隣の層であり、
  「最も近い」という意図とは矛盾しない**が、規則の記述がこの場合を想定していないことは記録に値する
- **この補いが S-2 の合否を動かすか**: 動かさない、と評価する。次の 3 つを計算した（いずれも参考であり、事前登録の規則ではない）:
  1. 記録どおり層 3 から 24 個補う（事前登録の実装） → 99 パーセンタイル 1.0254、SenMayo 1.0929 で**合格**
  2. 不足の 24 個を「全体の余りから無作為に」補う → 99 パーセンタイル 1.0012 で**合格**
  3. 頻度 0 の SenMayo 24 個を最初から除いて 98 個で組み直す → 99 パーセンタイル 1.0262 で**合格**
  どの補い方でも SenMayo の d は上回る。**補いの選択は S-2 の合否を左右しない**
- なお、頻度 0 の 24 個は全細胞で 0 であり分母が 122 に固定なので、**SenMayo の d には寄与しない**
  （98 個版でも d = 1.0929 で変わらない）。差が出るのは無作為集合の側だけである

## 3. 限界（判定を覆すものではないが、レポートに必ず書くべきもの）

1. **提供者を単位にすると有意でない**（§2.9）。細胞レベルの Welch p = 1.5×10⁻¹¹ は、提供者に繰り返しのある細胞では過大評価でありうる。
   両状態を持つ 7 人での対応比較は片側 p ≈ 0.11〜0.14。**効果量・有意性の記述は「細胞を単位とした場合」と限定する**
2. **S-2 の余裕が小さい**。無作為集合の平均 d 0.553 に対し SenMayo 1.093、99 パーセンタイル 1.025 を超える余裕は 0.067（約 0.35 sd）。
   1,000 組中 3 組が SenMayo を上回った
3. **陽性対照が無い**（PI 承認済み）。手法の健全性は陽性対照では確認していない
4. **SenMayo 122 個の 19.7%（24 個）が区間で未検出**で、得点は実質 98 個。リストの 5 分の 1 は寄与しない
5. **盲検でない 5 個が重なる**。ただし除いても結論は変わらない（d = 1.050）
6. **A2 の区間内でも検出遺伝子数が 1.13 倍違う**。機械的な正の相関が残る
7. **A1 は判定に使わない**。A1 も同じ向きだが、独立な追試ではなく、無作為集合の平均 d が −0.42 と A2 と逆
8. **手続きの小さな不一致**（判定には無関係）: A1 の乱数の鍵が事前登録の 20261013 でなく 20261012（§2.6）。
   plan §12 のチェックリスト #3〜#6 が「未」のまま（§2.7）。`gene_list.n_in_A1_var` が `null`（実際は 122/122 が A1 にもある）。
   plan §4.2 の「990 番目と 991 番目の平均」は numpy 既定の値と厳密には一致しない（差 0.00047、合否に影響なし）
9. **in silico の結果である**。発現の特徴を測っただけで、細胞が老化していることの確認ではない（仮説 §8-7）
