# 実験レポート: EXP-20261007-002 — 著者ラベル「退化した線維芽細胞」は、細胞老化の遺伝子リストの得点が参照より高いか（段階 1）

- 状態: 確定
- 対象の仮説: [HYP-20261007-02](../../hypotheses/HYP-20261007-02.md) — 著者ラベルの「退化した線維芽細胞」は細胞老化の発現特徴を持ち、活性化した間質の状態とは別の方向として測れる（段階 1。摂動を使わない発現データの検定）
- 作成: Labretary / 2026-10-11（本文は report-writer が作成）
- 承認: PI 2026-10-11「結論は固定してください」（ゲート G3）

## 要旨（5 行以内。結論を先に）

1. 予測: 腎臓アトラス（KPMP）の単一細胞 RNA-seq で、著者ラベルの退化した線維芽細胞は、参照の腎線維芽細胞より、細胞老化の遺伝子リスト（SenMayo、122 個）の得点が高い（効果量 0.5 以上、片側 p < 0.05）。
2. 実測: 検出遺伝子数を 1,000〜2,000 にそろえたうえで、得点は参照 81 細胞が 0.135（標準偏差 0.045）、退化 93 細胞が 0.182（標準偏差 0.041）。効果量（Cohen's d）1.093、片側 p = 1.5×10⁻¹¹ で、事前に決めた主判定を満たした。
3. 特異性の条件（頻度をそろえた無作為 122 遺伝子 1,000 組の 99 パーセンタイル 1.025 を超える）と検出された遺伝子数への依存の条件（そろえる前 2.110 → 後 1.093、比 0.518）も満たし、反証条件はどれも当たらなかった。
4. 意味: この単一細胞データで測れる範囲で、退化のラベルの細胞が細胞老化の遺伝子群をより多く検出する**ことが示唆される**。ただし提供者を単位にすると有意でなく、特異性の余裕も小さい（限界で述べる）。
5. 次にどうするか: 段階 2（候補 8 個が「活性化した間質の方向」と「細胞老化の方向」で分離するか）に進む（PI 指示 2026-10-11）。

## 1. 目的と狙い

- **何を知りたいのか**: 本研究の主題は細胞老化である。しかし現在の目標の状態（活性化した間質）は細胞老化を測っていない。原著（Lake ら 2023、PMID 37468583）は「退化した線維芽細胞」という命名の根拠に細胞老化の総説を引いているが、これは命名上の参照であって、その細胞が老化細胞だと示されたわけではない。**摂動を使わずに**、著者ラベルの退化した線維芽細胞が、細胞老化の遺伝子リスト（SenMayo）の得点を参照（腎線維芽細胞）より高く持つかを検定する。
- **なぜ今この実験が必要なのか**: これまでの 11 回の実験は細胞老化を一度も測っていない。段階 1 が不合格なら段階 2（候補遺伝子が「活性化した間質の方向」と「細胞老化の方向」のどちらへ動くかの分離）には着手しない、という 2 段階の入口に当たる。
- **この実験で答えが出ること**: 検出された遺伝子数の分布をそろえた区間で、著者ラベルの退化した線維芽細胞 93 細胞の SenMayo 得点が参照 81 細胞より高いか（効果量と片側 p）／その差が発現頻度をそろえた無作為な遺伝子集合より大きいか（特異性）／差が検出された遺伝子数の分布で説明されないか（検出された遺伝子数への依存）。
- **この実験で答えが出ないこと**: 細胞が実際に老化しているか（測るのは発現の特徴であり、老化そのものではない）／三次リンパ組織が作られるか（この実験は三次リンパ組織を測らない）／ヒトの腎臓で起きること（コンピュータ上の計算）／新規の候補遺伝子（既知リストの確認的な検定であり、探索ではない）。

## 2. 背景

- 腎臓の三次リンパ組織は、加齢や障害が続く腎臓に後天的にできるリンパ組織様の構造である。本研究の目的は、腎臓の三次リンパ組織と細胞老化に関わる**正しい遺伝子を見つけること**である。
- 使う主データは腎臓アトラス（KPMP）である（Lake ら 2023, Nature 619:585-594, PMID 37468583）。同じ研究は単一細胞 RNA-seq 版と単一核 RNA-seq 版を公開しており、両者で**退化した状態と検出遺伝子数の関係が逆**である（単一核では退化のほうが少なく、単一細胞では多い）ことを仮説 §2.1 が正面から扱っている。**したがって検出遺伝子数をそろえない比較には意味がない。**
- 細胞老化の指標は SenMayo（Saul ら 2022, Nat Commun 13:4827, PMID 35974106）の 125 遺伝子リストを一次情報から取得して固定した。本仮説を書く前に検出率を数えてしまった小さな遺伝子の集まり（CDKN2A・IL6・IL1B・CXCL8・SERPINE1・GLB1・LMNB1・MMP3）は、盲検でないため**判定に使わない**。
- これまでの経緯: HYP-20261007-01（EXP-20261007-001）で、活性化した間質へ寄せる候補 8 個の効果が単一細胞 RNA-seq でも再現することを確かめた（主判定は合格、遺伝子ごとは 2 個合格）。その次の一手として、細胞老化との接続を扱う本仮説の段階 1 を実施した。

### 3.4 比べたもの（対照）と、成功・失敗をどう判定するか

**得点の定義（結果を見る前に固定）**: 細胞 1 個の得点＝SenMayo の 122 遺伝子のうち生カウント > 0 のものの**割合**。発現量の大きさは使わない。分母は常に 122 に固定する（細胞ごとに変えない）。標準化は、区間の中の参照 81 細胞だけから出した平均 0.1346・標準偏差 0.0454 による（PI 判断 2026-10-11）。この標準化の選び方は効果量にも p にも影響しない。

結果を見る前に決めた判定基準は次のとおり（番号ではなく内容で示す）。

- **主判定**: (i) 向き＝退化の得点の平均 > 参照の平均、(ii) 効果量（Cohen's d）**0.5 以上**、(iii) 有意性＝**片側 p < 0.05**（等分散を仮定しない 2 標本の t 検定、Welch。対立仮説は「退化 > 参照」）。3 つすべてを満たせば合格。この条件の最小検出可能効果量は 0.38（n = 81 対 93、片側 α = 0.05、検出力 80%。d = 0.5 のときの検出力は 0.95）。参考値を併記するため、等分散を仮定する t 検定と Mann-Whitney U 検定（いずれも片側）の p も出した。
- **特異性の条件**: 発現頻度の分布をそろえて無作為に引いた 122 遺伝子の **1,000 組**で同じ比較を行い、**SenMayo の効果量がその 1,000 組の効果量の 99 パーセンタイルを厳密に超える**こと（主判定と同時に満たす必要がある）。
- **検出された遺伝子数への依存の条件**: そろえる前の効果量とそろえた後の効果量を両方報告し、**そろえた後がそろえる前の 3 分の 1 未満に落ちていないこと**。
- **反証条件（どれかに当たれば支持されない・判定不能・着手しない）**: 効果量が 0.5 未満／得点の大小の向きが逆／特異性の条件を満たさない／そろえた後の効果量がそろえる前の 3 分の 1 未満（判定不能）／使える遺伝子が 25 個未満（判定不能）／どちらかの状態の細胞が 30 未満（着手しない）。
- **対照**: 陽性対照は置いていない（PI 承認済みの設計）。あるのは発現頻度をそろえた無作為集合（陰性対照）だけである。
- **判定を変えない記録**: 提供者を 1 人ずつ除いたときの効果量と p、他の検定の p、区間を変えた版、得点の分布、提供者の内訳。

## 4. 結果

すべてコンピュータ上の計算である（実験的に確認された事実ではない）。図は作っていない（数表のみ）。

### 4.1 得点の分布（判定に使った区間）

| 状態 | 細胞数 | 提供者数 | 得点の平均 | 標準偏差 | 中央値 |
|---|---|---|---|---|---|
| 参照（FIB） | 81 | 31 | 0.135 | 0.045 | 0.131 |
| 退化（dFIB） | 93 | 11 | 0.182 | 0.041 | 0.180 |

- 0 や 1 に張り付いた細胞はどちらの状態にも無かった。

### 4.2 主判定 — 合格

| 条件 | 基準 | 実測 | 判定 |
|---|---|---|---|
| 向き | 退化 > 参照 | 0.182 > 0.135 | 満たす |
| 効果量 | 0.5 以上 | 1.093 | 満たす |
| 有意性 | 片側 p < 0.05 | 1.5×10⁻¹¹ | 満たす |

- 参考（判定は Welch）: 等分散を仮定する t 検定 片側 p = 9.5×10⁻¹²、Mann-Whitney U 検定 片側 p = 1.6×10⁻¹²。
- **事前に決めた主判定の 3 条件をすべて満たした。**

### 4.3 特異性の条件 — 合格

- 頻度をそろえた無作為 122 遺伝子 1,000 組の効果量の **99 パーセンタイルは 1.025**。SenMayo の効果量 **1.093** がこれを厳密に超えた。
- 参考: 無作為集合の効果量の平均は 0.553、標準偏差 0.19、最小 −0.056、最大 1.255。SenMayo を上回った無作為集合は 1,000 組中 3 組で、経験的な片側割合は 0.004。

### 4.4 検出された遺伝子数への依存の条件 — 合格

| 版 | 効果量 | 細胞数（参照 / 退化） |
|---|---|---|
| そろえる前 | 2.110 | 252 / 903 |
| そろえた後 | 1.093 | 81 / 93 |

- 比は **0.518** で、3 分の 1（0.333）を下回らなかった。**差の大部分が検出遺伝子数で説明される、とは言えない。**

### 4.5 反証条件 — どれも当たらない

- 効果量が 0.5 未満（非該当）／得点の大小の向きが逆（非該当）／特異性の条件を満たさない（非該当）／そろえた後の効果量がそろえる前の 3 分の 1 未満（非該当）／使える遺伝子が 25 個未満（実際は 122 個。非該当）／どちらかの状態の細胞が 30 未満（実際は 81 と 93。非該当）。
- 事前に決めた評価の順に当てた結果、最初に当たった条件は無く、**主判定・特異性の条件・検出された遺伝子数への依存の条件がすべて成立した。**

### 4.6 提供者を 1 人ずつ除く確認（記録。判定は変えない）

- 区間の提供者 35 人から 1 人ずつ除いて計算した。効果量の範囲は 1.026〜1.283、**効果量と p の基準を満たした残し方は 35/35**、向きが逆になった残し方は 0 だった。

### 4.7 盲検

- 盲検中の 5 遺伝子（TP53・CDKN1A・LTBR・SPP1・LCN2）は、出力・ログ・得点一覧のどこにも現れなかった（混入 0 件）。SenMayo の 122 個からは SPP1 を機械的に除いてある。

### 4.8 副次（単一核 RNA-seq。判定に使わない）

- 同じ向きで、効果量 1.025、片側 p = 4.6×10⁻⁴⁰ だった。参考の 99 パーセンタイルは 0.0541。
- **設計上、判定には使わない。** 単一核 RNA-seq では細胞老化の遺伝子の検出率が 1% 前後以下であり、この副次が不合格でも段階 1 の判定には影響しない（事前登録のとおり）。

## 5. 考察

- 結果が何を意味するか: 検出された遺伝子数の分布をそろえた単一細胞 RNA-seq の区間で、著者ラベルの退化した線維芽細胞は、参照の腎線維芽細胞より、SenMayo 122 遺伝子の検出割合が高い**ことが示唆される**。事前登録した規則（主判定・特異性の条件・検出された遺伝子数への依存の条件）を当てると段階 1 の基準を満たし、PI がゲート G3 で支持を確定した（2026-10-11）。**ただし効果量と有意性の記述は「細胞を単位とした場合」に限定する**（限界 1）。
- 別の説明の可能性:
  - 検出遺伝子数を 1,000〜2,000 にそろえても、区間の中で退化の検出遺伝子数の中央値 1,504 は参照 1,326 の **1.13 倍**残る。検出数の多い細胞ほど SenMayo も検出しやすいという機械的な正の相関が残り、これが差の一因でありうる。
  - 頻度をそろえた無作為集合でも平均で 0.553 の「退化側が高い」成分が残る（主判定の閾値 0.5 より大きい）。SenMayo の 1.093 は「一般的な成分に SenMayo 固有の上乗せが加わった値」と読める。特異性の条件はこの一般成分を除くために置いており、SenMayo は 99 パーセンタイルを超えたが**余裕は小さい**（限界 2）。
  - 細胞が提供者に繰り返し入るため、等分散を仮定しない t 検定の p は細胞を独立とみなしており、過大評価でありうる（限界 1）。
- 予想と違った点: 主判定は事前の予測どおり合格したが、**いちばん余裕が小さかったのは特異性の条件**だった（無作為集合の平均がすでに閾値を超え、99 パーセンタイルとの差は 0.067）。検出された遺伝子数への依存の条件（比 0.518）も余裕は大きくない。

## 6. 限界

検証担当（`validation.md`）が必須とする限定を、そのまま写す。

1. **提供者を単位にすると有意でない。** 両方の状態を持つ提供者は 7 人だけで、提供者単位の対応比較は片側 p ≈ 0.11〜0.14 で 0.05 を下回らない。細胞単位の p = 1.5×10⁻¹¹ は、**提供者への繰り返し（同じ人の細胞が複数入る）で過大評価でありうる**。**退化の 93 細胞の 49%（46 細胞）は提供者 163-2 の 1 人**である。
2. **特異性の余裕が小さい。** 無作為集合の効果量の平均がすでに 0.553（主判定の閾値 0.5 を超える）。99 パーセンタイルとの余裕は 0.067（無作為集合の標準偏差 0.19 の約 0.35 倍）で、1,000 組中 3 組が SenMayo を超えた。
3. **陽性対照が無い**（PI 承認済みの設計）。手法が働いていることの確認は、特異性の条件（頻度をそろえた無作為集合）のみである。
4. SenMayo 122 個のうち **24 個（19.7%）はこの区間で未検出**で、得点は実質 98 個で決まる。分母は 122 に固定しているので効果量には影響しないが、「122 個のリストの得点」という表現はこの点を留保して読む必要がある。
5. 前に検出率を数えた 5 個（IL6・IL1B・CXCL8・SERPINE1・MMP3）をそのまま使っている（PI 判断）。**この 5 個を除いた 117 個でも効果量 1.050 で、結論を支えていない**（参考。事前登録の規則ではない）。
6. **単一核の一致は支持の根拠に格上げしない。** 単一核 RNA-seq は判定に使わない設計であり、独立な追試でもない（同じ研究・同じ提供者を含む）。**無作為集合の効果量の平均が単一核では −0.42 で、単一細胞と逆**である。副次の数値を主の効果量と並べて「2 手法で再現」とは書かない。
7. 検証で見つかった手続きの小さな不一致（単一核 RNA-seq の無作為集合の乱数の指定が、事前登録の 20261013 ではなく 20261012 で実行されていた）。**乱数の指定を直しても単一核の結論は変わらない**（99 パーセンタイルが 0.1145 になるが、効果量 1.025 は大きく超える）。判定への影響は無い。

仮説 §8 から写す限界（結果を見る前に書いたもの）。

8. **退化した状態と検出遺伝子数の関係が、2 つの測定手法で逆**である。このラベルは測定手法に強く依存する。
9. **退化した状態は提供者が 11 人しかいない**（区間の中で）。特定の提供者に依存しうる。
10. **発現の特徴を測るだけであり、細胞が老化していることの確認ではない。**
11. 副の指標 8 個は盲検でない。判定に使わない。
12. **コンピュータ上の計算である。** 「示唆される」までで、実験的事実としては書かない。
13. 文献との一致・不一致は判定の根拠にしない。
14. 得点は「検出の有無」だけを見る。1 カウントでも高発現でも同じ 1 として数える。

## 7. 次のアクション

- **コンピュータ上で行うこと**: **段階 2 に進む**（PI 指示 2026-10-11）。段階 2 は、候補 8 個（MADCAM1・CXCL13・CCL21・CA12・ZFHX3・SLC4A9・GSN・ELN）が「活性化した間質の方向」では合格し「細胞老化の方向」では合格しない（2 つの方向が分離する）かを、前の実験の保存済み埋め込みで確かめる（段階 2 に新しい摂動は要らず、GPU 時間は 0 時間）。着手条件は「1 点でも満たさなければ着手しない」3 条件（段階 1 の合格・退化の方向の陽性対照 20 個以上・対照遺伝子で、退化の方向への標準得点が入力の長さおよび発現細胞数と相関しない〔相関係数の絶対値 0.20 以下〕）で、**このうち段階 1 は合格した**。残る 2 条件は本レポートの範囲外で、進める前に確認が必要である。
- **実験室で行うこと（提案。本実験はコンピュータ上であり提案にとどまる）**: ヒト腎線維芽細胞の初代培養で、SA-β-ガラクトシダーゼ染色と分裂停止を指標に、退化した状態のマーカーと細胞老化が同じ細胞で共存するかを確かめる（仮説 §9）。

## 8. このレポートで使った用語

| 用語 | 意味 |
|---|---|
| 腎臓アトラス（KPMP） | ヒト腎臓の単一細胞データ。本研究の主データ（Lake ら 2023, PMID 37468583） |
| 単一細胞 RNA-seq | 細胞 1 個ずつの遺伝子発現を測る手法。今回の判定に使った測定手法 |
| 単一核 RNA-seq | 核を 1 つずつ測る手法。検出率が低い遺伝子がある。今回は副次に使っただけ |
| 提供者 | 検体を提供した患者・ドナー 1 人 |
| 腎線維芽細胞 | 腎臓の間質にある線維芽細胞系の細胞。今回は参照の状態（著者ラベル FIB） |
| 退化した線維芽細胞 | 原著が「退化（degenerative）」と命名した線維芽細胞。今回は比較対象（同 dFIB）。**細胞が老化していると示されたものではない** |
| 検出遺伝子数 | 細胞 1 個で検出された遺伝子の数（`nFeature_RNA`）。今回は 1,000〜2,000 にそろえた |
| 生カウント | 正規化していない発現の実測値。今回は「検出＝生カウント > 0」に使う |
| SenMayo | 細胞老化に関連する 125 遺伝子のリスト（Saul ら 2022, PMID 35974106）。今回は A2 で使える 122 個を固定して使った |
| 得点（SenMayo 得点） | SenMayo の 122 個のうち検出されたものの割合。分母は常に 122 |
| 標準化 | 参照 81 細胞だけから出した平均 0.1346・標準偏差 0.0454 で得点を割り直すこと |
| 効果量（Cohen's d） | 2 群の平均の差をプールした標準偏差で割った値。今回は 0.5 以上を合格の基準にした |
| 主判定 | その実験で結論を決める 1 つの予測。今回は「退化の得点が参照より高く、効果量 0.5 以上、片側 p < 0.05」 |
| 特異性の条件 | 頻度をそろえた無作為 122 遺伝子 1,000 組の 99 パーセンタイルを SenMayo の効果量が超えること |
| 検出された遺伝子数への依存の条件 | そろえた後の効果量が、そろえる前の 3 分の 1 未満に落ちていないこと |
| 反証条件 | 結果を見る前に決めた、支持されない・判定不能・着手しないと読む条件。今回はどれも当たらなかった |
| 対照遺伝子群 | ここでは、発現頻度をそろえた無作為な 122 遺伝子の 1,000 組。陰性対照に当たる |
| 陽性対照 | 効果が出ると期待される既知の遺伝子。手法が働いているかの確認に使う。今回は置いていない |
| 提供者を 1 人ずつ除く検証 | 結論が特定の提供者に依存していないかの確認。今回は記録のみで判定は変えない |
| 盲検 | 手法の妥当性が確認できるまで、本命の遺伝子の結果を見ないこと（TP53・CDKN1A・LTBR・SPP1・LCN2） |
| 事前登録 | 結果を見る前に判定基準を文書に固定すること |
| 支持された | 事前に決めた基準を満たした |
| 判定不能 | 対照が働かないなど、判定できる状態になかった |
| 単精度（float32） | 計算の数値形式。今回はこれで計算し、GPU は使っていない |
| ゲート G3（結論確定） | 結果の判定（支持・否定・判定不能）を確定する PI の判断 |
