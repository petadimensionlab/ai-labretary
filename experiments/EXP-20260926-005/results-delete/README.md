## 注意（分類器 logits の扱い）
- start 細胞で P(PT_healthy) の中央値は 0（99 パーセンタイル 1.2e-3）で**分類器が飽和**している。|ΔP| の 99 パーセンタイルは 6e-5 で、遺伝子平均の ΔP は少数の細胞（|ΔP| > 0.01 は 0.3%）に支配される
- さらに logits は **bf16 の forward から出るため 2^-5 = 0.031 刻みに量子化**されており（`logits_*.npy` は float32 だが値は bf16 格子）、Δ(logit 差) が厳密に 0 の細胞が 53%。ΔP 系の指標（dP_raw, dP_a2, 探索的 dM_raw）は情報量が小さく、C4 の seed 間一致 0.27、細胞単位の長さ相関 −0.82 もこの量子化・飽和の影響と考えられる。**ΔP 系は判定の補助にとどめ、主指標 a2 で判断する**
