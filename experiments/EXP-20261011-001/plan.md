## 0. 目的と、この実験で何が決まるか

### 0.1 大きな目的とのつながり

本研究の目的は、腎臓の三次リンパ組織と細胞老化に関わる**正しい遺伝子を見つけること**である。
これまでの測り方（1 つの目標の状態への射影）は、活性化した間質と退化した状態の 2 本の向きを
区別して読めなかった（HYP-20261007-02 段階 2、EXP-20261007-003 で 2 本の遺伝子セットの平均スコアがほぼ同じ）。

この実験は、その区別を測れるようにする**方法の仮説**（HYP-20261011-01）を検証する。

- **P-1（方法の検証。確認は A1）**: 2 本の向きの**差**（`u_diff`）への射影 `z_diff` が、
  活性化の陽性対照（71 個）と退化の陽性対照（30 個）を**反対側に分離**するか。
  通れば、この測り方が使える。順位表を「活性化した間質に固有」「細胞老化に固有」「共通」に分けられる（CLAUDE.md §3.5）
- **P-2・P-3（候補 8 個の固有性。探索）**: 段階 2 で「2 本で値が同じ」だった原因が、
  「候補 8 個はどの目標にも固有でなく、共通の向きに動く」ことだと説明できるか（P-2：`z_diff` は 0 と区別できない、P-3：共通の向きで基準超）

## 4. 判定の規則（**事前登録。結果を見る前に固定する。config.yaml の decision: に同じ値が書いてあり、評価コードが照合する**）

### 4.1 指標の定義（仮説 §2 をそのまま。**式を変えない**）

| 語 | 定義 |
|---|---|
| 向き 1（活性化した間質） | `u_ada = unit(aStr) − unit(start)`、正規化。（A2 の start=FIB、A1 の start=FIB_MFIB） |
| 向き 2（退化した状態） | `u_deg = unit(dFIB) − unit(start)`、正規化 |
| **差の向き** | `u_diff = (u_ada − u_deg) / ‖u_ada − u_deg‖` |
| **共通の向き** | `u_common = (u_ada + u_deg) / ‖u_ada + u_deg‖` |

- 細胞ごとの値: `m = (d · u) / ‖d‖`（`d = pert − orig`。分母は移動の大きさ。**evaluate_013 と同じ式**）
- 移動量 0 の細胞: **外す前の表で 2 本（u_diff・u_common）とも射影を計算し、外す細胞 ID を後で除く。向きごとに表を作らない**（guardrails 2026-10-11）
- 層別補正: `evaluate_009.gene_stats_stratified`（発現の有無で層別した二次式 `lp`・`ll`。**実装を変えない**）
- 標準化: 群ごとに、そのデータの対照プール（A2: **510** / A1: **549**）の `D_raw` の平均・標準偏差で `z` にする
- `z_diff`＝差の向きの標準得点、`z_common`＝共通の向きの標準得点。集合の値は遺伝子セットの平均スコア（標準得点の平均）

### 4.2 主判定 P-1（方法の検証。**確認は A1**）

A1 の 3 群すべてで、次の (i)(ii)(iii) が成り立つ:

- **(i)** 活性化の陽性対照 71 個の遺伝子セットの平均スコア `z_diff` が**正**で、サイズを揃えたランダム遺伝子セット 1,000 組（71 個、A1 のプール 549 から復元あり）の**99 パーセンタイルを超える**
- **(ii)** 退化の陽性対照 30 個の遺伝子セットの平均スコア `z_diff` が**負**で、サイズを揃えたランダム遺伝子セット 1,000 組（30 個）の**1 パーセンタイルを下回る**
- **(iii)** 2 つの遺伝子セットの平均スコアの差（活性化 − 退化）が、大きさ 71 と 30 の無作為な 2 セット（独立に復元ありで引く）の差の**99 パーセンタイルを超える**

- 効果量の目安（**併記のみ**）: 4.5/√K → 71 個 0.53・30 個 0.82。粗い式 6.63/√K → 0.79・1.21（仮説 §5.2・§10）
- **最小検出可能効果量は、判定規則そのものをシミュレートして事前に出した**（`analysis/power_014.py` → `work/power_014.json`）:
  同時（(i)∧(ii)∧(iii)）で **MDE ≈ 0.66 z**（seed 間相関 ρ=実測 0.964。ρ=0〜0.9 で 0.63〜0.71）。
  条件ごと: (i) 0.32・(ii) 0.66・(iii) 0.35（ρ=実測）。**粗い式ではなくこの値を報告に使う**（guardrails 2026-09-30）
- 偶然の水準: 片側 1% に較正した規則。評価時に A1 のプール 549 で「サイズを揃えたランダム遺伝子セット 1,000 組の合格率」を実測し、
  1% から外れていないかを**記録**する（判定には使わない。`乱数の鍵: 20261022`）
- **P-1 が通ったときに言えるのは「この測り方は 2 本の向きを分離できる」まで**。特定の遺伝子の生物学的な主張ではない（仮説 §5.3）

### 4.3 副次（探索。A2 を主、A1 を従とする。**確認的な主張はしない**）

> **P-2**: 候補 8 個の遺伝子セットの平均スコア `z_diff` が、A2 の 3 群すべてでサイズを揃えたランダム遺伝子セット 1,000 組（8 個）の 99 パーセンタイル**以内**（0 と区別できない）であり、かつ、活性化の陽性対照 71 個の遺伝子セットの平均スコアより**小さい**。

- 閾値は「A2 で実測したサイズを揃えたランダム遺伝子セットの 99 パーセンタイル」を使う（仮説 §5.4。段階 2 の 0.80〜0.92 とは別に A2 で測り直す）
