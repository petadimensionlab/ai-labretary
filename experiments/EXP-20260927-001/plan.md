## 1. 問い
1. 過剰発現型の摂動で、細胞ごとに「移動距離」（摂動遺伝子の元の位置 = 最上位へ動かす距離）と入力の長さで偏りを補正し、分布の重なる null 遺伝子とだけ比べると、元の位置との交絡は除けるか（検定が較正（calibration。計測分野の「校正」(JIS Z 8103) とは別語）され、残差相関が消えるか）

## 5. 対照の選定（ISP の結果を使わない。`analysis/select_genes.py`）
### 5.1 null 遺伝子プール（推奨 1: 発現頻度と元の順位の両方でそろえる）
- 候補: Geneformer 辞書に収載、出発点で 300 細胞以上・10 提供者以上で入力に入る、|log2FC（出発点 vs 目標）| < 1.0、除外リスト（EXP-004 の既知リスト＋本実験の追加カテゴリ、§5.2 の文献確認で除外した遺伝子、HMGB1・MGST1・MAPKAPK2）に入らない、比較遺伝子と重ならない
- 固定 18 遺伝子それぞれについて、距離 d_n = max(|ln(細胞数比)| / ln 1.5, |Δlog2(1+元の位置の中央値)| / 0.25, |Δlog2(入力の長さの中央値)| / 0.25) の小さい順に 3 遺伝子（重複なし）→ 54 遺伝子（`work/null_pool.json`）
- 主検定で「使える null 遺伝子」（§6.1）の数（seed 11/12/13）: 陽性対照 22〜50（ESRRA の seed 12 が 22 で最少）、恒常発現遺伝子 27〜41、中立対照パネル 32〜51、比較遺伝子 27 以上。VCAM1 は 7〜15 で判定不能になりうる（参考の対照のみ）。null 遺伝子のうち AQP1・TMEM176A・RNASEK は一部の seed で 20 未満（較正の計算から外れる）

### 5.2 発現をそろえた比較遺伝子群（推奨 2）
- 考え方: 過剰発現型の陽性対照のうち HNF4A・ESRRA・PPARA は健常側で高く、NFE2L2 は修復不全側で高い。分類器は出発点と目標を分けるよう学習しているので、「健常側で高い遺伝子を足すと健常へ動く」だけなら駆動因子の証拠にならない。そこで、各陽性対照と**発現差・発現頻度・相対順位・元の位置**がそろい、既知の駆動因子でない遺伝子を 5 つずつ選び、それを上回ることを合格条件にする

- 除外: 自動（EXP-004 と同じ既知リスト・カテゴリ＋本実験の追加: PT の同一性の転写因子・核内受容体、脂肪酸酸化・ミトコンドリア生合成・エネルギー代謝の調節因子、NRF2 経路、OXPHOS・リボソーム等の接頭辞）と、文献知識による確認（距離順に現れた遺伝子すべてに判断・理由・不確実性を記録, `work/comparator_candidates.csv`）

## 6. 評価指標と判定基準（事前登録, ISP 実行前）
細胞ごとの値 y = 目標状態への接近度（補正前, `cells.csv` の `shift_goal`）。位置 lp = log2(1 + 元の位置)、長さ ll = log2(入力の長さ)。実装は `analysis/evaluate_matched.py`。

### 6.1 主検定: 移動距離をそろえた並べ替え検定
1. **偏り補正**: seed ごとに、null 遺伝子の細胞（対象遺伝子が null ならそれを除く）で y を lp・ll の 2 次式（1, lp, ll, lp², ll², lp·ll）に最小二乗で当てはめ（f）、各細胞の補正値 y − f(lp, ll) を作る。遺伝子の値 D_raw = 補正値の遺伝子平均
2. **重なる null 遺伝子だけと比べる**: 対象の細胞 i と null 遺伝子 h の細胞 j の距離 d = max(|lp_i − lp_j|, |ll_i − ll_j|)。対象の細胞の 80% 以上に d ≤ 0.5 の細胞を持つ h を「使える null 遺伝子」とする（移動距離と長さの分布が重なるもの）。20 未満なら、その遺伝子×seed は判定不能（NaN）
3. **分位** q = 使える null 遺伝子のうち D_raw が対象より小さい割合（遺伝子ラベルの並べ替え。帰無仮説は「対象は重なる null 遺伝子と交換可能」）

**区間内パーセンタイル検定ではなくこちらを主検定にした理由**:
- EXP-005 の事後検証で、元の位置を区間に分けた補正は区間の中に相関が残り、交絡がほとんど縮まなかった（seed4 +0.47 → +0.45〜+0.50）。区間内パーセンタイル検定も同じ「区間」の構造を持つ（区間を 50 に細かくしても、境界の置き方に依存し、区間内の傾きは残る）
- 主検定は区間を使わず、連続値の補正（2 次式）と「分布が重なる null 遺伝子だけを相手にする」制約を組み合わせる。比較の単位を遺伝子にしているので、遺伝子ごとのばらつき（遺伝子間の分散）がそのまま帰無分布に入る
- 較正を直接確かめられる（null 遺伝子自身を対象にしたときの分位の分布, §6.3 の判定基準: 較正）
- 合成データでの検査（`analysis/synthetic_check.py`, `work/synthetic/`）: 元の位置と長さに強く依存する見かけの効果を入れたデータで、交絡だけなら合格 0（判定「否定」）、真の効果を陽性対照 2 つに入れると 2 つとも合格（判定「支持」）。較正は上位 10% の割合 0.104・下位 10% 0.097（期待 0.10）、null の残差相関 |ρ| ≤ 0.06。同じデータで長さだけの補正（EXP-005 の長さ補正した接近度）では残差相関 0.81〜0.85
- 検査の途中で 2 回設計を直した（結果を見る前）: (i) 許容幅の中で単純にマッチさせるだけでは、分布の端の細胞ほど中央寄りの null 細胞が引かれる偏りが残った（残差相関 0.16〜0.45）→ 2 次式の偏り補正を追加、(ii) 1 つの null 遺伝子の細胞から重複ありで疑似遺伝子を作る方式は、null 間のばらつきを過大にして保守的になった（上位 10% の割合 0.02）→ 遺伝子ラベルの並べ替えに変更。経緯は `logs/progress.md`

### 6.2 副検定（判定に使わない）
- **区間内パーセンタイル検定**: seed ごとに null 細胞（対象を除く）で長さ 5 分位 × 各長さ区間の lp 10 分位 = 50 区間を作り、対象の細胞ごとに同じ区間の null 細胞の中での y の分位を求め、遺伝子平均 − 0.5 を W とする。分位 = null 遺伝子の W（自分を除いて計算）の中での位置。主検定と同じ基準を当てはめて一致を報告する
- **参考**: EXP-005 と同じ長さ補正した接近度（長さ 5 分位の null 平均を引く）と、その null 分位（比較の連続性のため）
- 方向対照（VCAM1・HAVCR1）の分位 ≤ 0.50 が 3 seed 中 2 以上（参考）

### 6.3 判定基準（主検定）
| 基準（用語集の名前） | 内容 | 合格ライン |
|---|---|---|
| 判定基準: 陽性対照の分離 | 陽性対照ごとに下の 3 条件を**すべて**満たす遺伝子の数 | 6 中 **2 以上** |
| 　(a) null からの分離 | q ≥ 0.90 | 3 seed 中 2 以上 |
| 　(b) 恒常発現遺伝子との差 | 同じ seed で D_raw が ACTB・GAPDH・PPIA を上回る組 | 9 組中 **7 以上** |
| 　(c) 比較遺伝子群との差（新規） | 同じ seed で D_raw が自分の比較遺伝子 5 つのうち **4 以上**を上回る | 3 seed 中 2 以上 |
| 判定基準: 恒常発現遺伝子の中立性 | ACTB・GAPDH・PPIA の q が 0.10〜0.90（NaN は範囲外） | 3 遺伝子とも 3 seed 中 2 以上 |
| 判定基準: 中立対照パネルの中立性 | 7 遺伝子の q が 0.10〜0.90 | 5 遺伝子以上が 3 seed 中 2 以上 |
| 判定基準: 較正（新規） | null 遺伝子自身を対象にした q（自分を除いた null と比較, 3 seed 合算） | q ≥ 0.90 の割合と q < 0.10 の割合がともに **≤ 0.20**（期待 0.10）。計算できた null×seed が 60 以上 |
| 判定基準: 交絡の除去（新規） | null 遺伝子の D_raw と、遺伝子ごとの lp の中央値・相対位置の中央値の Spearman ρ | 両方とも **\|ρ\| ≤ 0.25** が 3 seed 中 2 以上 |
| 参考: 非マーカー性 | 合格遺伝子に EXP-005 の ddet_pct ≤ 0.80 のもの（PPARGC1A 0.29, CPT1A 0.41, PPARA 0.60, ESRRA 0.61）がある | 示唆のみ |

**閾値の根拠（偶然合格する確率）**: 帰無仮説のもとで 1 seed で q ≥ 0.90 になる確率 ≈ 0.10（使える null が約 45 なら離散化で 0.09〜0.11）、3 seed 中 2 以上 ≈ 0.028。条件 (c) は交換可能性のもとで 1 seed あたり 2/6 = 0.33、3 seed 中 2 以上で 0.26。(a) だけでも 6 遺伝子中 2 以上が偶然合格する確率は ≈ 0.012（EXP-005 と同じ）、(a)(c) が独立なら 1 遺伝子あたり ≈ 0.007、6 中 2 以上で ≈ 0.001。(a) と (c) は正に相関するので実際の偶然合格率はその間（0.001〜0.012）。較正の上限 0.20 は、期待 0.10 に対し null 遺伝子が約 50（seed 間で同じ遺伝子なので実効 n は約 50）のとき二項分布で約 2.3 SD 上。交絡の除去の |ρ| ≤ 0.25 は、n ≈ 50 で真の相関 0 のとき 1 seed で超える確率 ≈ 0.08、3 seed 中 2 以上で不合格になる確率は約 0.02〜0.06。EXP-005 の null 20 遺伝子の値（seed 3 で 0.51）はこの基準で検出される

### 6.4 判定規則（事前登録, 上から順に適用）
1. 較正または交絡の除去が不合格 → **判定不能**（移動距離をそろえても交絡が残る／検定が較正されていない）
2. 恒常発現遺伝子の中立性または中立対照パネルの中立性が不合格 → **判定不能**（系が中立でない）
3. 陽性対照の分離（(a)(b)(c) をすべて満たす遺伝子が 2 以上）→ HYP-20260927-01 を**支持**。合格遺伝子に ddet_pct ≤ 0.80 のものがあれば「分離は分類器マーカーの付加だけでは説明できない」ことが**示唆される**（断定しない）
4. (a) を満たす遺伝子は 2 以上だが、(a)(b)(c) すべてを満たすのは 1 以下 → **否定**（null からは分離するが、恒常発現遺伝子または発現をそろえた比較遺伝子群と区別できない）
5. (a) を満たす遺伝子が 1 以下 → **否定**（移動距離をそろえた null から陽性対照が分離しない）
- 判定は主検定だけで行う。副検定・参考指標・提供者単位の指標が主検定と食い違っても判定は変えず、食い違いとして報告する
- 評価コードが出す `verdict_proposal` は提案であり、確定は PI（G3）。仮説の Status は変更しない

### 6.5 提供者単位の副指標（推奨 3。判定規則は変えない）
細胞ごとの補正値 r_i = y_i − （同じ seed の null 細胞のうち d が最も近い 50 個の、偏り補正した値の平均 ＋ f(lp_i, ll_i)）（対象が null ならその遺伝子を除く）を使う。
| 指標 | 定義 |
|---|---|
| 提供者ごとの null 超過の符号一致 | 遺伝子×seed×提供者で r を平均（細胞 3 未満の提供者は除く）→ 3 seed で平均 → 値 > 0 の提供者の割合。null 遺伝子の同じ割合の分布での分位（自分を除く） |
| 提供者を単位とした符号順位検定 | 上の提供者平均（14 人前後）で片側 Wilcoxon（参考） |
| 提供者間で変動する成分を分けた推定 | 遺伝子ごとに r ~ 1 + seed（和の対比）+（1 ∣ 提供者）の混合モデル（statsmodels MixedLM, REML）。切片（提供者の違いを除いた平均効果）・その標準誤差と z・提供者の分散・級内相関 |
| 提供者を 1 人ずつ除く検証 | 主検定で合格した陽性対照について、提供者を 1 人ずつ除いて (a) をやり直し、合否が変わる提供者の数 |
| 折半信頼性（遺伝子集合を固定） | seed ごとに提供者 14 人を 7 人 / 7 人に無作為に分ける（20 回, 乱数 seed 0）。各半分で遺伝子ごとの r の平均を出し、**固定した 102 遺伝子**（と固定 18 遺伝子の部分集合）の Spearman ρ を計算。平均・最小・最大・Spearman–Brown 補正を、遺伝子数 n = 102 / 18、各半分の提供者数 7 / 7、分割 20 回と一緒に報告。参考ライン 0.7（判定に使わない） |

## 9. 想定される失敗と対策
| 事項 | 対策・扱い |

## 10. 限界（事前に明記）
1. **EXP-005 の結果を見た後に作った計画である。** 移動距離をそろえるという方法の選択、null を元の位置でそろえる設計は、EXP-005 run O の探索的な結果（元の位置と効果の相関、事後検証で HNF4A・PPARA・NFE2L2 が上位に残ったこと）に動機づけられている。対策として、判定は 6 遺伝子すべてに対する件数で決め、特定の遺伝子に絞らない。seed・細胞（陽性対照の細胞の 18〜53% は EXP-005 と重なる）・null・比較遺伝子・判定条件は新しいが、出発点の細胞の母集団・提供者・モデルは同じなので、**独立な再現ではなく同じデータでの再検定**である
2. 比較遺伝子を「駆動因子でない」とした判断は知識に基づく（系統的な文献調査ではない）
3. 修復不全側と健常側で提供者が完全に分かれており、状態の違いと提供者の違いを分離できない（研究報告 §6）。提供者単位の副指標は出発点側の提供者のばらつきしか扱えない
4. 過剰発現型の摂動は「発現細胞で順位を最上位へ」であり、遺伝子導入ではない
5. 偏り補正の 2 次式が真の関係を近似しきれない可能性がある（判定基準: 交絡の除去で検出する。感度分析 §7）
6. in silico の結果であり、支持されても「このモデルが文献の保護因子の過剰発現を健常方向への移動として表す」ことが示唆されるにとどまる
