## 統合の妥当性（plan §A.4）
再実行した VCAM1・GAPDH（3 seed）と EXP-003 seed 3 の null 遺伝子 1 つ（ENSG00000112297）で、細胞（cell_uid の並び）・状態のセントロイドベクトル・細胞ごとの shift_goal / shift_start / ΔP の差は**すべて厳密に 0**（許容 1×10⁻⁶）。同じ機械・同じ config・同じ seed なら再現は完全 → EXP-003 の null・陽性・HK・パネルと統合して評価した。既存遺伝子の a2 は DE 遺伝子を加えても変わらない（補正は null 細胞だけで推定。最大差 < 1×10⁻¹²）

## 付随する所見（同じく事前登録）
- **A-S2: DE マッチ 10 遺伝子のうち 3 つ（AKAP12 3 seed、PPFIBP1 2 seed、ADAMTS16 2 seed）が C1 と同じ基準（null 上位 10% が 3 seed 中 2 以上）を満たす** → 現在の C1 は「駆動因子」に特異的ではない。aPT で上昇する非ドライバー遺伝子でも 30% が合格する（偶然合格率 10% の 3 倍）
- A-S3: DE 10 遺伝子の null 分位の平均は seed ごとに 0.54 / 0.55 / 0.66（帰無 0.5）。遺伝子単位（3 seed 平均）の Wilcoxon 片側 p = 0.22 → 「上昇遺伝子の除去一般が goal 方向へ動く」という全体的な偏りは、この 10 遺伝子では有意ではない。ただし個々の値の幅は大きい（AKAP12 0.95・PPFIBP1 0.87・ADAMTS16 0.83 vs ANKRD2 0.07・ARRDC4 0.15）
- ΔP(PT_healthy)（分類確率）では DE 10 遺伝子とも C1 基準を満たさず（0/10）、VCAM1 の分位も 0.75/0.90/0.60 と埋め込み指標より弱い

## 解釈（示唆。in silico の所見であり実験的事実ではない）
- VCAM1 の効果は「aPT マーカーを消したこと」だけでは説明できない大きさで、FT 分類器の埋め込みでこの遺伝子が特に強く使われていることが**示唆される**。ただし駆動因子であることの証拠ではない（分類器が VCAM1 を最も重みづけしている可能性と区別できない）
- 一方で C1（null 上位 10%）という基準そのものは駆動因子に特異的でない（非ドライバー 3/10 が合格）。今後は「null との比較」に加えて「DE マッチ群との比較」を合否に入れるのが妥当
- 限界: DE マッチ遺伝子の「非ドライバー」判断は知識に基づく判断で、系統的な文献検索ではない（AKAP12 は不確実性が高いと事前に記録。実際に最も大きく動いた DE 遺伝子でもある）。VCAM1 帯の距離は 0.98〜1.51 と完全一致ではなく、VCAM1 は帯内で最も発現細胞数が多い（4,674 vs 2,539〜3,761）
