## 1. 問い
1. 1 遺伝子 delete で、すべての遺伝子が goal・start・alt の全セントロイドから離れる「削除ドリフト」を差し引くと、陽性対照（VCAM1, HAVCR1）がランダム null とハウスキーピング遺伝子（HK: ACTB, GAPDH, PPIA）の両方から分離する指標は作れるか
2. その指標は細胞長・発現頻度の交絡が小さく、seed や細胞の抽出に対して安定か
3. コサイン変化だけ（EXP-001 の保存物）で足りるか、摂動変位ベクトル（e_pert − e_orig）が必要か

方法の検証であり、生物学的な仮説の検証ではない。主要対象（TP53/CDKN1A/LTBR）の再評価は、指標が決まり PI が承認した後に行う（§4.3）。

### 6.0 盲検化
- 指標の選定は **対照遺伝子だけ**（陽性 VCAM1/HAVCR1、HK GAPDH/PPIA/ACTB、発現頻度マッチのランダム null）で行う。主要対象 TP53/CDKN1A/LTBR と参照 SPP1/LCN2 の行は、解析スクリプトで読み込み直後に除外し（`assert` で確認）、新しい指標の値は計算していない。phase 0 の run でも主要対象・参照は回していない（`controls_only: true`）

### 6.1 候補指標
- raw: `shift_goal`（EXP-001 の主要指標）
- d: `shift_goal − shift_start`（EXP-001 で G2 に追加した差分指標。ベースライン）
- a1: 細胞ごとの null 平均を引く（同じ細胞を摂動した null 遺伝子の shift_goal の平均）。重なりが足りない細胞は a2 で代替
- a2: 細胞長ビン（null 細胞の長さ 5 分位）ごとの null 平均 shift_goal を引く
- b: null の細胞で shift_goal ~ shift_start + shift_alt を最小二乗で当て（run ごと）、残差の細胞平均
- c: 長さビンごとの null の平均・SD で shift_goal を z 化
- 各指標の null は、null 遺伝子自身の評価では leave-one-gene-out で推定
- （計算時に追加した同系統の変種: a3 = log 長 + donor の回帰で null を引く、a4 = log 長 + 削除位置の回帰、d2/d4 = d に a2/a4 と同じ補正）

### 6.2 方法妥当性の基準（対照のみ。run 1 tls_high が主、run 2 tls_low は再現確認）
| # | 基準 | 合格ライン |
|---|---|---|
| C1 | 陽性 vs null | VCAM1・HAVCR1 がそれぞれ同 seed の null の上位 10%（分位 ≥ 0.90）に 3 seed 中 2 以上 |
| C2 | 陽性 vs HK | 陽性 2 × HK 3 × 3 seed = 18 組のうち陽性 > HK が 15 組以上（≥ 83%） |
| C3 | HK は null の中 | GAPDH・PPIA・ACTB の null 分位が 0.10〜0.90 の範囲に 3 seed 中 2 以上（3 遺伝子すべて） |
| C4 | 安定性 | (i) seed 内で donor を 2 群に分けた split-half の遺伝子順位 Spearman（25 遺伝子, 20 回平均）≥ 0.7、(ii) seed 間で固定対照 5 遺伝子の順位 Spearman 平均 ≥ 0.7（参考, n = 5） |
| C5 | 交絡 | 遺伝子×seed 単位の指標と平均細胞長・発現細胞数の Spearman |ρ| ≤ 0.3。細胞単位（遺伝子内）の長さとの Spearman 中央値 |ρ| ≤ 0.2 |
| 付記 | null の中心 | null の負の割合を記録（補正後は 0.5 付近が期待値。合否には使わない） |

- **選定規則**: C1〜C3 をすべて満たし、C4・C5 の合格数が最も多い指標を採用。同数なら C2 の陽性−HK 差（null SD 単位）が大きい方。C1〜C3 を満たす指標がなければ「コサインのみの補正では不十分」と結論し、ベクトル水準の補正（phase 0）に進む
- ベクトル水準の指標（摂動変位 Δ から一般的な削除方向を除いて start→goal 方向へ射影）も phase 0（seed 0, 同じ細胞, 対照のみ）で C1〜C3・C4(i)・C5 により評価（1 seed なので C1/C3 は 1/1 を合格とする）

**(C) 解釈**
1. ドリフト自体は差し引ける: null の負の割合は raw 1.00 → a2・b・V1〜V4 で 0.42〜0.50（中心化される）
2. しかし **start→goal 軸（d, V 系）では、ドリフトを除いても GAPDH・PPIA が null の最上位に残る**。seed 0 で GAPDH の delete は 80%、PPIA は 71% の細胞で Δ が goal 側を向く（null 中央値 43%）。一様なドリフトでは説明できず、**HK の delete が埋め込み空間で start→goal 軸に沿った方向性の変化を持つ**ことが示唆される。HK は rank 符号化上も状態中立でない（入力内の相対位置 aPT − PT_healthy: GAPDH +0.14、PPIA −0.16、null 20 遺伝子の中央値 +0.03。1,500 細胞ずつ）
3. ベクトル水準の補正は、軸への射影ではコサイン差分 d とほぼ同じ情報しか持たない（d は Δ·(ĝ − ŝ) の 1 次近似。V0 と d の結果は一致）。ベクトルは「ドリフトの成り立ち」の診断には有用だが、今回の基準では指標を改善しなかった
4. HK を null 内に戻せたのは **goal 方向だけを見て細胞長ビンで null を差し引く a2 系**だけ（run 1・run 2・phase 0 の 3 データで C2・C3・C5 合格）。a2 の弱点は C1（VCAM1: 3 seed 平均 0.70 / 0.77、phase 0 では 0.95）と **C4（split-half ρ 0.06〜0.43）**
5. 全指標共通の制約: 100 細胞/遺伝子では split-half ρ が 0.26〜0.65 にとどまり、null・対照の遺伝子間差の多くが細胞抽出のばらつきで決まっている（C4 は全指標で不合格）

### 6.4 本番（§4.2）で確認する事前登録（本番データを見る前, 2026-09-26）
- **主指標: a2**（長さ 5 分位ビンごとの null 平均 shift_goal を細胞ごとに引き、遺伝子で平均）。選定理由: C1〜C3 を 3 seed で満たす指標はなかったが、C2・C3・C5 を 3 データすべてで満たした唯一の指標で、残る不合格（C1 の VCAM1、C4）はいずれも細胞数不足で説明しうる。ベクトル指標は HK を分離できず採用しない
- 副指標（比較のみ）: raw, d, d2, c, V2, V2L
- 合否: §6.2 の C1〜C5 をそのまま適用（seed 3–5, 200 細胞/遺伝子）。**C1〜C3 を満たせば a2 を「採用可」、C4・C5 も満たせば「確定」**。C1〜C3 のどれかが不合格 → HYP-20260926-01 は棄却（この系・この埋め込みでは補正後も陽性対照の特異的信号を検出できない）→ 主要対象の再評価は行わず、陽性対照か goal の定義を見直す
- split-half ρ の予測（Spearman-Brown, 50 細胞の半分で 0.43 → 200 細胞）: 0.75
- 補足解析（合否に使わない）: HK の方向性（Δ が goal 側を向く細胞の割合）、半径成分の割合、細胞長ビン数 3/5/10 での感度

## 9. 想定される失敗と対策
| 失敗 | 対策 |
|---|---|
| a2 が本番でも C1（VCAM1）不合格 | 棄却として報告。陽性対照の妥当性（VCAM1 は aPT での検出率 62% だが PT_healthy でも 6%）や goal 定義の見直しを次の案にする |
| HK が再び null 上位（C3 不合格） | HK の方向性（§6.3 C-2）を報告し、「HK は start→goal 軸で中立ではない」可能性を PI に提示。基準の変更（状態中立な遺伝子を陰性対照にする等）は PI の判断を仰ぐ（本実験の中では変えない） |
| 200 細胞に届かない遺伝子（HAVCR1 は発現細胞 659） | donor ≤ 25 で 14 donor なら 200 は確保できる見込み。届かなければ実数を記録（min 100） |
