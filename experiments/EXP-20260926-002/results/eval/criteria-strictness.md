# 評価基準は厳しすぎたか（HYP-20260926-01, EXP-20260926-002 案 A）

- 作成: Labretary / 2026-09-26（PI の問い「評価基準が厳しすぎるかどうか、厳しすぎないという根拠があれば示して」への回答。G3 で refuted と判定）
- 対象: 主指標 a2、案 A（対照のみ, 200 細胞 × seed 3/4/5, Pretrained, bf16）。数値は `criteria.csv`, `gene_seed_metrics.csv` から計算

## 結論
**厳しすぎたとは言えない。** HK に依存しない基準（C1 と C4）だけでも否定になる。
ただし C2（陽性 > HK）は、比較相手の HK が start と goal で発現差を持つため、比較相手の選び方として厳しすぎた可能性がある。C2 を外しても結論は変わらない。

## 根拠
### 1. C1（陽性対照が null 上位 10%, 3 seed 中 2 以上）は偶然では通りにくいが、効果のある遺伝子には通りやすい
- 効果のない遺伝子が偶然通る確率: 1 遺伝子 **5.5%**、陽性 2 つとも **0.3%**（null 20 遺伝子 → 上位 10% = 21 中上位 3）
- 実測の a2 分位（seed 3/4/5）: VCAM1 **0.70 / 0.60 / 0.70**、HAVCR1 **0.90 / 0.70 / 0.75**

| C1 の閾値 | VCAM1 | HAVCR1 | 効果のない遺伝子の偶然合格率（1 遺伝子 / 2 遺伝子とも） |
|---|---|---|---|
| 0.90（事前登録） | ✗ | ✗ | 5.5% / 0.3% |
| 0.80 | ✗ | ✗ | — |
| 0.75 | ✗ | ✓ | — |
| 0.70 | ✓ | ✓ | **25.9% / 6.7%** |

→ 両方が通るのは閾値 0.70 まで緩めたときだけで、その場合は効果のない遺伝子でも 26% が偶然通り、判定の意味がほとんどなくなる

### 2. C4（split-half ρ ≥ 0.7）はどの指標も満たさない
- 18 通りの指標の最大は **0.685**（指標 b）、a2 は **0.32**
- 細胞数を 100（案 B, 0.38）→ 200（案 A, 0.32）に倍にしても改善しない → 順位は donor の分け方で入れ替わる（不安定さの主因は細胞数ではなく donor 間の違い）

### 3. C1 と C4 を同時に満たす指標は 0
- どちらも HK を使わない基準

### 4. C2（陽性 > HK, 18 組中 15 以上）について
- 比較相手の HK 自体が start–goal 間で発現差を持つ（GAPDH log2FC −0.98, q < 0.001）→ 比較相手として厳しすぎた可能性
- ただし結果は **10/18** で、陽性と HK に差がないときの期待値とほぼ同じ（差がなくても 10/18 以上になる確率 **0.41**。事前登録の 15/18 以上は 0.004）
- 事後の比較（事前登録外）: 陽性 > 陰性対照パネル 7 遺伝子は a2 で 36/42。ただし HK と RP も同様に上位に来るため、陽性対照の特異性は示されていない

## 否定の範囲
否定されたのは「この設計（Pretrained、1 遺伝子 delete、CLS 埋め込み）で、提案した補正指標を使えば陽性対照を分離できる」という主張。VCAM1・HAVCR1 に生物学的な意味がないことを示したわけではない。

## 追記（EXP-20260926-003, FT モデル）
同じ基準を FT モデルに当てはめると C2（16/18）・C3・C3-panel（7/7）は合格し、C1 は HAVCR1 だけが不合格（0.45 / 0.75 / 0.75）。基準は FT モデルでは大部分が満たせる水準であり、Pretrained で満たせなかったのは基準の厳しさではなくモデル側（削除ドリフト）の問題だったことを支持する。
