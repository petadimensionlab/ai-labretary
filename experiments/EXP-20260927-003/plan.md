## 1. 問い

三次リンパ組織が多い提供者の腎線維芽細胞（出発点の状態）で、**LTBR・RELB・NFKB2**（LTβR–非古典的 NF-κB 軸）を過剰発現させると、細胞の状態が**三次リンパ組織オーガナイザー様の線維芽細胞**（目標の状態）へ近づくか。近づくとして、それは

1. 対照遺伝子群（移動距離と入力の長さをそろえたもの）より大きいか
2. 恒常発現遺伝子より大きいか
3. 発現をそろえた比較遺伝子群より大きいか
4. **筋線維芽細胞のセントロイドへの接近より大きいか**（＝「線維化の方向へ動いただけ」ではないか）

を、結果を見る前に決めた基準で判定する。CDKN1A（p21, 細胞老化側）は §4.2 の理由で**参考対象**とし、主判定には数えない。

## 4. 摂動の設計

### 4.1 循環性の回避（最重要）

目標の状態のラベルは **CCL19 / CCL21 / CXCL13 の検出そのもの**で定義されている。したがって

- **この 3 遺伝子は摂動対象から外す。** 仮説にあった「健全性チェックとしての CCL19 / CXCL13 の過剰発現」は、ラベルを定義する遺伝子を入力の最上位へ動かす操作であり、目標の状態へ近づくのは定義上ほぼ自明である。**判定には使わない**
- さらに、本実験の過剰発現型の摂動は「その遺伝子が入力に載っている細胞で、順位を最上位へ移す」操作である（§4.3）。出発点の状態は 3 遺伝子がすべて 0 の細胞なので、**この 3 遺伝子が入力に載る出発点の細胞は 0 個であり、対象としてそもそも成立しない**（`work/gene_stats_fib.csv` で確認: CCL19 / CCL21 / CXCL13 いずれも出発点での細胞数 0）
- 参考として回す場合でも（本計画では回さない）、**新規性の主張には一切使わない**ことをここで固定する
- パイプラインが「セントロイドへの接近」を検出できることの確認は、代わりに**筋線維芽細胞のセントロイドに対する ACTA2 / TAGLN の効果**で行う（§5, §6.3 の判定基準: パイプラインの陽性対照）。このセントロイドは著者の細胞種ラベルで定義され、ACTA2 / TAGLN の検出では定義されていないので、循環性は目標の状態ほど強くない

### 4.2 摂動する遺伝子（84 遺伝子。全 seed 共通の固定リスト）

| 役割 | 数 | 遺伝子 | 出発点での細胞数（提供者数） |
|---|---|---|---|
| **主対象**（新規予測） | 3 | LTBR / RELB / NFKB2 | 573 (22) / 616 (22) / 255 (19) |
| **参考対象**（主判定に数えない） | 1 | CDKN1A | **43 (13)** |
| パイプラインの陽性対照 | 2 | ACTA2 / TAGLN | 1,411 (22) / 1,216 (22) |
| 恒常発現遺伝子 | 3 | ACTB / GAPDH / PPIA | 2,642 / 656 / 865 |
| 中立対照パネル | 7 | CERS4, TATDN1, IFT25, VAPA, PHPT1, ANAPC16, EEF1D | 377〜1,598 |
| 比較遺伝子群 | 20 | 主対象 3 × 5 ＋ 参考対象 1 × 5（§5.2, `work/comparators.csv`） | 30〜673 |
| 対照遺伝子群（null） | 48 | 固定 15 遺伝子 × 3 ＋ CDKN1A 用の低頻度 3（§5.1, `work/null_pool.json`） | 38〜3,078 |

**CDKN1A が対象として成立するかの確認（指示 9 への回答）**: 単一核データのため CDKN1A の検出率は出発点で **0.75%（43 細胞 / 5,748 細胞、13 提供者）** しかなかった（`work/gene_stats_fib.csv`）。主対象の 100 細胞に対し 43 細胞では

- 提供者あたり上限 15 を当てても 43 細胞すべてを使い切る → **seed を変えても同じ細胞になる**（seed 間で変わるのは状態のセントロイドだけ）
- 発現頻度をそろえた比較遺伝子・対照遺伝子も 30〜60 細胞の低頻度遺伝子に限られ、その多くは単一核データでは周辺 RNA 由来の可能性がある

ため、**CDKN1A は参考対象とし、主判定（§6.3・§6.4）には数えない**。結果は報告するが、合格しても「示唆される」にとどめ、仮説の細胞老化側の枝については**事前に判定不能とみなす**。力のある検定にするには、非発現細胞への遺伝子導入型（Geneformer の `overexpress_tokens` は非発現細胞にも適用できる）に設計を変えた別の実験が必要で、それは本計画の枠組み（移動距離をそろえた検定）が使えないため新たな事前登録を要する。

**盲検**: LTBR と CDKN1A は盲検リスト（TP53, CDKN1A, LTBR, SPP1, LCN2）の遺伝子である。§11 のとおり、**PI による盲検解除の指示を得るまで実行しない**。TP53 / SPP1 / LCN2 は本実験でも回さず、評価コードが読み込み直後に除外して assert する。

### 4.3 摂動の種類と細胞の選び方

- **過剰発現型の摂動**（`overexpress`）。定義は EXP-20260927-001 と同じ「その遺伝子が入力に載っている細胞で、順位を最上位へ移す」。遺伝子導入ではない
- 遺伝子ごとに、出発点の細胞のうちその遺伝子が入力に載るものから **100 細胞・提供者あたり 15 細胞以下**（最少 30。参考対象と低頻度の対照はこれを下回らない）
- seed **21 / 22 / 23**（既出の 0〜5・11〜13 と重ならない）。seed ごとに細胞の抽出と状態のセントロイドをやり直す
- 実行可能性は摂動の前に確認済み（`work/precheck_coverage.json`）: 84 遺伝子 × 3 seed = 252 組のうち、主対象・恒常発現遺伝子・中立対照パネル・比較遺伝子・対照遺伝子はすべて規定の細胞数を確保。延べ **23,643 細胞×遺伝子**、使う出発点の細胞は重複を除いて **5,268 細胞**（全 5,748 細胞中）
- `perturbation.nproc: 1`（guardrails 2026-09-26）

### 4.4 入力の長さの交絡への対処（指示 4 への回答）

目標の状態の細胞は出発点より検出された遺伝子数が多い（中央値 2,050 対 1,538）。何も補正しないと、状態のセントロイドそのものが「入力の長さの方向」にずれ、**入力の長さを大きく見せる摂動はどれでも目標に近づいたように見える**。対策を 2 か所に入れる。

1. **状態のセントロイドを検出された遺伝子数の分布をそろえた後の細胞から作る**（新規。`run_isp.py` に `state_embs.rows_file` を追加して実現）
   EXP-20260927-002 と**同じ手順**: 状態ごとに 800 細胞・提供者あたり 60 細胞で抽出 → 目標（および対照）の各細胞に、log(トークン長)が最も近い出発点の細胞を 1 つずつ、置換なしで対応付ける（許容 |Δlog| ≤ 0.10）。対応の付いた細胞だけをセントロイドに使う。
   seed ごとの結果（`work/depth_match_summary.json`、摂動の前に確定済み）:

   | seed | 目標のセントロイドに使う細胞 | トークン長の中央値（目標 / 出発点） | 対照の状態のセントロイド |
   |---|---|---|---|
   | 21 | 610 | 1,669.5 / 1,670.5 | 695 |
   | 22 | 613 | 1,672.0 / 1,661.0 | 688 |
   | 23 | 599 | 1,646.0 / 1,646.0 | 682 |

   出発点のセントロイドも、この対応付けで選ばれた出発点の細胞（599〜613）を使う。**検出された遺伝子数の分布をそろえない目標のセントロイドも別に作り、感度分析として接近度を並べて報告する**（判定には使わない）。

2. **遺伝子の比較で長さをそろえる**（EXP-20260927-001 から継承）
   対照遺伝子は「発現頻度・元の位置・入力の長さの中央値」の 3 つで主対象にそろえて選ぶ（§5.1）。主検定は、細胞ごとの偏り補正（元の位置 log2(1+pos) と長さ log2(len) の 2 次式）を引いたうえで、**移動距離と長さの分布が重なる対照遺伝子だけ**を並べ替えの相手にする（§6.1）。さらに判定基準: 交絡の除去で、対照遺伝子の値が元の位置・相対位置・**入力の長さ**と相関しないことを確かめる（§6.3）。

### 5.1 対照遺伝子群（48）の選び方 — `analysis/select_genes_fib.py`

- 候補: 出発点で **300 細胞以上・10 提供者以上**で入力に載る、|log2 発現比（出発点 対 目標）| < 1.0、自動除外リストに入らない、比較遺伝子と重ならない
- 距離 d = max( |ln(細胞数比)| / ln 1.5, |Δlog2(1+元の位置の中央値)| / 0.25, |Δlog2(入力の長さの中央値)| / 0.25 )
- 固定 15 遺伝子（主対象 3・陽性対照 2・恒常発現遺伝子 3・中立対照パネル 7）それぞれに距離の近い 3 遺伝子 → 45。CDKN1A には低頻度の候補（30〜150 細胞・8 提供者以上）から 3 → **合計 48**
- **発現頻度だけでそろえた対照は使わない**（guardrails・EXP-20260926-005 の交絡）。元の位置と入力の長さを必ず含める
- 自動除外（候補を見る前に決めた）: NF-κB 経路とその上流受容体、三次リンパ組織のケモカイン・接着分子、細胞老化・DNA 損傷応答、線維化・筋線維芽細胞化、インターフェロン、低酸素・Notch・Wnt・Hippo、および接頭辞（NFKB, TRAF, CCL, CXCL, CCR, CXCR, TNFSF, TNFRSF, IL*, COL, SMAD, IFI, ISG, HLA-, IGH/IGK/IGL, MMP, TIMP, CDKN, WNT, FZD, NOTCH, JAK, STAT, SERPIN, LOXL, TLR, MT-, RPL/RPS/MRPL/MRPS ほか）
- 最初の抽出で現れた候補を文献知識で点検し、17 遺伝子を追加で除外した（理由は `work/null_pool.json` の `null_exclude`。例: RBCK1 = 直線状ユビキチン鎖による NF-κB 活性化、CCND1 = 細胞周期停止、TNC / LUM = 線維化の細胞外基質、B2M = 老化促進因子の報告）

**実行可能性（摂動の前に確認）**: 主検定で「使える対照遺伝子」の数は、主対象 30〜48、恒常発現遺伝子 41〜43、中立対照パネル 22 以上、比較遺伝子 28 以上、CDKN1A 47（下限 20 を全て満たす）。対照遺伝子自身では ASXL2 の seed 23 だけが 18 で、その組は較正の計算から外れる。

### 5.2 比較遺伝子群（20）の選び方 — `analysis/select_genes_fib.py`

考え方は EXP-20260927-001 と同じ。各対象について、**発現差・発現頻度・相対位置・元の位置**がそろい、本系（腎線維芽細胞・三次リンパ組織・細胞老化）の駆動因子と考えられていない遺伝子を 5 つずつ選ぶ。
距離 d = max( |Δlog2 発現比| / 0.5, |ln(細胞数比)| / ln 1.5, |Δ相対位置| / 0.10, |Δlog2(1+元の位置)| / 0.25 )。

| 対象 | 比較遺伝子（距離） | 「駆動因子でない」判断の不確実性 |
|---|---|---|
| **LTBR**（log2 発現比 +0.15, 573 細胞, 元の位置 1,158） | HOXA6 (0.21) / MTIF3 (0.23) / ATP6V1B2 (0.25) / OAT (0.25) / SPG21 (0.29) | 中 / 低 / 低 / 低 / 低 |
| **RELB**（−0.62, 616, 973） | SLC26A7 (0.35) / SHC3 (0.62) / MEGF9 (0.64) / OSBPL3 (0.65) / VPS35 (0.67) | 低 / 中 / 低 / 低 / 低 |
| **NFKB2**（−1.16, 255, 1,436） | ECH1 (0.63) / ARL2 (0.74) / CCT8 (0.96) / KIAA0040 (0.98) / LONRF2 (0.99) | 低 / 低 / 低 / 低 / 低 |
| CDKN1A（参考, −0.54, 43, 1,381） | GAD1 (0.44) / ASTN1 (0.52) / CYTIP (0.52) / S100A1 (0.61) / GPR34 (0.62) | 低 / 低 / 中 / 中 / 中 |

文献確認で除外した候補と理由は `work/comparator_candidates.csv` に全件記録した（例: TBRG1 = ARF・MDM2 と結合し p53 経路に関わる、TRIB2 = NF-κB・MAPK の調節、AGTR1 = 腎の炎症・線維化の主要な駆動因子、TGM2 = TGF-β 活性化を介した線維化、FRZB = Wnt 拮抗因子）。
NFKB2 の比較遺伝子は距離がやや大きい（0.63〜0.99）。NFKB2 は発現差が大きく（log2 −1.16）、かつ元の位置が下位（1,436）という組み合わせの遺伝子が少ないためで、**NFKB2 の条件 (c) は他の 2 遺伝子より甘い**ことを限界として明記する。

## 6. 評価指標と判定基準（事前登録。結果を見る前に固定）

細胞ごとの値 y = 目標状態への接近度（`cells.csv` の `shift_goal`、**正 = 目標へ近づく**）。位置 lp = log2(1 + 元の位置)、長さ ll = log2(入力の長さ)。実装は `analysis/evaluate_fib.py`（EXP-20260927-001 の `evaluate_matched.py` と同じ主検定）。

### 6.1 主検定: 移動距離をそろえた並べ替え検定

1. **偏り補正**: seed ごとに、対照遺伝子の細胞（対象遺伝子自身は除く）で y を lp・ll の 2 次式（1, lp, ll, lp², ll², lp·ll）に当てはめ（f）、各細胞の補正値 y − f(lp, ll) を作る。遺伝子の値 D_raw = 補正値の遺伝子平均
2. **重なる対照遺伝子だけと比べる**: 対象の細胞 i と対照遺伝子 h の細胞 j の距離 d = max(|lp_i − lp_j|, |ll_i − ll_j|)。対象の細胞の 80% 以上に d ≤ 0.5 の細胞を持つ h を「使える対照遺伝子」とする。20 未満なら、その遺伝子 × seed は判定不能（NaN）
3. **対照遺伝子群の中での順位** q = 使える対照遺伝子のうち D_raw が対象より小さい割合

同じ検定を**筋線維芽細胞のセントロイドへの接近度**（`shift_myof`）にも当てはめ、D_raw(MYOF) と q(MYOF) を出す。

### 6.2 副検定・参考（判定に使わない）

- 区間内パーセンタイル検定（長さ 5 分位 × 元の位置 10 分位 = 50 区間）
- 提供者単位の指標（提供者ごとの符号一致、片側 Wilcoxon、提供者の違いを分けた混合モデル、提供者を 1 人ずつ除く検証）
- 固定遺伝子集合での折半信頼性（提供者を 2 分割、20 回）
- 検出された遺伝子数の分布をそろえない目標のセントロイドへの接近度（感度分析）、対照の状態（`FIB_neg_TLSlow`）への接近度

### 6.3 判定基準

**主対象 1 遺伝子の合格条件** — (a)〜(d) を**すべて**満たすこと。

| 記号 | 名前 | 内容 | 合格ライン |
|---|---|---|---|
| (a) | 判定基準: 対照遺伝子群からの分離 | q ≥ 0.90 **かつ D_raw > 0 かつ 補正前の平均接近度 > 0** | 3 seed 中 2 以上 |
| (b) | 判定基準: 恒常発現遺伝子との差 | D_raw が ACTB・GAPDH・PPIA を上回る組 | 9 組中 **7 以上** |
| (c) | 判定基準: 比較遺伝子群との差 | 同じ seed で D_raw が自分の比較遺伝子 5 つのうち **4 以上**を上回る | 3 seed 中 2 以上 |
| (d) | 判定基準: 状態の特異性 | 同じ seed で **D_raw(目標) > D_raw(筋線維芽細胞)** | 3 seed 中 2 以上 |

**系全体の基準**

| 名前 | 内容 | 合格ライン |
|---|---|---|
| 判定基準: 較正 | 対照遺伝子自身を対象にしたときの q（自分を除いた対照と比較、3 seed 合算） | q ≥ 0.90 の割合と q < 0.10 の割合がともに **≤ 0.20**（期待 0.10）。計算できた組が 60 以上 |
| 判定基準: 交絡の除去 | 対照遺伝子の D_raw と、遺伝子ごとの元の位置の中央値・相対位置の中央値・**入力の長さの中央値**の Spearman ρ | 3 つとも **\|ρ\| ≤ 0.25** が 3 seed 中 2 以上 |
| 判定基準: 恒常発現遺伝子の中立性 | ACTB・GAPDH・PPIA の q が 0.10〜0.90（NaN は範囲外） | 3 遺伝子とも 3 seed 中 2 以上 |
| 判定基準: 中立対照パネルの中立性 | 7 遺伝子の q が 0.10〜0.90 | 5 遺伝子以上が 3 seed 中 2 以上 |
| 判定基準: パイプラインの陽性対照 | ACTA2 または TAGLN が、**筋線維芽細胞のセントロイドへの接近**で q(MYOF) ≥ 0.90 かつ D_raw(MYOF) > 0 | いずれか 1 遺伝子が 3 seed 中 2 以上 |

**符号の扱い（guardrails 2026-09-26）**: 接近度・D_raw を報告するときは必ず符号を併記する（正 = 目標へ近づく）。**比・倍率は判定に使わない**。対照遺伝子群が全て負（全ての遺伝子が目標から離れる）場合、「対照遺伝子群の上位」は「目標へ近づく」を意味しないので、(a) に D_raw > 0・平均接近度 > 0 の条件を入れてある。対照遺伝子の符号分布（`null_frac_negative`）も seed ごとに報告する。

### 6.4 判定規則（事前登録。上から順に適用）

1. 較正 または 交絡の除去 が不合格 → **判定不能**（移動距離をそろえても交絡が残る／検定が較正されていない）
2. 恒常発現遺伝子の中立性 または 中立対照パネルの中立性 が不合格 → **判定不能**（系が中立でない）
3. パイプラインの陽性対照 が不合格 → **判定不能**（セントロイドへ近づく効果を検出できることが示せていない）
4. (a)(b)(c)(d) をすべて満たす主対象が **2 以上**（3 中）→ HYP-20260925-02 の LTβR–非古典的 NF-κB 軸の予測は**支持される**
5. 同 **1 遺伝子のみ** → **一部支持**（その遺伝子について示唆されるにとどめ、仮説全体は支持としない）
6. (a) を満たす主対象が 1 以上だが (a)(b)(c)(d) をすべて満たすものが 0 → **否定**（対照遺伝子群からは分離するが、恒常発現遺伝子・比較遺伝子群・状態の対照と区別できない）
7. (a) を満たす主対象が 0 → **否定**（移動距離をそろえた対照遺伝子群から主対象が分離しない）

- CDKN1A（参考対象）は 4〜7 の件数に**数えない**。結果は報告し、合格しても「示唆される」にとどめる
- 判定は主検定だけで行う。副検定・参考指標が食い違っても判定は変えず、食い違いとして報告する
- 評価コードが出す `verdict_proposal` は**提案**であり、確定は PI（G3）。本計画では仮説の Status を変えない

### 6.5 反証条件（事前登録）

- LTBR・RELB・NFKB2 のいずれも 3 seed すべてで q ≤ 0.80、または D_raw の符号が負（目標から離れる）→ 主要予測は**棄却**
- 恒常発現遺伝子が主対象と同程度以上のシフトを出す（(b) が全滅）→ 非特異的なシフトとして**判定不能**
- 主対象が目標へも筋線維芽細胞へも同じだけ近づく（(d) が全滅）→ **否定**（線維化の方向へ動いただけ）

### 6.6 偶然合格する確率の見積もり

- (a): 帰無仮説のもとで 1 seed に q ≥ 0.90 となる確率 ≈ 0.10（使える対照遺伝子 30〜48 の離散化で 0.08〜0.11）。3 seed 中 2 以上 ≈ **0.028**（seed 間は同じ細胞を多く共有するので独立ではない。上限として 1 seed の 0.10 も併記する）
- (b): 恒常発現遺伝子と交換可能なら 1 組を上回る確率 0.5、9 組中 7 以上 ≈ **0.090**
- (c): 対象と比較遺伝子 5 つが交換可能なら 1 seed で 4 以上を上回る確率 = 2/6 ≈ 0.333、3 seed 中 2 以上 ≈ **0.259**
- (d): 目標と筋線維芽細胞のどちらへ大きく動くかが五分なら 1 seed で 0.5、3 seed 中 2 以上 ≈ **0.500**
- 1 遺伝子が (a)〜(d) をすべて満たす確率は、独立なら ≈ 3.3 × 10⁻⁴。実際には正に相関するので、**上限として (a) だけの 0.028** を使う
- **主対象 3 中 2 以上が偶然合格する確率**: (a) だけで見積もって 3 × 0.028² × 0.972 + 0.028³ ≈ **0.0023**。(a)〜(d) が独立なら 3 × 10⁻⁷ 程度。したがって偶然合格率は **0.0023 以下**と見積もる
- 較正の上限 0.20 は、期待 0.10 に対し対照遺伝子が約 48（seed 間で同じ遺伝子なので実効 n も約 48）のとき二項分布で約 2.3 標準偏差上。交絡の除去の |ρ| ≤ 0.25 は n ≈ 48 で真の相関 0 のとき 1 seed で超える確率 ≈ 0.09

## 10. 限界（事前に明記）

1. **目標の状態は推定ラベルである。** CCL19 / CCL21 / CXCL13 の 1 カウント以上の検出で定義しており、**組織学的な確認をしていない**。実際に三次リンパ組織のオーガナイザーとして機能する細胞であることは示されていない
2. **単一核データのため CDKN1A の検出率が 0.75%（43 細胞）しかない。** 細胞老化側の枝（CDKN1A）は本実験では力のある検定にならず、事前に判定不能としている（§4.2）
3. **皮質と髄質の線維芽細胞が混ざる。** 出発点には M-FIB（髄質）822 細胞、MYOF 1,118 細胞などが含まれる。部位・細胞種を限った感度分析は本実験では行わない（EXP-20260927-002 で参考値として報告済み）
4. **過剰発現型の摂動は「発現している細胞で順位を最上位へ」であり、遺伝子導入ではない。** LTBR を発現していない出発点の細胞（90%）については何も言えない
5. 比較遺伝子を「駆動因子でない」とした判断は知識に基づくもので、系統的な文献調査ではない（literature-scout による確認は未実施）。NFKB2 の比較遺伝子は距離がやや大きい（§5.2）
6. 出発点は三次リンパ組織が多い提供者 22 人に限られ、状態の違いと提供者の違いを完全には分離できない。提供者単位の副指標で安定性を見るが、参考にとどまる
7. 目標の状態の細胞は 65 提供者に広く散らばる一方、出発点は 22 提供者に集中する。検出された遺伝子数の分布はそろえたが、提供者構成の違いはセントロイドに残る
8. 状態の対照（筋線維芽細胞のセントロイド）に使う細胞の多くは出発点の細胞でもある（3 遺伝子陰性の筋線維芽細胞 1,640 のうち 1,132 が出発点）。したがって筋線維芽細胞のセントロイドは出発点のセントロイドに近く、条件 (d) は**目標と筋線維芽細胞のどちらへ強く動くかの相対比較**として読むべきで、「線維化していない」ことの証明ではない
9. **コンピュータ上の結果である。** 支持されても「このモデルが LTβR–非古典的 NF-κB 軸の過剰発現を、三次リンパ組織オーガナイザー様の状態への移動として表す」ことが**示唆される**にとどまり、実験的事実ではない
