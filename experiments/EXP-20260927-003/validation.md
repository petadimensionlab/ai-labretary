## 結論（提案）

1. **判定の提案: 判定不能（inconclusive）。** 事前登録の判定規則を上から順に当てはめると、規則 1（較正（calibration。計測分野の「校正」(JIS Z 8103) とは別語）・交絡の除去）は通過し、**規則 2（恒常発現遺伝子の中立性が不合格）で止まる**。実行担当の提案と一致する。規則 3 以降（パイプラインの陽性対照、主対象の合否）には到達しない。
2. **ただし「判定不能」は、この実験が主要予測を支持する証拠を出したという意味ではない。** 規則 2 を外して最後まで当てはめても、主対象 3 遺伝子はいずれも判定基準 (a)〜(d) を満たさず、規則 7（(a) を満たす主対象が 0）に該当して**否定**になる。つまり判定不能と否定のどちらの経路でも、「LTBR / RELB / NFKB2 の過剰発現が目標の状態へ細胞を動かす」という証拠は得られていない。
3. **GAPDH の非中立は、系の不具合ではなく指標の性質である（(ii) に近い）。** ただし、これまで記録されていた「元の順位が中位で上げしろが大きいから」という説明は**本実験では成り立たない**（後述 §3）。真の原因は、この主指標が「どのセントロイドにも一様に近づく成分」に支配されていて、GAPDH がその成分の最大級の外れ値であることにある。**恒常発現遺伝子の中立性を、過剰発現型・単一セントロイドへの接近度で判定する設計そのものが不適切**である。
4. **検出力は不足している。** この設計で (a) を 3 seed 中 2 以上で満たすのに必要な真の効果は **約 +3.5 × 10⁻⁵**（対照遺伝子群の分布で約 1.7 標準偏差）である。LTBR の観測値は最良の seed でも **+1.7 × 10⁻⁵**（約 0.9 標準偏差）で、最小検出可能効果量（minimum detectable effect）の約半分しかない。EXP-20260927-001 と同じ「対照のばらつきが効果と同じ桁」という問題が本実験にも残っている。
5. **重大な懸念（新規発見）**: 目標の状態への接近度と、出発点の状態・状態の対照（筋線維芽細胞）・対照の状態への接近度が、対照遺伝子間で **ρ = 0.92〜0.96** で連動している。主指標はほぼ「摂動による埋め込みの移動量」を測っており、方向の情報が乏しい。目標に特異的な成分（目標への接近 − 対照の状態への接近）で見ると、**LTBR・RELB・NFKB2 はいずれも対照遺伝子群の下位（分位 0.04〜0.19）**で、目標より対照の状態のほうへ強く動いている。

### 3. 恒常発現遺伝子の中立性が落ちた理由 — GAPDH をどう解釈するか

**結論: (ii) に近い。系の不具合ではなく、主指標の性質と GAPDH の性質の組み合わせで説明できる。したがって、過剰発現型・単一セントロイドへの接近度という設計では、GAPDH は中立性の判定に使えない。** ただし、これまで記録されていた説明（元の順位が中位で上げしろが大きい）は本実験では成り立たず、別の説明に置き換える必要がある。

#### 3.1 「上げしろが大きいから」では説明がつかない（記録の修正）

過剰発現型の摂動は、対象遺伝子を入力の順位列の最上位へ動かす操作なので、「元の位置」がそのまま移動距離になる。`.claude/memory/labretary-level.md` のドメインパターンは、EXP-20260926-005 run O の観測（GAPDH の元の順位が中位 0.71、PPIA 0.55、ESRRA 0.24 で、指標と元の順位の相関 ρ = 0.71）から、GAPDH の非中立を「上げしろが大きいこと」で説明していた。

**本実験では 3 つの恒常発現遺伝子の元の位置がほとんど同じである**（`results/eval/gene_seed.csv` の `relpos_med` = 元の位置 / 入力の長さ、100 細胞の中央値）。

| 遺伝子 | 相対位置 seed21 / 22 / 23 | 元の位置（log2(1+位置)） | 元の位置（おおよその順位） |
|---|---|---|---|
| ACTB | 0.989 / 0.989 / 0.989 | 10.71 / 10.57 / 10.69 | 約 1,680〜1,880 番目 |
| GAPDH | 0.984 / 0.981 / 0.983 | 10.89 / 10.68 / 10.75 | 約 1,640〜1,900 番目 |
| PPIA | 0.972 / 0.974 / 0.974 | 10.83 / 10.92 / 10.77 | 約 1,750〜1,930 番目 |

3 つとも入力のほぼ最後尾（相対位置 0.97〜0.99）にあり、**上げしろは実質的に同じ**である。それでも補正後の接近度は GAPDH +2.35 / +3.94 / +4.97 × 10⁻⁵、ACTB +0.18 / −2.32 / −3.69 × 10⁻⁵、PPIA +0.85 / +1.52 / −0.83 × 10⁻⁵ と大きく分かれる。**「上げしろ」では GAPDH と ACTB の差は説明できない。** ドメインパターンの説明はこの点で修正が必要である（次のアクション参照）。

なお、元の位置・相対位置による交絡は、主検定の偏り補正（元の位置・入力の長さの 2 次式）と、重なる対照遺伝子だけと比べる仕組みで取り除かれており、判定基準: 交絡の除去は元の位置・相対位置で \|ρ\| ≤ 0.16（3 seed とも）と十分小さい。GAPDH の非中立が位置の交絡の残りである可能性は低い。

#### 3.2 主指標は「どのセントロイドにも一様に近づく成分」に支配されている

補正前の平均接近度を、目標の状態・出発点の状態・対照の状態（三次リンパ組織が少ない提供者の、オーガナイザー標識が陰性の腎線維芽細胞）の 3 つで並べると、対照遺伝子 48 の間で強く連動している。

| seed | 目標への接近（対照遺伝子の平均 ± SD） | 出発点への接近（平均） | 目標と出発点の相関 |
|---|---|---|---|
| 21 | +3.25 × 10⁻⁵ ± 1.94 × 10⁻⁵ | +2.33 × 10⁻⁵ | **0.931** |
| 22 | +3.25 × 10⁻⁵ ± 2.12 × 10⁻⁵ | +2.56 × 10⁻⁵ | **0.956** |
| 23 | +3.56 × 10⁻⁵ ± 1.92 × 10⁻⁵ | +2.41 × 10⁻⁵ | **0.928** |

補正後の接近度でも、目標と筋線維芽細胞のセントロイドの間で Pearson 相関 **0.939 / 0.932 / 0.921**（対照遺伝子 48、seed 別）である。

つまり、過剰発現型の摂動には**削除型の「一様な削除効果」の裏返しにあたる「一様な接近」**があり、どの遺伝子を過剰発現させても細胞はすべてのセントロイドへ同じ向きに動く。主指標（目標のセントロイドへの接近度）は、その一様成分を取り除いていない。

#### 3.3 GAPDH はその一様成分の最大級の外れ値である

3 つのセントロイド（目標・出発点・対照の状態）への接近度の平均を「一様な移動量」として 84 遺伝子を並べると:

| 遺伝子 | seed21 順位 | seed22 順位 | seed23 順位 |
|---|---|---|---|
| **GAPDH** | **6 / 84** | **3 / 84** | **1 / 84** |
| ACTB | 35 / 84 | 78 / 84 | 79 / 84 |
| PPIA | 17 / 84 | 19 / 84 | 50 / 84 |
| ACTA2（パイプラインの陽性対照） | 4 / 84 | 9 / 84 | 48 / 84 |

GAPDH は 3 seed とも一様な移動量の上位で、seed23 では 84 遺伝子中 1 位である。一方、**目標に特異的な成分**（目標への接近 − 対照の状態への接近）で見ると:

| 遺伝子 | seed21 | seed22 | seed23 | 対照遺伝子群の中での位置 |
|---|---|---|---|---|
| GAPDH | −3.02 × 10⁻⁵ | −3.83 × 10⁻⁵ | −3.45 × 10⁻⁵ | 0.146 / 0.042 / 0.042（下位） |
| LTBR | −3.32 × 10⁻⁵ | −3.12 × 10⁻⁵ | −3.47 × 10⁻⁵ | 0.104 / 0.062 / 0.042（下位） |

#### 3.4 系の不具合（(i)）ではないと考える理由

- 判定基準: 較正が合格している（対照遺伝子自身を検定したときの上位 10%・下位 10% が 0.126 / 0.105、期待 0.10、n = 143）。検定の帰無分布は正しく作れている。
- 判定基準: 交絡の除去が、元の位置・相対位置について 3 seed とも \|ρ\| ≤ 0.16。位置の補正は働いている。
- 摂動の前に実行された合成データ検査（`work/synthetic/summary.json`）で、交絡だけの場面は「否定」、実効果を入れた場面は「支持」と正しく判定された。
- パイプラインの陽性対照 ACTA2 が、**筋線維芽細胞のセントロイドでは q = 1.000（3 seed とも、補正後の接近度 +1.03 / +0.97 / +0.77 × 10⁻⁴）、目標のセントロイドでは q = 1.000 / 0.938 / 0.316** と、軸によって明確に違う値を出している。指標にはセントロイドの方向を見分ける成分が確かに残っている。
- 欠測は 252 組中 **1 組のみ**（seed23 の対照遺伝子 ASXL2、重なる対照遺伝子が 18 個で下限 20 に届かず判定不能）。計算の取りこぼしによる偏りはない。

以上から、コードの不具合や計算の失敗ではなく、**「過剰発現型 × 単一セントロイドへの接近度」という指標が一様成分に支配されているという設計上の性質**と考える。GAPDH はその一様成分の外れ値であり、中立性の判定に使う対照としては不適切である。

#### 3.5 EXP-20260926-005 run O との関係

2 実験で GAPDH が同じ向きに外れることは再現した（run O: 3 seed とも分位 0.95。本実験: 3 seed 中 2 で 0.95〜1.00）。細胞系・目標の状態・対照の作り方が違うのに同じ向きに出るのは、**GAPDH 固有の性質（過剰発現したときの埋め込みの移動量が大きい）**が原因であることを支持する。ただし説明の中身は違う: run O では元の順位が中位であることが移動量の大きさに寄与していたのに対し、本実験では元の順位が他の恒常発現遺伝子と同じなので、順位以外の要因（モデルの中で GAPDH が占める位置）が効いていることになる。**原因の完全な特定はできていない**が、「過剰発現型では GAPDH を中立性の判定に使わない」という実務上の結論は 2 実験で一貫している。

### 4. seed21 の入力の長さとの相関 −0.489 が結果に与える影響

事前登録では「3 指標とも \|ρ\| ≤ 0.25 が 3 seed 中 2 以上」なので、seed21 の 1 件の逸脱では判定基準: 交絡の除去は合格のままである（規則 1 では止まらない）。逸脱の中身と影響を確かめた。

**逸脱の向き**: seed21 の対照遺伝子 48 で、補正後の接近度 = 9.45 × 10⁻⁴ − 8.69 × 10⁻⁵ × 入力の長さ（log2）という負の傾きがある。**入力が長い遺伝子ほど値が低く出る**。LTBR の入力の長さの中央値は log2 で 11.02（対照遺伝子の中央値 10.88 より長い側）なので、**この交絡は LTBR に不利に働いている**。

**seed21 を除いた場合**: 主対象の結論は変わらない。

| 主対象 | 3 seed すべて（事前登録） | seed22・23 のみ |
|---|---|---|
| LTBR | (a) 0/3、q = 0.775 / 0.829 / 0.139 | (a) 0/2、q = 0.829 / 0.139 |
| RELB | (a) 0/3、q = 0.200 / 0.300 / 0.094 | (a) 0/2 |
| NFKB2 | (a) 0/3、q = 0.021 / 0.500 / 0.167 | (a) 0/2 |

**長さの傾きをさらに取り除いた場合（事前登録外の感度分析）**: 各 seed で対照遺伝子の補正後の接近度から入力の長さの線形傾向を除き、残差で順位を付け直した。

| 遺伝子 | seed21（元 → 長さ補正後） | seed22 | seed23 | (a) を満たす seed 数（元 → 補正後） |
|---|---|---|---|---|
| **LTBR** | 0.775 → **1.000** | 0.829 → 0.875 | 0.139 → 0.167 | 0/3 → **1/3**（基準は 2） |
| RELB | 0.200 → 0.146 | 0.300 → 0.271 | 0.094 → 0.104 | 0/3 → 0/3 |
| NFKB2 | 0.021 → 0.083 | 0.500 → 0.583 | 0.167 → 0.188 | 0/3 → 0/3 |
| GAPDH | 0.884 → 0.938 | 0.951 → 0.938 | 1.000 → 1.000 | 2/3 → **3/3**（中立性はさらに悪化） |
| ACTA2 | 1.000 → 1.000 | 0.938 → 0.896 | 0.316 → 0.312 | 2/3 → 1/3 |

（この補正後も較正は保たれている: 対照遺伝子 144 組で上位 10% 0.083・下位 10% 0.104。）

**seed21 の交絡を取り除いても、主対象の結論は変わらない。** LTBR は 0/3 が 1/3 になるだけで、基準の 2/3 には届かない。また、この補正で GAPDH の非中立はむしろ悪化する（3 seed とも 0.90 超）ので、規則 2 で止まるという判定も変わらない。**seed21 の逸脱は、結論を左右する要因ではない。**

### 5. 検出力 — この実験が検出できたはずの効果の下限

EXP-20260927-001 で問題になった「対照のばらつきが陽性対照の効果と同じ桁」が本実験にも当てはまるかを確かめた。

**対照遺伝子群のばらつきの分解**（対照遺伝子 48 × 3 seed の補正後の接近度）:

| 成分 | 標準偏差 |
|---|---|
| 1 seed 内の全ばらつき | 2.04 × 10⁻⁵ |
| 同じ遺伝子の seed 間のばらつき（細胞の取り直しによる誤差） | **1.69 × 10⁻⁵** |
| 遺伝子固有で再現する成分 | 1.16 × 10⁻⁵ |

**遺伝子固有で再現する成分は全分散の約 32% しかない**。残り約 68% は、100 細胞を取り直すたびに変わる誤差である。実際、遺伝子 1 つ・1 seed の平均接近度の標準誤差は、細胞単位で 1.5〜2.5 × 10⁻⁵、提供者をクラスタとした場合で 1.6〜7.0 × 10⁻⁵ であり、対照遺伝子群のばらつきとほぼ同じ大きさである。

**(a) の合格ライン**（対照遺伝子群の上位 10%）は、補正後の接近度で **+2.53 / +2.73 / +2.25 × 10⁻⁵**（平均 +2.50 × 10⁻⁵）である。3 seed 中 2 以上でこれを超えるには、seed 間のばらつき 1.69 × 10⁻⁵ を考えると:

- **検出力 50%（3 seed 中 2 を期待値で満たす）に必要な真の効果 ≈ +2.5 × 10⁻⁵**（対照遺伝子群の分布で 1.28 標準偏差）
- **検出力 80% に必要な真の効果 ≈ +3.5 × 10⁻⁵**（同 1.7 標準偏差）

これに対し、観測された効果の大きさ（対照遺伝子群の平均からの標準偏差単位、seed ごと）:

| 遺伝子 | 目標のセントロイド | 平均 | 筋線維芽細胞のセントロイド | 平均 |
|---|---|---|---|---|
| ACTA2（パイプラインの陽性対照） | +1.72 / +1.20 / −0.40 | +0.84 | **+4.76 / +4.64 / +4.04** | **+4.48** |
| TAGLN（同） | −0.38 / −0.70 / −0.61 | −0.56 | +1.25 / +1.22 / +1.42 | +1.30 |
| **LTBR** | **+0.87 / +0.73 / −1.06** | **+0.18** | +0.93 / +1.01 / −0.82 | +0.37 |
| RELB | −1.12 / −0.52 / −1.37 | −1.00 | −0.55 / −0.17 / −0.61 | −0.44 |
| NFKB2 | −1.72 / +0.05 / −0.87 | −0.85 | −1.67 / −0.02 / −1.30 | −1.00 |
| GAPDH | +1.18 / +1.77 / +2.49 | +1.81 | +0.38 / +1.34 / +1.72 | +1.15 |

**結論**:

- この設計が確実に検出できるのは、**補正後の接近度で約 +3.5 × 10⁻⁵ 以上（約 1.7 標準偏差以上）の効果**である。ACTA2 の筋線維芽細胞のセントロイドへの効果（+1.03 × 10⁻⁴、約 4.5 標準偏差）は余裕をもって検出できている。
- **LTBR の効果は最良の seed でも +1.74 × 10⁻⁵（0.87 標準偏差）で、最小検出可能効果量の約半分**。仮に LTBR に真の効果があったとしても、**この大きさなら本実験では検出できない**。したがって LTBR については「効果がないことが示された」ではなく「**最小検出可能効果量より小さいので区別できない**」が正確な表現である。
- EXP-20260927-001 との比較: 同じ問題は残っているが、程度は軽い。EXP-20260927-001 では陽性対照の効果が対照のばらつきと同じ桁（約 1 標準偏差）だったのに対し、本実験ではパイプラインの陽性対照 ACTA2 が 4.5 標準偏差を出している。つまり**系は動いている**（§7）。足りないのは主対象の効果の大きさである。
- 検出力を上げる余地: 主対象の効果の標準誤差は細胞数の平方根に反比例する。LTBR は 573 細胞・22 提供者が利用可能なのに 100 細胞しか使っていない。全細胞を使えば標準誤差は約 0.42 倍になり、対照遺伝子群のばらつきも遺伝子固有成分（1.16 × 10⁻⁵）まで縮むので、**最小検出可能効果量は約 +1.5 × 10⁻⁵ まで下がる**。
- ただし、**細胞数を増やせば LTBR が合格するとは限らない**。seed 間の誤差を平均して得られる LTBR の効果の推定値は **3 seed の平均で +4.3 × 10⁻⁶**（+1.74 / +1.65 / −2.09 × 10⁻⁵ の平均）であり、細胞を増やして得られる最小検出可能効果量 +1.5 × 10⁻⁵ の約 3 分の 1 にとどまる。**細胞数の増加で判別できるようになるのは「LTBR の効果が +1.5 × 10⁻⁵ 以上か否か」であって、現在の点推定はそれを下回る。**


### 6. LTBR の食い違い — 比較遺伝子群には勝つのに対照遺伝子群からは分離しない

LTBR は判定基準: 比較遺伝子群との差 (c) を 3 seed 中 2 で満たす一方、判定基準: 対照遺伝子群からの分離 (a) は 0/3 である。理由を調べた。

#### 6.1 比較遺伝子群が弱い相手である

LTBR の比較遺伝子 5 つ（HOXA6・MTIF3・ATP6V1B2・OAT・SPG21）は、発現差・発現頻度・順位・元の位置をそろえて選ばれているが、**結果として対照遺伝子群の中では平均して下位に位置している**。

| seed | LTBR の補正後の接近度 / 順位 | 比較遺伝子 5 つの平均 | 比較遺伝子 5 つの順位の平均 |
|---|---|---|---|
| 21 | +1.74 × 10⁻⁵ / 0.775 | −3.38 × 10⁻⁶ | **0.458** |
| 22 | +1.65 × 10⁻⁵ / 0.829 | −1.79 × 10⁻⁵ | **0.229** |
| 23 | −2.09 × 10⁻⁵ / 0.139 | −1.47 × 10⁻⁵ | **0.271** |

比較遺伝子群の中央値が対照遺伝子群の 0.23〜0.46 分位にあるということは、**「比較遺伝子 5 つのうち 4 つ以上を上回る」は「対照遺伝子群の中央値を少し上回る」程度の要求しかしていない**ことを意味する。これに対し (a) は上位 10% を要求する。(c) の合格は (a) の合格を含意しない。食い違いは矛盾ではなく、**基準の厳しさの違い**である。

これは判定基準: 比較遺伝子群との差の設計上の弱点である。比較遺伝子群は発現の性質ではそろっているが、**過剰発現時の移動量（§3.2 の一様成分）ではそろっていない**。5 遺伝子という少数では、偶然に移動量の小さい遺伝子ばかりが選ばれうる。事前登録の偶然合格率も (c) だけなら 0.259 と高く見積もられており（`plan.md` §6.6）、(c) は単独ではほとんど証拠にならない。

#### 6.2 seed23 で符号が反転する理由 — 提供者の偏りではなく細胞の取り直し

| | seed21 | seed22 | seed23 |
|---|---|---|---|
| 補正前の平均接近度 | **+4.98 × 10⁻⁵** | **+4.91 × 10⁻⁵** | **+1.62 × 10⁻⁵** |
| 補正後の接近度 | +1.74 × 10⁻⁵ | +1.65 × 10⁻⁵ | **−2.09 × 10⁻⁵** |
| 対照遺伝子群の補正前の平均 | +3.25 × 10⁻⁵ | +3.25 × 10⁻⁵ | +3.56 × 10⁻⁵ |
| 提供者数 | 16 | 17 | 20 |
| 提供者平均が正の割合 | 12/16 | 13/17 | 12/20 |
| 細胞単位の標準誤差 | 1.61 × 10⁻⁵ | 1.49 × 10⁻⁵ | 1.62 × 10⁻⁵ |
| 提供者をクラスタとした標準誤差 | 1.61 × 10⁻⁵ | 2.51 × 10⁻⁵ | **3.10 × 10⁻⁵** |
| 入力の長さの中央値 | 2,082 | 2,176 | 1,991 |

確認した点:

- **符号は反転していない。** 補正前の平均接近度は 3 seed とも正（+1.62 〜 +4.98 × 10⁻⁵）である。符号が変わるのは補正後の値で、対照遺伝子群の水準（+3.25 〜 +3.56 × 10⁻⁵）を seed23 だけ下回ったためである。
- **細胞の重なりはほとんどない。** LTBR の 100 細胞は、seed21 ∩ seed22 = 18、seed21 ∩ seed23 = 23、seed22 ∩ seed23 = 13、3 seed 共通は **2 細胞**。573 個の対象細胞から 100 個ずつ取り直しているので、3 つの seed はほぼ独立な部分標本である。
- **提供者の偏りでは説明できない。** 提供者を 1 人ずつ除いても、補正前の平均接近度の符号は **3 seed とも一度も反転しない**（seed21 +3.93〜+5.80 × 10⁻⁵、seed22 +3.99〜+5.26 × 10⁻⁵、seed23 +1.01〜+2.34 × 10⁻⁵）。特定の提供者に依存した結果ではない。
- **細胞のサンプリング誤差で十分に説明できる。** seed21・22（約 +4.9 × 10⁻⁵）と seed23（+1.6 × 10⁻⁵）の差は 3.3 × 10⁻⁵ で、提供者をクラスタとした標準誤差（1.6〜3.1 × 10⁻⁵）の 1 標準誤差強にすぎない。§5 で示した「seed 間のばらつき 1.69 × 10⁻⁵（対照遺伝子全体）」とも整合する。
- **入力の長さの違いも一部寄与している。** seed23 の LTBR 細胞は入力が短い側（中央値 1,991、seed22 は 2,176）。ただし seed23 の長さとの相関は −0.101 と小さく、寄与は限定的である。

**まとめ: LTBR の seed23 の値は、提供者の偏りでも細胞の重なりでもなく、100 細胞という標本サイズに起因するばらつきである。** 3 seed を平均した LTBR の効果は +4.3 × 10⁻⁶ で、対照遺伝子群の中央値をわずかに上回る程度にすぎない。

### 7. パイプラインの陽性対照が合格していることの意味

ACTA2 は筋線維芽細胞のセントロイドに対して 3 seed とも q = 1.000（補正後の接近度 +1.03 / +0.97 / +0.77 × 10⁻⁴、対照遺伝子群の +4.5 標準偏差）、TAGLN は q = 0.854 / 0.914 / 0.949（+1.3 標準偏差）で、判定基準: パイプラインの陽性対照は合格している。

**言えること**:

- 過剰発現型の摂動と埋め込みの計算、状態のセントロイドの作り方、偏り補正、対照遺伝子群との比較という一連の手順は**動いている**。既知の駆動因子を過剰発現させれば、対応する状態のセントロイドへ、対照遺伝子群から明確に分離する形で近づくことを検出できる。
- したがって、主対象が目標の方向へ動かないことを「系が動かないから」と説明することはできない。

**言えないこと（重要な留保）**:

- **ACTA2 の効果の大きさ（+1.0 × 10⁻⁴）は、主対象に期待される効果の大きさの根拠にならない。** ACTA2 は筋線維芽細胞の**定義に近いマーカー**であり、セントロイドの定義にほぼ直結している。一方、目標の状態（三次リンパ組織オーガナイザー様の状態）は CCL19 / CCL21 / CXCL13 の検出で定義されており、LTBR はその上流の受容体である。上流の制御因子が下流のマーカーと同じ大きさの効果を出すと期待する根拠はない。
- **合格した軸は筋線維芽細胞のセントロイドであって、目標のセントロイドではない。** 目標のセントロイドに対して「対照遺伝子群から分離する形で近づいた遺伝子」は、84 遺伝子中 GAPDH と（seed21・22 の）ACTA2 しかなく、どちらも目標に特異的な動きではない（§3.3）。**目標のセントロイドへの接近が検出できることは、この実験では一度も示されていない。**
- したがって「系は動くが、この 3 遺伝子では動かない」という言い方は**半分しか正しくない**。正確には、**「筋線維芽細胞の方向へ動かす効果は検出できる。目標の方向へ動かす効果を検出できるかは未確認で、主対象 3 遺伝子は最小検出可能効果量を超える効果を示さなかった」**である。目標の方向についての陽性対照が存在しないことが、この実験の設計上の最大の穴である（§限界・§次のアクション）。

#### 8.3 提供者を 1 人ずつ除く検証

`criteria.json` の `lodo_primary_pass_genes` は空（`{}`）である。これは**欠測ではなく、(a)〜(d) を満たした主対象が 0 だったため計算対象がなかった**という意味である（`analysis/evaluate_fib.py` は合格した遺伝子にのみこの検証を行う設計）。

validator が補正前の平均接近度に対して独立に実施した結果は §6.2 のとおりで、**LTBR は 3 seed とも、どの提供者 1 人を除いても符号が反転しない**（合計 53 通りの除外で反転 0 件）。結論が特定の提供者に依存しているという証拠はない。

### 10. 判定基準の妥当性 — 厳しすぎないか

否定的な判定を提案する以上、基準が厳しすぎないかを確かめる必要がある。

#### 10.1 偶然合格率の実測（guardrails 2026-09-27: seed 間の独立を仮定しない）

対照遺伝子 48 に、主対象と同じ判定基準を当てはめた実測値。seed 間の相関はそのまま含まれている。

| 判定基準 | 事前登録の見積もり（`plan.md` §6.6） | 対照遺伝子 48 での実測 |
|---|---|---|
| (a) 単独（q ≥ 0.90 かつ符号正、3 seed 中 2 以上） | 0.028 | **1/48 = 0.021** |
| (a) + (b) + (d) ※比較遺伝子が定義できないため (c) を除く | — | **1/48 = 0.021** |

**事前登録の見積もり（0.028）は実測（0.021）とよく合っている。** EXP-20260927-001 で問題になった「独立を仮定して偶然合格率を 8 倍過小評価した」という失敗は、本実験では起きていない。したがって **(a) の基準が緩すぎて偽陽性が出やすいわけでも、厳しすぎて偶然すら通らないわけでもない**。

#### 10.2 合格ラインを変えた場合（事前登録の判定は 0.90 のまま。以下は感度分析）

| 合格ライン（q の閾値） | (a) を 3 seed 中 2 以上で満たす主対象 | 対照遺伝子 48 での偶然合格率 | (a)(b)(c)(d) すべてを満たす主対象 |
|---|---|---|---|
| **0.90（事前登録）** | なし | 1/48 = **0.021** | なし |
| 0.85 | なし | 2/48 = 0.042 | なし |
| 0.80 | なし | 4/48 = 0.083 | なし |
| 0.75 | **LTBR** | 11/48 = **0.229** | なし |
| 0.70 | **LTBR** | 13/48 = **0.271** | なし |

- **0.80 まで緩めても主対象は 1 つも (a) を満たさない。** LTBR が (a) を満たすのは 0.75 まで下げたときで、そのとき偶然合格率は 0.229（対照遺伝子の 4 遺伝子に 1 つが通る水準）に跳ね上がる。**LTBR の合格はこの緩めた基準では意味を持たない。**
- **どの閾値でも (a)(b)(c)(d) をすべて満たす主対象は 0** である。LTBR は (b) 5/9（基準 7）、(d) 0/3（基準 2）で、閾値とは無関係に落ちる。
- 閾値との距離: LTBR の最良の seed は q = 0.829（合格ライン 0.90 まで 0.071）、2 番目は 0.775（同 0.125）。3 番目は 0.139 で大きく離れている。**「あと少しで合格」ではなく、2 seed 中 1 が惜しく、1 seed は明確に不合格**という状態である。

#### 10.3 結論がどの基準に依存しているか

- **判定不能（規則 2）は、恒常発現遺伝子の中立性という 1 つの基準、さらに言えば GAPDH 1 遺伝子に完全に依存している。** GAPDH を中立対照から外せば、ACTB 2/3・PPIA 3/3 で規則 2 は通過する。
- しかしその場合、規則 3（パイプラインの陽性対照）は合格するので規則 4〜7 へ進み、**(a) を満たす主対象が 0 なので規則 7 = 否定**になる。
- **すなわち、GAPDH の扱いをどう変えても「支持」「一部支持」にはならない。** 判定は「判定不能」か「否定」のどちらかであり、その分岐だけが GAPDH に依存している。
- (b) は恒常発現遺伝子との比較なので GAPDH の非中立の影響を受ける。GAPDH を除いて ACTB・PPIA の 6 組で数え直すと、LTBR 5/6・RELB 2/6・NFKB2 2/6・CDKN1A 1/6 となる。事前登録の 9 組中 7（0.78）を 6 組に換算すると 4.7 組、すなわち 5 組以上が対応する合格ラインで、**LTBR だけが 5/6 で辛うじて届く**。ただし LTBR は (a) 0/3・(d) 0/3 なので総合の合否は変わらない。**(b) の扱いを GAPDH 抜きに変えても結論は変わらない。**

### 11. 評価コードに見つけた不具合（副検定のみ。主判定には影響しない）

`analysis/evaluate_fib.py` の `assess()` は、主検定と副検定（区間内パーセンタイル検定）の両方で呼ばれるが、判定基準: 状態の特異性 (d) の比較相手 `Dmy` が**常に主検定の尺度の値（`D_raw_myof`、コサインの差で 10⁻⁵ の桁）に固定されている**。副検定では対象側が区間内パーセンタイル（0 を中心に ±0.05 程度の桁）なので、**桁の違う 2 つの量を比べている**。

```python
Dm  = g.pivot(index="gene", columns="seed", values=dcol)          # 副検定では "W"（パーセンタイル）
Dmy = g.pivot(index="gene", columns="seed", values="D_raw_myof")  # 常にコサインの差
spec = {... bool(Dm.loc[x, s] > Dmy.loc[x, s]) ...}
```

その結果、副検定の (d) は実質的に「区間内パーセンタイルの符号が正か」だけを見る判定になっている（`criteria.json` の `secondary_within_bin_percentile` で、値が正の遺伝子 × seed はすべて `true`、負はすべて `false` になっていることで確認した）。

**影響**: `plan.md` §6.4 は「判定は主検定だけで行う」と事前登録しており、副検定は判定に使われない。副検定でも主対象の合格は 0 なので、**本実験の判定・結論は変わらない**。ただし副検定の (d) の数値は報告に使えないので、レポートには載せないこと。同じ `assess()` を使う今後の実験では修正が必要である。

## 限界

1. **目標の方向についての陽性対照がない。** パイプラインの陽性対照は筋線維芽細胞のセントロイドへ向かう効果しか確かめていない。三次リンパ組織オーガナイザー様の状態のセントロイドへ、摂動で近づけられることを示した遺伝子は本実験に 1 つもない。目標のセントロイドが「そもそも摂動で到達できる方向にあるか」が未検証である。なお、目標の状態を定義する CCL19 / CCL21 / CXCL13 は、出発点の細胞では定義上 0 なので、過剰発現型の陽性対照には使えない（guardrails 2026-09-27）。
2. **主指標が一様成分に支配されている。** 目標・出発点・対照の状態への接近度が対照遺伝子間で ρ = 0.92〜0.96 で連動しており、主指標の大部分は「摂動による埋め込みの移動量」である。目標に特異的な成分は残差にすぎず、判定基準: 状態の特異性 (d) 以外にこれを直接扱う基準が事前登録に含まれていない。
3. **検出力が不足している**（§5）。最小検出可能効果量は補正後の接近度で約 +3.5 × 10⁻⁵。主対象の効果はいずれもこれを下回る。「効果がない」ことを示したのではなく「この大きさの効果は検出できなかった」である。
4. **1 遺伝子あたり 100 細胞しか使っていない。** LTBR は 573 細胞・22 提供者、RELB は 616 細胞・22 提供者、NFKB2 は 255 細胞・19 提供者が利用可能である。seed 間の値のばらつき（§5、§6.2）の大半はこの標本サイズに由来する。
5. **折半信頼性が低い**（84 遺伝子で 0.06〜0.10）。遺伝子の順位付け自体が提供者の入れ替えに対して安定していない。
6. **三次リンパ組織オーガナイザー様の状態は推定ラベルである。** CCL19 / CCL21 / CXCL13 のいずれかが検出された腎線維芽細胞という定義で、組織学的な確認はしていない（`docs/用語集.md`）。目標の状態そのものの妥当性は本実験では検証していない。
7. **単一核 RNA-seq の検出率の制約。** 参考対象の CDKN1A は出発点で 43 細胞（検出率 0.75%）しかなく、3 seed とも同じ細胞集合になる（`n_cells` = 43 で一定、`lp_med`・`relpos_med` も 3 seed で同一）。seed を変えても独立な確認にならないので、CDKN1A の結果は seed 1 つ分の情報しか持たない。事前に参考対象としたのは妥当である。
8. **`plan.md` の再固定は申告に基づく。** バージョン管理下にないため、18:50 の再固定で本文のどこが変わったかを機械的に照合できない（guardrails 2026-09-27）。判定基準を実体として持つファイル（`config.yaml`・`analysis/*.py`・`work/*`）が 17:44 の固定から変わっていないことは確認できたので、判定基準が結果を見てから変えられた可能性は実質的に否定されるが、plan.md 本文については §13 の記載を信頼している。
9. **bfloat16 での計算の確認が実施されていない。** `plan.md` §7 は「主対象で順位が 0.85〜0.95 に入った遺伝子 × seed（最大 5 組）を float32（単精度）で再計算する」としていた。該当は LTBR × seed22（0.829）が近いが範囲外で、厳密には 0 組である。実施されていないのは計画どおりだが、**bfloat16 の影響が未確認のまま**であることは限界として残る。
10. **in silico の結果である。** 本実験が示すのはモデルの埋め込み空間での動きであり、実際の細胞で LTβR–非古典的 NF-κB 軸の活性化が三次リンパ組織オーガナイザー様の状態を誘導しないことを意味しない。
