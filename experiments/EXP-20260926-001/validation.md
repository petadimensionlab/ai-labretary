# EXP-20260926-001 検証（validation）

- 仮説: HYP-20260925-01（CKD の TLS-high 腎で aPT の TP53/CDKN1A/LTBR を delete → 健常 PT へ近づき、TLS-low より効果が大きい）
- 作成: Labretary（validator 解析: `validation-analysis/`、指標: `results/*/validation_metrics.json`）/ 2026-09-26
- 実行条件: Geneformer V2-316M、MPS、bf16（forward bf16 + コサイン fp32, PI 決定）、3 seed × 100 細胞/遺伝子（donor ≤ 15）、run 1（tls_high）1 h 55 min、run 2（tls_low）1 h 39 min
- すべて in silico の予測であり、生物学的事実ではない

## 1. 結論

**主要予測（TP53 / CDKN1A / LTBR の delete で aPT_CKD_TLShigh が PT_healthy へ近づく）は、事前登録した 2 指標のどちらでも支持されなかった。** 3 遺伝子とも、判定条件（null 上位 5% かつ FDR_norm < 0.05）を満たした seed は 0/3（FDR_norm の最小 0.23）。

| 指標 | 事前登録規則の機械的な適用 | 陽性対照 | Labretary の評価 |
|---|---|---|---|
| shift_goal | **inconclusive**（HAVCR1 が上位 10% に 1/3 seed。fp32 再計算では VCAM1 も 1/3 に下がり 2 つとも不合格） | 不合格 | inconclusive |
| shift_goal_minus_start | **refuted**（陽性対照 2/2 合格、主要 3 遺伝子は棄却条件に該当） | 合格（3/3） | **inconclusive 寄り**（下記） |

差分指標で陽性対照が「合格」したが、ハウスキーピング遺伝子 GAPDH・PPIA も同じ指標で 3/3 seed とも null 上位 10%（分位 1.00）に入った。陽性対照の合格は特異的な信号を示さず、パイプラインが「goal へ近づく遺伝子」を検出できることの確認になっていない。したがって、規則上は refuted だが、**「主要遺伝子に効果がない」と積極的に言えるだけの検出力が示されていない**。総合評価は「支持されない（判定不能寄り）」とし、確定は G3 で PI が判断する。

**文脈依存性（TLS-high > TLS-low）**: 符号を確認する修正後の判定で、どの遺伝子も基準を満たさなかった。LTBR の比 1.96（95% CI 1.02–4.27）は分子・分母ともに負（−3.25×10⁻⁴ / −1.65×10⁻⁴）で、仮説と逆向き（TLS-high の方が健常から大きく離れる）。他は CI に 1 を含むか極端に広い。plan §9 に従い「判定不能」。

## 4. 限界
1. **削除ドリフト**: run 1 の 90/90 の遺伝子×seed が goal・start・alt の 3 セントロイドすべてから離れた（`figures/deletion_drift.png`）。1 遺伝子の delete が埋め込みを一様に動かす成分が支配的で、「null の上位」は「goal へ近づく」ではなく「ドリフトが小さい」ことを意味しうる（guardrails 追記済み）
2. **TLS 対比の弱さ**: TLS-high と TLS-low のセントロイドの距離（1 − cos = 0.0006）は start–goal（0.0073）の約 1/12、細胞ごとの start シフトと alt シフトの相関は 0.998。事前チェック AUC 0.627 ± 0.206 と合わせ、この状態定義では 2 群の対比にほとんど意味がない
3. TLS-high / TLS-low は pseudo-bulk の組成から推定したラベルで、組織学的な TLS ではない
4. 差分指標は phase 0 の結果を見てから追加した（本番データを見る前に G2 で登録）
5. run 2 の CDKN1A（69 細胞・7 donor）、HAVCR1（62・7）、LCN2（48・6）は n が異なり、同列比較できない
6. 精度は PI 決定により bf16（phase 0 で fp32 と Spearman 0.879、基準 0.98 未達）
7. 多重比較は対象 5 遺伝子内のみ補正

## 5. 次のアクション
- **示唆されること**: この設計（CKD aPT、1 遺伝子 delete、CLS 埋め込み、推定 TLS 群）では、p53–p21 軸と LTβR の削除が健常 PT 方向への特異的な移動を生むという予測は支持されなかった。**示されたわけではないこと**: これらの遺伝子が生物学的に無関係であること
1. 方法の改善（次の実験の前提）: 細胞長をマッチさせた null、HK を陰性対照の合否判定に含める、差分指標は null を含めて fp32 で再計算する
2. 削除ドリフトの扱い: ドリフト成分（全遺伝子の平均シフト）を差し引いた指標、または emb_layer（中間層）や `cls_and_gene` での感度分析
3. TLS の対比: 分離がはっきりした状態定義（例: 空間データ Meylan 2022 由来の TLS シグネチャー、または B/形質細胞の近接情報）で別実験として組み直す
4. 仮説の扱い: G3 で PI が判定（refuted / inconclusive）。判定後に `hypotheses/tracker.md` を更新（Learning Protocol トリガー 5）
