## 0. 目的と、この実験で何が決まるか

### 0.1 大きな目的とのつながり

本研究の目的は、腎臓の三次リンパ組織と細胞老化に関わる**正しい遺伝子を見つけること**である。

前回（EXP-20261011-001・002、仮説 HYP-20261011-01）は、2 本の向きの差への射影（差の向き）という測り方が
**退化側を分離して読めない**（退化側のセット平均が負だが 0 と区別できなかった、反証条件 R-6/R-6'）ことから
**判定不能**になった。同じ研究（Lake ら 2023）の 2 つの測定手法だけでは、この方法の成否を切り分けられなかった。

PI 決定（2026-10-11）: **別のデータ（A6 尿管閉塞腎、Reck ら 2025）で、埋め込みだけを使って
この測り方の前提（2 つの向きが区別できる・状態が分離できる）を独立に測る。**

- この実験は**摂動をしない**。したがって、前回の「摂動の効果を差の向きへ射影した値」そのものは計算できない。
  測れるのは (i) 状態の分離（AUC）、(ii) 2 本の軸の幾何（なす角・検出された遺伝子数および総 UMI 数との関係）、
  (iii) 前回の退化側の不成立が A6 の幾何ではどう見えるか、である。
- 候補と陽性対照の「位置（向き）」は、発現と埋め込みの**相関**として測る（§4.5）。**これは摂動の確認ではない（幾何の確認のみ）。**
  相関は探索・記述として報告し、「摂動の結果が A6 で再現した」とは書かない（§4.5 の制約。PI 回答 2026-10-11・§12-6）

### 0.2 この実験で決まること・決まらないこと

| 決まること | どこで |
|---|---|
| A6 の埋め込みで、出発状態が 2 つの目標状態から分離できるか（2 系統） | §4 P-1 |
| 「活性化した間質」の軸と「退化・老化」の軸が、検出された遺伝子数と総 UMI 数、発現頻度の交絡を除いて異なる向きを向くか | §4 P-2 |
| 前回の退化側の不成立が、A6 の幾何でどう見えるか（記述） | §4 P-3 |
| 候補・陽性対照の発現が、どちらの軸に沿っているか（**相関・記述**） | §4 P-4 |

| 決まらないこと | 理由 |
|---|---|
| 摂動の効果（差の向きの z 値）が A6 で再現するか | 本実験は埋め込みのみ（PI 決定 (c)） |
| 候補が「活性化に固有」という**因果的な確認** | P-4 は相関（§4.5）。因果の確認には摂動が必要（PI 回答 2026-10-11・§12-6） |
| 三次リンパ組織が作られるか・細胞が実際に老化しているか | 目標は著者ラベルの状態 |
| ヒトの腎臓で実際に起きること | コンピュータ上の計算。「示唆される」まで |

## 4. 判定の規則（**事前登録。結果を見る前に固定する。config.yaml の `decision:` に同じ値が書いてあり、評価コードが照合する**）

### 4.1 指標の定義

| 語 | 定義 |
|---|---|
| 細胞埋め込み | 全 46,957 核を Geneformer（V2-316M・fp32・tf32 閉・cls）で 1 回エンコードした 1,152 次元ベクトル。`row_id` で結合（ガードレール 2026-09-27） |
| 状態のセントロイド | 検出された遺伝子数の分布をそろえた（10 分位マッチ、§6.1）後の各状態の平均埋め込み。**長さ 1 に直して使う** |
| 活性化した間質の軸 | `u_ada = unit(Myofibroblast セントロイド) − unit(Fibroblast セントロイド)`、正規化 |
| 退化・老化の軸 | `u_deg = unit(PT Injured/Inflammatory セントロイド) − unit(正常 PT セントロイド)`、正規化 |
| `d_depth`（検出された遺伝子数の大きい 5 分位と小さい 5 分位のセントロイドを結ぶ向き） | `d_depth = unit(検出された遺伝子数が大きい 5 分位の平均埋め込み) − unit(検出された遺伝子数が小さい 5 分位の平均埋め込み)`。集団は間質系＋管状系の全核 |
| 差の向き・共通の向き | 今回は摂動がないので**計算しない**。HYP-20261011-01 の 2.2 は差の向きの測り方の検証だが、A6 はその前提（幾何）を測る（§0.1） |

### 4.2 主判定 P-1（状態の分離。2 系統）

> **間質系・管状系の両方で、出発状態と目標状態が提供者単位の分割で分離でき、かつ、その分離は検出された遺伝子数と総 UMI 数だけでは説明できない。**

- 方法: 出発・目標の核の埋め込みでロジスティック回帰（StandardScaler + LR、`run_isp.precheck` と同じ実装）。
  提供者単位分割（GroupKFold 5 分割）の AUC 平均を主、層化分割を参考値とする
- 条件（両系統で）:
  - **(i)** 提供者単位の AUC 平均 ≥ **0.70**
  - **(ii)** 総 UMI 数と検出された遺伝子数の 2 変数だけでの分離 AUC ≤ **0.60**（`log n_genes`・`log n_umi` の 2 変数）
- 閾値の根拠: 0.70 は過去の事前チェックで使った水準（EXP-20260927-002 は検出された遺伝子数の分布をそろえた後 AUC 0.704 を合格にした）。
  0.60 は「検出された遺伝子数と総 UMI 数だけで分離できる」と読む水準（0.676〜0.85 の交絡例に照らし、それより低い 0.60）
- **間質系の注記**: 状態と疾患（閉塞/正常）がほぼ 1 対 1 のため、提供者単位の分割は「正常提供者しかテストに
  入らない fold」などを含み、AUC が定義できない fold がありうる。**定義できない fold は除外し、使えた fold 数と
  除外理由を併記する**。それでも AUC を出せない場合は、正常提供者内の分離（Fibroblast 対 Myofibroblast、
  normal donors のみ）に限った AUC を副次として読む。**主判定の合格条件は提供者単位 AUC ≥ 0.70 のまま**（§12-4）

### 4.3 主判定 P-2（2 本の軸は異なる向きを向く。交絡を除いて）

> **検出された遺伝子数の分布をそろえたセントロイドから作る `u_ada` と `u_deg` は、異なる向きを向き、`d_depth` に支配されず、検出された遺伝子数の分布のそろえ方に依存しない。**

- 条件（**3 つすべて**）:
  - **(a)** `sin(なす角(u_ada, u_deg)) ≥ 0.31`（角 ≥ 18 度。HYP-20261011-01 §9.2 の着手条件と同じ）を
    提供者 3 群（提供者を 3 つに分けた互いに重ならない群）の**すべて**で満たす
  - **(b)** `|cos(u_ada, d_depth)| ≤ 0.60` かつ `|cos(u_deg, d_depth)| ≤ 0.60`（軸が `d_depth` に支配されない）
  - **(c)** 検出された遺伝子数の分布をそろえないセントロイドから作る軸とのなす角が **≤ 30 度**（どちらの軸も検出された遺伝子数の分布のそろえ方に安定）
- 閾値の根拠: (a) は仮説 HYP-20261011-01 §9.2 が「差の向きが残す成分 sin が 0.31 未満なら着手しない」とした値の踏襲。
  (b) の 0.60 は「コサイン 0.6（約 53 度）以上が `d_depth` 方向の成分と共有されていたら、軸が検出された遺伝子数の大きさを測っている可能性を否定できない」という水準。
  (c) の 30 度は「マッチの有無で結論が変わらない」の目安
- **P-2 が通ったときに言えること**: A6 の埋め込みの幾何では、活性化した間質の方向と退化・老化の方向が
  別の向きとして立っている。**これは摂動の測り方（差の向き）が働くための前提の確認であって、測り方の成否そのものではない**（§0.1）

### 4.4 副次 P-3（前回の退化側の不成立が A6 ではどう見えるか。記述）

- 管状系が P-1 の分離（提供者単位 AUC ≥ 0.70、総 UMI 数と検出された遺伝子数の 2 変数だけでの分離 AUC ≤ 0.60）と P-2 の異なる向き（sin ≥ 0.31・`d_depth` に支配されない）を
  **両方**満たすかどうかを 2 値で報告する
- 読み方（**結果を見る前に固定**）:
  - 満たす: 「A1/A2 の退化側の不成立は、埋め込みの幾何で退化方向が立たないからではなく、A1 の退化状態のラベル
    （dFIB、検出遺伝子数の著しい減少を含む）または摂動の測り方に固有の問題であることを示唆する（記述）」
  - 満たさない: 「A6 の管状系でも退化方向が立たない。前回の不成立に似た形が独立データで再現された（記述）」
- **これは記述であり、方法の支持・否定を決めるものではない**（G3 は PI）

### 4.5 副次 P-4（候補と陽性対照の位置（向き）。**相関・記述。幾何の確認のみ**）

> **候補・陽性対照の発現は、活性化した間質の軸（u_ada）に沿うか（相関）。**
>
> **PI 回答 2026-10-11（§12-6）: P-4 は「幾何の確認のみ」であり、摂動の確認ではない。**
> 発現と埋め込みの相関が目標の軸に沿うことは、その軸が測れていることの確認であって、
> 摂動（過剰発現・抑制）で状態が動くことの確認ではない。**この区別を §0.1・§0.2・§4.5・§11 に固定する。**

- 測り方（**摂動を使わない**）:
  1. 間質系で検出された遺伝子数の分布をそろえた核（Fibroblast ∪ Myofibroblast、§6.1）で、遺伝子 g について
     発現値 `s_i = log1p(CP10k)` を**対照プールで当てた回帰**で総 UMI 数と検出された遺伝子数（`log n_genes`・`log n_umi` の完全二次式）から残差化する
  2. 各核の埋め込みを u_ada・u_deg へ射影した値 `proj_i` も同じ変数（総 UMI 数と検出された遺伝子数）で残差化する
  3. 遺伝子の位置 = `Spearman(s_i, proj_i)`（残差後）。**発現と埋め込みの相関**である
  4. **標準化**: 対照プール 500（候補と同じ検出率帯から選ぶ）の同じ統計量の分布で z にする。
     集合の値はセット平均。偽セット 1,000 組（8 個）の 99 パーセンタイルと比べる（乱数の鍵 20261112）
  5. 単一遺伝子の位置は、目標状態（Myofibroblast）で検出核が **20 核以上**の遺伝子に限る。
     未満（SLC4A9 = 2 核など）は「位置を推定できない（測定不能）」と書く
- 条件:
  - **(i) 陽性対照の健全性**: 活性化の陽性対照 71 個のセット平均 z（u_ada 方向）が正で、偽セット 1,000 組の
    99 パーセンタイルを超える。**超えなければ P-4 全体を判定不能にする**（陽性対照が働かない）。
    管状系の P-4（u_deg 方向）も、**A6 用に固定した管状系陽性対照 23 個（§5.1）**で同じ健全性チェックを行う。
    感度分析として T5 を含む 30 個版（§5.1・config の `sensitivity_include_T5`）でも再計算する
  - **(ii) 候補（探索・記述）**: 検出床を満たす候補（§0.4）の u_ada 方向の位置を 1 遺伝子ずつ報告する。
    **候補の「確認」はこの相関ではできない**（過剰発現の効果 ≠ 発現の相関）。PI 決定 (b) の「A6 で確認」は
    **PI 回答 2026-10-11 で「幾何の確認のみ」と確定（§12-1・§12-6）**。本計画は相関の値を探索として出す
- 管状系の退化軸: **PI 回答 2026-10-11（§12-3）で A6 用の陽性対照 23 個を固定した**（§5.1）。
  検出率の床 0.10 は満たすが、**軸に沿うかは埋め込み後にしか測れない**（検出率だけで「陽性対照として働く」とは
  断定しない）。管状系の P-4 はこの 23 個で健全性を測り、値を記述として報告する

### 6.4 循環性

- 状態の定義は**著者ラベル**（celltype_l2）のセントロイドから作る。遺伝子リストでは定義しないため
  `goal_defining` は空、`circular_overlap` は「問えない」（null）
- **ただし注釈自体が発現のクラスタリングから作られている以上、循環が完全に無いわけではない**（明記）

## 11. 限界（**結果を見る前に書く**）

1. **摂動をしない。** 前回の測り方の成否（差の向きの z 値）は A6 では計算できない。測れるのは幾何（軸・分離）と
   発現の相関（P-4）まで。**P-4 の合格を「摂動の結果の確認」と書いてはいけない**（§0.2・§4.5。PI 回答 2026-10-11 で
   「幾何の確認のみ」と確定。§12-6）
2. **埋め込みが測定の本体なので、「埋め込み前の着手前チェック」が完結しない。** 従来の順序（着手前チェック →
   本番）を埋め込みのみの実験にそのまま当てはめると、本番（埋め込み）の前に分離 AUC を出せない。
   本計画は「埋め込み前に測れる分」を固定し、残りを埋め込み後の A チェックで判定する（§3.1・§12-2）
3. **間質系は状態と疾患（閉塞/正常）がほぼ 1 対 1 で交絡する。** Fibroblast は正常 98.6%、Myofibroblast は閉塞 95.2%。
   提供者単位の分離 AUC はこの交絡の影響を受ける（§4.2 の注記・§12-4）
4. **管状系の退化軸の陽性対照は A6 用に組み直した（23 個）。** 検出率の床 0.10 は満たすが、
   **軸に沿うかは埋め込み後にしか測れない**。検出率だけで「陽性対照として働く」とは断定しない（§5.1・§9）
5. **SLC4A9 の検出は 2/585 核（0.3%）で、位置の推定に足りない。** PI 回答 2026-10-11 で
   **「測定不能」として扱い、採用 5 個（GSN・ZFHX3・CA12・ELN・CCL21）から外した**（§0.4・§12-1）
6. **A6 は snRNA(multiome) で、前回の A1（snRNA）・A2（scRNA）と測定手法・提供者・疾患がすべて違う。**
   これは独立データとしての長所だが、直接の数値比較はできない（判定は A6 内で閉じる）
7. **文献との一致・不一致を根拠の中心に置かない**（2026-10-03 の較正で差が無い）
8. **コンピュータ上の計算である。** 「示唆される」までで、実験的事実としては書かない
9. **候補の位置（P-4）は発現と埋め込みの相関である。** 因果（過剰発現で状態が動く）とは別の量。
   相関が無くても過剰発現の効果が無いとは言えず、その逆も言えない
10. **活性化 71 のまとまりは +0.029 で着手条件の目安ちょうど。** P-4(i) の健全性は埋め込み後に確認する
