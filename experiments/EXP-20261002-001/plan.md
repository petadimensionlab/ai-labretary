## 2. この再評価で何が決まり、何が決まらないか（**先に明確にしておく**）

**この再評価で、主判定の値は変わらない。** 変えるのは健全性の検査だけで、主指標そのものは変えない。

| | 値 | この再評価で変わるか |
|---|---|---|
| 介入セット 119 個の遺伝子セットの平均スコア z | **0.208 / 0.098 / 0.142** | **変わらない** |
| セットの絶対値の条件 | 0.41 | 変わらない |
| 最小検出可能効果量（80% で拾える効果） | 0.604 | 変わらない |
| 主指標の定義（向きへの射影、`lp`・`ll` の補正） | 変えない | 変わらない |
| 対象遺伝子・細胞の選び方 | 変えない | 変わらない |

- **この値はすでに見えている。** 2026-10-01 に PI へ報告済みである。
- 0.208 / 0.098 / 0.142 は絶対値の条件 0.41 にも最小検出可能効果量 0.604 にも届かない。
- **したがって、新しい検査が通れば結論は「否定（最小検出可能効果量 0.604 標準偏差以上の効果は
  認められなかった）」になることが、着手前から分かっている。**

**この再評価は仮説の盲検的な検定ではない。「すでに得た値を述べる資格があるか」を決める手続きである。**

→ だから §6 の検査と閾値は、**守る判断（0.41）と測定の精度だけから決める**。
主判定の値（0.208 / 0.098 / 0.142）は閾値の導出に一切使わない。
新しい検査が落ちれば、結論は「判定不能」のままになる。**その場合も結果を見てから閾値を緩めない。**

### 6.2 新しい検査 S-1 — 歪みの直接見積もり

**定義。** 交絡の候補 v ごとに、対照 500 個の中での分位 q_v（0〜1）を全遺伝子について求める。
対照だけを使って、標準化した残差 z を 5 つの分位に**同時に**回帰する:

> z = β₀ + Σ_v β_v · q_v + 誤差 （対照 500 個で当てる）

判定するセットの歪みを

> **b_v = β_v ×（セットの v の平均分位 − 0.5）**、　**B = Σ_v b_v**

とし、**|B| の 95% 信頼区間の上側**

> **上側 = |B| + 1.96 × √(a' V a)**　（a は分位のずれのベクトル、V は β の共分散行列）

で判定する。

| 項目 | 値 |
|---|---|
| 交絡の候補 v | **移動量（遺伝子ごとの ‖Δ‖ の中央値）・元の順位 log2(1+pos)・入力の長さ log2(length)・相対位置 pos/length・一様成分（遺伝子ごとの残差）** |
| 合格条件 | **上側 ≤ 0.10 標準偏差を 3 seed とも** |
| 実装 | `scripts/analysis/bias_budget.py` |

**性質。**

- **セットが偏っていなければ自動的に緩く、偏っていれば自動的に厳しくなる。**
  分位のずれが 0 なら b_v も信頼区間も 0 になる。
- **主指標の値（目標の向きへの射影）を一度も使わない。** 使うのは (1) 対照だけで測った傾きと
  (2) セットの遺伝子の交絡の候補の値だけである。
- **ただし「入力側の性質だけ」ではない。** 5 つのうち元の順位・入力の長さ・相対位置は
  トークン化した入力だけから作れるが、**移動量と一様成分は摂動の出力から作られる**。
  目標の向きには依存しないので主判定の値は見ないが、この区別を報告で省略しない。

### 6.3 なぜ「同時回帰」で、なぜ Σ|b_v| をそのまま使わないか（**数値で**）

交絡の候補どうしは強く重なっている（対照 500 個での順位相関、3 seed）:

| 組 | 相関 |
|---|---|
| 移動量 と 元の順位 | 0.873〜0.878 |
| 移動量 と 相対位置 | 0.780〜0.787 |
| 移動量 と 一様成分 | 0.436〜0.459 |
| 一様成分 と 元の順位 | 0.237〜0.264 |

候補を 1 つずつ当てた**周辺回帰**の b_v を単純に足すと、**同じ 1 つの歪みを 5 回数える**。
合成データでの実測（`work/selftest_bias_budget_006.json` の (2a)）:

> **周辺回帰の Σ|b_v| は、実際の歪みの 3.6〜4.3 倍になった。**

その結果、**交絡がまったく無い指標でも、分位が 0.75 に偏ったセットでは周辺回帰版の合格率が 0%**
（同時回帰版は 51.7%）だった。**同じ失敗（きれいな指標が落ちる検査）を繰り返すことになる。**

→ **判定には同時回帰（偏回帰係数）を使う。** 周辺回帰の Σ|b_v| は
「重複して数えた上限」として**必ず併記する**が、合否には使わない。

### 6.4 閾値 0.10 の導出（**過去に使っていたから、は根拠にしない**）

| # | 根拠 | 数値 |
|---|---|---|
| 1 | 守りたい判断（セットの絶対値条件。EXP-20261001-001 §6.2、PI が結果を見る前に固定） | **0.41 標準偏差** |
| 2 | 歪みが判断の 1/4 を超えないこと | 0.41 ÷ 4 = **0.1025 → 0.10** |
| 3 | 判断の線に対する割合 | 0.10 / 0.41 = **24.4%** |
| 4 | 消せない雑音との比（対照 119 個の遺伝子セットの平均スコア z の標準偏差、実測 0.0802 / 0.0782 / 0.0806） | 0.10 / 0.080 = **1.25 倍**。**系統的な歪みを、設計がすでに飲んでいる偶然のばらつきと同程度までに抑える** |
| 5 | 統計量の標準誤差との比（無作為な対照 119 個のセット 1500 件での `se_B` の中央値 **0.0073**） | 0.10 / 0.0073 = **13.7 倍** |
| 6 | 参考: 旧 M5 の閾値 0.10 と標準誤差 0.045〜0.047 の比 | **2.1 倍**（**これが「対照遺伝子の 59% が入れ替わっただけで合否が反転した」原因**） |

**#4 と #5 が同時に成り立つことが要点である。** 判断を守るには 0.10 以下にする必要があり
（#2〜#4）、かつ 0.10 は測定の精度の 13.7 倍あるので**測れる**（#5）。
旧 M5 は #5 が 2.1 倍しかなく、**測れない細かさを要求していた**。

**上限側の確認**: 予算を 0.41 の 1/2（0.205）まで緩めると、歪みだけで判断の線の半分を
動かせてしまう。1/8（0.051）まで締めると、無作為な対照セットの上側の 95 パーセンタイル
（実測 0.0742）を割り、**偏っていないセットでも落ちはじめる**。**0.10 はこの両者の間にある。**

| — | 対照 119 個の遺伝子セットの平均スコア z の雑音（これ以下は実際の歪みと区別できない） | **0.0802 / 0.0782 / 0.0806** |

**E の読み方。** 1 つのセットの「実際の歪み」には、どうやっても消えない雑音（0.080 標準偏差）が
乗るため、1 塊だけを見て一致を論じることはできない（`BC 偏った塊での見積もりと実際` に
その生の表を残してある。食い違いの最大 0.185 は、ほぼこの雑音である）。
3,200 セットをまとめた傾きで見ると **0.882（1.0 を含む）** であり、**見積もりは系統的に
外していない**。**区間は分け方（split）ごとのばらつきから作った。**
行を取り直す素朴なブートストラップは、同じ分け方の行どうしが相関しているため
区間を狭く見せる（実際、分け方を変えると傾きが 0.50〜0.71 と動いた）。

### 6.7 陽性対照 S-3 の扱い（**歪みの予算で合否を決めない**）

目標の軸の陽性対照 71 個は、性質が大きく偏っている（対照の中での平均分位、seed81）:

| 候補 | 移動量 | 元の順位 | 入力の長さ | 相対位置 | 一様成分 |
|---|---|---|---|---|---|
| 平均分位 | 0.457 | 0.545 | **0.334** | **0.668** | **0.217** |

このため歪みの見積もりは **B = +0.126 / +0.129 / +0.150、上側 0.238 / 0.239 / 0.258** で、
予算 0.10 を超える。**これは陽性対照の役割（目盛りが立っているかを見る）とは別の話である。**
そこで S-3 は次のようにする。

> **陽性対照の遺伝子セットの平均スコア z から歪みの上側を引いた値が、必要な 0.53 標準偏差以上であること。**

前回の値 0.976 / 1.057 / 1.029 から上側を引くと **0.718 / 0.818 / 0.771** であり、
0.53 に対して余裕がある。**歪みを最大限に見積もっても目盛りは立っている**と言える。

- **この計算は陽性対照の値（既報。EXP-20261001-001 の確定済みの出力）だけを使い、
  主判定の値は使わない。**
- 同じ扱いをセット単位の中立性 S-4 にも当てる（§6.8 の表）。
