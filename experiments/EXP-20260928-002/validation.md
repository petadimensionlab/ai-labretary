## 1. 結論（提案）

### 1.1 判定の提案: **否定された（主予測は棄却）**。判定不能ではない

事前登録の主判定（G-1）を機械的に当てはめた結果は**不合格**であり、
反証条件 **F-1** に当てはまる。同時に、判定不能を導く反証条件
（F-5 偽経路セット / F-6 アッセイの妥当性 / F-7 指標の健全性 / F-8 中立性）は
**どれも発火していない**。したがって「測れる状態になかった」のではなく、
「測れる状態で、事前に決めた大きさの効果が見つからなかった」と読める。

### 1.2 否定の強さ: **0.37 標準偏差以上の効果は否定できる。0.25〜0.37 は否定できない**

- 3 seed 平均の遺伝子セットの平均スコア = **+0.174**、遺伝子間の標準偏差 1.079、
  120 遺伝子の平均の標準誤差 0.099、**95% 信頼区間 [−0.019, +0.368]**。
- 信頼区間の上端 **0.368** は、事前登録の最小検出可能効果量（minimum detectable effect） **0.44**（ばらつき込み、plan.md §7）を下回る。
  → **「0.44 標準偏差以上の効果はない」は支持される。**実測ではもう少し強く、
  **0.37 標準偏差以上を否定できる**（片側 97.5%）。
- 一方、信頼区間は **0 を含む**。**0〜0.37 の範囲は一切区別できない。**
  事前登録が「見逃しうる」と書いた 0.25〜0.43 のうち、否定できたのは 0.37〜0.43 の部分だけで、
  **0.25〜0.37 は依然として見逃しうる。**
- 絶対値条件 0.245 までの距離は seed ごとに 0.088 / 0.106 / 0.018（観測は閾値の 0.64 / 0.57 / 0.93 倍）。
  **seed 53 だけは 99 パーセンタイル条件（0.212）を満たしたが（0.227）、絶対値条件 0.245 を満たさない。**
  3 seed すべてで両条件を満たすという規則には、どの seed も達していない。

### 1.3 「方向は正しいが大きさが足りない」という読み方は**支持されない**

交差（G-2）は合格しているが、これは**目標の軸と筋線維芽細胞の軸の 2 本しか比べていない**。
事前登録が用意した **3 本目の軸（対照の状態＝三次リンパ組織が少ない提供者の腎線維芽細胞）**を
入れると像が変わる。

> **この節の数値は検算できる形で残してある**（PI 指示 2026-09-29）。
> コード `analysis/third_axis_check.py`、出力 `results/eval/third_axis_002.json`。
> **どちらも事前登録の 38 ファイルには加えていない**（事後の検証用）。
> このコードは公式の評価コードと同じ式（二次回帰の補正・対照 980 個での標準化・自己除外）を使っており、
> 遺伝子ごとの値は公式の `results/eval/gene_seed_002.csv` と **3 軸すべてで最大差 5.1e-11** で一致する。
> **二次回帰の補正を省くと、どのセントロイドへも一様に近づく成分が残って 3 軸の大小関係が変わる。**
> 出力の各セットに「補正なしとの比較」を併記したので、補正の有無で何が変わるかもその場で確かめられる。

（seed ごとに −0.080 / −0.077 / +0.032。非マーカー部分セットは 3 seed とも負）。
つまり観測された弱い正の値は「三次リンパ組織オーガナイザー様の状態へ向かう成分」ではなく、
**「筋線維芽細胞から離れる方向の、状態を問わない成分」**でほぼ説明がつく。
交差（G-2）が合格したのは、経路セットが目標へ寄ったからではなく、

### 2.7 seed と機体の交絡（**同一機体内の差のほうが大きい**）

| **折半信頼性（split-half reliability）** | 提供者 22 人を 2 群に無作為分割して 1,136 遺伝子の値の順位を比べた。Spearman ρ の中央値 **0.837 / 0.821 / 0.845**（20 回の分割、範囲 0.798〜0.861）。**参考基準 0.7 を上回る** |

> これは「120 遺伝子を固定したときの、提供者をまたいだ安定性」を見ているだけで、
> 「この 120 遺伝子が経路の代表として無作為な遺伝子群と違うか」は見ていない。
> 仮説が問うているのは後者であり、事前登録もそちら（無作為な遺伝子セットとの比較）を採っている。
> 遺伝子のサンプリングを考えた 95% 信頼区間は **[−0.019, +0.368]** で 0 を含む（§1.2）。
> **測定は安定しているが、その安定して測れた値が小さい、というのが本実験の内容である。**

## 3. 経路セットの内訳と、設計上の弱点

### 3.1 層別 — 一部の層だけが動いて全体で薄まっていないか

経路セット 120 個は 3 つの層からできている
（plan.md §4.1 の S1 / S2 / S3。本文では名前で呼ぶ）。
**この表の数値も `results/eval/third_axis_002.json`（コード `analysis/third_axis_check.py`）から検算できる。**

| 層 | 数 | 目標の軸 | 筋線維芽細胞の軸 | 対照の状態の軸 | **目標 − 対照の状態** | 95% 信頼区間（目標の軸） |
|---|---|---|---|---|---|---|
| 経路の構成因子 | 61 | +0.111 | −0.152 | +0.172 | −0.061 | [−0.152, +0.374] |
| **一次文献の転写標的** | **13** | **+0.502** | +0.323 | **−0.296** | **+0.798** | [−0.139, +1.143] |
| キュレーション済みセット | 46 | +0.166 | +0.034 | +0.420 | −0.254 | [−0.152, +0.484] |
| 全体 | 120 | +0.174 | −0.029 | +0.216 | −0.042 | [−0.019, +0.368] |

**一次文献の転写標的 13 個だけが、質的に違う振る舞いをしている。**
この層だけが「目標の状態へ寄り、対照の状態からは離れる」という、
仮説が予測した形の動き（目標 − 対照の状態 = +0.66 / +0.83 / +0.90、3 seed とも正）を示す。
他の 2 層は逆（対照の状態のほうへ寄る）である。

**ただし、これを「効く層を見つけた」と読んではならない。**

- **層の違いは統計的に区別できない。** 3 層の差の検定（Kruskal-Wallis）p = 0.43、
  一次文献の転写標的 対 残り 107 個の差 +0.368（Welch の t 検定 p = 0.30）。
- **13 個では検定にならない。** この大きさのセットの閾値は 0.645〜0.652、
  事前登録の最小検出可能効果量は 1.25 標準偏差（plan.md §7）。観測 0.502 は**どちらにも遠く届かない**。
  信頼区間 [−0.139, +1.143] は 0 を含む。
- この層は**目標の軸と同時に筋線維芽細胞の軸でも正**（+0.323）なので、
  「目標の状態に特異的」とも言い切れない。
- **層の比較は事前登録では記述値であって、判定に使わないと決めてある。**

→ **「一部の層だけが動いて薄まっている」という読み方は、否定も確認もできない。**
仮説生成の材料としては残るが、本実験の結論にはできない。

### 3.2 個々の遺伝子（**記述値。「効く遺伝子」とは書かない**）

事前登録の記述値の規則（3 seed すべてで 2.5 標準偏差以上）に当てはまったのは
**経路セット 120 個中 3 個**である。

| 遺伝子記号 | 層 | 非マーカーか | seed 51 / 52 / 53 | 3 seed 平均 | 目標側への偏り |

| TNFSF10 | 経路の構成因子 | はい | 2.60 / 2.58 / 2.63 | **+2.61** | +0.114 |

偶然合格率は 0.0092 で、120 個なら期待 1.1 個。**3 個以上出る確率は 0.10。**

+0.174 は、多数の遺伝子のわずかな正の偏り（うち相当部分は目標マーカーの残留、§1.3）の合計である。

仮説（HYP-20260928-01 §7-3）と計画（plan.md §4.1、§13-3）が事前に指摘していた

このことは限界として必ず書く。**この可能性を根拠に主判定の不合格を割り引いてはならない。**

### 3.4 事前登録では検査しきれていなかった点（今後のために記録する）

## 4. 限界

計画 §13 の 10 項目をそのまま引き継ぐ。本検証で数値が確定したもの、
および検証の過程で新たに分かったものを次に書く。

### 4.1 この否定が言えること・言えないこと

| 言えること | 根拠 |
|---|---|
| この 120 遺伝子のセットに、**0.37 標準偏差以上の効果はない**（95%） | 3 seed 平均 +0.174、95% 信頼区間 [−0.019, +0.368] |
| 事前登録の最小検出可能効果量 **0.44 標準偏差以上の効果はない** | 同上（上端 0.368 < 0.44） |
| 判定は対照遺伝子の数（980 / 600 / 520）に依存しない | 3 版とも不合格 |
| 判定は特定の提供者に依存しない | 提供者を 1 人ずつ除いても 0.128〜0.236 |
| 判定は機体差で説明されない | 2 台の出力がバイト同一。同一機体内の seed 差のほうが大きい |
| アッセイは働いていた（判定不能ではない） | 陽性対照 1.39〜1.45、指標の健全性・中立性すべて合格 |

| **言えないこと** | 理由 |
|---|---|
| 「効果がない」 | **0〜0.37 標準偏差の範囲はまったく区別できない。**特に事前の見込み 0.25〜0.60 のうち **0.25〜0.37 は見逃しうる** |
| 「LTβR–非古典的 NF-κB 経路に効果がない」 | 測ったのは経路の構成因子が中心で、**代表的な分泌プログラムはほぼ測れていない**（ケモカイン・サイトカイン候補 45 個中 7 個しか残らない。§3.3） |
| 「経路を活性化しても状態は動かない」 | 過剰発現型の摂動は「遺伝子を入力の最上位へ動かす」操作で、**経路の活性化ではない**。しかも 1 遺伝子ずつであって同時摂動ではない |
| 「LTBR / RELB / NFKB2 は効かない」 | この 3 遺伝子は摂動していない。HYP-20260925-02 の判定には使えない |
| 「個々の遺伝子が効かない」 | 検定の単位はセット。C3・MAP3K5・TNFSF10 は記述値であって、**効く遺伝子とは書かない** |
| 三次リンパ組織が実際にできる／できない | 目標の状態のラベルは 3 遺伝子の検出による**推定**で、組織学的な確認がない |
| 細胞老化との関係 | 盲検中の遺伝子を摂動していないので、本実験は細胞老化に触れていない |

### 4.2 検出力の限界の内訳

| 大きさ | この設計での扱い |
|---|---|
| 0.44 標準偏差以上 | **否定できる**（事前登録の最小検出可能効果量、実測の信頼区間の上端 0.368 より上） |
| 0.37〜0.43 | **否定できる**（実測の信頼区間の上端より上） |
| **0.25〜0.37** | **否定できない。**合格しないことのほうが多い範囲で、実測の信頼区間にも入る |
| 0〜0.25 | 否定できない。絶対値条件 0.245 が事実上の床になっているため、**K をいくら増やしてもこの帯は測れない** |

> 仮説 §5 の F-1 は「0.46 標準偏差」、計画 §7.2 は「0.44 標準偏差」と書いている。
> 計画のほうが事前登録の規則そのもので計算し直した後の値なので **0.44 を採る**。
> どちらを採っても本検証の結論（上端 0.368 で否定できる）は変わらない。

### 4.3 判定基準が厳しすぎないかの確認（**否定を提案する側の義務として**）

- **偶然合格率は 0.0018**（独立に再計算。基準 0.02 以下）。
  規則は緩すぎないが、**5% 水準より 28 倍厳しい**。
- 絶対値条件 0.245 は、**別の実験（EXP-20260927-004、対照 84 個で K = 24）の偶然合格率 5% から
  持ってきた固定値**で、本実験の K = 120 では 99 パーセンタイル（0.213）を上回る。
  **実質的に判定を決めているのは、本実験で較正されたのではない 0.245 である。**
- **仮にこの絶対値条件を外し、99 パーセンタイル条件だけで判定したとしても、
  合格するのは seed 53 のみで、3 seed すべてという要件を満たさない。**
  → **規則を緩めても判定は不合格のまま。「厳しすぎたから落ちた」のではない。**
- 参考までに、事前登録ではない緩い検定（3 seed 平均を無作為セットと比べる片側検定）では
  経路セット p = 0.026、非マーカー部分セット p = 0.21。
  **最も緩い読み方でも、循環を除いた部分セットは偶然と区別できない。**

### 4.4 本検証で新たに分かった限界

1. **交差の検査（G-2）は特異性を保証していない。**目標の軸と筋線維芽細胞の軸だけを比べると、
   「筋線維芽細胞から離れる」動きが「目標へ寄る」と読めてしまう。
   対照の状態の軸を入れると、経路セットは**目標より対照の状態のほうへ寄っている**（§1.3）。
2. **偽経路セットの中心が 0 からずれている**（+0.049 / −0.048）。そろえる手続き自体の副作用（§3.4(a)）。
3. **このセットの seed 間のぶれは想定より大きい**（0.047 対 期待 0.019、無作為セットの上位 1.5%）。
   seed 3 つでは決定的でないが、次の実験では seed を増やすか、
   摂動する細胞を seed 間でそろえる設計を検討する価値がある。
4. **提供者単位で見ると弱い正の傾きは安定している**（21 人中 16〜19 人が正）が、
   これは遺伝子を固定したときの安定性であって、仮説が問うている
   「無作為な遺伝子群との違い」ではない（§2.8 の注）。**混同しないこと。**
