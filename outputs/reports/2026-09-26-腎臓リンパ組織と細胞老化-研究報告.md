- 状態: 確定
- 承認: PetadimensionLab (PI), 2026-09-27 — 実験 004 は部分的に支持、実験 005 は判定不能
- 期間: 2026-09-25 〜 2026-09-26
- 作成: Labretary / 2026-09-26
- 用語は [用語集](../../docs/用語集.md) に統一。各実験の原文は [閲覧ページ](https://claude.ai/artifact/8qytjWvp22YU5FC78eP5hi) で読めます

## 要旨

腎臓の三次リンパ組織が腎臓病で果たす役割を、細胞老化と結びつけて調べるため、公開データと Geneformer を使ったコンピュータ上の遺伝子摂動に取り組みました。2 日間で 5 つの実験を行い、**生物学的な結論はまだ出ていません**。代わりに、手法についての確度の高い結論が得られました。**いまの枠組みは、細胞の状態を動かす原因の遺伝子と、単なる目印の遺伝子や摂動の大きさとを区別できていません。** これは想定外の副産物ですが、ここを直さずに本命の仮説を検証しても、結果を信じられません。本報告はその判断の根拠をまとめたものです。

## 1. 目的と狙い

### 知りたいこと
腎臓の中にできる三次リンパ組織が、慢性腎臓病や腎臓癌の進行にどう関わるのか。とくに、細胞老化を起こした細胞との相互作用が鍵ではないかという見立てがあります。

### 具体的な問い
損傷から回復しきれない近位尿細管（修復不全の近位尿細管）は、どの遺伝子に依存してその状態に留まっているのか。その遺伝子を取り除けば、健常な状態へ戻る方向に動くのか。動くとすれば、三次リンパ組織が多い腎臓とそうでない腎臓で違いがあるのか。

### この 2 日で答えを出そうとしたこと・出なかったこと
| | |
|---|---|
| 出せた | 使えるデータがあるか。計算環境が動くか。**判定の仕組みが信用できるか** |
| 出せていない | 上の生物学的な問いそのもの |

答えが出なかったのは計算資源の不足ではなく、**判定の仕組みが要求水準に達していなかった**ためです。

## 2. 背景

腎臓に三次リンパ組織ができることは、加齢した腎臓や損傷後の腎臓で報告されています（Sato ら 2016, PMID 27699223）。その周囲には損傷マーカーを出したまま回復しない尿細管が見られ、免疫細胞と尿細管の相互作用が想定されています（Yoshikawa ら 2023, PMID 37548710）。老化関連 T 細胞を抑えると三次リンパ組織が縮小するという報告もあり（Sato ら 2022, PMID 34813503）、細胞老化との接点が示唆されています。

一方で、これらをヒトの単一細胞データで直接検証した研究は限られています。公開データを調べたところ、**三次リンパ組織の有無を細胞ごとに記録したヒトのデータは見つかりませんでした**。組織切片で確認したラベルがある公開データは、腎臓癌の空間データ 1 件のみでした。このため本研究では、遺伝子発現の組み合わせから三次リンパ組織の多さを**推定**して使っています。以降で「三次リンパ組織が多い提供者」と書くのは、すべてこの推定値です。

## 3. アプローチ

### 3.1 使ったデータ

公開データ 7 件、約 104 万細胞、7.7 GB を取得しました。すべて CC BY 4.0 の公開データです（データセットごとのライセンス表示は未確認）。

中心に使ったのは米国の腎臓精密医療プロジェクトによる腎臓アトラス（Lake ら 2023, PMID 37468583）で、慢性腎臓病・急性腎障害・健常の提供者を含みます。

### 3.2 使ったモデルと計算環境

Geneformer の 3.16 億パラメータ版を使いました。細胞を「発現量の高い順に並べた遺伝子の列」として表し、そこから細胞 1 個ごとの数値ベクトル（細胞埋め込み）を得るモデルです。遺伝子を 1 つ取り除いて再計算し、埋め込みが健常側へどれだけ動いたかを測ります。

計算機は 3 台を使い分けました。

| 計算機 | 用途 |
|---|---|
| 手元の Mac（M4 Pro） | 軽い解析、前処理、検証 |
| リモート 1 号機（NVIDIA GB10） | 追加学習、重い摂動計算 |
| リモート 2 号機（同型） | 並行して別の摂動計算 |

Apple 製 GPU でも Geneformer が動くことを最初に確認し、そのうえで重い計算はリモートに回す体制にしました。

### 3.3 やったこと

```
データ収集 → 仮説づくり → 実験 001（生物学の問い）
                                ↓ 判定不能
                          実験 002（指標の改良）
                                ↓ 否定
                          実験 003（モデルの改良）
                                ↓ 部分的に前進
                     実験 004・005（判定の仕組みの検証）
```

実験 001 で本命の問いに答えようとしましたが、判定できませんでした。以降の 4 つは、**なぜ判定できなかったのかを潰していく作業**です。本命の遺伝子は、判定の仕組みが信用できると確認できるまで見ない方針（盲検）にして、対照遺伝子だけで検証を進めました。

### 3.4 判定の考え方

毎回、**結果を見る前に**判定基準を計画書に書き込みました。基準は、効果があるはずの遺伝子（陽性対照）と、効果がないはずの遺伝子（対照遺伝子群・恒常発現遺伝子・中立対照）を比べる形です。

| 基準 | 内容 |
|---|---|
| 陽性対照の分離 | 陽性対照が対照遺伝子群の上位 10% に入る |
| 恒常発現遺伝子との差 | 陽性対照が恒常発現遺伝子を上回る（18 組中 15 組以上） |
| 恒常発現遺伝子の中立性 | 恒常発現遺伝子が対照遺伝子群の中に収まる |
| 中立対照パネルの中立性 | 中立対照 7 遺伝子のうち 5 つ以上が中立の範囲に収まる |
| 再現性（参考） | 提供者を半分に分けたときの順位の一致が 0.7 以上 |

## 4. 結果

### 4.1 実験 001 — 本命の問い（判定不能）

慢性腎臓病の修復不全の近位尿細管で、細胞老化に関わる 2 遺伝子とリンパ組織の受容体 1 つを削除しました。3 つとも、健常方向への動きは対照遺伝子群と区別できませんでした（基準を満たした試行は 0/3）。

ただし**この結果は「効果がない」ことを意味しません**。陽性対照（損傷マーカーとして確立した 2 遺伝子）も恒常発現遺伝子と区別できず、**判定の仕組み自体が働いていなかった**ためです。

原因は、遺伝子を 1 つ削除すると、どの遺伝子でも細胞がすべての状態から一様に離れることでした。90 通りすべてでこれが起きていました。この一様な動きが、遺伝子ごとの違いより桁違いに大きく、信号を覆い隠していました。

**PI の判定: 判定不能**

### 4.2 実験 002 — 一様な削除効果を差し引く（否定）

一様な動きを差し引く指標を 18 通り試しました。最も良かったのは、細胞の入力の長さごとに対照遺伝子の平均を差し引く方法（長さ補正した接近度）です。

| | 結果 |
|---|---|
| 一様な動きの解消 | 対照遺伝子が健常から離れる割合が 100% → 32% |
| 長さとの相関 | 解消（−0.06） |
| 中立対照 7 遺伝子 | 7/7 が中立の範囲 |
| **陽性対照の分離** | **不合格**（2 遺伝子の順位 0.67 と 0.78） |
| **再現性** | **不合格**（0.32。細胞数を倍にしても改善せず） |

判定基準が厳しすぎたのではないかを別途検証しました。陽性対照が通る水準まで閾値を緩めると、効果のない遺伝子でも 26% が偶然通ってしまい、判定の意味がなくなります。恒常発現遺伝子を使わない基準（陽性対照の分離・再現性）だけでも不合格なので、**基準の厳しさが原因ではない**と判断しました。

**PI の判定: 否定**

### 4.3 実験 003 — 追加学習したモデルを使う（主要な予測は否定、副次的な予測は支持）

事前学習のままのモデルではなく、「修復不全か健常か」を見分けるよう追加学習させたモデルを使いました。学習はリモート GPU で 13 分でした。学習に使った提供者と、摂動に使う提供者は完全に分けています。

| | 事前学習モデル | 追加学習済みモデル |
|---|---|---|
| 一様な動き（対照遺伝子が離れる割合） | 100% | **10〜15%** |
| 恒常発現遺伝子の中立性 | 不合格 | **合格** |
| 恒常発現遺伝子との差 | 10/18 | **16/18** |
| 陽性対照の分離 | 不合格 | **不合格**（1 遺伝子は合格、もう 1 遺伝子が不合格） |

**手法としては大きく前進しました。** 一様な動きと恒常発現遺伝子の偽陽性という 2 つの問題が、ほぼ解消しています。しかし陽性対照 2 つのうち 1 つが依然として分離せず、事前登録の規則により主要な予測は否定となりました。

**PI の判定: 否定**（副次的な予測 2 つは支持）

### 4.4 実験 004 — 合格した陽性対照は本物か

追加学習済みモデルで唯一分離した陽性対照について、「分類器が目印として使っている遺伝子を消しただけではないか」を確かめました。

**比較用の遺伝子**: 同じように損傷側で発現が上がるが、状態の原因とは考えられていない 10 遺伝子を、発現データだけを使って選び、同じ条件で摂動しました。

- この陽性対照は、3 回すべてで 10 遺伝子すべてを上回りました（効果の大きさは次点の 2.4 倍）。目印を消しただけでは説明できません。
- 一方で、**10 遺伝子のうち 3 つが陽性対照と同じ基準を満たしました**。偶然合格する確率 10% の 3 倍です。つまり**この判定基準は、原因の遺伝子に特異的ではありません**。

**提供者単位の解析**: 細胞ごとではなく提供者ごとに集計しても判定は変わりませんでした。分離した陽性対照は 13 人全員で同じ向きに動き、もう一方は 5 人にとどまりました。提供者間のばらつきが、後者の不合格の一因です。提供者を 14 人から 29 人に増やしても、再現性は 0.46 から 0.60 程度で、基準の 0.7 には届きませんでした。

**PI の判定: 部分的に支持**（比較遺伝子の予測は支持、再現性の改善は不成立）

### 4.5 実験 005 — 陽性対照を選び直す

文献で因果関係が報告されている遺伝子を陽性対照に選び直し、2 種類の摂動を行いました。

**削除型（5 遺伝子）**: 5 つとも対照遺伝子群と区別できませんでした。ただし恒常発現遺伝子も中立対照も正しく中立に収まっており、一様な動きもないため、**これは信用できる否定的な結果**です。

**過剰発現型（6 遺伝子）**: 3 つが基準を満たしましたが、同時に恒常発現遺伝子の 1 つも上位に来てしまい、事前登録の規則により判定不能としました。

さらに重要な発見がありました。過剰発現の効果の大きさが、**その遺伝子がもともと細胞内で何位にあったか**と相関していました（相関 0.32〜0.71）。対照遺伝子は発現頻度をそろえて選んでいましたが、この「上げしろ」はそろえていませんでした。基準を満たした 3 遺伝子も、恒常発現遺伝子の不合格も、これで説明がつく可能性があります。

**PI の判定: 判定不能**

## 5. 考察

### 最も確度の高い結論
実験 004 と実験 005 を合わせると、一貫した像が見えます。**いまの枠組み（遺伝子を摂動して対照遺伝子群と比べる）は、状態を動かす原因の遺伝子を、単なる目印の遺伝子や摂動の大きさから区別できていません。** 根拠は 2 つです。

1. 原因とは考えられていない遺伝子の 3/10 が、陽性対照と同じ基準を満たした
2. 過剰発現では、効果の大きさが遺伝子の元の順位で説明できてしまう

この状態で本命の遺伝子を評価すれば、合格しても不合格しても解釈できません。盲検を続けた判断は妥当だったと考えます。

### 追加学習は効いた
一様な動きの解消は明確な前進でした。ただし副作用として、追加学習したモデルは分類に使う目印の遺伝子を強く重みづけている可能性があり、「分離した = 原因である」とは言えなくなりました。改善と新しい落とし穴が同時に生まれた形です。

### 三次リンパ組織の比較は成立しなかった
三次リンパ組織が多い提供者と少ない提供者の細胞は、モデルの埋め込み上ほとんど区別できませんでした（重心間の距離が、損傷と健常の距離の 12 分の 1）。推定したラベルの限界か、そもそもこの軸が埋め込みに表れないのか、現時点では分かりません。

### 予想と違った点
当初は計算量が最大の制約だと考えていましたが、実際の制約は**判定の設計**でした。GPU 時間の合計は 12 時間ほどで、リモート機を使えば十分に収まります。時間を使ったのは、結果を信じてよいかの検証です。

## 6. 限界

- コンピュータ上の摂動実験は、モデルが学習した発現の連動に基づく予測であり、因果関係を直接示すものではありません
- 三次リンパ組織の多さはすべて推定値で、組織を見て判定したものではありません
- 計算精度に bfloat16 を使っています。効果が小さい場面では、この精度が判定の境界と同じ桁になります
- 損傷側と健常側で提供者が完全に分かれており、状態の違いと提供者の違いを分離できません
- 比較用遺伝子を「原因ではない」と判断した根拠は知識に基づくもので、系統的な文献調査ではありません
- 本命の遺伝子は一度も評価していません

## 7. 次のアクション

### 手法の修正（本命の検証より先）
1. 対照遺伝子を、発現頻度だけでなく**元の順位（上げしろ）でもそろえる**
2. 判定基準に、対照遺伝子群との比較だけでなく**発現をそろえた比較遺伝子群との比較**を組み込む
3. 提供者間のばらつきへの対処。提供者数を増やしても再現性が上がらなかったため、指標そのものの見直しが必要

### そのあとに行うこと
4. 手法が基準を満たしたら、盲検を解除して本命の 3 遺伝子を評価する
5. 三次リンパ組織の状態を、空間データ由来のシグネチャーで定義し直す（Meylan ら 2022, PMID 35231421）

### 実験室で行うこと
コンピュータ上で支持が得られた場合に限り、ヒト近位尿細管細胞で損傷・老化様の状態を誘導し、候補遺伝子を抑えて損傷マーカーの変化を測る。**現時点では、実験室での検証を提案できる段階にありません。**

## 8. このレポートで使った用語

| 用語 | 意味 |
|---|---|
| 三次リンパ組織 | 炎症が続く臓器の中に後天的にできるリンパ組織様の構造 |
| 近位尿細管 | 腎臓で原尿の再吸収を担う管の細胞 |
| 修復不全の近位尿細管 | 損傷後に健常へ戻りきらない状態の近位尿細管。本研究の出発点 |
| 細胞埋め込み | 細胞 1 個をモデルが数値ベクトルで表したもの |
| コンピュータ上の遺伝子摂動 | モデルの中で遺伝子を消す・増やして、細胞の状態の動きを計算する模擬実験 |
| 一様な削除効果 | どの遺伝子を消しても細胞がすべての状態から同じように離れる、遺伝子によらない見かけの動き |
| 長さ補正した接近度 | 細胞の入力の長さ別に対照遺伝子の平均を差し引いた、本研究の主指標 |
| 陽性対照 | 効果が出ると期待される既知の遺伝子。手法が働いているかの確認に使う |
| 対照遺伝子群 | 効果がないはずの遺伝子を発現頻度をそろえて多数選んだもの。比較の土台 |
| 恒常発現遺伝子 | どの細胞でも安定して働くとされる遺伝子 |
| 中立対照パネル | 損傷側と健常側で発現差がないことを確認して選んだ 7 遺伝子 |
| 追加学習済みモデル | 本研究のデータで「修復不全か健常か」を見分けるよう追加学習させた Geneformer |
| 提供者 | 検体を提供した患者 1 人 |
| 折半信頼性（split-half reliability） | 提供者を 2 群に分けて別々に順位を出したときの一致度 |
| 盲検 | 手法の妥当性が確認できるまで本命の遺伝子の結果を見ないこと |
| 事前登録 | 結果を見る前に判定基準を文書に固定すること |
