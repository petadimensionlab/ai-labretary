## 含まれていないもの（意図的に外した）

| 何 | なぜ |
|---|---|
| `data/raw/`（ヒト由来の発現データ） | 公開データだが大きい。**読み取り専用**で扱う約束のもの。入手先は `scripts/download_kidney_tls.sh` と `outputs/literature/2026-09-25-kidney-TLS-datasets.md` |
| `models/`（Geneformer の重み） | 大きい。入手は `scripts/setup_geneformer.sh` |
| トークン化済みデータ、遺伝子ごとの生の摂動出力 | 合計で数十 GB。**評価結果（`results/eval/*.json`）と経過ログは入れてある** |
| 資格情報（`.env`, HF_TOKEN, OPENROUTER_API_KEY） | **含めない**。混入がないことを確認済み |
| 音声ファイル | 大きい。原稿は `outputs/history/` にある |

**このため、この一式だけでは摂動の再計算はできない。** 経緯の把握・判断の引き継ぎ・
設計の作り直し（次の 2 段階は摂動を使わない）には十分である。
再計算が要るときは、元データとモデルを上の手順で取り直す。

## 引き継ぎ先への注意

1. **判定を書き換えない。** 仮説の status を変えてよいのは PI の判断を受けた後だけ
2. **結果を見てから判定基準を変えない。** 基準が不適切と分かったら、結論を出さずに設計を作り直す
3. **報告は必ず「目的・狙い → アプローチ → 結果 → 考察」の順で書く。** 略号を使わない（PI の強い指示）
4. **摂動に着手する前に `scripts/analysis/axis_feasibility.py` を通す。** 不合格なら着手しない
5. **細胞老化についてはまだレポートに書かない。** TP53 が盲検中で、測る土台も立っていない

理由と背景は `00-引継ぎ書.md` にある。
