## 要旨
EXP-20260926-005 の検証（`validation.md` §4）で見つかった「過剰発現型の摂動の指標が、遺伝子ごとの元の位置の影響を受けている疑い」について、事前登録外の探索的な追検証を行った。移動距離をそろえた対照（対照遺伝子群の中で元の位置が近いものだけを選んだ比較）に替えても、過剰発現型で上位に来た 3 遺伝子（HNF4A・PPARA・NFE2L2）は上位のまま残った。一方、区間に分けて元の位置の影響を差し引く補正では、遺伝子ごとの相関はほとんど縮まなかった。削除型の否定的結果は、この追検証でも変わらなかった。事前登録の判定（過剰発現型は判定不能、削除型は否定的）と仮説の状態（判定不能）はこの追検証によって変えていない。この結果を踏まえ、新しい検定を事前登録する提案をし、PI は 13 時前に「並行」で承認、EXP-20260927-001・EXP-20260927-002 に進んだ。

## 1. 目的と狙い
- 何を知りたいのか: `validation.md` §4 で指摘された疑い、すなわち過剰発現型の摂動の指標が「遺伝子の生物学的な効果」ではなく「その遺伝子がもともと入力のどの順位にあったか（元の位置）」で決まっている可能性が、対照の選び方を変えても残るかどうかを確かめる。
- なぜ今この実験が必要なのか: `validation.md` の本検証では、対照遺伝子群が発現頻度だけをそろえて選ばれており、元の位置はそろえていなかった。この設計の穴が判定不能の主因になったため、対照の選び方を変えた場合に結論が変わるかを見ておく必要があった。
- この実験で答えが出ること／出ないこと: 「元の位置をそろえた対照でも同じ遺伝子が上位に残るか」「区間補正で交絡がどれだけ縮むか」には答えが出る。ただし、これは事前登録された判定基準ではないため、仮説の支持・否定を確定させる材料にはならない。

## 2. 背景
- EXP-20260926-005 は、腎臓の修復不全の近位尿細管から健常な近位尿細管への接近度を、既知の関連遺伝子（HYP-20260926-04 で挙げた候補）の削除型・過剰発現型の摂動で調べる実験だった。
- `validation.md` §2 の事前登録判定では、削除型（run D）は否定的結果（陽性対照 5 遺伝子のうち対照遺伝子群の上位 10% に入ったものが 0/5）、過剰発現型（run O）は恒常発現遺伝子の中立性の判定基準が不合格（GAPDH が対照遺伝子群の上位 5% に入り続けた）だったため判定不能とされた。
- `validation.md` §4 で、過剰発現型の分位が遺伝子ごとの元の位置（トークン列での順位。数値が大きいほど元は下位）と強い相関を持つことが分かった（遺伝子単位の順位相関で 3 seed のうち 0.32〜0.65）。これが本 M6 の追検証の出発点。

## 3. アプローチ
### 3.1 使ったデータ
`results-oe/`（過剰発現型、3 seed）と `results-delete/`（削除型、3 seed）の細胞表。入力・盲検・環境は `validation.md` §1 に記載のとおりで、この追検証では変更していない。

### 3.2 使ったモデルと計算環境
EXP-20260926-005 で使った Geneformer の追加学習済みモデルをそのまま使用。追加のモデル学習・再摂動は行っていない（既存の摂動結果への事後的な集計替えのみ）。

### 3.3 やったこと（手順を順番に）
1. `experiments/EXP-20260926-005/analysis/verify_rank_null.py` を実行し、既存の細胞表から「長さ補正した接近度」を、元の位置（相対位置）で区間に分けて再補正した指標を作った（区間の分け方は 5 分割・10 分割の 2 通り、絶対位置での 5 分割も参考として作成）。
2. 対照遺伝子群についても、各遺伝子ごとに元の位置が近い対照だけを最も近い 10 個選ぶ「移動距離をそろえた対照」を作り、この対照に対する分位を計算した。
3. 事前登録された判定基準（`plan.md` §6 の閾値）をそのまま使い、上記の各補正・各対照の組み合わせ（合計 7 通り）で判定を再集計した。判定基準そのものは変更していない。
4. 遺伝子ごとの相関（区間補正の指標と元の位置の相関）を、区間補正の前後で比較し、交絡がどれだけ縮んだかを見た。

### 3.4 比べたもの（対照）と、成功・失敗をどう判定するか
- 対照は事前登録どおり、発現頻度をそろえた対照遺伝子群（20 遺伝子）。これに加え、探索的に「移動距離をそろえた対照」（同じ対照遺伝子群の中から元の位置が近いものだけを選び直したもの）を作った。
- 判定基準は `plan.md` §6 の事前登録どおり（陽性対照の分離、恒常発現遺伝子の中立性など）。この追検証では基準の値も対象遺伝子も変更していない。あくまで「補正の仕方」と「対照の選び方」を変えて、同じ基準に当てはめ直しただけである。

## 4. 結果
- **上位 3 遺伝子の維持**: 過剰発現型で陽性対照の分離の判定基準に合格していた HNF4A・PPARA・NFE2L2 は、移動距離をそろえた対照に替えても、対照分布の中の位置（分位）が +0.87〜+0.93（7 通りの補正・対照すべてで）にとどまり、上位のままだった。一方、ESRRA・PPARGC1A は元の集計と同様に下位側（+0.03〜+0.20）のままだった。
- **恒常発現遺伝子（GAPDH）の扱い**: 区間補正（相対位置の 5 分割・10 分割）を使った対照では、3 seed のうち 2 seed で GAPDH が中立の範囲に収まり、この補正・対照の組み合わせでのみ恒常発現遺伝子の中立性の判定基準に合格した。ただし絶対位置での区間補正では逆に GAPDH の分位が +0.90〜+1.00 と下位寄りになる回もあり、補正の作り方によって結果が変わる（安定していない）。
- **交絡の縮み具合**: 遺伝子ごとの相関（区間補正した指標と元の位置の相関）は、補正前後でほとんど縮まなかった（例: seed 4 で 0.47 → 0.45〜0.50、seed 3 で 0.65 → 0.49〜0.62、seed 5 で 0.32 → 0.27〜0.31）。つまり区間に分けて平均を引く程度の補正では、区間の内側に残る相関を取りきれていない。
- **削除型の否定的結果**: 削除型（run D）は、7 通りの補正・対照のいずれでも、陽性対照の分離の判定基準が 0/5（上限でも分位 +0.63）のままだった。`validation.md` §3 の否定的結果は、この追検証でも変わらなかった。

## 5. 考察
- 過剰発現型の上位 3 遺伝子が、対照の選び方（発現頻度だけをそろえた対照 → 移動距離もそろえた対照）を変えても残ったことは、この 3 遺伝子の順位上昇が「単に元の位置が低かったから動きやすかった」というだけでは説明しきれないことを**示唆する**。ただし、これは事前登録されていない探索的な集計であり、恒常発現遺伝子の中立性の判定基準は依然として補正の作り方に応じて合否が変わる不安定な状態にあるため、過剰発現型の判定不能という結論自体は変えられない。
- 区間補正で交絡がほとんど縮まなかったことは、区間の分け方（5 分割・10 分割・絶対位置）という粗い方法では、元の位置と指標の関係を十分に取り除けないことを示している。これは「区間の中でも元の位置による違いが残る」ためと考えられ、次の検定では区間よりも細かい対応づけ（個々の細胞ごとに近い対照を探す方法など）が必要になる根拠になった。
- 削除型の否定的結果がどの補正・対照でも揺るがなかったことは、この否定的結果が交絡の影響を受けにくい、頑健なものであることを支持する。

## 6. 限界
- ここで得られた「上位 3 遺伝子が残った」という結果は、あくまでコンピュータ上の集計替えによる探索であり、事前登録された判定基準による確定判断ではない。仮説の状態は判定不能のまま変わっていない。
- 移動距離をそろえた対照は、対照遺伝子群 20 遺伝子の中から選び直したものであり、母数が少ないため、遺伝子によっては対応する対照が 10 個に満たず、代わりに全体の対照分布を使った回もある（`verify_rank_null.py` の設計上の退避規則）。
- コンピュータ上の摂動実験は、モデルが学習した発現の連動に基づく予測であり、因果関係を直接示すものではない。

## 8. このレポートで使った用語
| 用語 | 意味 |
|---|---|
| 過剰発現型の摂動 | その遺伝子の発現順位を引き上げる操作 |
| 削除型の摂動 | その遺伝子を入力から取り除く操作 |
| 対照遺伝子群 | 効果がないはずの遺伝子を、発現頻度をそろえて多数選んだもの。比較の土台 |
| 恒常発現遺伝子 | どの細胞でも安定して働くとされる遺伝子（ACTB, GAPDH, PPIA） |
| 元の位置・移動距離 | 摂動する遺伝子が、その細胞の入力の順位列で何番目にあったか。過剰発現型の摂動では最上位へ動かすので、これがそのまま動かす距離になる |
| 長さ補正した接近度 | 細胞の入力の長さ別に対照遺伝子の平均を差し引き、一様な削除効果を取り除いた主指標 |
| 判定基準: 陽性対照の分離 | 陽性対照が対照遺伝子群の上位 10% に入ること |
| 判定基準: 恒常発現遺伝子の中立性 | 恒常発現遺伝子が対照遺伝子群の中（上下 10% の内側）に収まること |
| 判定不能 | 対照が働かないなど、判定できる状態になかった |
| 事前登録 | 結果を見る前に判定基準を文書に固定すること |
| 移動距離をそろえた並べ替え検定 | 細胞ごとに元の位置と入力の長さによる偏りを null 細胞で推定して差し引き、元の位置と長さの分布が重なる null 遺伝子の中で順位をつける検定（EXP-20260927-001 の主検定） |
| 区間内パーセンタイル検定 | 元の位置と長さで区間を作り、同じ区間の null 細胞の中での分位を細胞ごとに求めて遺伝子で平均する検定（EXP-20260927-001 の副検定） |
