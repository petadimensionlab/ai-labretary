## 要旨（結論を先に）
腎臓の三次リンパ組織と細胞老化を Geneformer による in silico perturbation で調べる研究の初日として、(1) Geneformer V2-316M が手元の Mac の Apple 製 GPU（MPS）上で動くことを確認し、(2) 公開データ 7 件・約 7.6 GB・約 104 万細胞を取得・照合し、(3) 実データでの実現可能性調査を行い、(4) 4 件の仮説を作成した。生物学的な結論はまだ出ていない。パイプラインの技術検証（スモーク実行）では 2 件の不具合を見つけて修正し、再発防止のガードレールとして記録した。

## 1. 目的と狙い
- 何を知りたいのか: 腎臓の三次リンパ組織が慢性腎臓病・腎臓癌にどう関わるかを、細胞老化と結びつけて Geneformer による遺伝子摂動で調べられるか。そのために必要な環境・データ・仮説が揃うか
- なぜ今この作業が必要か: 研究サイクル（仮説→計画→実行→検証→レポート）の起点であり、後続の実験がすべてこの日の環境とデータに依存する
- この段階で答えが出ること・出ないこと: 出ること＝環境が動くか、データが使えるか、仮説として成立する細胞状態・遺伝子・細胞数が確保できるか。出ないこと＝三次リンパ組織と細胞老化の生物学的な関係そのもの

## 2. 背景
腎臓に三次リンパ組織ができることは、加齢した腎臓や損傷後の腎臓で報告されている（Sato ら 2016, PMID 27699223）。その周囲には修復不全の近位尿細管が見られ、免疫細胞と尿細管の相互作用が想定されている（Yoshikawa ら 2023, PMID 37548710）。老化関連 T 細胞を抑えると三次リンパ組織が縮小するという報告もある（Sato ら 2022, PMID 34813503）。一方、これらをヒトの単一細胞データで直接検証した研究は限られ、三次リンパ組織の有無を細胞ごとに記録した公開データは、調査した範囲では見つからなかった（`outputs/literature/2026-09-25-tls-feasibility/feasibility.md` §5）。そのため本研究では、遺伝子発現の組み合わせから三次リンパ組織の多さを提供者単位で**推定**して使う方針にした。

## 4. 結果
### 4.1 環境構築（Geneformer V2-316M、Apple 製 GPU）
スモーク実行（`experiments/EXP-20260925-001`、ccRCC マクロファージ 50 細胞、delete 型で CXCL13・CCL19・CDKN1A ＋対照）は、2 件の不具合を経て完走した。

1. **1 回目（失敗、41.31 秒で停止）**: 設定の既定値が `emb_mode: cell` になっており、Geneformer V2 のトークン化（先頭に `<cls>` を付与）と食い違って `Emb mode 'cls' or 'cls_and_gene' required` で停止した。`emb_mode: cls` に固定して解消（ガードレール記録済み）
2. **fp32 実行（計算自体は 357 秒で完了したが、集計処理が KeyError 'gene' で失敗）**: 集計スクリプトの修正後に `summary.csv` を再生成して解消
3. **bf16（コサインも bf16 のまま。240.29 秒で完走）**: 完走はしたが、shift の値が bf16 の丸みで量子化されており不採用と判断
4. **bf16（forward のみ bf16、コサイン比較は fp32 に上げる。240.12 秒で完走、採用）**: 以後の標準設定とした

以上より、**Apple 製 GPU（MPS）上で Geneformer V2-316M の前処理・トークン化・delete 型摂動が完走することを確認した**（n = 50 細胞、1 seed のスモーク規模。シフトの値そのものは解釈しない）。

### 4.2 データ取得
7 件すべてダウンロードに成功し、`SOURCES.md` に記録した sha256 と一致した（サイズ不一致・失敗はなし）。

### 4.3 実現可能性調査（`feasibility.md`）
- 腎疾患データ（KPMP snRNA・scRNA、尿管閉塞腎）では、提供者単位の三次リンパ組織スコア（推定）が B 細胞＋形質細胞比率と強く相関した（Spearman ρ = 0.75 [n = 75 提供者] / 0.80 [n = 77] / 0.81 [n = 12]）。慢性腎臓病・急性腎障害は健常より高かった（Kruskal p = 3.6×10⁻⁴ / 9.9×10⁻⁵ / Mann-Whitney p = 0.0025）
- 加齢との関連は弱く疾患と交絡していた。KPMP snRNA でのみ、疾患調整後も弱い正の関連（β = +0.012/年、p = 0.019）が残ったが、他の 2 データセットでは再現しなかった。**加齢で三次リンパ組織が増えるという主張は 1 データセットの示唆にとどまる**
- 修復不全の近位尿細管の比率は三次リンパ組織スコア（推定）と相関した（ρ = 0.43〜0.84、疾患の交絡は未調整）
- in silico perturbation の対象細胞として確保できたのは、慢性腎臓病内の修復不全型近位尿細管（三次リンパ組織が多い群 7,533 細胞 / 14 提供者、少ない群 4,002 細胞 / 8 提供者）、三次リンパ組織オーガナイザー様の線維芽細胞（777 細胞 / 65 提供者、推定ラベル）、腎細胞癌の腫瘍内 B 細胞→形質細胞（活性化 B 1,498 細胞、IgG 形質細胞 283 細胞）
- 老化関連 T 細胞様・加齢関連 B 細胞様の細胞は非腫瘍データにほとんど存在せず（数細胞〜数十細胞）、細胞状態としては使えないと判断した（摂動対象の遺伝子としてのみ使う）
- CDKN2A（p16）の検出率は近位尿細管系で 1% 未満と低く、削除型摂動の対象にできない
- Geneformer のトークン辞書には、解析した 76 遺伝子のうち IGHG1・IGHA1 の 2 つを除いてすべて収載されていた
- **三次リンパ組織の有無を組織学的に記録した公開データは、調査した範囲では見つからなかった**。本研究の「三次リンパ組織が多い／少ない」はすべて発現の組み合わせによる推定である

## 5. 考察
- Apple 製 GPU 上で Geneformer V2-316M の delete 型摂動が一通り動くことを確認したことで、以後の軽い解析・技術検証は手元の Mac で完結できる見通しが立った。重い本番実行はリモート GPU を使う設計とした
- スモーク実行で見つかった 2 件の不具合（`emb_mode` の既定値、bf16 コサインの量子化）は、いずれも後続の本番実験（M1 以降）の設定に直接反映され、再発を防いだ。これは想定内の技術検証の効果である
- 実現可能性調査により、「三次リンパ組織の多さ」は組織学的な裏付けのない推定値であることが確認された。この限界は以後のすべての仮説・実験に共通する前提になった
- 老化マーカー（CDKN2A など）の検出率が低いデータセットがあることも分かり、削除型摂動の対象選びに影響した

## 6. 限界
- コンピュータ上の摂動実験は、モデルが学習した発現の連動に基づく予測であり、因果関係を直接示すものではない
- スモーク実行（50 細胞・1 seed）のシフトの値は技術検証のみが目的で、生物学的には解釈していない
- 三次リンパ組織の多さ（推定ラベル）は細胞組成に依存する指標であり、組織学的な三次リンパ組織の有無とは異なる
- CELLxGENE のデータセットごとのライセンス表示、腎臓アトラス（KPMP）の謝辞文言はいずれも未確認のまま

| 用語 | 意味 |
|---|---|
| 腎臓アトラス（KPMP） | 米国の腎臓精密医療プロジェクトが公開したヒト腎臓の単一細胞データ（Lake ら 2023, PMID 37468583） |
| 単一細胞 RNA-seq | 細胞 1 個ずつの遺伝子発現を測る手法 |
| 提供者 | 検体を提供した患者・ドナー 1 人 |
| 近位尿細管 / 修復不全の近位尿細管 / 健常な近位尿細管 | 腎臓で原尿の再吸収を担う管の細胞。障害後に健常へ戻りきらない状態／健常者由来の正常な状態 |
| 三次リンパ組織 | 炎症が続く臓器の中に後天的にできるリンパ組織様の構造 |
| 三次リンパ組織スコア | 提供者ごとに関連遺伝子の発現から推定した三次リンパ組織の多さ。組織を見て判定したものではない推定値 |
| Geneformer | 大量の単一細胞データで学習した遺伝子発現の基盤モデル。本研究では 3.16 億パラメータの第 2 版を使用 |
| 事前学習モデル | 追加学習をしていない、配布されたままの Geneformer |
| コンピュータ上の遺伝子摂動 | モデルの中で遺伝子を消す・増やすなどして、細胞の状態がどう動くかを計算する模擬実験 |

| 細胞埋め込み | 細胞 1 個をモデルが数値ベクトルで表したもの |
| bfloat16 での計算 | 計算を低い精度（bf16）で行い高速化する方式。本研究では計算本体のみ bfloat16、状態の比較は float32（単精度） |
| 恒常発現遺伝子 | どの細胞でも安定して働くとされる遺伝子（ACTB, GAPDH など） |
