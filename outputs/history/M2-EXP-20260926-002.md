- 作成: Labretary / 2026-09-27（記録に基づく事後作成）
- 承認: PetadimensionLab（PI）, 2026-09-26 — G3: refuted

## 要旨（結論を先に）
1. 前の実験（EXP-20260926-001）では、1 遺伝子を削除すると、どの遺伝子でも細胞がすべての状態（出発点・目標・対照）から一様に離れる「一様な削除効果」が見つかり、陽性対照と恒常発現遺伝子が区別できず判定不能となった。
2. 本実験では、この一様な効果を差し引く指標を 18 通り作り、対照遺伝子だけで比較した（本命遺伝子は盲検のまま）。
3. 最有力だった指標「長さ補正した接近度」（細胞の入力の長さの分位ごとに対照遺伝子群の平均を差し引く）は、本番の独立な検証（200 細胞/遺伝子 × 3 seed, 3 時間 56 分）で、**恒常発現遺伝子が対照遺伝子群の中に収まる基準**と**中立対照パネルの中立性の基準**は満たしたが、**陽性対照の分離**・**恒常発現遺伝子との差**・**再現性**の基準は満たさなかった。
4. PI から「判定基準が厳しすぎたのではないか」という問いがあり、Labretary が定量的に検討した結果、恒常発現遺伝子を使わない基準（陽性対照の分離・再現性）だけでも不合格であり、**基準の厳しさが原因ではない**と判断された。
5. HYP-20260926-01 は PI により**否定（refuted）**と判定され、事前登録した反証条件に従って本命遺伝子（TP53, CDKN1A, LTBR）の再評価は行われなかった（盲検を維持）。

## 1. 目的と狙い
- 何を知りたいのか: 1 遺伝子の削除型の摂動で観測される、細胞埋め込みが全状態から一様に離れる「一様な削除効果」を差し引けば、陽性対照（VCAM1, HAVCR1）が、効果のないはずの遺伝子（対照遺伝子群、恒常発現遺伝子）から分離する指標を作れるか。
- なぜ今この実験が必要なのか: EXP-20260926-001 では、90 通りの遺伝子×seed の組み合わせすべてで削除により細胞が全状態から離れる現象が見つかり、恒常発現遺伝子（GAPDH, PPIA）が陽性対照と同じく対照遺伝子群の上位に来てしまったため、判定不能（PI, G3）となった。PI からの指示は「次の実験は、まず、削除による一様な効果を差し引いた指標にしてください」。
- この実験で答えが出ること／出ないこと: 出る — 一様な効果を補正する方法として何が有効かという方法論上の問い。出ない — 三次リンパ組織や細胞老化そのものに関する生物学的な問い（本命遺伝子は評価しない）。

## 2. 背景
腎臓の三次リンパ組織と修復不全の近位尿細管の関係を調べる一連の研究の一部。前段の EXP-20260926-001 で、Geneformer の細胞埋め込み空間において、1 遺伝子の削除がどの遺伝子でも細胞をすべての状態の重心から遠ざける現象（一様な削除効果）が確認され、判定の土台となる指標そのものに問題があることが分かった。本実験は生物学的な新規予測ではなく、方法の妥当性を検証するもの。

## 3. アプローチ
### 3.1 使ったデータ
腎臓アトラス（KPMP, Lake ら 2023, PMID 37468583）を、EXP-20260926-001 と同一の入力・同一のトークン化データ（データ部分のみ複製）で使用。出発点（修復不全の近位尿細管、三次リンパ組織が多い群）7,533 細胞・14 提供者、目標状態（健常な近位尿細管）6,149 細胞・22 提供者、対照の状態（三次リンパ組織が少ない群）4,002 細胞・8 提供者。状態ラベルは組織学的な確認によるものではなく、発現データからの推定値である。

### 3.2 使ったモデルと計算環境
Geneformer V2（3.16 億パラメータ、事前学習モデルのみ。追加学習はしていない）。細胞埋め込みは CLS トークンの出力（最終層）を使用。計算は手元の Mac（M4 Pro, Apple 製 GPU）、bfloat16 での計算で前向き計算を行い、状態の近さの計算（コサイン類似度）は float32（単精度）で実施。

### 3.3 やったこと（手順）
1. **予備検証（phase 0）**: 対照遺伝子のみ 25 遺伝子（陽性対照 2、恒常発現遺伝子 3、ランダム対照遺伝子 20）、seed 0、細胞ごとの元・摂動後の細胞埋め込みも保存する設定で 34 分の小規模 run を実施。EXP-20260926-001 と同一の細胞・同一の指標値が完全一致することを確認し、取り出したベクトルの計算精度も検証した。
2. **一様な削除効果の分解**: 対照遺伝子 2,000 細胞分の摂動変位ベクトルを解析し、一様な効果の平均のうち 56%が「どの向きに動いても近くの重心から離れる」という向きに依存しない成分（変位の大きさの 2 乗に比例する項）であることを確認した。
3. **候補指標の比較（対照遺伝子のみ、本命遺伝子は盲検で除外）**: コサイン類似度のみを使う指標 8 通りと、摂動変位ベクトルからの射影を使う指標 5 通り、計 18 通りの指標を、EXP-20260926-001 の保存データおよび phase 0 のデータで評価した。最有力だったのは「長さ補正した接近度」（細胞の入力の長さの 5 分位ビンごとに、同じ細胞を摂動したランダム対照遺伝子群の平均の目標状態への接近度を差し引き、遺伝子ごとに平均する指標）。
4. **中立対照パネルの選定**: ISP の結果を一切使わず、発現データと文献調査だけから、恒常発現遺伝子とは別に「出発点と目標状態で発現差がない」ことを確認した 7 遺伝子（中立対照パネル）を選定した。文献由来の候補 57 遺伝子は選定規則を 1 つも満たさず、データ駆動で選び直した。探索目的のみでリボソームタンパク質遺伝子 2 種も加えたが、合否判定には使っていない。
5. **本番（独立な検証）**: PI 承認のもと、まず安価な案（同一細胞・同一 seed を流用、約 1 時間 6 分。これは EXP-20260926-001 と完全に同じ細胞のため独立な追加証拠にはならない）を実施し、次に新しい seed（seed 3, 4, 5）・200 細胞/遺伝子・34 遺伝子（陽性対照 2、恒常発現遺伝子 3、中立対照パネル 7、探索用リボソームタンパク質遺伝子 2、ランダム対照遺伝子 20）で本番の独立な検証（3 時間 56 分）を実施した。

### 3.4 比べたもの（対照）と、成功・失敗をどう判定するか
- 陽性対照: VCAM1, HAVCR1（既知の障害マーカー遺伝子）
- 対照遺伝子群: 発現頻度をそろえたランダム遺伝子 20（seed ごとに選び直し）
- 恒常発現遺伝子: ACTB, GAPDH, PPIA（PI 方針により合否判定に含める）
- 中立対照パネル: CERS4, TATDN1, IFT25, VAPA, PHPT1, ANAPC16, EEF1D（発現データのみで選定）
- 判定基準（結果を見る前に固定。plan.md §6.2, §10）:
  - 判定基準: 陽性対照の分離 — VCAM1・HAVCR1 それぞれが対照遺伝子群の上位 10% に、3 seed 中 2 以上で入ること
  - 判定基準: 恒常発現遺伝子との差 — 陽性対照 2 × 恒常発現遺伝子 3 × 3 seed = 18 組のうち、陽性対照が上回る組が 15 組以上
  - 判定基準: 恒常発現遺伝子の中立性 — ACTB・GAPDH・PPIA が対照遺伝子群の中（上下 10%の内側）に、3 seed 中 2 以上で収まること
  - 判定基準: 中立対照パネルの中立性 — パネル 7 遺伝子中 5 以上が同様に収まること
  - 参考: 再現性 — 提供者を 2 群に分けた折半信頼性（split-half reliability）の遺伝子順位の一致（スピアマン相関）が 0.7 以上
  - 参考: 交絡のなさ — 指標が細胞の入力の長さ・発現頻度と強く相関しないこと（|相関| ≤ 0.3、細胞単位では ≤ 0.2）
  - 選定規則: 陽性対照の分離・恒常発現遺伝子との差・恒常発現遺伝子の中立性のすべてを満たす指標を「採用可」とする。1 つでも不合格なら HYP-20260926-01 は棄却とし、本命遺伝子の再評価は行わない。

## 4. 結果
主指標「長さ補正した接近度」の本番（独立な検証, 34 遺伝子 × 200 細胞 × seed 3/4/5）の結果は次のとおり。

| 判定基準 | 結果 | 判定 |
|---|---|---|
| 陽性対照の分離（上位 10%, 3 seed 中 2 以上） | VCAM1: 分位 0.70 / 0.60 / 0.70（seed 3/4/5）、3 seed 平均 0.667。HAVCR1: 0.90 / 0.70 / 0.75、平均 0.783 | 不合格 |
| 恒常発現遺伝子との差（15/18 組以上） | 18 組中 10 組で陽性対照が上回った | 不合格 |
| 恒常発現遺伝子の中立性 | ACTB 分位 0.217、GAPDH 0.80、PPIA 0.867（いずれも範囲内） | 合格 |
| 中立対照パネルの中立性（5/7 以上） | 7/7 が範囲内 | 合格 |
| 参考: 再現性（半分割, 0.7 以上） | スピアマン相関 0.319（細胞数を 100→200 に倍増しても、100 細胞時の 0.38 から改善せず） | 不合格 |
| 参考: 交絡のなさ | 細胞の入力の長さとの相関 −0.058 | 合格 |

一様な削除効果そのものは差し引けた: 補正前は対照遺伝子群の摂動でほぼ全数（分位が負になる割合 100%）が目標状態から離れる方向に動いていたが、長さ補正した接近度で補正した後は 32%まで下がり、中心化された。

18 通りの候補指標のうち、陽性対照の分離・恒常発現遺伝子との差・恒常発現遺伝子の中立性の 3 つをすべて同時に満たす指標は、独立な本番検証・予備検証のどちらでも見つからなかった。

**PI からの問い「判定基準が厳しすぎたのではないか」への回答（`criteria-strictness.md` に記録）**:
- 陽性対照の分離の基準（分位 0.90 以上）は、効果のない遺伝子が偶然合格する確率が 1 遺伝子あたり 5.5%、2 遺伝子とも合格する確率は 0.3%と、偶然には通りにくい設計だった。実測の分位（VCAM1 0.60〜0.70、HAVCR1 0.70〜0.90）が両方合格する閾値まで基準を緩めると 0.70 まで下げる必要があり、その場合は効果のない遺伝子でも 25.9%（2 遺伝子とも合格する確率 6.7%）が偶然合格してしまい、判定の意味がほぼ失われる。
- 再現性の基準（0.7 以上）は 18 通りの指標のうち最も高かったものでも 0.685（長さ補正した接近度は 0.319）にとどまり、恒常発現遺伝子を使わない基準（陽性対照の分離・再現性）だけでも不合格だった。
- 恒常発現遺伝子との差の基準は、比較相手の恒常発現遺伝子自体が出発点と目標状態の間で発現差を持つため、比較相手の選び方として厳しすぎた可能性がある（GAPDH log2 発現差 −0.98, q<0.001）。ただし実測は 10/18 で、差がないと仮定した場合の期待値とほぼ同じであり（差がなくても 10/18 以上になる確率 0.41）、この基準を外しても結論は変わらない。
- 結論: **判定基準が厳しすぎたとは言えない。**恒常発現遺伝子に依存しない基準だけでも否定される。

## 5. 考察
- 一様な削除効果は、コサイン類似度の水準で差し引くことができた（対照遺伝子群の目標状態への接近度が負になる割合が 100%から 32%へ、ほぼ中心化された）。しかし、出発点から目標状態への軸に沿った成分に注目すると、補正後も GAPDH・PPIA が対照遺伝子群の中で最上位に残り続けた。予備検証では、GAPDH の削除で細胞の 80%、PPIA の削除で 71%が目標状態側へ動いており（対照遺伝子群の中央値は 43%）、これは一様な効果では説明できない。恒常発現遺伝子の入力内の相対的な位置（出発点と目標状態の差）も中立ではなく（GAPDH +0.14、PPIA −0.16、対照遺伝子群の中央値 +0.03）、この事前学習モデルの埋め込み空間では、恒常発現遺伝子が出発点から目標状態への軸に対して中立でない可能性が示唆される。
- 摂動変位ベクトルそのものを使った補正（一様な方向の除去、平均ドリフトの減算、局所的な平均の減算、主成分の除去など 5 通り）も試したが、いずれも恒常発現遺伝子を対照遺伝子群の中に収めることができず、コサイン類似度による「長さ補正した接近度」を上回らなかった。ベクトル水準の解析は、一様な削除効果の成り立ちを診断するうえでは有用だった（56%が向きに依存しない成分と分かった点）が、指標そのものの改善にはつながらなかった。
- 陽性対照の分離が不合格だったことは、VCAM1・HAVCR1 に生物学的な意味がないことを示すものではない。否定されたのは「事前学習のままのモデル・削除型の摂動・CLS 埋め込みという設計で、今回提案した補正指標を使えば陽性対照を分離できる」という、方法に関する主張である。
- 再現性が細胞数を倍にしても改善しなかったことから、不安定さの主因は細胞数の不足ではなく、提供者間のばらつきであることが示唆される。

## 6. 限界
- コンピュータ上の摂動実験は、モデルが学習した発現の連動に基づく予測であり、因果関係を直接示すものではない。
- 部分的な盲検: EXP-20260926-001 で計算済みの目標状態への接近度・その差分指標については、本命遺伝子の値を Labretary・PI ともに既に見ている。ただし本実験で新しく作った候補指標については、本命遺伝子の値は一度も計算していない。
- 計算精度に bfloat16 を使用。効果の小さい場面では判定の境界と同じ桁になりうる。
- 三次リンパ組織の多さの群分けはすべて推定値であり、組織学的に確認したものではない。
- 3 seed（新規 seed 3, 4, 5）での検証にとどまり、折半信頼性は低い。

## 7. 次のアクション
- コンピュータ上で行うこと: 事前学習のままのモデルでは陽性対照を分離できなかったため、「修復不全か健常かを見分けるよう追加学習させたモデル」による摂動実験に進む（EXP-20260926-003）。
- 実験室で行うこと: 現時点では提案できる段階にない（本命遺伝子は未評価）。

| 中立対照パネル | 出発点と目標で発現差がないことを発現データだけで確認して選んだ 7 遺伝子 |
| 判定基準: 陽性対照の分離 | 陽性対照が対照遺伝子群の上位 10%に入ること |
| 判定基準: 恒常発現遺伝子との差 | 陽性対照が恒常発現遺伝子を上回ること（18 組中 15 組以上） |
| 判定基準: 恒常発現遺伝子の中立性 | 恒常発現遺伝子が対照遺伝子群の中に収まること |
| 判定基準: 中立対照パネルの中立性 | 中立対照パネル 7 遺伝子のうち 5 つ以上が中立の範囲に収まること |
| 参考: 再現性 | 折半信頼性が 0.7 以上 |
| 参考: 交絡のなさ | 入力の長さや発現頻度と相関しないこと |
| 折半信頼性 | 提供者を 2 群に分けて別々に順位を出し、両者がどれだけ一致するか |
| 支持された・否定された・判定不能 | 事前に決めた基準を満たした／否定の条件に当てはまった／判定できる状態になかった |
| 事前登録 | 結果を見る前に判定基準を文書に固定すること |
| 盲検 | 手法の妥当性が確認できるまで、本命の遺伝子の結果を見ないこと |
| ゲート G3（結論確定） | 結果の判定（支持・否定・判定不能）を確定する PI 判断 |
