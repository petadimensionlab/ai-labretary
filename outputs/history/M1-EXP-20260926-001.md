# マイルストーン報告 M1 — EXP-20260926-001: CKD 腎の修復不全型近位尿細管における p53–p21 軸・LTβR 削除の in silico perturbation

- 日時: 2026-09-26（G1 仮説採択 → phase 0 → PI の bf16 方針決定・G2 計画承認 → 本番実行 → 検証 → G3 判定不能）
- PI の判断（ゲート）: G1 済（2026-09-26、[HYP-20260925-01](../../hypotheses/HYP-20260925-01.md) を実験対象に採択）／G2 済（2026-09-26、bf16 方針・FDR の扱い・差分指標の追加を含めて計画承認）／G3 済（2026-09-26、**判定不能（inconclusive）**）
- 次のマイルストーンへのつながり: 「陽性対照が恒常発現遺伝子と区別できない＝判定の仕組み自体の検出力が確認できない」という結果を受け、次の実験（`EXP-20260926-002` 以降、方法論の検証）は、本命の遺伝子を見ずに一様な削除効果を差し引いた指標の開発に進んだ（`hypotheses/tracker.md`）

- 対象の仮説: [HYP-20260925-01](../../hypotheses/HYP-20260925-01.md)（CKD の三次リンパ組織が多い腎で修復不全型近位尿細管の TP53/CDKN1A/LTBR を削除→健常方向へ、三次リンパ組織が少ない腎より効果が大きい）
- 作成: Labretary / 2026-09-27（記録に基づく事後作成。実験自体の `experiments/EXP-20260926-001/report.md` は 2026-09-26 に Status: final・PI 承認 済）

## 要旨（結論を先に）
ヒト CKD 腎の修復不全型近位尿細管で TP53・CDKN1A・LTBR を Geneformer 上で削除しても、健常な近位尿細管方向への移動は、事前登録した 2 つの指標のどちらでも支持されなかった（判定条件を満たした試行は 3 遺伝子とも 0/3 seed）。しかし、陽性対照（VCAM1・HAVCR1）が恒常発現遺伝子（GAPDH・PPIA）と区別できず、判定の仕組み自体の検出力が確認できなかったため、PI は結論を「判定不能」とした。主な原因は、どの遺伝子を削除しても細胞埋め込みが全状態から一様に離れる「一様な削除効果」である。三次リンパ組織が多い群・少ない群の対比も、状態の分離が弱く（重心間距離が出発点と目標の間の距離の約 12 分の 1）意味をなさなかった。

## 1. 目的と狙い
- 何を知りたいのか: CKD 腎の修復不全型近位尿細管において、p53–p21 老化軸（TP53・CDKN1A）と三次リンパ組織由来シグナルの受容体 LTBR を削除すると、細胞状態が健常な近位尿細管へ近づくか。その効果は三次リンパ組織が多い腎で、少ない腎より大きいか
- なぜ今この実験が必要か: M0 の実現可能性調査で、この状態定義（修復不全型近位尿細管 7,533 細胞 / 14 提供者、健常 6,149 細胞 / 22 提供者、三次リンパ組織が少ない群 4,002 細胞 / 8 提供者）が確保でき、事前チェック（分類の精度）も出発点と目標の間で良好（後述）だったため、最初の生物学的な問いとして選ばれた
- この実験で答えが出ること・出ないこと: 出ること＝この設計・この指標で、事前登録した基準を満たすか。出ないこと＝これらの遺伝子が生物学的に無関係であるという結論（判定不能のため）

## 2. 背景
腎臓の三次リンパ組織は加齢・障害腎で形成され、修復不全の尿細管と相互作用すると報告されている（Sato ら 2016, PMID 27699223; Yoshikawa ら 2023, PMID 37548710）。本実験は、細胞老化（p53–p21 軸）と三次リンパ組織由来シグナル（LTα1β2 の受容体 LTBR）が修復不全型近位尿細管の状態維持に関わるという仮説を in silico で検証したものである。M0 の実現可能性調査（`outputs/literature/2026-09-25-tls-feasibility/feasibility.md`）では、この状態の細胞が十分確保できることと、三次リンパ組織の多さがすべて推定ラベルであることの両方が分かっていた。

## 3. アプローチ
### 3.1 使ったデータ
腎臓アトラス（KPMP）scRNA（Lake ら 2023, PMID 37468583、`data/raw/kidney_tls/A2_KPMP_v1.5_scRNA_Lake2023.h5ad`、読み取り専用）。raw の整数カウントから 17,684 細胞 × 30,635 遺伝子の入力を作成した。

| 状態 | 定義 | 細胞数 / 提供者数 |
|---|---|---|
| 出発点: CKD・三次リンパ組織が多い修復不全型近位尿細管 | 修復不全型近位尿細管 ∧ CKD ∧ 三次リンパ組織スコア高 | 7,533 / 14 |
| 目標: 健常な近位尿細管 | 健常近位尿細管の細分類 ∧ 正常 | 6,149 / 22 |
| 対照の状態: CKD・三次リンパ組織が少ない修復不全型近位尿細管 | 修復不全型近位尿細管 ∧ CKD ∧ 三次リンパ組織スコア低 | 4,002 / 8 |

三次リンパ組織スコアの高低は、提供者単位の pseudo-bulk での関連 8 遺伝子の発現から推定した三分位であり、組織学的な判定ではない。

### 3.2 使ったモデルと計算環境
Geneformer V2-316M（事前学習モデル）、細胞埋め込みは先頭トークンによるもの（V2 の必須設定）、手元の Mac（Apple M4 Pro、Apple 製 GPU）。精度は**bfloat16 での計算（順伝播 のみ bf16、状態の比較は float32）を PI が標準に決定**した。事前確認（phase 0）では、bfloat16 と float32 の遺伝子順位の一致度（Spearman）が 0.879 で、目安とする基準 0.98 には届かなかった（上位 5 件の一致は 5/5、符号の一致は 10/10）。この精度の差はレポートの限界として明記した。

### 3.3 やったこと（手順）
1. **phase 0**（本番の前段階）: 入力作成・簡易実行チェック、事前チェック（出発点と目標の細胞埋め込みで分類の精度を確認）、bfloat16 と float32 のペア比較、時間計測
2. 事前チェックの結果: 出発点 vs 目標のロジスティック回帰 5 分割 AUC は提供者単位の分割で 1.00 ± 0.00（良好）。出発点 vs 対照の状態は 0.627 ± 0.206（境界的。fold ごとに 0.34〜0.83 とばらつきが大きい）
3. G2（計画承認）で PI が bfloat16 方針・統計量の扱い・追加指標を確定（下記）
4. 本番実行（`run_isp.py`）: 対象の遺伝子ごと・seed ごとに、その遺伝子を発現している出発点の細胞から提供者あたり 15 細胞以下・合計 100 細胞以下を抽出し、削除して埋め込みを再計算。3 つの seed（サブサンプル）で繰り返し。run 1（三次リンパ組織が多い群を出発点）、run 2（少ない群を出発点、文脈依存性の確認用）
5. 精度確認のための再計算: run 1 のうち判定境界にある 10 組を float32 で再計算し、判定が変わらないかを確認

### 3.4 比べたもの（対照）と、成功・失敗をどう判定するか（結果を見る前に決めた基準）
- 陽性対照: VCAM1、HAVCR1（削除で修復不全型近位尿細管から健常側へ動くことが既に知られている遺伝子）
- 対照遺伝子群: 発現頻度をそろえたランダム 20 遺伝子（seed ごとに抽出）
- 恒常発現遺伝子: ACTB、GAPDH、PPIA（非特異的なシフトの大きさの参照。対照遺伝子群には含めない）
- 主要な判定基準: TP53・CDKN1A・LTBR のそれぞれで、目標状態への接近度が、同じ seed の対照遺伝子群の上位 5% に入り、かつ対象 5 遺伝子内で多重比較補正した有意水準を満たすことが、3 seed のうち 2 以上で成立すること
- 文脈依存性の基準: 三次リンパ組織が多い群でのシフトが少ない群でのシフトの 1.2 倍以上で、提供者単位のブートストラップ信頼区間が 1 を含まないこと（両方向とも目標に近づく向きであることを前提とする）
- 判定不能の条件: 陽性対照（VCAM1・HAVCR1）が対照遺伝子群の上位 10% に入らない場合は、棄却ではなく判定不能としてパイプライン・状態定義を見直す
- G2 で追加登録した副次指標: 「目標方向への接近度 − 出発点方向への接近度」（一様な削除効果を差し引くための差分指標）。phase 0 の結果を見てから、本番データを見る前に追加したことを明記する

## 4. 結果
### 4.1 対照の挙動
- 目標状態への接近度（単独）では、陽性対照 HAVCR1 が上位 10% に入った seed は 1/3 のみで、不合格。float32 で再計算すると VCAM1 も 1/3 に下がり、2 つとも不合格になった
- 差分指標では、VCAM1・HAVCR1 とも 3/3 seed で合格した。しかし**恒常発現遺伝子 GAPDH・PPIA も同じ指標で 3/3 seed とも対照遺伝子群の最上位（分位 1.00）に入った**。つまり陽性対照の合格は、目標方向への特異的な移動を示していない
- 一様な削除効果: run 1 で調べた 90 通りの「遺伝子×seed」の組み合わせすべてで、削除は出発点・目標・対照の状態という 3 つの重心のすべてから細胞を遠ざけた（`experiments/EXP-20260926-001/figures/deletion_drift.png`）

### 4.2 主要な 3 遺伝子（run 1: 三次リンパ組織が多い群が出発点、各遺伝子 100 細胞 × 3 seed）
| 遺伝子 | 目標状態への接近度（平均 ± SD） | 対照遺伝子群での分位（seed 0/1/2） | 差分指標（平均 ± SD） | 対照遺伝子群での分位 | 判定条件を満たした seed |
|---|---|---|---|---|---|
| TP53 | −2.45×10⁻⁴ ± 3.3×10⁻⁵ | 0.55 / 0.45 / 0.35 | −2.65×10⁻⁵ ± 1.3×10⁻⁵ | 0.85 / 0.85 / 0.60 | 0/3（両指標） |
| CDKN1A | −2.07×10⁻⁴ ± 4.1×10⁻⁵ | 0.55 / 0.50 / 0.95 | −3.98×10⁻⁵ ± 9.7×10⁻⁶ | 0.50 / 0.30 / 0.80 | 0/3（両指標） |
| LTBR | −3.09×10⁻⁴ ± 1.0×10⁻⁴ | 0.10 / 0.50 / 0.35 | −4.71×10⁻⁵ ± 1.0×10⁻⁵ | 0.45 / 0.30 / 0.60 | 0/3（両指標） |

- 3 遺伝子とも、負の値（目標から離れる方向）を含んでおり、対照遺伝子群の中でも特に上位に来る seed は見られなかった
- 事前登録規則の機械的な適用: 目標状態への接近度は陽性対照不合格のため「判定不能」、差分指標は主要 3 遺伝子が棄却条件に該当し形式上は「支持されない」。ただし差分指標の陽性対照の合格が恒常発現遺伝子と区別できないため、総合評価は「判定不能寄り」とし、確定は PI の G3 判断とした
- 文脈依存性: 基準を満たした遺伝子はなかった。LTBR の比は 1.96（信頼区間 1.02–4.27）だったが、分子・分母がともに負の値（三次リンパ組織が多い群・少ない群のどちらでも目標から離れる方向）であり、「三次リンパ組織が多い群のほうが目標から大きく離れる」ことを意味し、仮説とは逆向きだった（`.claude/memory/guardrails.md` に「比の符号を必ず確認する」として記録）
- 図: `experiments/EXP-20260926-001/figures/null_vs_genes_tls_high.png`, `null_vs_genes_tls_low.png`, `fp32_recheck.png`

### 4.3 頑健性チェック
- seed 間の順位の一致（run 1、目標状態への接近度、Spearman）: 3 組のうち最小 0.673（差分指標では 0.89〜0.94）
- 提供者を 1 人ずつ除く検証: 主要な結論（判定条件を満たす seed が最大でも 0）は変わらなかった
- float32 での再計算（判定境界の 10 組、32.5 分）: 主要な判定は変わらなかった。bfloat16 と float32 の差は、目標状態への接近度で平均絶対差が値の約 15%、差分指標で約 59%（HAVCR1 の 1 seed では差分指標の符号が反転）

## 5. 考察
- この設計では、p53–p21 老化軸と LTBR の削除が修復不全型近位尿細管を健常方向へ特異的に動かすという予測は支持されなかった。ただし、陽性対照が恒常発現遺伝子と区別できなかったため、「これらの遺伝子に効果がない」ことが**示されたわけではない**
- 主な原因は一様な削除効果と考えられる。1 遺伝子の削除は入力の遺伝子順位列全体を変え、細胞埋め込みを全状態から一様に遠ざける成分を生む。この一様成分が、遺伝子ごとの方向の違い（値としては 10⁻⁵ の桁）より大きく、対照遺伝子群との比較が「目標に近づくか」ではなく「一様な削除効果が小さいか」を測ってしまっていた可能性が示唆される
- 三次リンパ組織が多い群・少ない群の重心間の距離は、出発点と目標の間の距離の約 12 分の 1 で、細胞ごとの出発点方向と対照の状態方向のシフトの相関は 0.998 だった。事前チェックの分類精度（0.627 ± 0.206）と合わせ、この推定ラベルによる対比は埋め込み上ほとんど区別できないことが示唆される

## 6. 限界
- コンピュータ上の摂動実験は、モデルが学習した発現の連動に基づく予測であり、因果関係を直接示すものではない
- 三次リンパ組織の多い群・少ない群はいずれも提供者単位の pseudo-bulk 組成から推定したラベルで、組織学的な三次リンパ組織ではない
- 精度は PI 決定により bfloat16（順伝播 のみ）。差分指標では判定の閾値との差が bfloat16 由来の誤差と同じ桁だった。float32 での再計算は判定境界の遺伝子に限られ、対照遺伝子群自体は bfloat16 のまま比較した
- 差分指標は phase 0 の結果を見てから追加した（本番データを見る前の G2 で登録）
- 三次リンパ組織が少ない群での一部の遺伝子（CDKN1A 69 細胞・7 提供者、HAVCR1 62 細胞・7 提供者、LCN2 48 細胞・6 提供者）は細胞数が他と異なり、同列に比較できない
- 多重比較の補正は対象 5 遺伝子内のみ。seed 間の頑健性の比較も一部の遺伝子（約 10 個）に限られる

## 7. 次のアクション
- コンピュータ上で行うこと: 一様な削除効果を差し引いた指標の開発（本命の遺伝子を見ずに、対照だけで指標を評価・選定する）。細胞の入力の長さをそろえた対照遺伝子群の作成。恒常発現遺伝子を陰性対照の合否判定に正式に含める。三次リンパ組織の状態を、空間データ由来のシグネチャー（Meylan ら 2022, PMID 35231421）で定義し直すことの検討
- 実験室で行うこと: 本 in silico 実験は判定不能に終わったため、現時点では実験室での検証を提案できる段階にない（仮説側の「支持された場合の次の一手」は据え置き）
- 仮説トラッカーの扱い: HYP-20260925-01 は「判定不能」として `hypotheses/tracker.md` に記録済み（Learning Protocol トリガー 5）
