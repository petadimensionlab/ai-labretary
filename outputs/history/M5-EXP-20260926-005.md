# 実験レポート: EXP-20260926-005 — 文献で因果が確立した陽性対照による検証（削除型・過剰発現型）

- 対象の仮説: [HYP-20260926-04](../../hypotheses/HYP-20260926-04.md)（文献で因果が確立した近位尿細管の障害ドライバー・保護因子を陽性対照にすると、追加学習済みモデルの ISP が対照遺伝子群から分離するか。分離が分類器マーカーの除去・付加だけで説明できるか）
- 作成: Labretary（report-writer）/ 2026-09-27（記録に基づく事後作成）
- 承認: `hypotheses/tracker.md` 記録 — PI の G3 判断（2026-09-27）で HYP-20260926-04 は「inconclusive」

**日時**: 実行は 2026-09-26（削除型・過剰発現型の摂動、リモート計算機 2 号機、両 run 合わせて約 1 時間 40 分）。検証（validator）は同日。G3 判断は 2026-09-27。本レポート作成は 2026-09-27。
**PI の判断（ゲート）**: G3（結論確定）— PI 2026-09-27。HYP-20260926-04 を inconclusive と記録（削除型は有効な否定的結果、過剰発現型は摂動サイズの交絡により判定不能）。
**次のマイルストーンへのつながり**: 過剰発現型で見つかった「摂動サイズ（元の順位）の交絡」は、2026-09-27 の探索的な事後検証（別マイルストーン担当）と、次の実験 EXP-20260927-001（移動距離をそろえた並べ替え検定の事前登録）の設計に引き継がれた。

## 要旨
- 追加学習済みモデルの削除型摂動で唯一分離した VCAM1 は、修復不全の近位尿細管の極端な目印遺伝子であり、判定基準の合格が「目印遺伝子の除去」で説明される懸念があった。この懸念を切り分けるため、陽性対照を文献で遺伝学的な因果効果が確立した遺伝子に置き換えて再検証した。
- 削除型（5 遺伝子: HIF1A, NOTCH1, EGFR, YAP1, KEAP1）はいずれも対照遺伝子群と区別できなかった（5 遺伝子中 0 が合格）。ただし恒常発現遺伝子・中立対照パネルは正しく中立の範囲に収まり、一様な削除効果も見られなかったため、これは有効な否定的結果と判断された。
- 過剰発現型（6 遺伝子: HNF4A, PPARGC1A, PPARA, ESRRA, CPT1A, NFE2L2）は 6 遺伝子中 3 が合格基準を満たしたが、同時に恒常発現遺伝子の 1 つ（GAPDH）も 3 seed とも対照遺伝子群の中で上位 10% 相当の分位 0.95 に入ってしまい、事前登録の規則により「判定不能」となった。
- 探索的な追加解析で、過剰発現の効果の大きさが、遺伝子のもともとの入力内順位と相関していた（遺伝子単位の相関 0.65・0.47・0.32、seed 3/4/5）。対照遺伝子は発現頻度のみをそろえており、この「上げしろ」をそろえていなかったため、合格した 3 遺伝子・GAPDH の不合格は摂動サイズの交絡で説明できる可能性が示唆された。
- PI は 2026-09-27 に HYP-20260926-04 を inconclusive（判定不能）と確定した（削除型は有効な否定、過剰発現型は判定不能）。

## 1. 目的と狙い
- **何を知りたいか**: EXP-20260926-003・004 で使った VCAM1・HAVCR1 は「修復不全側の目印遺伝子」であり「修復不全状態を駆動する原因遺伝子」ではない可能性がある。陽性対照を、近位尿細管細胞で遺伝学的操作の因果効果が報告されている遺伝子に置き換えたとき、追加学習済みモデルの ISP（主指標: 長さ補正した接近度）がそれらを対照遺伝子群から分離するかを確認する。
- **なぜ必要か**: EXP-004 で、対照遺伝子群の中での順位の上位 10% という判定基準自体が原因遺伝子に特異的でない（比較遺伝子 10 個中 3 個が偶然合格）ことが分かったため、より確からしい陽性対照でこの手法が機能するかを直接確かめる必要があった。
- **この実験で分かること／分からないこと**: 手法（コンピュータ上の遺伝子摂動）が文献で確立した因果効果を検出できるかどうかの検証であり、腎臓の三次リンパ組織や細胞老化そのものについての生物学的な結論は出ない。

## 2. 背景
EXP-20260926-003 phase 3 で、追加学習済み（修復不全 vs 健常の 2 クラス）分類器の細胞埋め込みでは一様な削除効果がほぼ解消した（対照遺伝子群が健常から離れる割合が 100% から 10〜15% に低下）。恒常発現遺伝子 3 つと中立対照パネル 7 遺伝子はすべて対照遺伝子群の内側に収まったが、陽性対照 2 つのうち VCAM1 は対照遺伝子群の中で上位 10% 相当の分位 0.98 で合格した一方、HAVCR1 は 0.45/0.75/0.75 で不合格のままだった。VCAM1 は修復不全側の細胞の 62.1%、健常側の 7.6% の細胞で検出される極端な目印遺伝子であり（検出率の差は背景 9,615 遺伝子中 99 パーセンタイル）、この合格が目印遺伝子除去の効果である可能性が課題として残っていた（HYP-20260926-04 の起点）。

## 3. アプローチ
### 3.1 使ったデータ
腎臓アトラス（KPMP, Lake ら 2023, PMID 37468583）のトークン化済み入力（EXP-001/003 と同一, sha256 一致）。開始状態は EXP-003 phase 3 と同じ修復不全側の近位尿細管（三次リンパ組織スコアが高い群, 追加学習に未使用の 14 人・7,533 細胞のうち 200 細胞/遺伝子を抽出）、目標重心は追加学習に使っていない健常 9 人（3,106 細胞中 500 細胞）。

### 3.2 使ったモデルと計算環境
EXP-003 で作成した追加学習済み分類器（修復不全 vs 健常の 2 クラス）。細胞埋め込み・bfloat16 での計算と float32（単精度）でのコサイン距離。実行はリモート計算機 2 号機（spark-c083, NVIDIA GB10）。同一計算機で 2 つの run を順に実行し、機械差を比較に持ち込まないようにした。seed 3/4/5。

### 3.3 やったこと（手順）
文献調査で、近位尿細管に対する遺伝学的操作（欠損・過剰発現）の因果効果がマウスまたはヒト組織で報告されている遺伝子を選定した（各遺伝子の文献根拠・PMID は HYP-20260926-04 に一覧化）。削除型 5 遺伝子（HIF1A・NOTCH1・EGFR・YAP1・KEAP1、いずれも欠損が健常方向を示す報告あり）と、過剰発現型 6 遺伝子（HNF4A・PPARGC1A・PPARA・ESRRA・CPT1A・NFE2L2、いずれも発現低下が障害の一因、回復・過剰発現が保護的とする報告あり）を、ISP を 1 回も回す前に確定した。方向が文献間で対立する遺伝子（TGFBR2, SMAD3）や検出細胞数が不足する遺伝子（KLF15, SNAI1, TWIST1, FOXM1, CDKN2A）は不採用とした。あわせて遺伝子ごとに「目印度」（開始状態と目標状態での検出率の差の、背景分布に対する分位）を事前に算出し、目印度が低い（0.80 以下）遺伝子が合格すれば、目印遺伝子除去では説明できない証拠になるという整理を行った。

### 3.4 比べたものと判定基準（事前登録）
削除型 run・過剰発現型 run それぞれで、発現頻度をその陽性対照セットにそろえた対照遺伝子群 20 個（seed ごと）、恒常発現遺伝子 3 つ（ACTB・GAPDH・PPIA）、中立対照パネル 7 遺伝子を同時に評価した。判定基準は、陽性対照のうち対照遺伝子群の中で上位 10% に 3 seed 中 2 以上入る遺伝子数が、削除型で 5 中 2 以上・過剰発現型で 6 中 2 以上（偶然にこの基準を満たす確率はそれぞれ約 0.75%・1.2% と見積もった）。さらに、合格した各陽性対照が恒常発現遺伝子を 9 組中 7 組以上で上回ること、恒常発現遺伝子 3 つと中立対照パネルが正しく中立の範囲に収まることを求めた。どちらか一方の run でこれらすべてを満たせば支持、両方の run で陽性対照の分離基準を満たさなければ棄却、恒常発現遺伝子か中立対照パネルが不合格の run はその run を判定不能とする、とあらかじめ定めた。

## 4. 結果
### 4.1 削除型（run D）
文献で欠損が健常方向を示すとされる 5 遺伝子（HIF1A・NOTCH1・EGFR・YAP1・KEAP1）は、いずれも対照遺伝子群の中で上位 10% に入らなかった（5 遺伝子中 0 が合格）。一方、恒常発現遺伝子 3 つ・中立対照パネル 7 遺伝子はすべて正しく中立の範囲に収まり、対照遺伝子群が健常から一様に離れる割合も 12% にとどまり（EXP-002 以前に見られた一様な削除効果は生じていない）、系が正常に機能していることを確認した。→ 事前登録の規則により、有効な否定的結果と判定した。

### 4.2 過剰発現型（run O）
文献で発現低下が障害の一因、過剰発現が保護的とされる 6 遺伝子（HNF4A・PPARGC1A・PPARA・ESRRA・CPT1A・NFE2L2）のうち 3 遺伝子が対照遺伝子群の中で上位 10% の基準を満たした。しかし、恒常発現遺伝子の 1 つである GAPDH が 3 seed とも分位 0.95 で対照遺伝子群の中で上位 10% 相当に入ってしまい、事前登録の判定基準（恒常発現遺伝子は中立の範囲に収まる必要がある）を満たさなかった。→ 事前登録の規則（恒常発現遺伝子か中立対照パネルが不合格の run は判定不能）に従い、run O は判定不能とした。合格した 3 遺伝子をもって支持と書くことはできない。

### 4.3 探索的な追加解析（摂動サイズの交絡）
事前登録の判定には使っていない探索的解析として、摂動前の遺伝子の入力内順位（元の位置）と主指標の遺伝子単位の相関を調べたところ、run O では相関係数が seed 3/4/5 でそれぞれ 0.65・0.47・0.32 と強い正の相関があり、対照遺伝子 20 個だけでも同様の相関（seed 3 で 0.51, p=0.02）が見られた。固定した 18 遺伝子で見ると、遺伝子のもとの順位と主指標の相関は 0.71（p=0.001）で、GAPDH（元の順位の分位 0.71）や EEF1D（0.72）のような高発現遺伝子が上位に来やすいことと整合していた。一方、run D では同様の相関は見られなかった（seed 3/4/5 で −0.11・−0.06・−0.23）。→ run O で合格した遺伝子・GAPDH の不合格は、「摂動でどれだけ元の順位を引き上げたか」という摂動の大きさによって相当程度説明できる可能性が示唆された。対照遺伝子群は発現頻度のみをそろえており、この「上げしろ」をそろえていなかったことが設計上の見落としだった。

なお、参考指標として見た再現性も対照的だった。run O の折半信頼性（split-half reliability）は 0.871、seed 間の順位一致は 0.907 と高かった一方、run D の折半信頼性は 0.37 にとどまった。run O の高い安定性は、生物学的な信号ではなく元の順位という単純な量が安定して測れていることによる可能性が高い。

## 5. 考察
- 削除型の否定的結果は、系（埋め込み・対照遺伝子群・判定手続き）が正常に機能している状態で得られたものであり、信頼できる否定的所見と考えられる。文献で確立した 5 つの因果関係のいずれも、この手法のこの条件では検出されなかった。
- 過剰発現型は、合格した遺伝子があった一方で対照であるはずの恒常発現遺伝子も合格ラインに入ってしまったため、事前登録どおり判定不能とせざるを得なかった。探索的な解析から、この現象の背景には「摂動でどれだけ遺伝子の順位を引き上げたか」という摂動サイズが指標の値を左右しているという交絡があることが示唆された。
- この結果は EXP-20260926-004 の知見（判定基準そのものが原因遺伝子に特異的でない）と合わせて一貫した像を作っている。現在の枠組みは、原因遺伝子と、単なる目印遺伝子や摂動の大きさの効果とを十分に区別できていない。
- 分類確率（ΔP）を副指標として計算したが、分類器がすでに開始状態でほぼ飽和しており（健常確率の中央値がほぼ 0）、加えて bfloat16 での計算の格子（0.031 刻み）により変化が厳密に 0 となる細胞が過半数（53%）を占めた。そのため副指標は情報をほとんど持たず、結論には使わなかった。

## 6. 限界
- コンピュータ上の摂動実験は、モデルが学習した発現の連動に基づく予測であり、因果関係を直接示すものではない。
- 過剰発現型の摂動は「その遺伝子を発現している細胞で、入力内の順位を最上位に引き上げる」操作であり、発現していない細胞への遺伝子導入を模したものではない。
- 対照遺伝子群は発現頻度のみをそろえたものであり、摂動サイズ（元の順位）はそろえていない。これが過剰発現型の判定不能の主因と考えられる。
- 分類確率は分類器の飽和と bfloat16 での計算の丸めのため信頼できる副指標にならなかった。
- （参考, 事後の探索的検証）2026-09-27 に、摂動サイズをそろえた対照での再検証が別途行われている。これは事前登録の判定（本レポートの結論）を変えるものではなく、別のマイルストーンで扱われる。

## 7. 次のアクション
- 過剰発現型の摂動を続ける場合は、発現頻度に加えて摂動サイズ（元の順位）をそろえた対照遺伝子群、または移動距離をそろえた並べ替え検定を事前登録して使う。
- 削除型の否定的結果（5 遺伝子すべて不合格）を踏まえ、削除型の陽性対照としてさらに別の駆動因子候補を探すか、この手法の削除型での感度そのものを見直す。
- 手法が判定基準を満たすまで、盲検対象の本命遺伝子（TP53・CDKN1A・LTBR など）の解除は行わない。
