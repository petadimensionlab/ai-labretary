## 要旨（結論を先に）
1. EXP-20260926-002 で、事前学習のままのモデルでは一様な削除効果を補正しても陽性対照が分離できなかったため、本実験では「修復不全か健常か」を見分けるよう追加学習させたモデル（追加学習済みモデル）で同じ検証を行った。
2. 追加学習に使った提供者と、摂動に使う提供者は完全に分離した（学習に一切使っていない提供者の細胞だけで摂動を実施）。
3. 追加学習は、ゲート評価（学習に使っていない提供者での判別性能の確認）に合格し、リモート計算機で摂動を実行した。
4. 追加学習済みモデルでは、一様な削除効果（対照遺伝子群が目標状態から離れる方向に動く割合）が事前学習モデルのほぼ全数から 1 割程度まで減少し、恒常発現遺伝子との差の基準も改善したが、**陽性対照の分離の基準は、HAVCR1 が不合格だったため満たされなかった**。事前登録した規則により、HYP-20260926-02 の主要な予測は**否定**と判定された。
5. 一方、一様な削除効果が減ったこと、恒常発現遺伝子に対する優位性が改善したことという副次的な予測は支持された。合格した陽性対照 VCAM1 についても、分類器が目印として使っている遺伝子である可能性が残るため、これだけで「原因の遺伝子」と結論づけることはできない。

## 1. 目的と狙い
- 何を知りたいのか: 近位尿細管の障害の軸（修復不全 対 健常）を見分けるよう追加学習させたモデルの細胞埋め込みでは、（1）1 遺伝子の削除による一様な効果が小さくなるか、（2）陽性対照（VCAM1, HAVCR1）が恒常発現遺伝子・中立対照パネル・対照遺伝子群のすべてから、EXP-20260926-002 と同一の事前登録基準で分離するか、（3）同じ細胞・同じ遺伝子・同じ目標状態の重心での事前学習モデルと比べて改善するか。
- なぜ今この実験が必要なのか: EXP-20260926-002 で、事前学習のままのモデルでは一様な削除効果を差し引いても陽性対照が対照遺伝子群・恒常発現遺伝子から分離できないことが分かった。Geneformer の原論文の摂動実験は、疾患状態で追加学習した分類モデルを使っており、追加学習によって出発点から目標状態への軸が埋め込み空間の中で強調されれば、遺伝子ごとの違いが一様な効果に対して相対的に大きくなると期待された（Theodoris ら 2023, *Nature* 618:616, PMID 37258680）。
- この実験で答えが出ること／出ないこと: 出る — 追加学習という方法上の工夫が、一様な効果と陽性対照の分離という 2 つの問題を解決するかという問い。出ない — 三次リンパ組織そのものの生物学的な役割（本命遺伝子は合格が確認され PI の承認を得るまで評価しない）。

## 2. 背景
EXP-20260926-002（M2）で、事前学習のままの Geneformer の細胞埋め込みでは、1 遺伝子の削除がどの遺伝子でも細胞をすべての状態の重心から一様に遠ざける現象があり、この効果の 56%は向きに依存しない成分（変位の大きさの 2 乗に比例する項）であることが分かった。長さで補正した接近度という指標で一様な効果を差し引いても、陽性対照（VCAM1, HAVCR1）を対照遺伝子群・恒常発現遺伝子（ACTB, GAPDH, PPIA）から分離できず、方法仮説は否定された（G3, PI, 2026-09-26）。PI からの指示は「追加学習をしていない事前学習モデルではなく、追加学習をしたモデルを使った摂動実験を試みること」。ただし、追加学習に使った細胞と摂動対象の細胞が同じだと、目標状態への移動を「その方向を学習させたモデル」で読むという循環になりうるため、この点への対策を計画時点で複数用意した（§3.4）。

## 3. アプローチ
### 3.1 使ったデータ
腎臓アトラス（KPMP, Lake ら 2023, PMID 37468583）。EXP-20260926-001・002 と同一の入力。出発点（修復不全の近位尿細管、三次リンパ組織が多い群）7,533 細胞・14 提供者、目標状態（健常な近位尿細管）6,149 細胞・22 提供者、対照の状態（三次リンパ組織が少ない群）4,002 細胞・8 提供者。3 つの状態は提供者が重ならない（計 44 提供者）。

**提供者の分割（追加学習用と摂動用を完全に分離）**: 追加学習の課題は 2 分類（三次リンパ組織が少ない群の修復不全の近位尿細管 対 健常な近位尿細管）とした。学習に用いた提供者は修復不全側 6 名（1,565 細胞）・健常側 8 名（1,571 細胞）。検証（早期終了の判断用）は修復不全側 2 名・健常側 5 名。摂動に使う出発点の細胞（三次リンパ組織が多い群の修復不全の近位尿細管）は 14 提供者全員を、学習・検証のどちらにも使わない「学習に使っていない提供者」とした。目標状態の重心も、追加学習に使っていない健常な提供者 9 名（500 細胞）から作成した。三次リンパ組織が少ない群は追加学習の対象データに含まれるため、対照の状態への移動は参考値にとどめた。

### 3.2 使ったモデルと計算環境
事前学習: Geneformer V2（3.16 億パラメータ）。追加学習: 下位の層を凍結し、2 分類（修復不全 対 健常）を判別するよう追加学習させたモデル（追加学習済みモデル）。追加学習はリモート計算機（NVIDIA 製 GPU 搭載機, リモート計算機 1 号）で実施し、bfloat16 での計算を使用。摂動の実行も、当初手元の Mac を予定していたが、PI の方針（重い計算はリモート計算機で行う）により、追加学習と同じリモート計算機 1 号で実施した。事前学習モデルとの比較のため、同一の細胞・同一の遺伝子・同一の目標状態の重心で、事前学習モデルによる摂動も同じリモート計算機で実施した。

### 3.3 やったこと（手順）
1. **事前準備**: 提供者の分割の検証、追加学習用データの作成、追加学習・再開・評価の一連の流れを小規模データで確認（手元の Mac の CPU のみ）。この過程で、使用ライブラリの版の組み合わせにより、学習を中断して再開する処理がエラーで止まる不具合を発見し、修正した。
2. **追加学習（リモート計算機 1 号）**: 小規模な試し実行（20 ステップ）で速度とメモリ使用量を確認したのち、本番の学習を実行。学習は約 13 分で完了した。
3. **ゲート評価（学習に使っていない提供者 23 名, 2,082 細胞での判別性能の確認）**: 追加学習済みモデルの判別性能（AUROC 0.99999、マクロ平均 F1 スコア 0.998、提供者ごとの正解率の最低値 0.99）が、比較対象（事前学習モデルの埋め込みに標準的な分類手法を組み合わせたもの。AUROC 0.99996、マクロ平均 F1 スコア 0.993、提供者ごとの正解率の最低値 0.969）を下回らないことを確認し、**合格（GO）**と判定した。合格しなければ、この先の摂動実験は行わない予定だった。
4. **対照遺伝子の摂動（追加学習済みモデル）**: EXP-20260926-002 の本番と同一の設計（削除型の摂動、対照遺伝子のみ 34 遺伝子、200 細胞/遺伝子、seed 3/4/5）で実施。実行時間は約 44 分。
5. **対照遺伝子の摂動（事前学習モデルとの対応比較）**: 同一の細胞・同一の遺伝子・同一の目標状態の重心（学習に使っていない健常な提供者 9 名）で、事前学習モデルによる摂動を同じリモート計算機で実施。実行時間は約 46 分。
6. 本命遺伝子（TP53, CDKN1A, LTBR）と参照遺伝子（SPP1, LCN2）は、対照遺伝子の評価結果が確定するまで一度も計算していない（盲検）。

### 3.4 比べたもの（対照）と、成功・失敗をどう判定するか
- 陽性対照: VCAM1, HAVCR1（EXP-20260926-001・002 と同一）
- 対照遺伝子群・恒常発現遺伝子（ACTB, GAPDH, PPIA）・中立対照パネル（7 遺伝子）・探索用リボソームタンパク質遺伝子（2 遺伝子, 報告のみ）: EXP-20260926-002 と同一の遺伝子・同一の選定方法
- モデルの対照: 同じ細胞・同じ遺伝子・同じ目標状態の重心での事前学習モデル
- 分類器の対照（ゲート）: 凍結した事前学習モデルの埋め込みに標準的な分類手法を組み合わせたもの
- 循環性（学習に使った軸と同じ軸の移動を、その軸を学習したモデルで読むこと）への対策: (1) 埋め込みの移動（主指標）と分類確率の変化（副指標）の両方を読み出し比較する、(2) 特異性は恒常発現遺伝子・中立対照パネル・対照遺伝子群との比較で判定する（分類器が単に「発現の多い遺伝子を消すと障害らしさが減る」ように学習していれば、恒常発現遺伝子やパネルも同様に動くはず）、(3) 事前学習モデルとの比較、(4) 摂動に使う細胞は追加学習に一切使っていない提供者のものだけを使う
- 判定基準（結果を見る前に固定。EXP-20260926-002 §6.2 と同一の基準をそのまま適用）:
  - 判定基準: 陽性対照の分離 — VCAM1・HAVCR1 それぞれが対照遺伝子群の上位 10%に、3 seed 中 2 以上で入ること
  - 判定基準: 恒常発現遺伝子との差 — 18 組中 15 組以上で陽性対照が恒常発現遺伝子を上回ること
  - 判定基準: 恒常発現遺伝子の中立性 — ACTB・GAPDH・PPIA が対照遺伝子群の中に、3 seed 中 2 以上で収まること
  - 判定基準: 中立対照パネルの中立性 — パネル 7 遺伝子中 5 以上が同様に収まること
  - 判定: 上記 4 つの基準をすべて満たせば主要な予測を支持。1 つでも不合格なら棄却（本命遺伝子の再評価は行わない）
  - 副次的な予測: 一様な削除効果（補正前の対照遺伝子群の目標状態への接近度が負になる割合、および目標状態への接近度を出発点・目標状態間の重心距離で割った値）が事前学習モデルより小さいこと／恒常発現遺伝子との差の基準での勝ち数が事前学習モデル以上であること

### 副次的な予測
- **一様な削除効果の減少（支持）**: 補正前の対照遺伝子群が目標状態から離れる方向に動いた割合は、事前学習モデルでは 3 seed とも 100%だったのに対し、追加学習済みモデルでは 10% / 15% / 15%に減少した。目標状態への接近度を出発点・目標状態間の重心距離で割った値も、事前学習モデルでは −0.036〜−0.038 だったのに対し、追加学習済みモデルではほぼ 0 になった。
- **恒常発現遺伝子に対する優位性の改善（支持）**: 恒常発現遺伝子との差の基準での勝ち数は、補正指標で 16/18 対 10/18、補正前の指標では 17/18 対 6/18 と、いずれも追加学習済みモデルが上回った。

### 参考: 分類確率の変化（副指標）
分類ヘッド（追加学習で新設した判別部分）の予測確率の変化でも同じ長さ補正を適用したところ、VCAM1 の分位は 0.75 / 0.90 / 0.60、HAVCR1 は 0.35 / 0.50 / 0.15 で、埋め込みの移動と同じく、陽性対照は対照遺伝子群から際立って分離しなかった。

## 5. 考察
- 追加学習は、EXP-20260926-002 で見つかった 2 つの問題（一様な削除効果、恒常発現遺伝子の偽陽性）をほぼ解消しており、方法として大きく前進したことが示唆される。
- しかし、陽性対照 2 つのうち HAVCR1 が健常方向への特異的な移動を示さなかったため、主要な予測は事前登録の規則により否定と判定された。VCAM1 だけが一貫して対照遺伝子群の上位に来ており、VCAM1 は追加学習させた分類器が判別に直接使っているマーカー遺伝子である可能性があるため、この結果だけでは「VCAM1 の削除が状態を動かす原因である」ことの証拠にはならない（循環性への懸念、§3.4）。
- 提供者を半分に分けたときの順位の一致（再現性）は 0.46 にとどまり、追加学習済みモデルでも提供者間のばらつきによる不安定さが残っている。
- 本結果は、EXP-20260926-002 の判定基準が厳しすぎたのではという問いへの追加の根拠にもなった。同一の基準を追加学習済みモデルに当てはめると、恒常発現遺伝子との差・恒常発現遺伝子の中立性・中立対照パネルの中立性はいずれも合格しており、基準自体は満たせる水準にあることが分かる。したがって、事前学習モデルで基準を満たせなかったのは、基準の厳しさではなく、事前学習モデル側の一様な削除効果の問題だったことが支持される。

## 6. 限界
- コンピュータ上の摂動実験は、モデルが学習した発現の連動に基づく予測であり、因果関係を直接示すものではない。
- 循環性: 出発点と目標状態を分けるよう学習させた分類器で、目標状態への移動を読んでいる。VCAM1 の合格は、分類器が使う目印を消したことの反映である可能性が残り、原因の遺伝子であることの証拠にはならない。
- 再現性が低く（0.46）、順位が提供者の分け方に左右される。
- 三次リンパ組織の多さの群分けはすべて推定値であり、組織学的に確認したものではない。
- リモート計算機での実行環境は、手元の Mac とソフトウェアの版が異なる（記録済みの逸脱）。
- 本命遺伝子・参照遺伝子は一度も評価していない。

## 7. 次のアクション
- コンピュータ上で行うこと: 合格した陽性対照（VCAM1）が「分類器の目印を消しただけ」ではないかを、発現データだけで選んだ比較用遺伝子との比較で確認する（EXP-20260926-004）。また、陽性対照そのものの選び直しと過剰発現型の摂動の追加（EXP-20260926-005）。

| 事前学習モデル | 追加学習をしていない、配布されたままの Geneformer |
| 追加学習済みモデル | 本研究のデータで「修復不全か健常か」を見分けるよう追加学習させた Geneformer |
| コンピュータ上の遺伝子摂動 | モデルの中で遺伝子を消す・増やすなどして、細胞の状態がどう動くかを計算する模擬実験 |
| 削除型の摂動 | その遺伝子を入力から取り除く操作 |
| 細胞埋め込み | 細胞 1 個をモデルが数値ベクトルで表したもの |
| 状態の重心 | ある状態の細胞群の埋め込みの平均。状態の代表点 |
| 目標状態への接近度 | 摂動によって、細胞が目標の状態の重心にどれだけ近づいたか |
| bfloat16 での計算 | 計算を bf16 という低い精度で行い高速化する方式 |
| 一様な削除効果 | どの遺伝子を消しても細胞がすべての状態から同じように離れてしまう、遺伝子によらない見かけの動き |
| 陽性対照 | 効果が出ると期待される既知の遺伝子。手法が働いているかの確認に使う |
| 対照遺伝子群 | 効果がないはずの遺伝子を、発現頻度をそろえて多数選んだもの。比較の土台 |
| 恒常発現遺伝子 | どの細胞でも安定して働くとされる遺伝子（ACTB, GAPDH, PPIA） |

| 判定基準: 恒常発現遺伝子との差 | 陽性対照が恒常発現遺伝子を上回ること（18 組中 15 組以上） |

| 判定基準: 中立対照パネルの中立性 | 中立対照パネル 7 遺伝子のうち 5 つ以上が中立の範囲に収まること |
| 参考: 再現性 | 折半信頼性（split-half reliability）が 0.7 以上 |
| 参考: 交絡のなさ | 入力の長さや発現頻度と相関しないこと |
| 折半信頼性 | 提供者を 2 群に分けて別々に順位を出し、両者がどれだけ一致するか |
| リモート計算機 1 号（spark-cf5b） | NVIDIA GB10 搭載機。Tailscale 経由で接続 |
| 支持された・否定された・判定不能 | 事前に決めた基準を満たした／否定の条件に当てはまった／判定できる状態になかった |
| 事前登録 | 結果を見る前に判定基準を文書に固定すること |
| 盲検 | 手法の妥当性が確認できるまで、本命の遺伝子の結果を見ないこと |
| ゲート G3（結論確定） | 結果の判定（支持・否定・判定不能）を確定する PI 判断 |
