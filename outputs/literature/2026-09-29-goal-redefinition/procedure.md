# 目標の状態の定義を組み直すための選定手順（**数える前に固定した**）

- 作成: 2026-09-29 / hypothesis-builder
- 固定時刻: 下記 §6 に記録（数え上げのスクリプトを 1 行も走らせる前に書いた）
- 対象データ: `data/raw/kidney_tls/A1_KPMP_v1.5_snRNA_Lake2023.h5ad`（**読み取りのみ**）
- PI 指示 2026-09-29「選択肢 1: 手元の単一核データ A1 のまま、目標の状態の定義を組み直す」

---

## 1. 解く問題

過剰発現型の摂動は「その遺伝子が入力に載っている細胞」に対してしか成立しない
（guardrails 2026-09-27）。従来の出発点 `FIB_neg_TLShigh` は
「CXCL13・CCL19・CCL21 がすべて 0 の線維芽細胞」と定義されていたため、
**この 3 遺伝子を摂動の対象にできる細胞は構造的に 0 だった**。

よって新しい定義は次の 2 つを同時に満たさなければならない。

1. 目標の状態を**この 3 遺伝子を使わずに**定義する
2. その結果できる新しい出発点の中に、**3 遺伝子（および他の候補）を 120 細胞以上で発現する細胞が残る**

## 2. 固定する数え方

- 線維芽細胞: `subclass.l2` ∈ {FIB, M-FIB, aFIB, dFIB, dM-FIB}（著者注釈。19,049 細胞の想定）
  - `MYOF` / `cycMYOF`（筋線維芽細胞）は**含めない**（guardrails 2026-09-28: セントロイドから除くなら摂動側も除く）
- 発現の検出: `raw/X` の生カウントが **1 以上**
- 提供者あたりの上限: **20 細胞**（EXP-20260928-002 の `max_cells_per_donor` の実績値）。
  上限を当てた後の細胞数 = Σ_提供者 min(その提供者の検出細胞数, 20)
- 1 遺伝子あたりの下限: **120 細胞**（`min_cells_per_gene` の実績値）
- 記録する量: 検出遺伝子数（`n_genes`）と総カウント（`n_counts`）を細胞ごとに記録する

## 3. 合否の条件（**結果を見る前に固定**）

候補は次の F-1〜F-5 を**すべて**満たしたときにだけ「使える」と判定する。

| # | 条件 | 閾値 |
|---|---|---|
| F-1 | 目標の状態の細胞数・提供者数 | **300 細胞以上 かつ 10 提供者以上** |
| F-2 | 出発点の細胞数・提供者数 | **2,000 細胞以上 かつ 20 提供者以上** |
| F-3 | 摂動の対象にできる遺伝子の数 | 提供者上限 20 を当てた後に **120 細胞以上**となる遺伝子が、**CXCL13・CCL19・CCL21 のうち 1 つ以上を含んで合計 3 つ以上** |
| F-4 | 循環性 | 目標の定義に使う遺伝子の集合 ∩ 摂動の対象にする遺伝子の集合 = **空**。重なりを数値で報告する |
| F-5 | 検出遺伝子数・総カウントの交絡 | 目標と出発点で検出遺伝子数の中央値の比が **1.5 倍以内**。かつ、検出遺伝子数・総カウントの 2 変数だけのロジスティック回帰の提供者分割 AUC が **0.75 未満**（0.75 以上なら、検出された遺伝子数の分布をそろえた後の細胞数で F-1/F-2 を数え直す） |

F-3 で「CXCL13・CCL19・CCL21 のうち 1 つ以上」を要求するのは、
この 3 遺伝子を摂動できないなら今回の組み直しの目的（EXP-20260928-002 で
「出口が測れていない」とされた部分を測る）を果たさないためである。

## 4. 候補を調べる順番（**固定**）

上から順に調べ、**F-1〜F-5 をすべて満たした最初の候補を採る**。
満たさなかった候補は「使えない」と理由つきで記録し、次へ進む。
すべて落ちた場合は「使える候補は無い」と報告する（無理に通さない）。

1. **(A) 三次リンパ組織を形づくる細胞の別のマーカー**で目標を定義する
   （CXCL13/CCL19/CCL21 を使わない。文献の裏づけは `literature-scout` に委託）
2. **(C) 提供者単位の三次リンパ組織スコア × 線維芽細胞のサブタイプ**
   - **スコアは細胞の組成（B 細胞・形質細胞の割合）だけで作る**。
     既存の `donor_A1.csv` の `TLS_score` は CXCL13/CCL19/CCL21/LTB を含むので**使わない**
     （循環するため）。使うのは `frac_BPL_lymph` / `frac_BPL_all`（細胞数の比）のみ
3. **(A+C) 両者の組み合わせ**（マーカーで定義した目標を、提供者のスコアで層別する）
4. **(B) 空間データ由来のシグネチャー**（Meylan 2022, PMID 35231421）
   - 前提: シグネチャーの遺伝子リストが**実際に入手できること**。入手できなければ
     「この時点では使えない」と記録する（推測で作らない）
5. **(D) その他**

## 5. 数える項目（候補ごとに必ず出す）

1. 目標の細胞数・提供者数、出発点の細胞数・提供者数
2. 出発点の中での、候補遺伝子ごとの検出細胞数・検出提供者数・提供者上限 20 後の細胞数・120 の合否
3. 目標の定義に使った遺伝子と、摂動の対象にする遺伝子の重なり（個数と一覧）
4. 目標と出発点の検出遺伝子数の中央値、検出遺伝子数・総カウントだけの AUC
5. 従来の `FIB_org`（3 遺伝子いずれか陽性、716 細胞 / 64 提供者）との重なり
   （Jaccard 係数、目標に占める `FIB_org` の割合、`FIB_org` に占める目標の割合）
