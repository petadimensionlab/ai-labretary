## 0. 結論（要約）
1. **GAPDH・PPIA・ACTB は、いずれも start（aPT_CKD_TLShigh）と goal（PT_healthy）の間で発現が異なる**（donor pseudo-bulk、Welch 検定、start 13 donor vs goal 21 donor）。
   - GAPDH は start で低い: log2FC −0.98、q < 0.001、検出率 0.80 vs 0.96。
   - ACTB は start で高い: +0.78、q < 0.001。
   - PPIA は start で高い: +0.35、q = 0.017。
   - ただし、発現頻度が同じ遺伝子の期待値を差し引くと、PPIA の発現差は消える（+0.02、同等性 TOST p = 0.04）。残るのは Geneformer 入力内の順位のずれだけである（相対順位 −0.058）。
   - **発現差の大きさ・向きは、ISP での HK の振る舞い（GAPDH/PPIA は null 上位、ACTB は null 内）を単純には説明しない**（§4）。
2. **リボソームタンパク質（RP）遺伝子は、今回の系では陰性対照の本命にならない。**
   - 発現頻度で補正した点推定は 0 に近いものが多い。しかし donor 間のばらつき（CV 0.23〜0.38）のため、±0.25 log2 の同等性を示せた RP 遺伝子はない（候補中の RP 17 遺伝子、TOST p ≥ 0.07）。
   - 高頻度の非 RP 遺伝子と比べると、start で約 0.28 log2 高い。
   - Geneformer の中央値スケーリングで、RP は入力の**末尾付近**（相対順位 0.66〜0.96）に置かれる。
   - 以上から、合否判定ではなく**探索枠（2 遺伝子）**として回すことを提案する。
3. **事前登録用の選定規則（R1〜R6）**を全遺伝子に適用した。条件を満たしたのは 4,210 適格遺伝子中 71 遺伝子。
   - **文献由来の候補 57 遺伝子（7 カテゴリ: 現行 HK 3、古典 HK 13、Eisenberg の均一 11、腎 HK 10 など）は 1 つも規則を満たさなかった。**
   - 推奨パネルはデータ駆動の 7 遺伝子: CERS4, TATDN1, IFT25, VAPA, PHPT1, ANAPC16, EEF1D（start 検出 18〜74%）。
   - 探索枠は RP 2 遺伝子: RPS13, RPL32。
4. 合否基準への組み込み（提案）:
   - 現行の **C3-HK は PI の指示どおり維持**する。
   - 新たに **C3-panel** を加える: パネル 7 遺伝子のうち **5 以上**が、null 分位 0.10〜0.90 に 3 seed 中 2 以上で入ること。
   - 参考として誤判定率を試算した。理想的な陰性対照 3 遺伝子が「全部合格」する確率は 0.51〜0.72 しかない（§6.3）。

## 2. 解析方法（`scripts/analysis/negctrl_candidates.py`）

### 2.1 データ
- `experiments/EXP-20260926-001/work/input.h5ad`（生カウント、`n_counts` = 行和を確認）
- start 7,533 細胞（14 donor。20 細胞以上の donor は 13）、goal 6,149 細胞（22 donor、同 21）、alt 4,002 細胞（8 donor、同 7）
- **start と goal に共通の donor はない**（状態と donor・疾患が完全に交絡している）

### 2.2 計算した統計量（遺伝子ごと）
- **検出率、CP10k 平均**（状態別）
- **donor pseudo-bulk の log2(CPM+1)**: 20 細胞以上の donor だけを使う。これで次を計算した:
  - donor 平均の差（log2FC、start vs goal と start vs alt）
  - Welch 検定と BH 補正の q 値
  - ±0.25 log2 の同等性 TOST
  - donor 間 CV
- **Geneformer 入力内の順位**: tokenizer と同じ手順で計算した（count / n_counts × 10⁴ / 遺伝子中央値 → 降順、先頭 4,094）。
  - 相対順位 relrank: 0 が先頭、1 が末尾。発現している細胞での平均。
  - 絶対順位、先頭 10 位以内に入る割合、tokenized 検出細胞数
- **発現頻度での中心化（`_c`）**:
  - null は start の発現細胞数でマッチさせて抽出する。そのため陰性対照も「同じ頻度の遺伝子と比べて」中立であればよい、と考えた。
  - null 抽出プール（start で 300 細胞以上、除外リスト外）を検出細胞数で並べ、近い 201 遺伝子の移動中央値を期待値として差し引いた。
  - 背景: start は UMI 中央値 3,405 vs 2,819 と深く、トークン数の中央値も 1,353 vs 1,020 と多い。そのため**生の log2FC は全体が正にずれる**（適格遺伝子の中央値 +0.60）。
  - 期待値の例（start 検出細胞数 1,000 / 3,000 / 6,000）:
    - log2FC: +0.79 / +0.55 / +0.33
    - relrank 差: +0.024 / −0.087 / −0.130
- Geneformer V2 の token 辞書（`token_dictionary_gc104M.pkl`）: 辞書に収載されている 18,040 遺伝子のみを対象にした。候補はすべて収載されている。

## 4. HK（ACTB/GAPDH/PPIA）の発現差は ISP での振る舞いを説明するか

**結論: 3 遺伝子とも発現差はある。しかし発現差の大きさ・向きは、ISP での振る舞いと対応しない。**

| | 発現差 | ISP（a2 補正後、EXP-002 phase 0） | 整合性 |
|---|---|---|---|
| GAPDH | 最も大きい。start で低い（中心化後 −1.31 log2、検出率 −0.17）。入力内の順位も start で後ろ（Δrr_c +0.21）。Lan 2016 の解糖系シフトとは向きが逆だが、Kang/Lan とも代謝の変化自体は支持する | null 上位 | 素朴な予想（goal で多い遺伝子を start から消すと goal から離れる）とは逆に、goal 側へ動く（80% の細胞）。**単純な発現模倣では説明できない** |
| PPIA | 頻度中心化後の発現量は中立（+0.02、TOST p = 0.04）。入力内の順位は start で前寄り（Δrr_c −0.058、生の値で −0.19） | null 上位 | 「start で順位が高いものを消すと goal に近づく」とは整合する。ただし効果の大きさを説明するには弱い |
| ACTB | start で高い（中心化後 +0.45） | null 内（0.23） | 発現差があっても null 内に収まっている |

- 発現差のある遺伝子が ISP で null 外に出るとは限らない（ACTB）。逆に、発現量が中立に近くても null 外に出る（PPIA）。
- したがって、「発現差の小ささ」で選んだパネルが ISP で null 内に入るかは**試してみないと分からない**（PI の指摘どおり）。
- 発現データで選ぶ意義は、少なくとも「既知の状態差を持つ遺伝子を対照に入れる」という明白な欠陥を避けることにある。
- 別の要因の候補として、入力内の位置（相対順位）がある。
  - HK と RP は Geneformer の中央値スケーリングで**末尾付近**に置かれる（ACTB 0.89、RP 0.66〜0.96）。null 遺伝子は中位（約 0.5）、陽性対照は前寄り（0.25〜0.36）である。
  - 削除位置が後ろほど、後続トークンのずれは小さい。これが raw 指標で HK が「ドリフトの小さい側 = null 上位」に来た一因である可能性がある（EXP-002 の a4 で扱った削除位置の交絡と同じ問題）。
- **注意: 依頼文の「RPL/RPS は rank-value encoding の先頭付近」は、本系・V2 の中央値スケーリングでは当てはまらない。**
  - 先頭付近にあるのは MT- 遺伝子（相対順位 0.07〜0.2）である。RP は後ろにある。
  - 「高頻度の遺伝子ほど tokenized で先頭に来る」という前提で設計しないこと。

## 5. リボソームタンパク質遺伝子の判定
- **合否判定には使わず、探索枠にとどめる。**
- 根拠:
  1. 生の比較では、事前候補 14 RP 遺伝子のうち 8 つが start で有意に高い（q < 0.05、+0.4〜+0.8 log2）。頻度中心化後の点推定は多くが 0 に近い。しかし高頻度帯（start で 5,500 細胞以上）の遺伝子の 58% が RP なので、**期待値の一部は RP 自身で決まっている**（循環）。高頻度の非 RP 遺伝子と比べると、RP は start で +0.28 log2 高い（中央値 0.39 vs 0.11）。
  2. donor 間 CV が 0.23〜0.38 と大きい。±0.25 log2 の同等性を donor 水準で示せた RP はない（候補中の RP 17 遺伝子、TOST p 0.07〜0.91）。
  3. 生物学的にも、リボソーム生合成は老化・傷害で変化する（Lessard 2018）。組織特異的な RP も存在する（Guimaraes 2016）。
  4. 入力内では末尾付近にあり、陽性対照や null と削除位置の分布が重ならない。
  5. 総 RNA に対する安定性は、正規化後の番兵としては弱い（Deeke 2020）。
- 一方で、試す価値はある。高頻度・末尾位置の遺伝子を削除したときの振る舞いは、HK の解釈（位置効果か、状態特異的な信号か）に直結する。
  - そこで、RP 候補のうち TOST 以外の条件をすべて満たすものから、**RPS13 と RPL32**（中心化後 FC +0.06 / +0.01、Δrr_c +0.003 / +0.002）を探索枠として回すことを提案する。

### 6.3 合否基準への組み込み（提案、PI の判断事項）
- **C3-HK（現行のまま、PI の指示どおり）**: ACTB・GAPDH・PPIA がすべて、null 分位 0.10〜0.90 に 3 seed 中 2 以上で入ること。
- **C3-panel（新設）**: パネル 7 遺伝子のうち **5 以上**（≥ 71%）が、null 分位 0.10〜0.90 に 3 seed 中 2 以上で入ること。
- **探索枠（RPS13, RPL32）**: 同じ分位を報告するが、合否には使わない。本番で null 内に安定して入れば、次の実験でパネルへの昇格を検討する。
- **誤判定率の試算**（理想的な陰性対照、つまり null と交換可能な遺伝子で、1 seed あたり 0.10〜0.90 に入る確率を 0.8 とした場合）:
  - 1 遺伝子が 3 seed 中 2 以上で合格する確率は 0.80〜0.90。下限は seed 間の完全相関、上限は独立を仮定した値。
  - **C3-HK（3/3 必須）の合格確率は 0.51〜0.72**。完全な陰性対照でも 3〜5 割で不合格になる。
  - C3-panel の ≥ 5/7 は 0.85〜0.97。≥ 6/7 だと 0.58〜0.84 に下がる。
  - パネル遺伝子が GAPDH のように null 外へ出やすい場合、C3-panel の合格確率は低い（1 seed あたり 0.2 なら 0.005、0.5 なら 0.23）。
  - 参考値として、C3-HK を「3 遺伝子中 2 以上」に緩めると 0.90〜0.97 になる。PI の判断材料として記す。
- 指標の選定規則（EXP-002 plan §6.2: C1〜C3 をすべて満たす指標を採用）での扱い:
  - 提案: C3 を「C3-HK **かつ** C3-panel」とする（HK を判定に残すという PI 指示に沿う）。
  - C3-HK だけが不合格で C3-panel が合格した場合も、判定は不合格とする。そのうえで「HK に状態特異的な信号がある可能性」を別途報告する。
  - PI の判断事項: C3-HK を「3/3 必須」のままにするか「2/3 以上」に緩めるか（上の誤判定率を参照）。本番データを見る前に決めること。

### 6.4 実装・計算量の注意
- `run_isp.py` の `negative_fixed` は 1 つの `fixed_role`（現在は housekeeping）しか持てない。パネルと探索枠を別の role で記録するには、config の拡張が必要になる。
  - 例: `controls.negative_panel`、`controls.negative_exploratory`。
  - 同時に、validate の C3-panel 実装も必要になる。
  - `negative_fixed` に入れた遺伝子は、ランダム null の抽出から自動で除外される（run_isp.py L898–902）。パネルも同じ扱いにすること。
- 追加する計算量: 9 遺伝子 × 200 細胞 × 3 seed = 5,400 細胞×遺伝子 × 0.684 s ≈ **1.0 h**。
  - 本番（dry-run 3.28 h）と合わせて約 4.3 h になる → G2 の見積もりを更新する必要がある。

## 7. 限界
- **状態と donor・疾患が完全に交絡している**（start と goal に共通の donor はない）。発現の同等性は donor 間比較であり、バッチ差を含む。
- 中心化は「null と同じ頻度の遺伝子に比べて中立」を意味するだけで、絶対的な不変性ではない。高頻度帯の期待値は、RP を中心とする少数の遺伝子で決まる。
- TOST の検出力は donor 数（13 vs 21）で制限される。R2 に合格する遺伝子が少ない（79）のはこのためでもある。
- 発現の中立性は、ISP での中立性を保証しない（§4 の ACTB/PPIA の例）。これは PI の指摘どおり、試してみないと分からない部分である。
- scSEG の上位遺伝子リストは入手・確認できていない。候補には本文の例（RPL26, RPL36, HINT1）だけを入れた。
- 規則の閾値（0.25 log2、0.05、0.03、75% 分位）は妥当な慣例値だが、根拠となる外部基準はない。
  - 閾値は ISP の結果を見る前に固定した。
  - 閾値を変えて合格遺伝子が変わっても、ISP の結果を見て変えてはならない。
